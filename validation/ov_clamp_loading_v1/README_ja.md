# 調整クランプの負荷と電流比較

クランプのREF分圧を30.1k/332k、初期誤差±0.1%として比較。
基準1.224〜1.259VとREF電流0〜0.9µAを仮に組み合わせると1.33475〜1.40049V。
0.9µAは25°C最大0.5µAと温度偏差0.4µAを加えた寸法比較で、全状態保証ではない。

元のOV分圧が1.5Vへ達する入力電圧で、クランプ上側比較電圧を維持するために
残るカソード電流を計算。35.7k/10kでは約7.85µA、3.57k/1kでは約122.39µA。
同じ分圧比でも抵抗を1/10へ下げることが電流確保に有効。
クランプ分圧の抵抗負荷だけを含めたOV検出比較は後者で5.37715〜5.61488V。

次の設計比較には3.57k/1kを用いる。ただし現在の接続案を確定値として置換しない。
TLV431B基準の規定は10mAで、今回の実カソード電流とは異なる。
低電流での精度、規定前のカソード電流、安定性と過渡応答が未確認。
100µA以上を1点で確保したことだけで全電源範囲・全温度のクランプを保証しない。
