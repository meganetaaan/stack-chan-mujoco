# BQ→通常制御電源の起動許可接続

**製作HOLD。** ISO7710FDR＋両側100nFを追加。全体226部品。
起動許可の未接続箇所をつないだが、全体起動や電源消失時の動作は未合格。

一次資料：[TI ISO7710 Rev.E](https://www.ti.com/lit/ds/symlink/iso7710.pdf)、
端子表・3.3V電気特性・DC消費電流・Table7-2。
**F付き**のLowデフォルト品を使用する。Fなし品の代用は不可。

| 端子 | 接続 |
|---|---|
| 1・3 VCC1 | BQ_CTRL3V3 |
| 2 IN | BQ_AUX_START_REQUEST（故障保持ゲートの出力） |
| 4 GND1 | CELL_B_MINUS |
| 5 GND2 | PACK_RETURN |
| 6 OUT | SYS__LOGIC_START_ALLOW→既存1kΩ→SHDN |
| 7 NC | 開放 |
| 8 VCC2 | SYS__STOP_AUX3V3 |

出力側を、自分が起動するLOGIC3V3で給電すると起動できない。
主FET後段で常時接続されるSTOP_AUX3V3を使用する構成を選択した。
両接地を銅箔で直結しない。ロボット全体はシャントで両接地がつながっているため、
全体がガルバニック絶縁されたとは主張しない。この信号経路でシャントを迂回しない目的である。

入力側ゲートの既存10kΩプルダウンは47.5kΩへ変更した。
抵抗の総変動±1%と入力電流試験点10µAを使う比較では負荷86.6µAとなり、
ゲートの100µA出力仕様を使った比較範囲に入る。型番TNPW060347K5BEEA。
判定基準を緩めたのではなく、負荷抵抗を変更した。中間入力電圧や部分給電は未確認。

## 静的検算

- 入力Highの電圧余裕：最低0.750V（同一BQ電源、ゲートVCC−0.15V比較）。
- 出力High時のSHDN：約2.638V以上という条件付き比較。許可側1V条件を上回る。
- SHDN=0.4Vでの抵抗性吸込み能力：約138.6µA。必要な10µA条件と比較。
- 追加消費：BQ側DC最大2.4mA、STOP側の比較値約1.512mA（出力負荷を含む）。
- 旧STOP系条件付き予算と合計：約2.978mA。1kΩ入口抵抗の電圧降下は約3.007Vの比較値。

上記は試験条件付き部品仕様と既存の未認定予算による机上比較で、実機の上限電流ではない。
LDOの自己消費、漏れ、起動、ノイズ、部分給電など、旧予算の未確認条件は残る。
追加した負荷を無視して従来のSTOP電源余裕や予備充電結果を流用しない。

入力側だけ無給電で出力側が有効ならLow、入力開放もLowが部品の規定動作。
出力側が無給電・立上り中でもSHDNが確実に停止するかは、この規定だけでは証明できない。
レギュレーターの禁止、アイソレーターの出力状態、内蔵SHDNプルアップ、外付け抵抗を含めて
確認する必要がある。断線以外の信号High故障も別途扱う。
