# 22%候補の正式評価

開発20条件の総合20/20と状態記録の再評価を確認してから、候補を凍結して正式40試行を開始した。正式40試行が完了し、固定20/20・ランダム化18/20の総合通過を確認した。全40試行の状態記録から再評価した `audit.json` も同じ結果となった。

`candidate/snapshot.json` はモデル・参照・制御・実行エンジン・物理設定・評価条件・依存環境の凍結記録。制御・実行ソースはコミット `9563fa8` のもの。`candidate/run_claim.json` はこの候補で正式試験を開始した記録であり、成功の証拠ではない。

実行コマンド：

```sh
python run_yaw_acceptance.py --snapshot validation/yaw_acceptance_phase22_v1/candidate/snapshot.json --out outputs/yaw_acceptance_phase22_v1 --workers 10
```

固定シード217000〜217019、ランダム化シード218000〜218019を、同じ205秒・24区間で全て評価する。固定20/20、ランダム18/20以上の総合合格を必要とする。シードの置換・失敗の再試行は行わない。全40試行の状態・実行ソース・判定は `trials/`、再評価結果は `audit.json` に保存した。`partial_checkpoint.json` は30件時点の履歴であり、最終集計は `trials/summary.json` を使う。

## 物理条件と適用範囲

物理刻み1 ms、指令処理20 ms。全12軸でトルク・速度制限、遅延、目標角速度制限6 rad/s、40 msの目標フィルタ、飽和保護を適用する。転倒、自己衝突、関節制限逸脱、足裏以外の床接触、数値異常を物理刻みごとに判定する。浮遊ベースの位置・姿勢を強制せず、開始姿勢の設定後はMuJoCoで積分する。

ランダム条件は凍結済み基準設定から、全体質量・慣性倍率0.95〜1.05、胴体重心各軸±1 mm、接触摩擦係数0.6〜1.0、トルク倍率0.9〜1.0、速度倍率0.95〜1.05、追加遅延0〜4 ms、初期関節角±0.005 radを使う。各条件の実際の値は各試行のreportに保存する。真のランダム質量から公称参照や静的補償を作り直していない。

現候補は関節位置サーボと公称参照で動作し、IMUによる姿勢補正・学習方策は使用しない。設定上のIMUノイズ・バイアス値も記録されるが、現候補の制御には入力されない。IMUフィードバックの耐ノイズ性能をこの試験から主張しない。

質量・慣性・モータ特性は実機同定前の設計値と代理形状近似である。電源電圧低下、温度、摩耗、床の段差などを網羅した試験ではない。機構の固定側締結・ねじ選定・支持強度の未確定事項はr8モデルのREADMEに記載している。結果の適用範囲は、この公開モデルと凍結した物理・ばらつき条件におけるシミュレーションである。

## 正式結果

固定20試行は全て総合合格、ランダム20試行は18件が総合合格。全40試行が205秒を物理異常なしで完了したが、以下2件は追加の動作・着地基準で不合格となった。失敗は除外せず、再試行・差し替えは行っていない。凍結対象の変更はなかった。

- 218004：運動指標は通過したが、14_backwardの有効着地が左右16/0回、16_backwardが0/16回となり不合格。
- 218015：着地要件は通過したが、4つの後退区間で横速度RMSEが0.030 m/sを超過して不合格。
