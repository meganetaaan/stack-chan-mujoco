# ブーツ・ヨーク両部品の局所弾性接触

固定支持ブロックを実ヨークの切出し形状へ置換。ブーツ・ヨークともE=1120 MPa、ν=0.35の仮の等方線形弾性材として計算した。ナット面へ下向き20 N、ねじ頭座面へ上向き20 Nを面積配分し、入力の合力・合モーメントがゼロであることを確認した。摩擦なし片側接触、ペナルティ1000000 N/mm³、0.7 mmの一次四面体。

ソルバ完了、アンカー合反力の相対値2.008e−16、最大めり込み6.356316e−6 mmで事前の数値条件を満たした。接触圧最大値6.356316 MPa、節点変位最大値はブーツ0.002491623 mm、ヨーク0.004927387 mm。変位は採用アンカーに対する量であり、相対圧縮や全機構の変形量とは区別する。

固定支持体より接触圧が高い。メッシュと接触面も異なるため増分の全量を支持弾性だけに帰属させないが、固定支持体の結果を実ヨークへ流用できないことを示す。接触圧は材料内部の主応力と同一ではなく、仮の材料許容値との単純比較で強度合否を決めない。

局所切断面の自由境界、ねじ・ナット剛性省略、単一メッシュ、仮荷重という制限がある。アンカー合反力が小さくても個別の拘束が局所解へ影響しない証明にはならない。収束、アンカー感度、実部品応力、クリープ、歩行荷重と全締結部の成立は未確認。製造承認なし。
