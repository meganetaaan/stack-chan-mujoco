# ヨー支持の比較組立v5：強度区分を明示したM2六角ナット

**Bossard BN109 / 1088211を、ヨー取付板8箇所の比較候補とする。公称配置は成立するが、締結強度/製造リリースは未完了。**

v4の薄い四角ナット用包絡を、カタログ二面幅4mm・最大高さ1.6mmの六角ナット回転包絡へ変更した。他44部品は変更せず、M2ねじ径、ねじ軸、座金、支持部、脚長を維持した。正式revBと足部のナット選定は変更していない。

[メーカー作成の仕様表（販売店掲載）](https://media.distrelec.com/Web/Downloads/_t/ds/1088211_eng_tds.pdf)は鋼・強度区分6・亜鉛めっきを明示する。従来A56202の「A2」は材種であり、同じ意味の強度区分ではない。今回の情報追加は強度評価の入力改善であって、許容荷重の確定ではない。数値の保証荷重や締付けトルクを独自に補っていない。

## 結果

- 52部品の順序・体積・重心をSTEP読み戻しで照合。
- 全1,326組を正式revBと比較し、体積干渉の増加判定0。
- v5で正の重なりが残る12組は従来の背板ねじ包絡。ナット交換による追加重なりはない。組立全体の強度/公差合格とはしない。
- ナット下端Z91.9mm据置き、上端Z93.5mm。M2x10ねじ先端Z98mmとの突出し4.5mmは公称値。完全ねじ山の有効かかり長さを表さない。
- 六角の全回転を含む円柱半径は4/√3mm。実接触面・面取り・ねじ山を表さず、質量や面圧計算には使わない。

## 未完了事項と次の設計判断

公差を含むねじかかり、対象サイズの保証荷重、座金/造形座面の圧力とクリープ、締付け方法、緩み止め、工具アクセスを同じ締結として確認する必要がある。標準の廃止表示があり、供給される製品の版・証明書は未確認。厚くしたことだけで保持強度を合格にしない。これらが成立するまで任意の予圧を置いたFE追加は行わない。

v4からの変更は8個の包絡だけ。既存12変更部品の質量差を残すが、新ナット質量は未確定なので、`change_accounting.json`の質量・一次モーメント・慣性差はナット変更を除外した値と改名した。全身質量更新には使わない。
