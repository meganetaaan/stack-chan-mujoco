# 全体エネルギーからの未収束診断

3段階の全要素・全積分点の保存応力から等方線形弾性のコンプライアンス式でひずみエネルギーUを積分。独立に荷重面の三角形面積から±20 Nを再構成し、保存した最終接触力・平均拘束力と変位による仕事と比較する。切断積分の最終contact_force_Nを使用し、投影サンプル圧を積分して代用しない。

2U=u·(F_external+F_contact+F_gauge)の絶対誤差は全6部品ケースで8.70e−11 Nmm以下、事前1e−6 Nmm基準内。これは離散解の整合確認であり、連続体解の精度保証ではない。

|mesh mm|boss弾性エネルギー Nmm|spacer弾性エネルギー Nmm|
|---|---:|---:|
|0.5|0.03334571|0.00110797|
|0.35|0.03455986|0.00127728|
|0.25|0.03534540|0.00155673|

第2→第3段階の変化はboss2.27%、spacer21.88%。spacer体積の同変化は約0.0076%に過ぎず、体積差だけで大きなエネルギー差を説明できない。全体の変形エネルギーも変わっており、最大節点や特異点だけを除外して解消する問題とは判断できない。

次の精査はspacerの体積メッシュ・曲げ表現と荷重面近傍を対象とする。現状はP1変位であり、メッシュの局所性・接触面分割の影響を切り分ける必要がある。原因の断定、部品形状変更の承認、強度合格はしていない。元の応力10%・変位5%の収束条件をこのエネルギー診断へ置き換えない。

```sh
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/audit_rounded_elastic_energy.py
```
