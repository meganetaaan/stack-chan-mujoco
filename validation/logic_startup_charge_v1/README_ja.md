# 制御電源の起動充電条件

現容量候補の初期上限27.975 µFを0 Vから3.393 Vへ充電するとQ=CV=94.919 µC、蓄積エネルギー0.16103 mJ。実機ピーク電流を仮定せず、電荷保存から入力保護の選定条件を定めた。

連続負荷の仮枠20 mAと同じ20 mAに電流制限すると、負荷が実際に20 mAを使う間は正の充電電流を保証できない。したがって20 mA連続出力という前回の目標を、そのまま分岐の電流制限値にしない。

参考として1 msでこの電荷を渡すには平均94.919 mAの充電分が必要で、一定20 mAの負荷を仮定すると平均合計114.919 mA。ただし1 msはユーザー要求でもTPS709の実起動時間でもなく、ピーク・定常定格を示す数値でもない。一定電流モデルで負荷も一定ならt=Q/(I供給−I負荷)となり、余裕電流がなければ充電できない。実際のLDO制御・負荷の立上がりはこのモデルと異なる。

**入力保護の選定条件:** 定常20 mA枠に加えて起動充電を扱う。電流制限・ヒューズを決めた後、実部品の立上がり、フォールドバック、最小制限電流、I²tと繰返し投入を確認する。現計算だけで保護部品を選定完了にしない。入力側コンデンサの突入、LDO自己電流、未統合MCU等の容量、温度変動は未算入。

再現: `.venv-engineering/bin/python software/sim/circuits/bound_logic_startup_charge.py --out /tmp/logic-startup-charge`（出力先未作成）。仮定・出典ハッシュ・計算式はplan/report.json。追加の容量掃引・推測したLDO過渡波形は不要と判断した。
