# 組立済み電源・後板ユニットの水平挿入 — 不採用経路

## 結論

完成した後板ユニットを後ろからX方向へ水平に差し込む経路は不採用。最終位置の30 mm手前で、台座と既存ヨー固定ねじが衝突する。完成状態の静的隙間だけでは組立を保証できないことが確認された。

- 左台座とleft_plate_1_screw: 重複9.62124 mm³。
- 右台座とright_plate_0_screw: 重複9.62124 mm³。
- 右台座とright_plate_1_screw: 重複4.69403 mm³。
- 右基板用ナットright_module_0_nutとright_plate_1_screw: 重複2.50015 mm³。
- その他、左台座の隙間0.316 mm、右基板用ねじの隙間0.02742 mmも0.5 mm基準を満たさない。

これらは基板の外包形状だけの疑似衝突ではなく、モデル化した台座・締結部品同士の結果。最終位置で既存ねじに合わせて設けた逃げは、挿入中には位置がずれる。

## 組立状態と検査

既存後板1、既存の後板固定ボルト8本と後部座金8枚を除去し、他の固定機構は保持。取付機構43部品と左右モジュール外包2個を一体で移動させる。既存機構35点に電池・トレイ・Tab5・TTLを加えた39点を相手にした。支持部の仮保持は必要だが治具形状や重力下の安定は未モデル化。

試験前にX変位-70,-50,-30,-20,-10,0 mmを指定。-70/-50では不合格なし、-30で実CADに対する失敗証拠を得たため終了。細かい刻みへ変更して「通過」を探すことはしない。サンプル間を全て確認したとは主張しないが、一つの失敗姿勢でこの直線経路を拒否できる。AABB間距離が基準以上の組は距離の下界で排除し、近い組を実形状で比較した。

## 次の設計判断

この結果は後板ユニットのあらゆる組立方法を否定するものではない。上方へ持ち上げてから挿入・着座する経路、または機体/支持部の組立順序変更を検討する。追加検査の前に上方余裕と仮保持条件を確認し、経路の最小隙間を連続的に保証できる条件を設定する。単なる最終位置合格や粗いサンプル全通過で組立完了にはしない。

台座形状、外形、既存0.5 mm基準は今回変更していない。正式な組立手順と製作リリースは未成立。
