# TPU保持部の材料候補レビュー

Ultrafuse TPU 95AのメーカーTDS版2.0を確認。出典・方向別数値・試験速度・調湿条件をsource_review.jsonに記録。採用・材料許容値の確定ではない。

非圧縮neo-Hookeanのμ=E/3、単軸公称応力μ(λ−λ^-2)を公表引張点と比較。初期弾性率からの予測は50%伸びで約2倍。単一パラメータの材料則をそのまま押込み解析に使用する根拠はない。速度条件も異なるため、差を材料則だけに帰属させない。

傘径8→穴径6 mmへの一様な径方向圧縮を仮定すれば伸長比0.75、体積一定で軸方向伸長比1.778となる。ただし実際の傘は折れ曲がり・接触するので、これは実ひずみや力の予測ではない。

次は大変形を伴う押込みを要しない分割保持板等と比較する。材料試験を本ゴールの必須作業へ追加するのではなく、公表データで説明できる設計と解析範囲を追求する。押込み案は未合格として保存。

python3 software/sim/structural/screen_tpu_constitutive.py --source validation/tpu_retention_material_review_v1
