# 負荷側バス給電のゲートドライバ候補

2026-09-21。UCC27517DBVRをAO3400A用の評価候補に追加。ピン接続案は`schematics/power/brake_gate_driver_candidate.json`。製造回路ではない。

## 部品仕様

[TIデータシート](https://www.ti.com/lit/ds/symlink/ucc27517.pdf)、SLUSAY4D、§7/8.3/8.5。推奨給電4.5–18 V。全規定温度の起動しきい値最大4.65 V。4.5 V給電・出力10 mA時のHigh側降下最大0.130 V。UVLOでは出力Low。12 V条件のタイミングやピーク駆動能力を5 Vでの保証値に転用しない。

## 接続判断

ドライバVDDを主電源遮断器より負荷側のサーボバスへ接続する。GNDはバスGNDに戻し、シャント上端と混同しない。IN−はGND、IN＋は今後選定する同バス給電の過電圧検出回路から駆動する。主電源停止信号で吸収を無効化しない。ゲート直列抵抗、ゲート–ソース抵抗、局所バイパス容量は実部品と過渡条件の選定を残す。

通常下限4.75 Vに対し起動までの配線降下予算は0.10 V。VDDへ安易に直列ダイオードを挿入しない。ドライバGNDをシャント上へ移すと供給電圧も下がるため、この接続案の判定は流用できない。

既存抵抗包絡と6 Vから算出した電流上限比較値を0.1 Ω候補シャントに適用すると、ソース上昇は0.13553 V。ドライバ出力の上記試験条件を使ったVGS比較値は4.23447 Vで、MOS候補の2.5 V規定点に対する余裕は1.73447 V。ただしシャント公差、GND過渡、ゲート電流、温度依存を含む完成回路の保証ではない。

|---|---|
| 通常バス | ドライバ給電範囲とDCゲート予算の比較は可能。実ゲート波形未確認 |
| 主電源切離し、バスに残留/回生あり | ドライバは負荷側から給電される。比較器・基準電源も同時に維持される必要がある |

| 分岐ヒューズ開放/ケーブル抜け | 共通吸収器までの経路喪失は未解決。ドライバ給電変更では解消しない |
