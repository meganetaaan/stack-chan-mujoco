# 主遮断器の立上り設定候補

## 判断

dVdt端子15→GNDの6.8 nF比較候補を、村田GRM1885C1H682JA01（C0G、50 V、0603、初期±5%）へ具体化した。発注用包装末尾と使用条件での有効容量は未確定。6.8 nFはTIの比較表にもある値を選んだもので、ユーザー指定でも、必要突入電流から確定した値でもない。採用・製造リリースはしない。

[村田の部品一覧](https://www.murata.com/-/media/webrenewal/tool/library/common-pdf/static-model/component-list-s-mlcc-2506.ashx?cvid=20250805040438000000&la=ja-jp)、[TI TPS25982 Rev D](https://www.ti.com/lit/ds/symlink/tps25982.pdf)の6.5〜6.7、7.3.3.1、設計例を参照。TIの10ページを画像で確認：dVdt充電電流2〜6.33 µAに対し、PG遅延120 µsはTYP列でMAX記載なし。立上り表を最悪値へ読み替えない。

## 条件付き比較

I/C近似と初期容量公差だけなら0.2801〜0.9799 V/ms、0→5.25 Vのランプ部分は5.358〜18.743 ms。既存の仮想容量960 µFでは容量充電電流0.269〜0.941 Aとなる。起動中のサーボ消費電流はこれに含まれない。960 µFは回生比較の仮値であって12軸実機の容量上限ではない。

この結果から「20 msで起動する」「一定時間後にPGが必ず成立する」とは判定しない。電源投入遅延、ゲート充電とPG判定、温度・バイアスを含む実効容量、負荷、上流電源の挙動が残る。ランプ式の条件付き計算を実回路の保証範囲とはしない。容量だけを充電する理想条件のエネルギー13.23 mJも、全起動時の損失・SOA成立の根拠ではない。

## 起動期限の決め方と終了条件

必要な関係は「正常起動の最遅時間 < タイマー最短時間」かつ「タイマー最長時間＋遮断最遅時間 < 異常継続の許容時間」。両方の根拠が揃うまでタイマー値を選ばない。起動期限を長くして正常起動を通すだけでは保護成立にならない。

今回の追加計算は一回の上下限比較で終了。未確認の負荷や容量を仮定した掃引は追加しない。実部品による電源段と負荷容量一覧、起動電流の根拠、熱・エネルギー条件を先に揃える。机上で保証できない実起動波形は#49の評価対象とし、#24の机上設計完了とは区別する。
