# 回生抵抗の温度・耐久変化の感度

初期公差だけの定格照合を補う。Vishay資料28730（05-Dec-2024）p1の低抵抗域TCR −10〜−80 ppm/K、p9の耐久試験での抵抗変化許容±(5%R+0.1 Ω)を参照。

温度25→200℃を仮定し、初期公差−5%、耐久変化の減少側を公称値基準で加算後、線形TCR係数を適用する感度ケース。これは実筐体の温度計算や製品寿命の保証ではない。

6 V時のV²/R: 初期公差のみ8.06271 W、温度追加8.17719 W、耐久変化追加8.84047 W。最後は条件付きP70=8.4 Wを超える。従来の限定比較を全変動条件の合格へ拡張できない。計算上必要な公称抵抗は4.94063 Ω以上で、次候補5.1 Ωの回生吸収能力を別途確認する。

一次資料: https://www.vishay.com/docs/28730/ac_ac-at_ac-ni.pdf

再現: `.venv-engineering/bin/python software/sim/circuits/check_brake_resistance_envelope.py`

事前plan.jsonに仮定と限界を記録。200℃は抵抗線の仮温度で、P70の周囲温度70℃とは別。組み合わせた変化量の保証、TCR適用範囲、基板/筐体温度は未確定。候補の採用・Issueの完了を意味しない。
