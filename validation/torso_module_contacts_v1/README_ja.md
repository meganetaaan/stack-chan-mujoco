# 胴体統合で検出したモジュール包絡の重複16件の照合

## 結論

同じ最終配置のねじ8点・スペーサー8点について、簡略包絡をメーカー共通STEPに
置き換えて比較すると、16組すべて体積重複0mm³、形状距離0mmだった。
公称CAD上では取付面に接触する配置で、簡略包絡の体積重複を根拠に
ねじ・スペーサーを削る判断はしない。元の100部品統合CADとその失敗記録は変更しない。

ただし、共通STEPの上面部品高さ8.0mmに対し5V版図面は6.1mmで、
5V専用形状と同一であることは未確認。高さが大きい共通形状だからといって、
全ての部品位置が保守的な包絡になっているとは限らない。
今回の結果は「共通STEPとの公称重複を否定」の範囲に限る。
距離0は取付面の接触であり、部品間クリアランスの確保を意味しない。

## 再現

[Pololu公開STEP](https://www.pololu.com/file/0J2219/d42v110fx-step-down-voltage-regulator.step)を取得し、次を実行する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_torso_module_contacts.py /path/to/d42v110fx-step-down-voltage-regulator.step
```

入力STEPのSHA256は`ef086976c6ac9be62aca7c31dce3efcd014115ec4a11c5a3cd1e24d4e67463a4`。
スクリプトは一致を確認し、不一致なら停止する。統合CADの100ソリッドと部品一覧の
体積対応も確認する。元の重複フラグ16組をそのまま検査し、基準0.01mm³は変更していない。
`report.json`に各組の旧包絡重複量、新しい重複量・距離、入力ハッシュを保存。

## 残件と終了条件

この16組について追加の細分化・包絡調整は行わない。
5V版の取付穴周辺・下面部品配置の資料照合と、ねじ・スペーサー・穴位置の公差積上げが次の作業。
メーカー公差で判定できない部分は、現品照合箇所を指定して実測Issueへ分離する。
基板の圧縮・曲げ、締付け保持、ねじ締結長、工具アクセスは本検査では証明しない。
Tab5と外装の0.4mm、および全身・配線の干渉は別の未完了事項として残る。
製作リリースおよび#17–20の完了判定はfalseのまま。

後続：`validation/pololu_hole_tolerance_v1`に固定軸の公差反例を記録。公称重複0の結果とは別に、位置合わせ自由度の確認が必要。
