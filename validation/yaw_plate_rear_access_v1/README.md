# 金属板先付け後の背面支持締結アクセス

既存背面工具16個と追加した板2枚・固定部品32個の544比較。体積干渉は0。ただし上側4本のナット工具と金属板後側ねじ頭の隙間が0.827007 mmで、既存公称0.90 mm基準に未達。組立工程2の追加物による制約であり、先付け順序を成立とは判定しない。

既存ナット工具は半径4 mmの簡略円柱で実工具ではない。今回の制約対だけなら、軸を変えず外半径を0.072993 mm以上小さくすると幾何上0.90 mmへ届く（外径約7.854 mm以下）。これは工具選定に必要な寸法条件であり、基準の緩和ではない。実工具のソケットかみ合い、肉厚、入口形状、柄/手元包絡、購入公差を含めた検査が必要で、この値だけを根拠に工具を採用しない。

次はM3ナットに適合する実工具で既存簡略包絡を置き換え、完全な柄まで含む経路を一度検査する。リブやねじ頭を削ってこの検査だけを通さない。条件に合う実工具を選べなければ組立工程を再設計する。

入力ハッシュ、距離が境界箱下限か正確な距離か、全比較をreport.jsonへ保存。今回の対象は追加板/金属板固定部品のみ。胴体・サーボ・既存固定具等を含む完全な工具検査ではない。manufacturing_releaseはfalse。

LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_yaw_plate_rear_access.py --out validation/yaw_plate_rear_access_repeat
