# 電池保持の方向別荷重

電池荷重推定v1を読み、XYZ各成分の最小・最大を同時刻のベクトルとして保存。
底面中心(29,0,65)mmへ力を移す際のモーメントr×Fも保存した。
r=(0,0,15)mm。電池自身の回転慣性モーメントは未加算。

履歴中の最大下向き成分は1.6537N、横Yは最大絶対値0.2809N。
力の作用点移動で生じるモーメント最大は左4.5361Nmm、右4.5084Nmm。
異なる時刻の成分最大を合成した値ではない。

名目上、底面が下向き、壁とガイドが横向き、ベルトが上向き・転倒方向を支える。
現履歴のZ最大は約6.7e-13Nで計算の丸め誤差相当だが、これを理由にベルトを省かない。
回転モーメント、停止・取扱い荷重、隙間での衝突、予荷重、更新質量が未評価だからである。
壁高さ8mmより電池中心が高いことも、力の大きさだけで横ずれ保持を判断できない理由。
接触圧力分布と各部品の分担は、今回の合力・モーメントだけでは決まらない。

再現:

```sh
.venv-engineering/bin/python software/sim/structural/summarize_battery_load_direction.py --out /tmp/battery-direction-new
```

入力ハッシュと各ピーク時刻をreport.jsonへ保存。強度合格・製造リリースではない。
