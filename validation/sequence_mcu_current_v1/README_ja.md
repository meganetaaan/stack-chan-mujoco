# 起動制御MCUの動作候補と電流枠

STM32G030F6P6の設計候補をHCLK16 MHz、Range1、Flash実行（prefetch/cache使用）、内部HSI16とする。未実装の条件であり、タイマ・最悪実行時間・起動期限の成立を示すものではない。低消費電力モードの省電流を電源選定の前提にしない。

[ST DS12991 Rev6 Table25 pp44–45](https://www.st.com/resource/en/datasheet/stm32g030f6.pdf) の16 MHz/Range1/Flash行は85℃・3.6 Vで最大2.9 mA。特性評価に基づく値で製造時全数試験ではなく、周辺無効・I/Oアナログ等の測定条件がある。実際の内部発振器、デジタル入力、タイマ等を含むアプリ全体の保証値にしない。

既存の抵抗・静止IC参考値6.977558 mAに2.9 mAを加えた参考小計は9.877558 mA。R14とMCU Enableの外部抵抗電流は既に抵抗表に含み、MCU本体に重ねて加算しない。

**電源選定上の決定:** LOGIC3V3の連続出力選定目標を暫定20 mAとする。Codexの設計枠であり、ユーザー要求でもメーカー上限でもない。根拠は現在の参考小計の2倍を上方に丸め、未集計の内部発振器・周辺・入力追加電流等へ10.122442 mAを予約すること。2倍という係数自体に部品保証はない。残る負荷が枠を超えれば電源容量を増やし、結果を通すために負荷を削除しない。

この決定は供給源候補を選ぶための入口で、20 mA電源の採用承認ではない。HSI・周辺、MAX6816内部プルアップ、入力中間電圧、リセット/書込み/デバッグ、過渡電流とデカップリング、供給源の精度・損失を確認する。ピーク電流枠は未確定。STOP_AUX3V3は別系統であり、20 mAをそちらの負荷へ転用しない。

計算: `output_rail_loads_v1/report.json`のlogic小計 + `logic_ic_current_review_v2/catalog.json`のLOGIC3V3静止参考値 + 0.0029 A。report.jsonに結果を保存。候補MCU設定はg030_controller.jsonへ反映した。#21〜#24および通電判断は未完了。
