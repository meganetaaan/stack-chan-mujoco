# 再許可ボタン反転段の候補

SN74LVC1G04DBVRをMAX6816出力の反転候補とする。[TI資料](https://www.ti.com/lit/ds/symlink/sn74lvc1g04.pdf)、SCES214AF、§4/5.3/5.5。3.0〜3.6 V給電では入力High下限2.0 V、Low上限0.8 V。MAX6816の規定出力条件のHigh下限VCC−1.0 V、Low上限0.4 Vと比較する。

LOGIC3V3下限を旧設計配分3.207 Vとした比較では、High余裕0.207 V、Low余裕0.4 V。3.207 Vは新しい電源回路の保証ではなく、供給下限を確認する必要がある。入力漏れ最大5 µAはMAX6816の出力試験負荷より小さいが、実配線容量・追加負荷を含む動的保証にはならない。

この反転器はSchmitt入力ではなく、3.3±0.3 V給電の入力遷移条件10 ns/Vがある。MAX6816のデバウンス時間20〜80 msは論理遷移の待ち時間であり、出力立上り/立下り時間ではない。両者を混同せず、実出力エッジの根拠を得るまでインターフェース合格にしない。入力へRCを追加してさらに遅くする設計も無検証では行わない。

ピン候補：1 NC、2 A=MAX6816 OUT、3 GND、4 Y=PRESS（SN74HCS74第2段CLK）、5 VCC=LOGIC3V3。出力High/Lowと受け側Schmittしきい値、電源投入/低下、同時エッジ、基板容量の照合は残る。Ioff機能を回路全体の無給電安全性とみなさない。

今回の終了は型式と静的入力余裕の比較、未確定エッジ条件の抽出まで。ゲートモデルを理想化した追加波形でこの欠落を埋めない。#24は未完了。
