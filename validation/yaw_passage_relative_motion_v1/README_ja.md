# 配線開口と支持棚の相対運動：既存FE場の診断

## 結論と次の設計判断

保存38ケースの選択時刻について、支持棚Z89の動きを剛体移動で近似し、開口周辺の変位との差を求めた。棚全体で近似した場合の最大差は **0.024798 mm**、4本の支持ねじ周辺で近似した場合は **0.023681 mm**。近似方法による開口位置の予測差は最大 **0.005047 mm**。

これは、支持部全体の最大絶対変位0.220130 mmを、そのままサーボに取り付くコネクタと開口の接近量に使えないことを示す診断である。ただし、サーボ・板・コネクタがこの剛体運動をするという証明ではない。今回の値を公称隙間1.3 mmから引いて合格にしたり、従来0.2 mm配分を緩和したりしない。

棚の形状だけを追加補強する前に、**金属板の曲げ、4本の支持ねじの引張り、板と棚の圧縮接触・離間**を結び付けた荷重経路を扱う。既存の `yaw_plate_load_transfer_v1` は、保存荷重の圧縮接触だけでは釣り合わず、ねじ等による引張り経路が必要と示している。棚面全体の接着荷重と剛体近似を、その締結成立の代わりにはできない。

## 手法・検査・終了条件

- `yaw_current_archive_envelope_v1` の六つの単位応答を重ね合わせ。新しい構造解析・細分化・形状変更は行わない。
- 棚全体1765節点、支持ねじ軸半径3.2 mm以内315節点（各87/77/76/75節点）でそれぞれ等節点重みの最小二乗剛体運動を計算。
- 開口外接長方形をX/Y各1 mm拡張したZ86..91の478節点で相対変位を比較。基準点は開口中心[-14,34,89] mm。
- 各応答の節点座標一致、剛体近似行列の階数6、各ケースの最大絶対変位が元レポートと一致することを検査。
- 38選択時刻の診断を終了条件とし、追加の近似領域走査はしない。

## 限界

二つの近似は実解の上下限ではなく、差も誤差保証ではない。等節点重みは面積重みでも接触圧分布でもない。半径3.2 mmは近傍抽出条件で、実座圧分布を表さない。板・ボルト・サーボ・コネクタの剛性と接触は解いていない。右荷重は左形状へ対称変換した。全時刻包絡、最新質量、実際のハーネス形状、有限変形後のCAD隙間は未確認。製作保留、#5/#19未完了を維持する。

## 再現

元の六つの単位応答がない場合は `yaw_current_archive_envelope_v1/README.md` に従って生成する。出力先は未使用ディレクトリを指定。

```sh
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/diagnose_yaw_passage_motion.py --envelope validation/yaw_current_archive_envelope_v1 --out /tmp/yaw-passage-reproduce
```

事前計画はplan.json、近似別・ケース別のベクトル変位はreport.json。
