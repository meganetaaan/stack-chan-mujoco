# 胴体印刷部品の質量割当て

既存のPETG候補（典型密度1.27 g/cm³）を、現行ヨー台帳の外装と左右固定支持部の幾何モーメントへ適用した。ABS/PETG/TPUが使用可能というユーザー要求とは別に、PETG・均一中実という設計比較の仮定である。TPUはここで荷重支持部へ割り当てない。

追加質量214.079 g、割当て済み小計660.349 g。小計は全胴体質量ではない。トレーは前段で割当て済みなので追加しない。原点慣性と一次モーメントも合成し、重心慣性の正定値・主慣性モーメントの三角不等式を確認した。

残る密度項は後部ワッシャー8点。既に割当て済みの取付ワッシャー8点とは別物であり、その材料を無条件に転用しない。ネジ・ナット・配線・保護基板等の未確定項はreport.jsonに保持する。

この結果は均一中実CADの比較値であり、空隙や充填構造を含む印刷後の質量分布、強度、製造承認を示さない。MuJoCo本番モデルは未更新。

再現（リポジトリルート、未存在の出力先を指定）：

```sh
.venv-engineering/bin/python software/sim/structural/allocate_base_print_mass.py --out /tmp/base-print-mass-review
```

上流の電池置換台帳が同じヨー台帳を参照していることをSHA-256で照合する。
