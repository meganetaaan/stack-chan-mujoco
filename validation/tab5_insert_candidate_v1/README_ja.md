# Tab5着脱枠：熱圧入インサート候補

結論：ナット4個とスライド蓋4個の代替として、CNC Kitchen TC-M3x5.7を4個使う案を優先比較候補にする。Tab5背面の形状を蓋ストッパーに使う依存をなくす。製作承認ではなく、正式CAD・BOM・質量台帳は未更新。

## 要求・仕様・仮定

- ユーザー条件：ABS/PETGで3Dプリント可、部分的なTPUも可。外形・脚長の基本構成を保持する。
- メーカー寸法図：M3標準、長さ5.7、外径4.6、下穴4.0、下穴からの最小壁厚1.6 mm。図の貫通穴を採用。メーカーは同じ造形条件で下穴径を確認する手順を案内している。
- 商品ページは型番・見出しが5.7 mmなのに説明文は3.0 mm。寸法図を比較の根拠とするが、調達品の寸法一致を製造前に確認する。出典・PDFハッシュはsources.json。
- 設計仮定：ABSまたはPETGの耳の内側から圧入し、インサートをabs(Y)=55〜60.7に配置。下穴4.0 mmは補正前CAD値。締結部のTPU化はこの案に含めない。

## 確認結果

印刷前と圧入後近似の枠はそれぞれ有効な単一ソリッド。既存111部品の胴体から旧枠・ナットを除いた部品に対し、新枠とインサート外形の新規体積干渉は0（判定閾値0.01 mm³）。下穴から耳上下端まで2.0 mm、インサート外径から1.7 mm。メーカー最小壁厚の公称寸法条件を満たす。

既存SLH-M3-10の先端はabs(Y)=54、インサート内側端55で、公称1 mm突出し全長5.7 mmを跨ぐ。ねじ山の不完全部・面取り・公差を含む有効掛かり長さの保証ではない。側面ねじ頭を含む全幅132 mmは前候補と同じ、元の128 mmから4 mm増で脚長変更なし。

インサートと印刷前樹脂の体積重複約23.10 mm³/個は圧入用の意図した重複。圧入後モデルは外径円筒を除去した近似で、溶融樹脂の流動・収縮・盛り上がりを再現しない。ねじ・ローレットは簡略形状。

## 次の判断と終了条件

今回の寸法比較は終了。スライド蓋案の追加探索と局所応力メッシュ細分化は行わない。次は4支持点への設計荷重・モーメント配分を求め、耳根元・インサート抜け/回転・固定殻座面について必要強度と変位余裕を定義する。前の固定境界で得たFE結果を本締結へ継承しない。

実測に分ける事項は、同一材料・積層・造形条件での圧入品質、抜け/回転限界、締付け後のクリープ、繰返し着脱後の保持である。試験数や荷重を都合よく仮置きして合格にせず、設計荷重から試験条件を確定して#48の実機評価へ引き継ぐ。試験条件未確定の現状では製作HOLD、#17〜20は未完。

組立前の単体枠に圧入する工程を想定するが、加熱工具の具体形状・接近性は未確認。全身動作、配線、正式質量・慣性、Tab5と枠を結ぶ別の4本のねじもこの比較に含めない。
