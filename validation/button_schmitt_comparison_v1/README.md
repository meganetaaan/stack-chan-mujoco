# ボタン反転段：Schmitt入力候補との比較

Nexperia 74LVC1G14を比較した。[メーカー資料](https://assets.nexperia.com/documents/data-sheet/74LVC1G14.pdf)、Rev19.1、表8。3.0 V給電時の上昇しきい値最大1.71 V、下降しきい値最小0.88 V。MAX6816の出力規定値を同じ3.0 V点で比較すると、High余裕0.29 V、Low余裕0.48 Vとなる。

Schmitt入力はSN74LVC1G04候補にあった通常CMOSの入力エッジ制約を回避する方向の候補だが、ここで3.3 V電源の全変動域を合格としない。表の3.0 V/4.5 V点間を線形補間した値を保証値にしてはいけない。現在のLOGIC3V3公差全域と出力負荷でしきい値の包絡を確定する必要がある。

**今は部品表の反転器を置換しない。** 現候補のエッジ適合未確認と、Schmitt代替の電源全域適合未確認を比較事項として残す。典型グラフだけで決めず、受信しきい値と送信出力の規定条件が揃う接続を最終選定する。部品追加や理想波形の生成ではこの仕様不足を埋めない。

今回の終了は代替方式の一次資料比較1件。電源確定後に同じ電圧域で再審査する。#24は未完了。
