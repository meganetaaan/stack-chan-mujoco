# 閉じ部を上面・前側へ限定したベルト経路候補

## 結果

ベルトY=±20mm、幅12.7mm、単層厚み予約2.5mmは維持。
二重厚み5mmの区域を上面Z>=98mmと前側X>=43.2かつZ>=65mmに限定し、後側は単層とした。
前案の基準・厚みを緩めたのではなく、組立時の閉じ部位置を変更した案。
実厚みのメーカー上限は依然未確認で、2.5mmは空間予約。

事前計画plan.jsonに対し、トレーは有効な単一ソリッド。電池・ベルト間の体積干渉0。
他98部品との0.01mm³超の体積干渉0、ベルトから周辺部品の最小公称隙間は左右とも0.7mm。
v4は不採用、v5を次の組立検討候補とする。正式トレーポインターはまだ置換しない。

## 組立条件と限界

閉じ部と端部が後ろ側へ回らない位置で装着する必要がある。これを保つ方法と作業性は未検証。
上面から前側へ曲がる部分で、必要な係合長を連続して確保できるか確認する。
200mm切出しは候補であり、曲げ半径・実厚み・装着張力を含む有効係合長は未確定。
0.7mmを公差・振動・変形込みの合格余裕とはしない。閉じ部の浮きも評価対象に含める。
保持力・電池面圧・トレー腕/ねじの強度は未確認。FEや実測を実施したとは扱わない。

この時点で配置の試行は終了する。次はベルトの装着・電池の取り出し経路と閉じ部の保持を具体化し、
荷重と実部品物性に基づく評価へ進む。製作HOLD。
