# ボス上面の外付けナット案

閉室/側面挿入案に代わり、内部ナット室を埋めてボス上面z=−11.6 mmへPTS A56202を置く。ねじはNBK SLH-M2-10候補へ変更。頭径/高さ/床側位置は従来どおり、首下だけ8→10 mm。足外形・脚長は変更しない。

**今後の組立検討では本案を優先する。** 造形途中の封入と、室の公差だけに依存する回り止めを不要にする。ナットは工具で保持して締結し、交換可能。ただし工具両側アクセスと実締付け・緩み止めの仕様は未確定で、製造リリースではない。

## 確認結果

左右とも有効な単一ソリッド。ナット/ねじと既存ブーツ・ヨークの重複0。ナット周囲の半径4 mm・上向き20 mmの工具予約包絡もブーツ/ヨークと重複0。この予約包絡は実工具ではなく、サーボ本体・ホーン・全身姿勢との照合は残る。ねじ山の噛合いは公称軸包絡で、CADのねじ/ナット接触だけでねじ規格適合とはしない。

ねじ先端z=−9.9 mm、最大厚ナット上面z=−10.4 mmで呼び突出0.5 mm。面取り・不完全ねじ・長さ公差による有効かかり不足の確認が必要。新ねじのメーカー呼び質量0.23 gは8 mm品より各0.04 g増。ヨークの充填体積は各27.3694 mm³増、材料密度確定後に質量反映する。

前のボスFEはナット底面z=−14.2 mmへ負荷していた。本案では−11.6 mmで荷重を受けるため、過去応力・変位を新形状の合格証拠へ転用しない。評価すべき量は実座面圧、ボスの圧縮/曲げ、締付け保持と足裏滑り止め。未知予圧での追加解析は開始しない。
