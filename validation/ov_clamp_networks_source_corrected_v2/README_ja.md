# クランプ電流条件の仕様引用を訂正

TI TLV431 SLVS139Z（2024年6月）§5.6ではTLV431AC/AIの最小動作電流IK(min)の最大値は80µA、AQは100µA。§5.7のTLV431Bは100µA。いずれもVKA=VREF、特記のない表項目は25°C条件である。既存比較はTLV431AIを対象としながら100µAを使用していたため、100µAを**維持する設計比較値**として分類し、型種別のメーカー値・条件を別欄に記録した。

100µAを80µAへ下げて判定を通す変更は行っていない。旧v1と判定基準・4つの計算結果が完全一致することを確認した。未成立判定も維持。35.7k/10kの高抵抗案では必要電流が不足し、3.57k/1k案は比較計算を通っても低電流時の精度・規定前電流・応答・全温度の保証は未完了である。

同表の動的インピーダンス最大0.4ΩはVKA=VREF、f≤1kHz、IK=0.1..15mAで示され、これだけを任意の調整電圧・温度・高速故障過渡の誤差上限へ流用しない。10mA時の基準精度と実回路の低電流条件を混同しない。

既存revNの電圧監視→インバータ→OVLO経路は端子の静的範囲の別解だが、`validation/window_ovlo_timing_v1`で遮断時間の上限が得られていないため、唯一の高速保護として不採用を維持する。二案とも波形の仮定を都合よく設定して採用しない。部品選定・回路統合・製作は保留。
