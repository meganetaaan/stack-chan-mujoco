# 最小座面・支持反力の診断

支持面の部材応力を境界積分点へ評価し、底面外向き法線−zに対するトラクションσnのz成分を計算した。正は上向き、すなわち圧縮支持。入力は `../sole_minimum_bearing_v1` の保存変位とメッシュ。

1 mmメッシュの圧力評価値は0.442–1.866 MPaで全点圧縮。ただし面積積分16.326 Nに対し、組立方程式の支持反力は20 Nで18.37%の差がある。応力由来の境界トラクションは厳密には力の釣合いを満たさないため、離間なしの証明には使えない。細分化して境界応力回復の精度を確認する。

106個の支持節点で負の二次要素節点反力が存在するが、二次形状関数の符号と荷重の弱形式表現により、節点力の符号を局所圧力の符号と同一視できない。この数を引張接触の個数として数えない。

再現:

```sh
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/audit_sole_bearing_traction.py --source validation/sole_minimum_bearing_v1 --out outputs/sole_traction_repro
```

モデルは両側拘束のまま。剛体支持、締付力20 N、材料E=1120 MPa・ν=0.35の仮定も変更していない。片側接触・実スペーサー・歩行荷重の検証は未完了。
