# 電流検出の配線・残余誤差予算

既存のIC閾値比較下限45mV、検出抵抗温度公差込み上限8.363mΩ、片脚モデル電流4.917Aから、残る正方向の検出誤差は3.880mV未満と導いた。共通電流経路の抵抗だけに換算すると0.789mΩ未満となる。これは採用した余裕率ではなく、既存負荷で制限が始まる境界であり、全量を配線へ割り当てない。

判定式は `I_load * R_shared + V_other_positive < 3.880mV`。部品端子から独立したKelvin配線を引き、コネクタ・ビア・大電流配線の先から検出しない。端子パッド、検出入力電流、熱起電力、残る経時・実装変化が同じ予算を消費する。負方向誤差は最大制限電流を増やすため別途MOSFET負担へ反映する。

実配線未完成のため合格ではない。IC閾値の実動作条件への適用、モデル負荷の実機ピークへの適用も保留。抵抗値を下げて判定だけを通す変更はしていない。
