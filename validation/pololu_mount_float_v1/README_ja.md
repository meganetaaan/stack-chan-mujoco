# 現行保持部の個別位置合わせ余地

## 設計判断

固定軸モデルの公差反例に対し、現行保持部を変更せず、ねじ・ナット・スペーサーを
同時にX/Y各±0.05mm移動した。左右8穴×4方向＝32条件で、各部品と自分のブラケットの
体積重複はフラグ0.01mm³以下。PCB穴位置の各座標±0.1mmに対し、穴中心との残差は
0.070711mmで、公称穴2.18mm／ねじ包絡2mmの半径隙間0.09mmに収まった。

したがって、固定軸モデルの反例だけで現行ブラケットを即座に長穴加工する必要はない。
一方、残余半径隙間は0.019289mmであり、造形位置・穴径・ねじ径の誤差を含む保証ではない。
これは選んだ配置での余裕で、全造形寸法を±0.019mmにせよという製造指示ではない。
組立時にさらに調整できる範囲と、各部品の誤差の組合せを求める必要がある。

スペーサー座面の投影面積は最小8.682579mm²。
下面0.001mm厚の形状を下向きに移し、ブラケットとの交差体積から求めた幾何量である。
圧縮・クリープ・締付け保持の許容面積ではなく、荷重に対する合格値にはしていない。

## 範囲と残件

- 公称形状の32姿勢で、自分のブラケットとの配置を検査した。
- 移動経路、任意の連続位置、他の部品、ナット回転、ねじ傾きは今回の対象外。
- ねじ包絡と基板穴は前回と同じ。公差・基準を変更して反例を消していない。
- 次は穴・ポケットの仕上がり限界と位置決め基準を設定し、個別調整で組める範囲を示す。
  公差範囲が閉じなければ、保持と座面を維持する範囲でブラケット側を変更する。
- 基板側の穴拡張は候補にしない。公称確認だけで製作リリースやIssue完了としない。

## 再現

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_pololu_mount_float.py
```

条件は`plan.json`、32姿勢の入力・重複量・座面幾何量は`report.json`。
元データは既存43部品の電源取付組立で、CADの変更はない。
