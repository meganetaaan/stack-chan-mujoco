# r9 胴体質量の出典照合

再現（リポジトリ直下）:

```sh
.venv-engineering/bin/python software/sim/mujoco/audit_r9_base_mass.py \
  --out validation/base_mass_provenance_development_v1/report.json
```

包装CADの部品別記録から、r9生成器と同じくヨーカプラを除き、電池固定ねじ2本を各0.30 gへ置換して集計する。重心回り慣性には平行軸の定理を適用する。照合基準は質量・重心各成分・慣性各成分の絶対差がそれぞれ1e-12以下（各SI単位）。結果は全成分で差ゼロ、胴体質量0.5229396482513734 kg。

樹脂5部品の質量／CAD体積から密度1240 kg/m³を確認した。現在の構造解析用PETG密度1270 kg/m³と異なるため、候補比較では密度による変化と形状による変化を区別する。旧背面カバーの動力学上の割当質量は36.02626694 gであり、別密度で求めたCAD質量を引いてはいけない。

25 gの配線・締結部品枠は部品別内訳がない。新規ねじ等の追加時にはこの枠との重複を解消する必要がある。電池103 g、コンバータ20 g、インターフェース12 gも未選定品の予約値である。本結果は旧モデルの出典照合のみで、候補形状・質量へのモデル更新や負荷再評価、製造承認を意味しない。
