# MRバッファをシュミット入力品へ変更

優先候補をNexperia 74LVC1G17GVへ変更する。非反転1ゲート・1個という構成は維持する。メーカーが入力立上り／立下り時間を無制限としているため、旧LVC1G34の10 ns/V条件を満たすための追加IBIS解析は停止する。旧モデル監査は削除せず保存する。外部ノイズによるしきい値の往復、電源異常、停止保持まで解消したとは扱わない。

MR入力負荷上限48.47 µAは100 µAの出力保証条件内。共通想定電源3.207〜3.393 VではHigh／Low余裕はいずれも0.8621 V。入力漏れ最大1 µAはHCS11出力の20 µA条件内。

入力しきい値はメーカー表の1.8／2.3／3.0／4.5／5.5 V点を確認。列挙点全体の最大VT+は2.79 V、最小VT−は0.46 Vで、HCS出力下限High3.107／上限Low0.1 Vに対し余裕がある。ただし離散点の確認を、実電源区間全域の極値保証へ読み替えない。入力しきい値の適合保証は残件として明記する。DC出力の合格と入力側の未確認を分ける。

SC-74A（SOT753）のピン番号は1NC・2A・3GND・4Y・5VCC。旧DBVとの基板フットプリント互換を推定せず、実寸照合する。起動中の独立クリア／既定OFF段は引き続き必要。

今回は部品選択とインターフェース机上判断で終了。エッジ制約を緩和したのではなく、制約が異なる実部品に設計を変更した。#24の全体合格や製造承認ではない。

出典：[Nexperia 74LVC1G17 Rev16.1](https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf)、2026-09-21確認。旧候補はprevious_lvc1g34_candidate.jsonに保存。
