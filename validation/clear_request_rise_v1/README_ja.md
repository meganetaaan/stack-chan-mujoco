# クリア要求線の開放時立上り

終了した不確実性：R14=100kΩのままLVCオープンドレインへ直結する案を、
立上り確認なしで採用できるか。結論は採用不可（仕様適合が未証明）。
部品故障や実機波形の不合格を証明したものではない。

要求は停止・再起動抑止。R14、電源範囲、容量シナリオは設計側の仮定。
メーカーの入力エッジ制限10ns/Vを緩和しない。
V=3.207(1-exp(-t/RC))、R=101kΩで解析。
仮の総容量1/5/10pFで0.8→2.0Vの通過は69.7/348.6/697.1ns。
2.0V地点の局所傾斜を10ns/V以下にする容量は0.120pF以下となる。
これは局所傾斜による設計スクリーニングであり、メーカー試験波形の代用ではない。
容量を都合よく0に置くことで適合扱いにはしない。

次の構成候補はSEQUENCE_CLEAR_REQUEST → 74LVC1G17GV → 74LVC1G06GW → RESET_N。
R14は最初の入力に残し、R4=75kΩ候補と組み合わせる。
1G17は遅い入力を許容するが、追加だけで全体合格とはしない。
受信閾値、出力負荷とエッジ、電源立上り／低下中の抑止を確認後に統合する。
現行回路・BOMは変更しない。

追加解析の終了条件：整形段の入力開放時・駆動時レベル、後段入力のエッジ条件、
給電遷移時のEN抑止を仕様根拠付きで判定する。容量掃引の細分化は行わない。
実測では開放・接続復帰を含む波形を確認するが、机上設計の不足とは分ける。
