# ブーツ・ヨーク取付部の形状確認

左右各4本の半径1.15 mmのZ方向穴について、ブーツと新ヨークの軸位置が一致した。各穴周囲の半径3 mm、z=[−20,−12] mmの領域は、凍結r9の対応部品と比較して追加・除去とも0 mm³。両部品の重なりは0 mm³。

ただし部品間の最短距離は左右とも0.2 mm。直接接触しておらず、締付け時の荷重伝達面や隙間処理は未定義である。all_nominal_checks_passは穴一致・重なり・局所形状保持の狭い判定のみを表し、組立成立や締結強度の合格ではない。この間隙を無視した固定境界で構造合格を主張しない。

追加加工が穴周囲の指定領域を侵していないことは確認したが、従来の穴配置や縁端距離そのものの妥当性は証明しない。ねじ・ナット・座面の仕様、工具アクセス、予圧、公差、取付部変形と強度は引き続き未完了。

## 再現

```sh
export LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu"
.venv-engineering/bin/python software/sim/structural/check_boot_yoke_mounts.py --out outputs/reproduce_boot_yoke_mounts
```

出力先は未作成のディレクトリを指定する。判定条件・入力SHA・穴座標・近傍差分体積を保存した。製造承認は行わない。
