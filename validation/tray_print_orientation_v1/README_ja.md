# トレイ造形方向の幾何比較

revB STEPの6軸方向について、最下面の平面面積と、それ以外の下向き平面面積を集計。
平面のみを対象とし、曲面、橋渡し長さ、サポート生成、密着性や強度は未評価。
最下面面積は接着成功率ではなく、方向比較の幾何量である。

| 積層方向（本体座標） | 高さmm | 最下面mm² | その他下向き平面mm² |
|---|---:|---:|---:|
| X± | 28.9 | 28.5 | 1320.26 |
| Y± | 124.4 | 44.20 | 553.60 |
| Z+（取付姿勢） | 15 | 24.0 | 2043.66 |
| Z−（上下反転） | 15 | 263.4 | 1804.26 |

スライサー確認の第一候補をZ−とする。取付姿勢のままでは最下部の小さな固定タブから
造形が始まり、広い床を直接ベッドへ置くことにはならない。
Z−なら壁上端等が初層となるが、電池に接する床面に支持が必要か検査する。
支持痕で電池へ局所圧力が生じるなら、この向きを採用しないか、接触面を保護する
設計変更を行う。現段階で反転STLを製造リリースしない。

次の終了条件は、指定プリンタ・ノズルでの層断面とサポート接触を確認し、
固定穴・ベルトガイド・電池接触面の加工/除去余裕を示すこと。
層方向の強度判断も別に必要。最下面面積の大小だけで造形可能とは判定しない。

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/screen_tray_print_orientation.py --out /tmp/tray-orientation-new
```
