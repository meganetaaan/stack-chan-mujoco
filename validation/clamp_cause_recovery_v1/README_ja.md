# 停止原因を保持解除へ伝えるrevE

前回の反例ではU9がENだけを下げ、U7は許可を保持した。revEではU9の停止原因をU7 MRへ直接伝える。U9とENは別ネットとし、通常のEN Lowから停止原因へ帰還しない。各電圧と遅延が落ち着いた論理比較で、両しきい値の高低を入れ替えても保持許可が解除され、復帰だけでは戻らないことを確認した。

EN自体の再投入防止はまだ合格ではない。未実装の指令シーケンサが許可取消をPOWER_ENABLE_COMMANDへ反映する必要がある。結果中のEN_after_sequencer_honors_permissionはこの条件付きの値で、実装済みの出力ではない。

## 実部品と静的比較

U11は[Nexperia 74LVC1G17GV](https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf)、U10は[TI TPS3808G01DBVR](https://www.ti.com/lit/ds/symlink/tps3808.pdf)。U11は5 V給電で3.3 V停止原因を受け、U10 MRへ5 V側信号を出す。これによりMRの内部プルアップを通じた5 Vから3.3 Vへの直接接続を避ける。

10 kΩ総合±1%、既存電源仮値では、停止原因Lowの吸込比較392.2 µAはU9の1 mA規定点以下。Low最大0.4 VはU7 MRの比較上限0.9621 V以下。U11出力負荷はU10内部プルアップ最小70 kΩから75 µAで、100 µAの出力規定内。High下限4.65 V／Low上限0.1 VはU10 MRの比較条件を満たす。

RAIL_HEALTH_N High比較3.19387 Vは、U11の既知のしきい値規定点とは余裕がある。ただし実5 V全域のしきい値保証へ点間補間はしない。既存候補と同様に全電圧域の入力適合は未確認。漏れ電流の規定点も無給電状態へ拡張しない。

U10はSENSE=VDD=入力側5 V、CT開放で12〜28 msの解除待ち。これは手動解除確認を置換しない。U9低電圧→U7 MR→ラッチCLR、およびU11→U10→ENの伝搬とパルス捕捉は別評価が必要。監視電源も失われる場合と、出力側が回生で高くなる場合は未確認。

## 候補比較と解析の範囲

単体LVC1G07案には、Schmitt表記があっても入力遷移速度規定が残る。HCS05は遅い入力へ対応するが、今回確認した特性表には独立したOFF出力漏れの規定を見つけられなかった。新たな未知条件をモデルで埋めるより、既存の出力・MR負荷比較を使える構成へ進めた。これらの候補はBOMへ追加しない。

今回の終了条件は接続分離、既知反例の保持許可解除、静的インターフェース比較まで。回路過渡や全故障を合格とはしない。#24未完了、通電保留。
