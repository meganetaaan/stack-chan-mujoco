# 起動待ち受信部から制御ICへの負荷比較

STM32C011の資料表を画像でも確認した。入力漏れは代表値欄で、最大値欄は空欄。
この値を保証最大値として採用しない。
別候補STM32G030は標準入力の最大値と製品全体の漏れ式を規定する。
全44 I/O分の漏れと固定項を保守的にこの1出力へ割り当てた比較値は13.08 µA。
すべての入力がGND〜VDD内、切替ダイオードと内部プル抵抗を無効とする条件付きである。

既存220 kΩを加えると約29.61 µAで、前段の20 µA出力規定による計算に収まらない。
560 kΩでは約19.57 µA、1 MΩでは約16.72 µAとなる。
抵抗を大きくすると電源断時の漏れによる電圧や放電時間も増えるため、
単に定常計算が通る値へ変更して統合完了にはしない。

G030は同じ20端子でも複数ポートが同じ端子へ接続される箇所があり、
C011の端子割当・リセット機能・設定をそのまま流用できない。
現行統合回路revIとC011の端子候補は変更していない。比較結果から次の選定を行う。

再現：

```sh
python3 software/sim/circuits/screen_sequence_input_load.py --out /tmp/sequence-input-load
```

資料出典と条件はreport.jsonを参照。これは部品選定の定常負荷比較で、
実回路の停止・起動・過渡シミュレーションではない。
