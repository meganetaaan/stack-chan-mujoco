# 現行足部revEの圧縮接触面

現行inventoryが指すSTEPのハッシュを照合し、左右28組について、
同じ高さで法線が反対向きの水平面の共通面積を抽出した。
28組すべてに公称の圧縮接触面がある。面積が正であることを強度合格とは扱わない。

| 対象 | 公称接触面積 mm² |
|---|---:|
| 外装とヨーク | 96.4783 / 足 |
| ヨークと足裏保持部 | 3521.2912 / 足 |
| 保持部と接地材 | 4015.7221 / 足 |
| 外装ねじ頭とヨーク | 7.1864 / 本 |
| 外装ナットと樹脂座面 | 11.8452 / 個（最大幅4 mmのCAD包絡） |

ナット幅の既存部品仕様3.7〜4.0 mmと公称穴径2.3 mmを使うと、
中央配置・面取りなしの理想的な接触面積は9.5352〜11.8452 mm²。
以前の局所解析で用いた幅4.4 mmの空洞床面全体は15.2052 mm²である。
同じ力で比較した平均面圧は、実寸法を考えた理想面では以前の約1.28〜1.59倍になる。
これは破損予測やピーク応力の倍率ではなく、荷重の分布面積を修正する理由である。

## 次の強度評価へ渡す条件

旧screen_boot_nut_seat.pyは旧外装・全面分布荷重・理想拘束の比較解析であり、
横挿入開口を持つrevEの完了証跡へ転用しない。
次の評価では実ナット接触域、ねじ軸力、座面の面外曲げ、締結部の分離と残留変形を扱う。
横開口で低下する拘束も含め、周囲を完全固定した局所解析だけで合格にしない。

今回の終了条件は接触面の有無と面積の特定であり、追加のメッシュ細分化は行わない。
強度評価の開始には荷重・締付け・造形条件に基づく許容値の根拠が必要。
面取り、穴仕上げ公差、傾き、実材料、摩擦・クリープは未確認で、
この理想面積を保証最小面積として使わない。

## 再現

リポジトリルートから、未作成の出力先を指定する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/audit_current_foot_bearing.py --out /tmp/foot-bearing-check
```

plan.jsonに入力ハッシュと抽出条件、report.jsonに面の高さ・法線・重心・面積を記録。
