# 補強候補の質量差分

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" \
  .venv-engineering/bin/python software/sim/mujoco/compare_candidate_base_mass.py \
  --out validation/candidate_base_mass_development_v1/report.json
```

凍結r9の部品集計との一致を先に確認し、胴体外装、背面板、左右ヨー固定支持部の4部品を現在の候補STEPから求めた質量・重心・重心回り慣性へ置換する。CAD形状の妥当性、候補指定のSHA256、集計慣性の正値性を確認する。PETGは1270 kg/m³、アルミは2700 kg/m³とする。密度と形状による差を分離して報告する。

|部品|元モデルからの増分 g|
|---|---:|
|胴体外装|4.819|
|アルミ背面板|50.730|
|左ヨー支持部|25.050|
|右ヨー支持部|25.050|
|合計|105.650|

胴体質量は522.940→628.589 g。胴体座標系の重心は(9.651, 0.00879, 74.899)→(-0.637, 0.00728, 73.761) mm。脚などを据え置けば全体約918.440→1024.090 g相当。ただし締結部品の内訳未確定のため最終総質量とはしない。

既存の配線・締結部品25 g枠はそのまま保持し、新規M3締結部品は個別加算していない。この枠に収まることを確認した意味ではない。電池・基板等も旧予約値を保持する。未変更樹脂部品の密度は旧モデルのままとする。ソリッド体積からの計算であり、実際のインフィルや製造ばらつきは未校正。

この結果は質量差分の台帳であり、MuJoCoの衝突形状・質量設定・負荷記録はまだ変更していない。既存の構造解析や回路解析を補強後の機体に対する合格証跡として扱わない。次に締結部品台帳を確定し、形状と質量を整合させた候補モデルで負荷を再評価する。
