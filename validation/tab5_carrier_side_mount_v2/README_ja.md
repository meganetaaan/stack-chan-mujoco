# Tab5取付枠の側面締結部候補

v1の各突起を、X46.3..50、|Y|60.5..62.5mmの連結部で着脱枠へつないだ。
X46.3より後ろへ連結部を延ばさず、固定側外装との隙間を維持した。
結果は固定側・枠とも有効な単一ソリッド。相互・周辺部品との体積干渉なし。
左右各2点、X42/Z88,112mmの外側からねじを操作する構成を候補とする。

## 部品選定前の条件

通し穴径3.4mm、六角ポケット対角6.6mm・深さ2.8mmは設計仮置き。
実ねじ頭、首下長さ、ナット公差・ねじ掛かりは未選定。現CADをそのまま製作図とはしない。
ナットは内側からポケットへ入れられる想定だが、挿入経路と取外し時の保持は未検査。

突起外面|Y|61mmと固定側内面の隙間を、ねじの締付けで無条件に潰してはいけない。
固定側の実座面を照合し、スペーサーまたは接触ボスで予圧を受ける構成を次に定める。
その後、枠→連結部→突起→ねじ/ナット→固定側外装の荷重伝達を評価する。
せん断を摩擦だけに依存させるか、別の位置決めで受けるかも未確定。
頭部を収める座ぐりはまだない。外形評価は実ねじ頭を含めてやり直す必要がある。

前回の枠単体の引出し証拠は、新突起やねじへ自動継承しない。
ねじ解除・ナット保持・工具・配線と、枠を前へ引く経路を部品選定後に確認する。
形状の連結性は強度の証明ではないため、締結条件未確定のFEは追加しない。
製作HOLD、正式候補ポインター・質量台帳は据置き。
