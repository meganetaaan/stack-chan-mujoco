# 着脱式Tab5枠・LB-020を含む胴体統合候補

## 統合内容と結果

既存torso_power_integration_v2の100部品から外装・旧トレー・旧電池を外し、
固定側外装、着脱枠、側面ねじ4本・ナット4個、LB-020包絡、新トレー、ベルト2本を追加した111部品。
assembly.stepのソリッド順序はreport.jsonのpartsに対応する。

変更14部品同士と変更対保持97部品の計1,449組を検査。1,321組は外接箱で除外し、残りを体積交差で検査。
0.01mm³を超える新しい体積干渉は0。
全体範囲はX−67.7..64、Y−66..66、Z0..128mm。ねじ頭のため全幅132mm。
その他の胴体外接寸法・Tab5位置は維持。

## 評価を継承しない項目

保持97部品同士は再検査していない。旧統合結果にあった電源モジュール包絡と固定具の接触フラグなどを
今回の「新規干渉0」で解決したとは扱わない。
Tab5と枠をつなぐ4本のねじはまだ未選定・未モデル化。側面ねじ4本と混同しない。
新しい保護基板・配線・コネクター、脚と足、造形公差、変形・動的干渉は含まれない。

この統合CADは次の工具・ねじ抜き・枠引出し・電池交換検査の入力に使える。
以前の枠単体の引出し結果は、新しい側面突起とナットへ自動継承しない。
側面ねじを外した後にナットを保持する仕組みも未完成。
強度・締付け・面圧・緩み・電池保持が未確定で、製作HOLDを維持。
正式CADポインター・MuJoCo質量はまだ置換しない。
