# 最新Tab5枠：座面積と強度評価の入力

**側面固定ではインサート抜けに加え、ねじ頭直下の固定殻の圧縮・曲げ・クリープを評価する。** 現115部品CADの接触面12か所を抽出した。ねじ頭側の面積は枠側パッドより小さく、同じ接触合力で平均面圧は約1.77倍になる。強度や許容締付力の合格結果ではない。

## 確認した形状と計算

同一平面上にある部品の面どうしの共通領域から面積を求め、独立した円環式と1e-6 mm²以内で一致することを確認した。側面パッドは各軸の周囲を切り出して、別のパッドの面積を加算しない。入力STEP・部品対応表・計算コードのハッシュを保存した。

| 接触部（各4か所） | 接触面積 mm² | 接触合力1 Nあたり平均面圧 MPa | 接触合力50 Nの比較 MPa |
|---|---:|---:|---:|
| 側面ねじ頭―固定殻 | 14.6791 | 0.068124 | 3.4062 |
| 枠パッド―固定殻 | 25.9181 | 0.038583 | 1.9292 |
| Tab5固定ねじ頭―枠 | 15.2053 | 0.065767 | 3.2883 |

50 Nは設計側の感度比較点で、必要締付力・許容値・推奨組立値ではない。全比較点（1/10/50/100 N）と個別面積は[report.json](report.json)。接触合力Nと面積Aについて平均面圧はN/A。ねじ予圧と外力からNへ至る接触解析は今回行っていない。

CADには樹脂座面の公称接触があるが、実造形の反り・粗さ・公差を含まない。実際の接触面積は減少し得る。平均面圧が許容値以下でも局所面圧・殻の曲げが成立するとは限らない。`A×許容面圧`は均一接触なら対応する合力であり、これだけで許容予圧を決めない。

## 要求・仕様・仮定の区別

- ユーザー要求：ABS/PETG/TPUを使用可能。破損・脱落・変形による干渉を判断し、局所最大応力の収束だけを完了条件にしない。
- 選定部品の寸法：SLH-M3-10/M3-8を現在のCADへ配置。今回の抽出はCADに対するもので、メーカー寸法公差を検査した結果ではない。
- 設計条件：公称平面接触、現モデルの穴径と座面形状、上記の合力比較点。材料許容値・安全率・予圧・摩擦係数は未設定のまま残す。

旧7 MPaの引張系スクリーニング値を座面圧縮やクリープの許容値に流用しない。ねじメーカーの最大トルクも樹脂・インサート・Tab5の組立トルクに転記しない。

## 荷重経路と次の解析で出す量

Tab5 → 背面ねじ/接触面 → 枠の取付パッド/縁 → 側面耳・インサート → 側面ねじ/接触パッド → 固定殻 → 胴体支持、という経路を対象とする。Tab5背面ねじ群と側面ねじ群は別の接合部であり、以前の側面4点反力をTab5背面ねじへ直接転用しない。

| 対象 | 必須の評価量 | 合否へ必要な入力 |
|---|---|---|
| ねじ頭直下・接触パッド | 接触合力、接触面積/圧力分布、座面沈み・殻の曲げ変位 | 材料/積層方向別の圧縮・曲げ・時間温度依存、予圧範囲 |
| 側面インサート | 引抜き合力、回転モーメント、周囲の相対変位 | 使用材料・圧入工程での保持特性、ねじ掛かり、熱影響 |
| 耳・枠の根元 | 断面力とモーメント、層方向の応力/ひずみ、局所座屈の有無 | 現CADの断面、造形方向、物性、接触に対応した境界条件 |
| 接合面 | 離間、接線ずれ、保持予圧の変化 | 摩擦または滑り後の支圧経路、孔クリアランス、予圧ばらつき |
| 顔と固定殻・配線 | 相対変位による隙間減少、残留変形、配線への荷重 | 公差込みの隙間・配線経路と許容曲げ/引張条件 |

荷重の同時刻の組合せを維持し、異なる時刻の最大値を合成しない。[既存の等剛性4点荷重](../tab5_carrier_load_map_v2/README_ja.md)は旧動作と旧枠形状による条件付き比較であり、現構成の最悪荷重や予圧の根拠に使わない。[最新全機からの荷重再生成](../current_load_mass_basis_v1/README_ja.md)が必要。

## 追加解析の開始条件と終了条件

開始前に、材料・造形方向、最新全機の荷重、締付力範囲、Tab5の有効雌ねじ深さ、接触/滑りの扱いを定義する。未定値を一律固定拘束や旧許容応力で埋めない。

追加解析の目的は「組立時と使用時に座面が損傷/緩みを生じるか」「耳・枠が変形して保持・隙間を失うか」の判断。終了条件は上表の量を出し、事前に根拠を定めた許容値・安全率へ照合できること。メッシュ感度は合力・接触面積・変位・評価対象領域の応力について確認する。鋭角や完全固定端の点最大応力だけが増加する場合は、特異点と物理的破損の区別を残し、細分化を繰り返すだけで完了にしない。

#18の最悪荷重・許容値以内という完了条件は未達。#20の製作/締結条件も未完。材料・実工程固有の保持とクリープ確認は#48の対象となるが、設計荷重・接触条件・必要許容値の定義は設計側に残す。
