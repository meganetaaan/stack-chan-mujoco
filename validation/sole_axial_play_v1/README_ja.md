# 固定ねじを含めた軸方向遊びの確認

変更後の保持部を下方へ0/0.2/0.4/0.5/0.6/0.7mm動かし、ヨーク・ブーツ・
既存ねじ・スペーサーとの交差を確認した。左右とも0.6mmまでの検査姿勢で交差0、
0.7mmでヨークと約3.475mm³の交差。ねじ／スペーサーとは全姿勢で交差0。

元の保持穴半径3.2mmに対しスペーサー半径3mm、ねじ頭半径1.9mmのため、
このねじを締めても保持部そのものを軸方向へ挟む座面にはならない。
ねじの横滑り止めと、足裏の上下保持を同じ機能とみなしてはならない。
この結果は摩擦・接着・変形を含む実際の遊び量測定ではなく、公称剛体形状の証拠。

**製作判断：頭位置変更＋キー穴拡大を固定完了の構成として採用しない。**
挿入余裕の改善と引換えに上下の遊びを残している。都合よい締付け摩擦を仮定せず、
保持部を実際に挟む座面・ワッシャ等の締結構造を設計する。
その際、床側のねじ頭隙間0.55mm、樹脂座面厚、締付け荷重経路、工具アクセスを
同時に満たす必要がある。ワッシャを単純に床側へ足して隙間を消費する案を即採用しない。

再現：

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_sole_axial_play.py --out /tmp/sole-axial-play-recheck
```
