# 横挿入開口と座面変形の局所比較

結論：この局所モデルでは開口による大きな剛性低下は現れなかったが、
開口の影響が数値差より小さく、強度合格や影響ゼロとは判定できない。
この不確実性に対する追加のメッシュ細分化はここで止める。

旧閉鎖形状と現行横挿入形状を同じ4 mm角のナット接触域で比較した。
力1 Nは線形応答の正規化であり、実機荷重・締付け力を1 Nに変更していない。
E=1120 MPa、ν=0.35は旧比較と同じ仮定で、造形品の保証値ではない。

| 支持条件 | 現行／旧の変形しやすさ比（0.7 mmメッシュ） | メッシュ変更による変化 |
|---|---:|---:|
| 底面完全固定 | 1.0049 | 約2.57% |
| 底面法線拘束＋面内最小拘束 | 1.0075 | 約1.45〜1.50% |

開口の影響として得た0.49〜0.75%はメッシュ変更差より小さい。
数値検査を満たしても、この微小差の符号・大きさを確定したとは扱わない。
支持条件を変えた影響は現行で約21%あり、実際の接触・拘束の評価が優先される。

## 失敗からの修正

v1は要素中心で接触域を選び、旧形状の粗いメッシュで荷重面積が
意図した11.845 mm²に対し15.619 mm²になった。約32%の誤差で比較不成立。
v2はナット接触域の面を形状に分割線として与えた。分割数は1.0／0.7 mmのまま。
荷重面積誤差は約3.50／1.88%、全ケースの力釣合い誤差は1e-7 N未満。
事前設定した5%の面積・変形感度条件は変更していない。
5%はこの比較の数値品質の仮基準で、部品の強度・変形合否基準ではない。

## 適用限界と次の判断

周囲を切り出した局所モデル、摩擦・分離を解かない支持、面取りなしの
ナット接触域である。二次要素の負の等価節点反力だけで引張接触と断定しない。
一方、これを片側接触が成立する証明にも使わない。
ねじ軸力、材料方向性、クリープ、脱落、全体変形・干渉は未評価。

次は実締結の接触・締付け・造形条件に基づく許容値を定める。
同じ理想拘束の細分化を続けて#5を閉じることはしない。

## 再現

リポジトリルートから、未作成の出力先を指定する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/compare_boot_seat_opening.py --imprint --out /tmp/boot-seat-comparison
```

`--imprint`を外すとv1の荷重面選択方法を再現する。
plan.jsonに事前条件、report.jsonに8ケースのエネルギー・変位・釣合いを保存した。
