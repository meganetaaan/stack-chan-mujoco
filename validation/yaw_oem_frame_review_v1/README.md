# ケース締結の構成比較

目的は「8 mmねじの掛かり不足を、部品適合を維持してどう解消するか」。追加応力解析は行わず、ねじ長・座面・純正フレームの3案を比較した。

| 案 | 公称寸法上の効果 | 判断 |
|---|---|---|
| 現状棚3 mm＋指定M2×8 TAP | ケース下穴への進入0.5 mm | 製造リリース不可。先端形状/公差控除前でも小さく、保持根拠なし |
| 棚のねじ座面を2 mm下げ、残り1 mm＋同ねじ | 進入2.5 mmへ増える | 樹脂残厚1 mmの座面抜け/クリープが新しい不確実性。単純な座ぐりだけの案は優先しない |
| 棚3 mm＋M2×10相当 | 進入2.5 mmへ増える | ROBOTIS S3 M2×10は検索で見つかったが、X330指定TAPとの互換性を確認できない。採用品へ追加しない |
| 純正FPX330-S101を介して固定 | 指定フレームの締結構成を検討できる | 次の比較候補。現行棚の直置き代替として自動的に適合すると扱わない |

2.5 mmは幾何計算値であって合格に必要な掛かり長ではない。比較のために保持基準を新設していない。前面・背面の内部通し長、ねじ先端不完全部、引抜き許容、繰返し組立は別に評価する。

## 純正フレームの図面

メーカーのダウンロード一覧からFPX330-S101図面（Mar-19-21、FOR REFERENCE ONLY）を取得。原図PDFとURL/SHA256を保存。幅28.6 mm、長さ34 mm、高さ7 mm、断面に内側23 mm、別方向の取付穴間隔30 mmを示す。平板の代用品ではなく側壁・耳・リブを持つ形状。現行の16×30 mm背面4軸へそのまま重ねる穴配置ではないため、ケースとの指定接続面と取付方向を先に確認する。

同じX330用でも、フレームを付ければ背面ねじの不確実性が自動的に消えるわけではない。次の検討はメーカーSTEPと取付説明による接続の照合1案まで。現在の外形/工具/脚軌道に入らない場合は採用せず、ケース座面を金属部品で支える別構成との比較へ進む。樹脂1 mmへ薄肉化した解析を先行しない。
