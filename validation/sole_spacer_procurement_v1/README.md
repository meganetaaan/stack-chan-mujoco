# 足裏固定スペーサーの調達寸法照合

2026-09-21。対象は `../sole_wide_seat_v1/cad` の外径6、内径2.3、厚さ0.9 mmの独立スペーサー。足裏の公称貫通穴径は6.4 mm。解析上の剛体座面が通ったことを、調達部品の適合証明に置き換えない。

## 候補と判定

- [Accu HPW-M2-V2-A2-BL](https://www.accu.co.uk/api/product-datasheet?id=407083): 商品名は外径6 mm、同じデータシートの寸法表は7 mm（+0/−0.36）。内径2.2（+0.14/−0）、厚さ0.9（+0/−0.2）mm、A2ステンレス。記載が矛盾するため選定保留。寸法表の範囲6.64–7 mmでは現在の穴に全数入らない。半径方向干渉は0.12–0.30 mm。商品名を根拠に6 mmとしてCADへ登録しない。
- [Hardware Specialty 951289](https://www.hardwarespecialty.com/Product/951289): 商品表示はM2、内径2.2、外径7、厚さ0.6–1 mm、ステンレス。外径7 mmなので現行穴への直接置換不可。Accuの記載矛盾を解消する証拠としては扱わない。
- [Aspen ME380 M2](https://www.aspenfasteners.com/m2-din-9021-iso-7093-metric-fender-washers-a2-stainless-steel/): 外径6 mmの公称表示を検索で確認した候補。ただし今回取得したページ本文から厚さ・公差を確定できていない。調達承認・解析材料登録は行わない。

この調査で外径6 mm金属スペーサーが市場に存在しないとは結論しない。部品発注・問い合わせは行っていない。

## 次の設計判断

確定した公差をもつ6 mm製品、または加工図で寸法を指定する部品を選ぶ。7 mm品を使う場合は足裏穴拡大に加えて保持部の横荷重、残り肉厚、工具・組立経路、座面の接触解析を再評価する必要がある。現在の6 mm座面解析はそのまま転用できない。

採用前に外径・内径・厚さ・平面度・端面処理・材料特性の根拠を揃え、ねじ頭寸法と合わせて床面への突出余裕を評価する。厚さ0.7–0.9 mmなら公称頭高さ1.3 mm、足裏厚さ3 mmに対する沈みは0.8–1.0 mmだが、他の公差・TPU圧縮・摩耗は未配分なので合格判定ではない。締付力20 Nも仮定のまま。

再現: `python3 validation/sole_spacer_procurement_v1/check_fit.py`。結果は `fit_report.json`。判定条件は穴径から外径を引いた隙間が非負であること。製造公差未確定の穴には公称値のみ使用した。この段階でIssue #17–20の完了は主張しない。
