# 純正側面フレームのヨー配置確認

FPX330-S101をケース側面へ置く1案を確認。図面の内幅23 mmをケース前後Z=65..88に合わせ、フレームの長手をロボットXへ向けた。耳の穴軸がケース16×30 mm配置に対応する寸法上の仮説。左右各2枚、計4枚についてサーボ形状との体積交差0。ただし実ねじ・工具・メーカー組立説明との完全照合ではない。

現行の穴付き支持棚とは各266.85629 mm³の体積交差がある。**現行棚へ純正側面フレームをそのまま追加する案は不合格**。フレームを使う場合は棚を別の支持形状へ変更し、フレーム側面の接続穴から胴体へ荷重を伝える構造が必要。干渉部分を単に削るだけでは荷重経路がなくなるおそれがあり、形状切除だけの合格化は行わない。

メーカー国内販売ページ https://e-shop.robotis.co.jp/product.php?id=436 は品番903-0301-000、X330用側面フレームとし、付属品に本体用PHS M2×8 TAP、ホーン用PHS M2×4 TAP、フレーム用M2×4とM2ナットを区別する。付属ねじの存在は、このロボットでの荷重許容を保証しない。次の候補ではメーカー取付構成を維持したケース接続と、胴体接続の2経路を別々に検討する。

範囲：最終静止姿勢の4枚対ケース/支持のみ。配線、全身干渉、組立経路、フレーム許容荷重は未確認。採用BOMには昇格しない。今回の1案で比較を終了し、同じ位置の追加サンプリングはしない。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_yaw_oem_side_frame.py --out validation/yaw_oem_side_frame_repeat
```
