# SHDNの初期OFF用抵抗候補

左右PERMIT端子からGNDへ100kΩ（TNPW0603100KBYEA）を各1個追加した。
既存`manual_rearm_resistors_revI.json`の型番を再利用し、コントローラ近傍へ置く候補。
SHDNを浮かせた状態から進めたが、駆動側受信回路は未設計なので初期OFF保証ではない。

LTC4365 Rev.BのSHDN下降しきい値最小0.4V、漏れ±10nAの記載を比較に使う。
抵抗総合±1%を仮置きするとRmax=101kΩ、IC漏れだけの比較電圧は1.01mV。
外部から流れ込む電流を含め0.4V未満とする追加漏れ予算は3.9504µA未満となる。
この数値は受信部品を選ぶための制約であって、実受信部の漏れを測った値ではない。

ICの漏れ試験条件はSHDN0.75V、VIN34Vである。無給電時や電源立上りに
同じ値を無条件で当てはめない。駆動側の電源OFF時の漏れ・保護ダイオード、
容量結合、断線、抵抗温度・寿命、ON時の駆動能力を実回路で照合する必要がある。
静的な抵抗式を起動過渡シミュレーションの代わりにはしない。

## 専用受信バッファ候補

[Nexperia 74LVC1G17GV Rev.16.1](https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf)
を左右各1個追加。入力は既存POWER_ENABLE_COMMAND、出力は各PERMIT、電源はAUX_3V3。
各バッファに既存候補GRM31C5C1H104JA01Lの100nFを付ける。
NC端子をGNDへ仮接続せず、接続データで明示的な未接続とした。

電源OFF漏れ規定±2µA（VCC0V、VIまたはVO5.5V）を前回の比較に追加すると、
(2µA+10nA)×101kΩ=0.20301Vで、0.4V未満の比較予算に収まる。
ただし試験点から低電圧・立上り途中の漏れ保証へ拡張しない。
出力HIGH時の100kΩ負荷は3.3Vで約33.3µA（Rmin99kΩ）で、
資料の100µA負荷の出力電圧規定を使う範囲に収めやすい。
実AUX電圧範囲・受信しきい値・電源シーケンスとの整合は未完了。

共通POWER_ENABLE_COMMANDにバッファ入力2個分が追加されるため、
既存駆動回路の静的負荷と立上り検査も更新する。SHDNの局所プルダウンだけでは
バッファ入力が不定の状態を防げず、上流の初期状態保証は別途必要。
この追加は手動許可・起動監視が完成したという意味ではない。
