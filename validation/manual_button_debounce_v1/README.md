# 手動再許可ボタンのデバウンス候補

MAX6816EUS+Tを再許可ボタン専用の評価候補とする。[メーカー資料](https://www.analog.com/media/en/technical-documentation/data-sheets/MAX6816-MAX6818.pdf)、19-4770 Rev8、pp2/4/5。2.7–5.5 V給電、開閉両方向のデバウンス時間20〜80 ms。3.3 Vロジック側へ置き、サーボバスへ直結しない。供給/小口発注可否は未確認。

入力は内部プルアップとGNDへ閉じるNOボタンを使う候補。出力は押下Lowなので、正エッジDFFへは**極性反転段が必要**。出力を直接CLKへ接続すると解除で投入する回路になり、要求を満たさない。反転段は未選定で、出力High下限と受信入力しきい値を負荷条件で照合する。

UVLO中は入力がデバウンスなしで出力へ伝わる。したがってデバウンス部品を追加しても、電源立上り・低下時にラッチのクリアを維持する外部回路が必要。起動出力が必ず80 ms遅れると仮定してはならない。電源/監視が有効になり、ボタンの安定解除を確認した後に再許可受付へ進む。実回路のリセット解除とCLKとのタイミングを別途確認する。

## 採用条件

- この20〜80 ms遅延を停止要求や故障遮断の経路へ入れない。停止は独立した優先経路で処理する。
- ボタンの実バウンス、断線、GND短絡、電源再投入時押しっぱなしを試験前条件へ含める。
- 押下パルスが短い場合は受理されない仕様として扱い、UI/試験手順を合わせる。具体的な操作時間は部品最大遅延と回路条件から決める。
- ロジック電源の低下中は入力整形・出力段が不定になり得るためENを既定オフへ保持する。
