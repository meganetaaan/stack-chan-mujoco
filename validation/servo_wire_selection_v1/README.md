# 個別給電線材の机上選定

2026-09-21。追加回路シミュレーションなし。終了条件は線材1候補の端子寸法・曲げ・電圧降下を確認し、試験用か全身用かを区別すること。

## 判断

Alpha Wire 3051（AWG22、7/30錫めっき銅、PVC）を**固定配線の単関節治具用候補**にする。歩行中に繰返し曲がる全身ハーネスとしては未承認。3051の曲げ半径指定は繰返し寿命の保証ではない。予備候補5851はAWG30かつ被覆外径が対象端子下限未満なので、この電力配線候補から外す。

3051の被覆外径は0.062±0.002 inch = 1.524〜1.6256 mm、SEH-001T-P0.6の1.0〜1.9 mm内。公称AWG22も適用範囲内。ただしAWG呼称だけで圧着を確定せず、撚線断面・圧着高さ・工具の組合せを確認する。Alphaのカタログ断面表記とJSTのmm²上限の丸め差もあり、圧着工程の承認は残す。

資料の10倍径の曲げ半径に従い、最大径から半径16.256 mm以上を治具配線の設計入力とする。可動関節内に無理に収めず、固定側で余長と引張逃がしを持たせる。105℃という線材温度表記をEH接点を含む組立全体の温度定格に使わない。

## 電圧降下と必要な確認

メーカーの20℃公称抵抗16.2 Ω/1000 ftから0.0531496 Ω/m。片道250 mm（**治具の計画長、CAD実測長ではない**）ならV+/GND往復0.0265748 Ω。サーボ側の接点2個に環境試験後20 mΩ/個を置くと合計0.0665748 Ω。1 Aという比較点で降下66.575 mV、0.10 V予算から33.425 mVが残る。

これは公称値による構成比較で合否保証ではない。抵抗公差・温度・共通幹線・遮断器・リップルは未算入。実際の最大DC電流と最大線温度が決まる前に、全身給電や1 A制限の成立を承認しない。片道250 mmを満たすためにケーブルを張り詰めたり、可動域を減らして通さない。

この段階の設計判断は、両端EH着脱より、分配側直結・片端EHの方が電圧予算を残せること、3051は固定治具で評価候補になること。全身可動配線の品番は別途、繰返し屈曲/曲げ半径と実CAD経路から選ぶ。

## 次の部品確定条件

- 3051の色/梱包を含む注文コード、供給性、圧着工具・適合線径を確認。
- 接点や線材の公称抵抗を保証上限とせず、調達仕様と試験条件で上限を固定する。
- #49で組立抵抗、端子電圧、接点温度、引張保持を確認。仕様資料の欠落は机上側に残す。
- 全身用は曲げ包絡・線長・重量を#19/#20へ戻す。今回の治具候補をそのまま可動部BOMへ昇格しない。
