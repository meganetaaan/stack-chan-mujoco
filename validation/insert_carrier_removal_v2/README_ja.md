# 115部品胴体の顔ユニット取り外し経路

側面4ねじを外し、Tab5・枠・4インサート・Tab5固定ねじ4本の計10部品を前方（+X）へ40 mm平行移動する。固定101部品との1,010組を検査し、外接箱で1,005組を除外、5組を詳細検査した。交差フラグ・形状エラーは0、詳細検査の最大単片交差体積は0 mm³。参照した115部品STEPと部品表のハッシュはreport.jsonに保存。

検査前の条件と終了条件はplan.json。固定部品を逆方向へ掃引した領域を元ソリッドと境界面の押出しで表し、移動開始位置の部品との交差を調べる。単位立方体の掃引と解析的直方体との対称差体積0も確認した。公称形状に対する連続経路の検査であり、離散姿勢のみの検査ではない。

0.01 mm³は数値判定閾値。外接箱との交差が閾値以下の組を除外し、詳細側は各掃引片に閾値を適用する。片ごとの値は和集合の交差体積上限ではなく、最小隙間も測っていない。reportのnominal_path_clearはこの限定した判定を示す。

Tab5固定ねじを残す手順の幾何候補で、Tab5内部のねじ深さ/接触や締結成立を証明しない。移動ユニット内部の未解決交差は元の胴体検査から継続。配線・コネクタの切離し、手工具、造形公差、たわみ、保持能力は対象外。全脚動作や製作・整備手順の承認でもない。製作HOLDを維持する。
