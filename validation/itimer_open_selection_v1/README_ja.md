# 過電流ブランキングの選定

左右TPS259813LRPWの10番ITIMERは外付けコンデンサなしを試作候補にする。資料5ページは開放を最速応答の構成として認める。既存統合回路でも各ITIMERネットの端点は当該ICの10番のみであり、他部品・明示配線への接続がないことを確認した。電気的な接続変更ではなく、未選定だった端子の扱いを明確化したもの。

選定理由は、通常動作の短時間過電流を許容する必要時間が根拠付きで決まっていないため。電流閾値・性能基準を緩和するものではない。通常歩行・旋回で誤停止しないことや短絡のエネルギー成立は未確認。

TPS25981 SLVSGG6Dの9ページに記載された開放時1.8 µsは典型値で、条件はIOUTがILIMを30%超過してから出力低下まで。最大時間としては使えない。将来コンデンサを追加する場合も、容量、放電電流、電圧差の最悪組合せと遮断遅延を含むエネルギー確認を先に行う。

出典：https://www.ti.com/lit/ds/symlink/tps25981.pdf
再現：

```sh
python3 software/sim/circuits/check_itimer_open_selection.py --out /tmp/itimer-open-check
```

当面はITIMERの容量掃引を行わず、未完了のゲート駆動・回生吸収・OVLO端子保護を進める。PCBでITIMERへ不要なテスト配線や容量を追加しない。既存assembly.jsonの「Timer passive not selected」は本選定によって更新されるが、故障エネルギーの未確認は解消しない。
