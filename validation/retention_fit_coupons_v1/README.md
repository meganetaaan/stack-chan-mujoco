# 足裏固定の局所嵌合試験片

#48のM0へ渡す未実施の試験片データ。隙間0.20/0.35/0.50 mmの各組について、ヨーク相当板とTPU頭付き軸のSTEP/STLを出力した。全身の部品CADは変更していない。

- ヨーク相当：26×16×3 mm。実候補と同じ軸半径2.8 mm/頭半径4 mm/頭厚1.5 mm/スライド8 mmを使う。
- STEPは共通組立座標。STLは各部品の最低面をZ=0へ移動済み。STLをそのまま組立位置の検査に使わない。
- `.20`は既存局所嵌合寸法を再現。`.35`と`.50`は隙間比較用で、完成機への採用案と決定したものではない。
- 径方向と軸方向隙間を同時に変えているため、試験前に径/高さを別々に測り、組立成否だけで原因を推測しない。
- 板は選定するヨーク材料/造形条件、軸はTPU材料/造形条件を記録。試験片を造形しやすい向きへ変えた場合は実部品と同じ工程の証拠にしない。頭下面のサポート除去/仕上げの有無を記録する。

## 未実施の評価手順

1. 各組を識別して別保管し、使用したファイル、材料、積層、実寸、計器精度、仕上げを記録する。
2. 大穴へ軸を挿入し、8 mmスライドする。強い変形を伴う押込みで寸法不一致を隠さない。挿入/移動の可否と引っ掛かる位置を記録する。
3. 完成位置での縦/横の遊びと頭の掛かり代を実測し、隙間を増やすことの保持への影響を記録する。
4. 初回各1組は寸法傾向の探索に限定。工程公差能力の保証には複数造形・再現性の評価が必要。失敗した組も保存する。

終了条件は、現公差の解釈を修正する根拠か、寸法変更の方向を決める根拠を得ること。局所嵌合成功から全足裏の脱落強度・クリープ・疲労・ハーネス干渉を合格にしない。滑り止めねじを省いた試験片なので保持力のM1試験には使用しない。
