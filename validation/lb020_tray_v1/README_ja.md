# LB-020用トレー形状候補

## 結果

24×70×36mmの電池包絡を中心(29,0,80)mmへ配置する横向き案。
既存取付軸(29,±61.2,63)mmを保持した新トレーを作成した。
事前条件はplan.json、判定値はreport.json、形状はtray.stepとbattery.step。

- トレーは有効な単一ソリッド、体積6752.795mm³。
- 電池との体積干渉0、他98部品との0.01mm³超の体積干渉0。
- 胴体外接範囲は変更前後ともX −67.7..64、Y −64..64、Z 0..128mm。
- 電池中心と取付軸を保持し、底面を62mmへ下げた。床・壁1.5mm、壁高さ8mm。
- 旧接続腕の電池側突出を空洞加工で除去。連結性は確認したが、その断面強度は未確認。

この範囲では外形を増やす必要はない。脚動作と干渉しないことまでは証明していない。
両側0.7mmの隙間は設計仮置きで、メーカーの寸法公差・膨張許容・造形精度に基づく合格値ではない。
トレー単体のCADのみで電池を拘束できるとは扱わない。

## 正式採用までの残件

脱落防止ベルトとアンカー、取付ねじ/相手材/締付け、電池端子と配線出口、挿抜経路を具体化する。
TPUを使う場合は緩衝材としての厚さ・硬度・圧縮を別途定め、電池を過大に締め付けない。
次の解析は固定方式の確定後に行い、ベルト荷重による壁・腕の破損、保持力、変形干渉を評価する。
固定が未確定な段階ではFEを追加しない。
LB-020のPCM遮断・復帰仕様も未確認。現行の正式トレー・電池・質量台帳を置換せず、製作HOLD。
