# インサート付きTab5枠の連続抜取り経路

111部品の胴体から側面ねじ4本を除去し、Tab5・枠・インサート4個を一緒に+Xへ40 mm移動する公称経路を確認。残る101部品との606組のうち601組を保守的外接箱で除外、5組を形状で詳細検査した。体積干渉フラグ・形状生成エラーはいずれも0。

離散位置だけの確認ではない。移動部品を初期位置へ固定し、障害物を−Xへ掃引した領域と比較する。領域は元ソリッドと全境界面の直線押出しで覆う。押出し片ごとに交差体積を検査するため、レポートの最大値は和ではない。公称干渉フラグの閾値0.01 mm³。単位立方体を2 mm移動した場合の掃引が3×1×1 mm直方体となる独立例で生成方法を照合した。

これは寸法候補の移動経路の確認。インサートの抜け/回転、印刷公差、枠のたわみは含まない。枠は圧入後の近似形状で、Tab5も簡略CAD。Tab5対枠の別の取付ねじ4本は未モデル化であり、Tab5と枠が剛に保持されることをこの解析で保証しない。電源/通信ケーブル、手、工具、新電源基板も対象外。

取り外し順の候補は、停止・電源切離し後にケーブルを外し、顔と枠を支持して側面4本を外してから前へ引き出す。停止・ケーブル・支持操作は手順候補で未検証。電池交換経路は既存`lb020_service_path_v1`を参照し、配線/取付ねじを追加した際に一連の手順を再確認する。
