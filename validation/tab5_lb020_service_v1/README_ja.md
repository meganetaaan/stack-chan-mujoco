# Tab5取り外し経路と取付情報の照合

## 結論

Tab5を前方へ17mm移動する包絡は、LB-020電池・新トレー・2本のベルトを含む101部品と公称体積干渉なし。
最小隙間は外装との0.4mm。これは固定具・配線・工具を含む着脱成立の証明ではない。
電池交換の候補順序はTab5固定解除→前方退避→電池ベルト解除→電池9mm持上げ→前方引抜き。
固定解除と電気的切離しの手順は未確定なので、現物向け作業指示として使用しない。

## メーカー仕様とCADから分かることの区別

[Tab5公式資料](https://docs.m5stack.com/en/core/Tab5)は側面1/4″-20三脚ナットを明記。
今回確認した本文では、各取付穴の深さ、締付けトルク、許容荷重を確定できない。
Tab5 Keyboardなど別製品のM3記述を本体に流用しない。
CADは12×128×80mmの外接形状、平面16面・円筒13面を持つ。
円筒の半径・軸位置・方向をreport.jsonへ抽出したが、ねじ種類・有効深さの証明には使わない。
円筒面には外形丸み等も含まれ得るため、13面を13個の取付穴とは解釈しない。

次の固定設計では側面の明示された取付インターフェースを候補にし、底付き防止とねじ解除工具の経路、
回り止めを具体化する。必要寸法・許容値の根拠が揃わない部分は確定図面として出さない。
ねじを使わず外周で拘束する場合も、画面・端子・ボタン・ケースへの荷重を評価する必要がある。

## 検査範囲

plan.jsonの条件に従い、Tab5外接直方体の連続掃引を作成。各保持部品を個別に検査した。
正の体積干渉閾値0.01mm³。Tab5背面X52→69mm、終端で胴体前端64mmを5mm越える。
この5mmは終端条件、0.4mmは公称CAD値であり、公差・変形込みの合否基準ではない。
配線の抜差し・余長・端子位置、手の支持、ねじ/工具、未配置保護基板は評価外。
同じ包絡検査の反復は終了し、固定部と配線の設計を次の対象とする。製作HOLD。

再現：`LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_current_tab5_removal.py`。
