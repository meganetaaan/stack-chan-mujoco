# 前端棚板の下側増厚：干渉により棄却

変更前に、外形不変、固定部品・メーカーサーボ形状との追加干渉0.01 mm³以下、
既存ポート通路まで1.3 mm以上を条件として一形状だけ検査した。
前端X=-7.9..11.6 mm、Y=中心±18 mm、Z87..89 mmへ2 mm厚を追加し、
既存形状とねじ逃げを維持した。正式候補v5を比較相手とした。

左右とも単一ソリッド・外形維持・ポート通路1.3 mmは満たすが、
取付板との追加重複589.386 mm³、メーカーサーボ形状との重複179.275 mm³がある。
この2値は相互に重なる領域を含み得るので合計しない。
追加体積997.073 mm³は使用可能な補強体積ではない。

結論：形状案を棄却。FE、細分化、質量モデル更新、正式候補への採用は行わない。
支持部の下側を単なる空き領域と扱えない。取付板と支持部を含めた接続構造を
見直す必要がある。サーボ外形を削る、干渉部を黙って除外する、許容変位を緩める
対処は行わない。部品を統合する場合もサーボ・コネクタ・組立順・ねじ保持・
荷重分配を再定義してから構造解析する。

この結果は他の全補強方法が不可能である証明ではない。実機試作HOLD、Issue未完了を維持。
