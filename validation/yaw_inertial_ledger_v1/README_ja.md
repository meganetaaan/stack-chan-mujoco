# ヨー支持部変更後の質量・慣性の加算台帳

旧モデルの部品別割当、選定金属板、ねじカタログ質量、密度未設定のCAD体積を一つの台帳へ統合した。**全身モデルの更新・荷重評価の完了ではない。**

旧胴体・背面カバー・左右ヨー支持部と25 gの配線締結予約を除外し、保持する旧割当と金属板5点を加算した部分質量は418.959449 g。ねじ20本のカタログ質量12.36 gを加えた部分質量は431.319449 gとなる。造形部品・ワッシャー・ナット・未集計配線等を含まないので、これを胴体質量、保証下限、全身質量として使わない。保持した電池・電子部品等の予約も依然として条件付きである。

各部品の重心回り慣性を直接加算せず、共通の胴体CAD原点回りへ平行軸変換した。質量、一次モーメント、原点回り慣性を保存し、最終部品が揃ってから全体重心と重心回り慣性を求める。旧モデルの全成分から元の集計を独立に再構成し、誤差は質量1.12e-16 kg以下、一次モーメント0、慣性8.68e-19 kg m²以下だった（数値整合確認の閾値1e-12）。これは強度や物性の実証ではない。

新規52部品の内訳は、金属板5点、密度係数を保持した造形部品3点とワッシャー16点、質量だけ判明したねじ20本、質量も未確定のナット8点。造形を一様密度で扱える場合に限り、19点の係数へ選定密度を掛けて加算できる。インフィルなどによる非一様な材料配置には流用しない。ねじの衝突用包絡形状から慣性を逆算することも避けた。

次に必要なのは造形仕様、ワッシャー材質、ナット質量、配線・残りの締結部品の内訳と配置である。全身モデルを更新するには、脚・足の変更も別途照合する。これらが埋まるまでは未知値を0にしてMuJoCoへ出力しない。未定の全質量・慣性はJSONでnullとしている。

再現：`.venv-engineering/bin/python software/sim/structural/build_yaw_inertial_ledger.py --out /tmp/yaw-inertial-ledger-check`（未作成の出力先）。旧モデル、金属板集計、現行部品表の参照ハッシュを検査する。#17・#18の荷重更新に向けた入力整理であり、完了条件の変更はない。
