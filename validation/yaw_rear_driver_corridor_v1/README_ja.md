# 背面ドライバー連続接近経路

## 判断

52部品のヨー支持revAに対する背面8方向、刃／柄それぞれの連続直線接近包絡を確認。対象ボルト自身を意図したかみ合いとして除外した816比較で、包絡の最小隙間下限1.70 mm、従来0.90 mm基準を満たす。この範囲では支持形状変更を要しない。工具・ねじのかみ合い適合を含む組立全体の承認ではない。

## 仕様と仮定

- Wera 05118070001：2.5 mm六角、刃径4 mm、刃長60 mm、柄長97 mm、全体157×13×13 mm。メーカー資料（2026-09-21確認）：https://hybris-media.wera.de/download/pdfgenerator-datasheets/en/05118070001.pdf
- 比較用Accu SSCF-M3-16-12-9：六角2.5 mm、深さ1.3 mm、頭高さ3 mm、頭径最大5.68 mm。https://www.accu.co.uk/metric-cap-head-screws/16007-SSCF-M3-16-12-9
- このボルトは12.9級で、現行の8.8級候補とは別。採用変更ではなく深さ1.3 mmを使う比較。現行CADの頭径5.5 mmと最大5.68 mmの差も未統合。
- 0.90 mm隙間、うち合計0.40 mm公差予算は従来のCodex仮定。メーカーの実寸公差保証ではない。

工具を回転包絡の外接直方体で囲い、後方で工具全体が組立外となる位置から差込み位置までの連続移動を包含する。形状間の距離は外接箱距離による下限で判定する。自ボルトだけを幾何位置で一意に識別し除外した。ソケットに丸軸が入るというモデルではなく、かみ合い検証を明示的に別扱いにした。対象ボルト以外への工具空間は保守的に評価する。

## 終了と残件

この固定した経路比較は終了。追加の経路サンプリングや支持切削は行わない。次に採用ボルトの型番・頭径公差・ソケット仕様と工具先端有効長、組立トルクを確定する。未収録の胴体隅固定品・サーボ・配線、作業台や手の空間は本結果に含まれない。保持強度の証明にも使わない。#17/#19の完了条件未達は維持する。
