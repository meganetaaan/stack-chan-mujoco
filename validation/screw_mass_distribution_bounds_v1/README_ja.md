# ねじ20本の条件付き質量分布範囲

メーカー公称質量の合計12.36gと、現行CADの包絡箱を使う。箱内の非負の任意の質量分布について、一次モーメント・原点慣性の各成分の上下限を解析的に求める。干渉用形状を均一密度として重心・慣性の一点推定を作るものではない。

各座標の区間と二乗・積の区間から積分を囲む。慣性の非対角成分には負符号を含める。各成分の端点は同時実現できるとは限らず、そのままMuJoCo慣性テンソルとして入力しない。固定seedの任意分布400組について直接積分との包含を確認した。これは式の数値照合であり物理範囲の保証ではない。

重要な未確認事項：公称CAD箱は実ねじの製造公差を含む保証包絡ではなく、公称質量にも保証幅がない。本結果を実機の最悪条件とは扱わない。製造寸法包絡・質量幅の確定後に同じ区間計算で更新する。製造承認・全体モデル更新は保留。

再現：

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/bound_screw_mass_distribution.py --out /tmp/screw-moment-review
```
