# UBECの型番と製品寿命の照合

30603000は中国語メーカー製品ページで5Vを含む4設定・10A/20Aと確認。
同社の生産終了一覧にSTOPPEDとして掲載されている。
北米の同じページ見出しの商品は30603003、UBEC10A-Car、6/7.4/8.4Vである。
従来の「地域ごとの仕様矛盾」は少なくとも今回のページでは別型番の混在だった。

30603000の旧CAD・質量・解析は比較履歴として保持。新規調達の確定品と扱わない。
在庫の有無は未調査で、生産終了から購入不能とは断定しない。
代替品は5V・入力範囲・連続電流・過渡・逆流／回生・保護・寸法・質量を別途選定する。
30603003の6Vを旧5V設計へ無変更で接続する案は採用しない。

出典と確認日はreport.json。購入・問い合わせ送信は行っていない。
旧シミュレーションや台帳の入力ハッシュは当時の状態を表すので書き換えない。
今回変更する供給候補JSONは製品寿命・判断のメタデータで、旧比較値は保持する。
