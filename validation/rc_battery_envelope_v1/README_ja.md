# 3S候補電池と旧予約スペースの比較

旧予約20.5×70.4×38.4mmに対し、候補電池は60×30×22mm。
軸に平行な6方向を列挙すると、全方向で旧予約を超える。
最小変更となる配置はX/Y/Z=22/60/30mmで、X方向に1.5mm増える。
旧中心(29,0,80)mmを保持した包絡はX18–40、Y−30–30、Z65–95mm。
同じ中心での厚さ増加は前後各0.75mm。掲載公称質量の差は−27g。

これは空洞・トレイの干渉検査ではない。予約を超えることだけで胴体に入らないと
判定せず、逆に体積減少だけで入るとも判定しない。斜め配置の探索は行っていない。
配線出口・XT30とバランス端子・公差・膨張余裕・緩衝材・ストラップ・取出しを含まない。

設計判断：旧トレイの流用は未承認。上記向きを次の実形状干渉検査の初期配置とする。
脚長や胴体外形を変更せずに、トレイと保持部を調整できるか確認する。
−27gだけを全身質量へ適用せず、トレイと保護・配線の更新も合わせて扱う。
