# ナット後挿入用の側面開口候補

足裏固定ボスの+x側へ幅4.4×高さ1.8 mmの開口を設けた。ナットの底側支持面を残し、造形途中の封入に依存しない組立案にする。左右STEPを保存。完成機の外形・脚長を拡大しない。

公称最大包絡4×4×1.2 mmナットをx+8から0まで1 mm刻みで移動し、左右ともヨーク/ブーツとの重複体積0を確認した。両ヨークは有効な単一ソリッド。除去体積は各14.256 mm³。これは9姿勢の公称検査であり、連続経路・公差・指/工具のアクセスを保証しない。

## 組立候補

ねじとスペーサーを外した状態でナットを側面から挿入し、ねじ軸に合わせ、スペーサー/ねじを下から組む。ねじが入った状態ではナットの並進が制限されるが、ねじが完全に緩むと脱落可能。ねじ緩み対策・締付け保持は未確定。交換は逆順。

この案では側壁の一部を除去するため、閉じたボスの既存FE結果を流用して強度合格にしない。ナット座の曲げ・開口端の割れ・回り止め・実締付けでの変形を次の判断量にする。材料/予圧根拠が不足するため、この時点でメッシュ解析を追加しない。

先に解く条件は室幅の製作公差、開口のブリッジ造形、ナット保持工具のアクセス、取り付けたねじの保持。既存の±0.20 mm境界公差で隙間が保証できない問題は残る。寸法案を採用しただけで#17〜#20を完了にしない。

