# 電流監視の給電ドメイン

**履歴：負荷側LDO入力案は起動循環のため撤回。現行は`../brake_sensor_startup_dependency_v1/README.md`の上流入力案。以下は当時の判断を保存する。**

2026-09-21。INA180A1の供給はサーボバスへ直結しない。推奨上限5.5 Vに対し現検出器の静的開始上限比較は5.568862 Vで、過渡以前に範囲外となり得る。絶対最大6 Vを通常動作の保証に使わない。

一次資料：[INA180](https://www.ti.com/lit/ds/symlink/ina180.pdf)、SBOS741H、§7.1/7.3/7.5。動作給電2.7–5.5 V。センサーの入力共通モード範囲と給電範囲は別であり、入力が高電圧対応でもVSを高くできるとは限らない。

## 給電案

各枝にTPS70933DBVRを追加し、負荷側サーボバスからSENSE3V3_A/Bを生成する。電池側AUX3V3とは接続しない。独立したLDOを置いても共通バス/GND故障への独立性はない。吸収指令用TPS3700とゲートドライバは元のバス給電を保ち、このセンサーLDOを共通依存点に追加しない。

[TPS709](https://www.ti.com/lit/ds/symlink/tps709.pdf)、SBVS186H。ENは内部バイアスで有効にでき、VINへ接続しない。局所入出力コンデンサーを部品条件どおり選定する必要がある。既存の電池側LDOの過渡モデルを、入力源・負荷・容量が異なるこの構成へそのまま流用しない。

センサーに電源が入っているだけでは出力の有効性を証明しない。3.0 V以上という旧監視開始条件は設計配分であり、LDO/監視ICの公差・起動時間・センサー整定を含む有効信号を実回路で作る必要がある。起動中や電源低下中は電流値を正常判定へ使わない。

## 遮断との関係

- 監視電源が不正なら、新たな主電源投入を許可しない。
- 運転中の監視喪失は保護機能喪失として停止要求へ渡す。電流ゼロと置換しない。
- 電源喪失を検出する回路・停止ラッチまで同じLDOだけに依存すると、停止要求も失われる。上流側の既定オフ遮断・再許可回路との接続が必要。
- 上流遮断後も回生吸収用の検出器/ドライバは負荷側で動く。センサーLDO追加は分岐切離しや抜線後の吸収経路を解決しない。

この審査は給電適合とドメイン選択で終了。センサーLDOの短絡/過電圧故障、コンデンサー、出力負荷、過渡、監視器・ラッチ接続は未確認。完成回路表へのピン統合前に、実部品と有効信号を確定する。#22/#24は未完了。
