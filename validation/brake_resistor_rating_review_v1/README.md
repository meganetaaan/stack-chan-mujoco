# 回生抵抗候補の定格照合

Vishay AC10・4.7 Ωを各枝1本、計2本の候補として整理。メーカー資料28730（05-Dec-2024）p1のP70=8.4 Wと、保存済み遅延回生試験の主枝ピーク6.0315 Wを照合し、この限定比較は定格内。記録した1回0.0812168 Jだけからパルス耐量を推定していない。副枝がほとんど消費しなかった結果をもって、半分の定格を選ばない。

6 V・初期公差−5%の4.465 Ωで、スイッチ抵抗を無視したV²/R上限は8.06271 W。8.4 Wまでの余裕は小さく、温度・経時変化・過渡オーバーシュートを加えた最悪保証ではない。巻線インダクタンスも未モデル化。

メーカーp10の本体最大44×直径8 mm、単体4.5 gから、2本で9 gの追加質量となる。リード形成と樹脂部品への熱距離を含む配置は未実施。定格照合は密閉筐体での熱成立を意味しない。最終型番・調達・搭載・連続故障・繰返し・発熱を確認するまでBOM確定とはしない。
