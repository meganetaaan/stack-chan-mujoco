# ヨー支持・背面板の公称スタック統合

既存2 mm背面構造板と支持側M3×16締結を同じ座標で組み合わせた。旧外側座金は各5.881061 mm³、板に干渉。ねじ・外座金・六角レンチ予約をX方向−0.20 mm移し、板後面X=−64.2に着座させた。

8本ともねじ座面−64.7、ナット前面−50.6、公称スタック14.10 mm、ねじ突出1.90 mm。従来13.90/2.10 mmは旧カバーに対する値であり、この統合組立には使わない。M3×16の長さを変える必要は今回の公称チェックではない。

支持/板と各ねじ・座金・ナットの64組の交差体積は既存0.01 mm³基準以下。突出は既存公称1 mm基準以上。これらは設計スクリーニングであり、購入品のねじ公差・有効掛かり・締付け・強度・全身干渉・工具経路の合格ではない。支持側の外側部品が従来より0.20 mm突出するため全身外形/工具確認へ引き継ぐ。元の失敗形状・記録は保存した。

`yaw_plate_nominal.step` は板、左右支持、8組の締結のみ。四隅胴体締結、サーボ、配線、工具は含めない。製造図として利用しない。

再現（リポジトリ直下、未使用の出力先を指定）：

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/integrate_yaw_plate_stack.py --out validation/yaw_plate_stack_repeat
```

入力ハッシュ、事前plan、各ねじ寸法、各交差チェックはJSON/CSVに保存。追加FEなし。本寸法不整合の調査はここで終了し、購入締結品と全身統合へ進む。
