# 最新制御入力枝のメーカー過渡モデル用プローブ

41部品候補からTPS26600/TPS70933、入力分圧・制限/モード抵抗、100nF dVdT、直接接続された電源容量を生成した。9 V/12.6 Vの2ファイル。メーカーLIBのサブ回路端子順を読んで物理パッケージ番号との対応を照合済み。LIBは公開リポジトリへ再配布せずURL/ハッシュをmanifest.jsonへ保存。

**未実行。起動成功・保護合格の証拠ではない。** 作成環境のPATHにPSpiceは見つからなかったが、他のホストやGUI環境まで存在しないと断定しない。

TI提供モデル：
- https://www.ti.com/lit/zip/slvmbr3b ：TPS26600_TRANS.LIB、暗号化PSpice版Final1.2。
- https://www.ti.com/lit/zip/sbvm571 ：TPS70933_TRANS.LIB、Final1.10。

既存`validation/tps709_model_compatibility_v1`はngspice過渡解析が時間上限までに完走しておらず、数値設定の探索終了を記録している。今回、同じ試行は繰り返さない。暗号化モデルを別ICや理想スイッチへ差し替えて完走を装わない。

生成：

```sh
.venv-engineering/bin/python software/sim/circuits/export_pack_startup_pspice.py --efuse-zip /path/to/slvmbr3b.zip --ldo-zip /path/to/sbvm571.zip
```

対応PSpice環境で各LIBを回路ファイルと同じ場所へ置いて実行する。解析の終了条件は50ms終端まで完走し、入力・保護出力・3.3V・入力電流が有限値で保存されること。これは互換性/公称起動の確認段階で、次に波形と各レールの部品許容値を照合する。数値条件や部品値を合格させる目的で変更しない。完走不能ならログを保存して止める。

負荷は前回の部分電流予算から抵抗へ置換し、3.3V時だけ約11.041mAに一致する。低電圧時のMCU挙動・リセット順序は含まない。理想入力100µs、理想公称容量は接点/ESR/温度包絡ではない。eFuseモデルは温度依存を含まず熱遮断も電力/時間による簡略化、LDOモデルも温度・入力依存のグランド電流を含まない。最悪条件の適合は別途必要。
