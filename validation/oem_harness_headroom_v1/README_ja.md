# 純正ケーブルの配電端比較

両端EH案と片端EH＋配電側直結案を、旧0.10V予算で比較。片脚4.917A・XC330枝0.887Aのモデル条件では、接点4個とeFuseだけで112.263mV。線材抵抗をゼロとしても12.263mV超える。片端EHなら76.783mVで、残余23.217mVは線材・幹線・逆流遮断等の合計に割り当てる必要がある。

eFuseの8.4mΩは3A表条件からの比較で、4.917Aへの適用は仮定。3Aの行も保存し、定格条件と区別した。旧予算は旧変換器下限4.85Vからの値であり、UBECの出力下限を保証しない。動的負荷・実電流上限・全損失は未確認。

追加接点案の優先順位を下げ、純正のサーボ側圧着を維持し、配電端のみ切断して引張り止め付き直結とする経路案へ変更する。実際の切断・はんだ工程と加工後長さは未発行。線材抵抗を仮定して合格にはしない。
