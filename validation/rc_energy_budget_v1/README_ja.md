# 850mAh候補の歩行エネルギー予算

## 設計判断

現在の条件付き負荷モデルだけを理由に電池容量を増やさない。
一方、850mAhで実機10m歩行を保証できたとは判定しない。
Tab5等の電池側消費、実効変換効率、低電圧停止までの使用可能エネルギーを
同じ予算へ入れることが、容量選定を確定するための残件である。

ユーザー指定の10m・平均0.10m/sを境界速度で計算すると100秒。
これは1試行の設計比較点であり、20試行を無充電で行う追加要求ではない。
既存の理想ブリッジモデル上限9.834Aを5Vで100秒持続させると、
サーボ側49.17W、1.36583Whとなる。これは実機最大入力電流の保証ではない。

[HOBBYWING説明書](https://hobbywing.oss-cn-shenzhen.aliyuncs.com/pdf/pdfen/UBEC10A2-6S.pdf)
の効率90%以上という記載を比較値90%として使うと1.51759Wh。
電池の公称11.1V×0.85Ah=9.435Whの16.08%に当たる。
ただし条件を限定した効率保証、配線損失、実電池の使用可能容量を含む値ではなく、
残り83.92%を「保証余裕」と呼ぶことはできない。

## 完了させる予算

`E_usable >= 1.36583 / eta + P_aux / 36 + E_other`（Wh）

- E_usable：温度・劣化・負荷・セル別停止条件込みで使用可能な電池エネルギー。
- eta：サーボ分岐の変換と配電損失を含めた実負荷でのエネルギー効率。
- P_aux：100秒間のTab5・制御回路の電池側平均電力（W）。
- E_other：100秒外の起動・停止と、根拠を明示した予備分。二重計上しない。

ピーク電流、電圧降下、保護協調、熱の合格はこのエネルギー式と別に必要。
未知値を仮置きした追加シミュレーションで容量合格にはしない。
