# セル入力コンデンサ短絡の机上評価

## 結論

現候補は単一コンデンサ短絡時のセル放電を遮断できない。
CHG/DSGの主電源遮断だけでは、この故障に対するセル低電圧保護は成立しない。
抵抗の定格を上げるだけでは解消しないため、入力フィルタ候補の採用を保留する。

## 事前に置く判断条件

セル監視回路の単一C短絡について、継続放電の経路と部品損失を示し、
遮断を担う実部品または故障を封じ込める構成を特定する。
抵抗が焼損して開放することを、仕様のないヒューズ機能として信用しない。
これは設計側の単一故障評価条件であり、ユーザーが指定した数値ではない。

## 計算と接続経路

物理セル1〜3の各差動Cの短絡を個別に扱う。並列C2個のうち1個の短絡でも同じ経路になる。

`セル正極 → 上側入力抵抗 → 短絡C → 下側入力抵抗 → 同じセル負極`

4.2Vの固定電圧源と、初期公差−0.1%の22.1Ω抵抗2個を使う。
I=V/(2R)=95.1177mA、各抵抗P=I²R=199.747mW。
同一抵抗2個の解析であり、全故障・全温度の最大値ではない。

Vishay TNPW0603 e3のP70はモードごとに0.110/0.170/0.210W。
今回の値は前2条件を超え、最大表記値0.210Wには下回るが、膜温度・基板放熱の
成立が未確認であり熱合格にはできない。端子温度を指定した別の高定格を無条件に適用しない。
出典：[メーカー仕様書 Rev.10-Apr-2026、pp.1–2](https://www.vishay.com/docs/28758/tnpw_e3.pdf)。

このセル局所ループはパック主電流シャントも高側保護FETも通らない。
入力差動電圧がゼロとなりICがUVを検出しても、主FETのOFFでは局所放電が止まらない。
主ヒューズにも遮断能力を期待できない。VC0対VSSのC短絡は本理想回路では
セルを跨がないため同じ放電計算を適用しないが、監視への影響は未確認。

## 再現と限界

```sh
python3 software/sim/circuits/check_bq76942_filter_short.py
```

結果はreport.json。実電池の容量・内部抵抗・放電時間を仮定していない。
IC内部のクランプ・入力電流、接続過渡、抵抗の温度上昇は未モデル化。
計算の目的は主遮断で保護できない経路の識別であり、部品焼損や発火の予測ではない。

## 次の設計判断

Cを直列に分け、1個短絡しても直流経路が残らない構成、または監視線の
遮断部品を比較する。前者は短絡後も残ったCに全セル電圧がかかること、
合成容量とRC誤差、開放故障を確認する。後者は約95mAでも確実に遮断できる
特性と正常時の誤差・開線検出への影響が必要。
この残件は#24の設計内に残し、#49へ移して完了扱いにはしない。
