# 閉じ部を上側に限定した経路：不合格

v2の幅12.7mmと単層厚み2.5mm予約は維持し、二重厚みをZ>=80mmの上側U字経路に限定した。
これは組立時の閉じ部位置を指定する別案であり、v2を合格に書き換えるものではない。
事前条件はplan.json。ガイド位置と電池中心は維持。

結果：左右ヨー支持、金属板、ねじ類の10組に体積干渉が残る。
閉じ部を上へ移すだけでは解決しない。v1の幅10mm・厚み1.5mm包絡の合格は、
今回の実品候補へ引き継げない。正式採用・製作はHOLD。

厚み未確認のまま細くして合格を得ることはしない。この経路の試行はここで止める。
次の設計はベルトのY位置または床の通し経路を変更する。位置変更で2本の間隔が狭くなる場合は、
回転モーメントに対する保持力と電池端部の浮きを再評価する。
製作候補BOMには31013切出し2本を比較候補として残すが、発注・強度確定は行わない。
