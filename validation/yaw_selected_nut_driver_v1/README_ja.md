# 選定工具の軸と支持部の局所隙間

Wera05118120001の公表軸径5.7 mm・軸長60 mmを中実円柱として支持部だけと比較。
先端Z91.9 mmはナット座面に対応する比較位置で、実ソケット嵌合の証明ではない。
旧上面補強との最小隙間0.45 mm、逃げ変更後0.90 mm、左右8箇所すべて体積干渉なし。
半径方向計算4.0−2.85=1.15 mmよりCADの最小隙間が小さいのは、
工具底面と元の支持部上面の高さ差0.90 mmが残るため。
既存の公称0.90 mm比較条件を満たすが追加余裕はない。実工具・造形公差は未確定。

柄・手・周辺部品・進入経路・ねじ先端のソケット内底付き・締付けトルクは範囲外。
他の工具にも適合するとの判断、組立完了・製造承認は行わない。
工具を小さく仮定したのではなく、別保存のメーカー仕様に基づく限定比較。
