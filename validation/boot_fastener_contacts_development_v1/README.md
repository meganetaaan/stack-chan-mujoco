# ブーツ締結金物の接触面積

低頭ねじ・角ナットの公称包絡と現候補CADから水平接触面を抽出した。左右8締結位置、計16接触で正の接触面積と重なりなしを確認した。

- ねじ頭／ヨーク z=−19 mm：7.186393195 mm²/本
- ナット／ブーツ z=−14.6 mm：11.845243716 mm²/個

事前に宣言した10、20、40 Nの軸力に対する平均面圧をreport.jsonへ保存した。40 Nではねじ頭側約5.566 MPa、ナット側約3.377 MPa。これらの力は感度評価点であり、採用する予圧や許容荷重ではない。

この面積はねじ包絡の円柱・平面に基づく。実ねじ頭の付け根丸み、面取り、平面度、座面の傾き、不均一接触は未反映。平均面圧だけでは局所圧縮、ヨーク曲げ、ナット引抜き、座屈、長期クリープ、締付けトルクを判断できない。メーカーのねじ最大トルクを樹脂締結部の許容値へ転用しない。

次の構造解析で接触面を与えるための幾何証跡であり、強度・締結合格や製造承認は未達。

