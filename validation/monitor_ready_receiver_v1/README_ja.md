# 起動待ち信号の受信部品比較

結論：Nexperia 74LVC1G17GVを次の受信回路検討候補とするが、まだ統合しない。
ユーザーの要求である保護成立を、端点仕様の補間だけで合格扱いにしない。

同じ機能名でもTI製品と漏れ電流規定が異なる。100 kΩ±1%という設計仮定では、
電源断時の出力漏れによる電圧比較値はNexperia 0.202 V、TI 1.01 V。
これは後段漏れを含まず、受信Lowの合格判定ではない。
外部プルダウンを省くと、出力を切り離す機能だけではLowを作れない。

両製品ともSchmitt閾値は離散的な電源電圧で規定されている。
実際の3.207〜3.393 V全域へ補間した値を保証値として使わない。
入力容量も代表値なので、TPS3808の遅延負荷条件が満たされたとは判定しない。
電源断時の漏れ規定はVCC=0 Vの条件であり、途中電圧の出力抑止とは区別する。

次の設計判断では、電源範囲全体の入力規定を持つ受信方式、
遅延負荷、電源遷移中の禁止経路を確認する。現行統合候補はrevGのまま。
この残件は実機検証へ移して完了扱いにしない。

再現（リポジトリルートから未作成の出力先を指定）：

```sh
python3 software/sim/circuits/screen_monitor_ready_receiver.py --out /tmp/monitor-receiver-check
```

report.jsonに数値の前提、部品ごとの出典、未確認事項を記録した。
接続確認と仕様比較であり、回路の過渡シミュレーションではない。
