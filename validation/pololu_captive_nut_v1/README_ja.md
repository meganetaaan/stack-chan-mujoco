# 電源基板の締結候補と横差しナット用台座

## 構成

部品候補は `docs/prototype/mechanical/pololu_mount_fasteners/candidate.json`。各8個:

- NBK SLH-M2-12: M2×0.4、長さ12、頭径3.8・高さ1.3 mm、0.29 g。メーカー最大トルク0.3 N·mは、この基板・樹脂座面の組立トルクに使用しない。
- MISUMI SP-J2-3: POM、外径4・内径2.1・長さ3±0.1 mm、0.04 g。内径は従来の仮置き2.2とは異なる。型番はメーカー製品一覧、寸法はメーカー配布カタログで照合。最新納期は未確認。
- Bossard BN109/1088211: 既存比較候補と同じM2ナット。対辺4、高さ最大1.6 mmの理想六角形で空間検査し、実ねじ・面取り・公差は未モデル化。

## 台座変更と寸法関係

v2台座の各基板穴に幅X4.2、高さZ95.1〜96.9 mmの横差しスロットを追加。ナット上面をZ96.9に当て、下面Z95.3、ねじ頭座面Z106.6398から12 mm下の先端Z94.6398とした。幾何学的突出量0.6602 mmは事前設定の1ピッチ=0.4 mmを超える。これは実ねじ端部・不完全ねじ・ナット面取りを含む有効噛合いの判定ではない。

スロットの上には材料5.165 mmを保持。Z96.9以上の元の材料との差分体積0、各台座1ソリッドを検証。完成品強度や締付け保持の確認とは区別する。

## 検査範囲

8本のねじと8個のナットを、各自の台座と既存固定部52点・電池・トレイ・Tab5・TTLに比較する計912組。自身の台座との接触を意図した接触と扱い、それ以外には0.5 mmの公称隙間基準を適用する。体積重複は意図した接触部にも許容しない(数値閾値0.01 mm³)。結果は不合格0、意図しない相手部品との最小距離1.6398 mm。詳細はreport.json。

本検査の組立STEPには基板・スペーサは含めない。スペーサは外径と公称高さが前回予約形状と同じだが、公差・穴位置・ねじ径との組合せは未資格化。ねじ/ナットと相手ねじの接触、基板の実穴、ナット挿入経路、工具、動作干渉は未評価。

## 試作前に残る事項

スロットは横から挿入する案であり、逆さにした時の脱落防止・回り止め能力を保証しない。造形精度と座面変形、POMの温度依存クリープ、締付トルク、緩み止め、有効噛合い、基板の穴周辺銅箔とねじ頭の絶縁、後板の締結が未確定。特に非導電スペーサを選んだだけでは金属ねじによる短絡対策は完了しない。製作リリース=falseを保持し、FEは実締結構成と荷重条件の確定後に行う。
