# 制御分岐の故障停止モード選定

部品候補をTPS26600から **TPS26601RHFR**（24端子VQFN）へ絞り、MODE開放の遮断後ラッチ保持を設計候補とする。根拠は[TI TPS2660 RevG 比較表、§9.3.5、§9.4](https://www.ti.com/lit/gpn/tps2660)。注文コードは同資料の注文表に掲載されている。旧TPS26600検討記録は比較履歴として残す。

理由: TPS26600のMODE開放は自動再試行。402 kΩで選ぶ電流制限＋ラッチは、過負荷中に電流を制限し、熱遮断へ至ってから保持する動作であり、タイマによる遮断と同じではない。過負荷の持続をタイマで判定する候補としてTPS26601の遮断モードを選ぶ。

**故障ごとの扱い**

- 過負荷: 電流が遮断閾値を超える間タイマが進み、遮断後はラッチ保持。
- 突発短絡: 内部fast-tripの後、数µsの停止を経てゆっくり再投入し電流制限に移る仕様がある。したがって「一度も再投入しない」とは主張しない。再投入時と最終遮断までのエネルギーを評価する。
- UVLO/OVP: 過負荷ラッチと同一扱いにせず、入力復帰で電源が戻ることを想定する。サーボ側の手動再開ラッチは引き続き必要。
- ラッチ解除: 試作の保守操作では入力電源をPOR解除条件まで落とす方式を候補とする。保持容量の放電が未設計なので、コネクタを短時間抜くだけで解除できるとは保証しない。SHDNによる解除も仕様上可能だが、給電を失うMCU自身による自動解除には依存しない。

RILIM120 kΩは比較値のまま。遮断閾値45..110 mAは制限電流85..115 mAと別仕様であり、最小45 mAでも20 mAの定常枠より高い。ただし抵抗許容差・3S条件適用と起動充電は未評価。タイマ中に充電を完了できるか、または閾値未満で充電できるようスルーレートを制御できるかを確認してから電流設定を採用する。

**次の評価の終了条件:** 実部品のタイマ・電流閾値条件と入力/出力容量から起動時の誤遮断がないこと、短絡後の再投入を含む通過エネルギー、電源復帰時のサーボ禁止を示す。未知波形の任意掃引で合格にしない。現アセンブリ未統合・製造リリースなし。
