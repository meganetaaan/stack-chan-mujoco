# 座金組込みねじの置換比較

## 判断

NBK SNSQS-M3-16は実在する座金組込み候補だが、現行SNS-M3-16＋平座金の直接置換には採用しない。メーカーが組み合わせたねじ・座金なので個別の首下合わせを減らせる一方、ばね座金とA2-70ねじへの変更を伴う。組込み構造を固定部の保持・緩み止め能力の証明とはしない。

## 現行との差

平座金は現行同様に外径7・厚さ0.5 mm。さらにばね座金T約0.7 mm、自由高さ約2Tを含む。図のLは首下から先端までなので、ばねをTまで圧縮した名目比較では現行より積層+0.7 mm、先端突出1.8→1.1 mm、頭背面X=−67.7→−68.4 mm。自由状態の名目比較ではそれぞれ+1.4、0.4、−69.1 mmとなる。Tは概略値であり、この二状態を実公差上下限とはしない。

ねじはSUSXM7・A2-70。現行8.8級ベースの580 MPa計算値を流用しない。ばねを閉じる荷重、樹脂支持の許容締付け力、板のねじ山保持能力が未確定なので、ばねを閉じることを組立手順へ追加しない。

## 終了条件と次の判断

本候補の直接置換可否の机上比較は終了。現行BOMを維持し、この案の追加シミュレーションは行わない。採用を再検討するのは、同じ荷重データでA2-70ねじ・ばね座金・樹脂座面の許容締付け範囲を示せる場合に限る。首下着座の未確認を解消する目的だけで新たなばね荷重の仮定を導入しない。

外側平座金の実品仕様とボルトの首下適合は残件。無通電の嵌合確認用試験片は可能だが、保持荷重を与える試験条件と製造リリースは別途判断する。原本SNSQS.pdfと出典SHA256を保存した。
