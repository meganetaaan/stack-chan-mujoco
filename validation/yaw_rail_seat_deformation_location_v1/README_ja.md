# 最新支持部の変形位置と取付面のゆがみ

`yaw_rail_seat_deformation_v1`と同一の3 mmメッシュ・単一保存荷重を再利用し、変位場を保存した。最大変位0.238077 mm、要素数13275、自由度75072が前回と一致する。メッシュの細分化は行っていない。

- 最大変位位置は [11.6,18.5,91] mm、変位ベクトルは [-0.02538,-0.09473,0.21694] mm。
- 取付面1765節点への微小剛体運動の最小二乗近似では、平均位置 [-13.1299,26.7656,89] mmの移動は [-0.00202,-0.05564,0.05135] mm、回転は [-0.005168,-0.002494,-0.001617] rad。
- 剛体運動を除いた面のゆがみは最大0.081735 mm、RMS 0.029005 mm。これは接触面の離間量でも許容値でもない。
- ひずみエネルギーの領域別割合は背面25.73%、中央25.89%、前方48.39%。領域は診断のためのX座標区分で、部品境界ではない。

**設計への反映:** 取付面を完全剛体とみなして最大変位だけ移動させる干渉検査では、面のゆがみが欠落する。次の組立解析では板と支持部の相対変位を扱う必要がある。前方の寄与が大きいため、背面だけの補強を採用する根拠にはならない。エネルギー割合だけから変更形状や強度余裕を決めない。

合否基準は変更しない。既存0.2 mm配分は未達のまま。等方材、理想背面固定、接触なし、旧単一荷重という限界も前回どおり。

再現（出力先は未作成）:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/locate_yaw_shelf_deformation.py --mesh validation/yaw_rail_seat_deformation_v1/support_3.msh --step validation/yaw_rail_seat_v1/left_yaw_fixed_support.step --out /tmp/yaw-rail-seat-location
```

メッシュがない場合は指定STEPから3 mmで再生成する。既存メッシュを指定する場合は同じSTEP由来であることを呼出側が確認する。使用したメッシュのハッシュをreport.jsonに記録する。節点変位・応力等はfield.npzに保存した。
