# 金属板v4締結の周辺/工具確認

8固定組の頭・軸・座金・ナットと周辺8部品を照合。ハード部品256比較で今回の公称0.90 mm隙間/0.01 mm³交差基準内。突出4.9 mmの先端も含む。ただしケースTAPねじ頭、支持背面締結、実ハーネス、完全な脚は今回対象にない。

工具128比較には14不合格：上ナット工具と胴体8、後側下六角キーとヨー連結部4、同キーと変換器2。完成状態の保守アクセスは不合格として残す。工具はφ8上ソケット/φ3下キーの予約であり、実工具の径・空洞深さは未選定。

## 組立工程の候補

1. 胴体外で金属板を支持へ固定する。サーボ/連結部/変換器はまだない。上ナット工具と下キーを両側から使う。
2. 金属板付き支持を背面構造板/胴体へ固定する。サーボや電源部品を後付けする、既存の支持背面締結順序を維持する。
3. ケースを下方から取り付け、上面の既存ケース用アクセス穴から指定TAPねじを締める。
4. ホーン連結部・脚・変換器・配線を取り付ける。

これは依存順序の候補であり、工程2の支持背面工具と追加金属板/ナットの干渉、工程3の挿入公差/工具、工程4の組付け経路は未証明。14不合格を単に無視して組立完了にしない。今は金属板ナット用の穴を胴体へ追加せず、まずこの工程の成立を検査する。

距離のbounding box下限が0.90 mm以上ならその保守的下限で判定し、それ以外を正確なCAD距離で評価した。report.jsonはdistance_is_lower_boundで区別し、下限を真の最短距離と表示しない。全入力ハッシュ保存。
