# 制御電源の異常評価範囲と優先順位

2026-09-22のGitHub #6/#24本文を同ディレクトリに保存。今回の確認は要求と追加仮定の分類であり、異常試験の合格を追加しない。

## 要求の由来

#6は起動・全軸負荷・加減速・停止・低残量、公差を含む最悪条件、および短絡・逆接・低電圧・回生等の適用する異常を要求する。#24は検出/遮断・残留エネルギー・復帰条件の記録と、模擬できない専用IC内部挙動の実機試験引継ぎを求める。

全ICの任意の内部短絡を一律に耐える要求は本文にはない。一方、制御電源の故障が駆動の不意な許可に伝わる可能性は検討対象なので、LDO IN–OUT短絡を無関係として削除しない。

前回候補文書の「出力側過電圧への対処を決めるまで成立済みにしない」はCodexが追加した設計判断。ユーザー指定の合格基準として扱ったり、これだけを理由に保護素子の追加を必須化したりしない。保護レベルを決めるための故障影響分析として保存する。

## 先に閉じる必須ケース

| ケース | 確認する成立条件 | 現状 |
|---|---|---|
| 正常起動/再投入 | 実効容量充電中もリセット/許可が規定順序。電流制限との整合 | 未確認 |
| 制御入力/出力の対地短絡 | 遮断/制限、配線・部品エネルギー/温度、残留電荷、復帰操作 | ピン接続のみ。動作と限界未確認 |
| 電池逆接 | 主入口・GND/RTN・信号/USB等の迂回経路も含む | サブ回路では未確認 |
| 低電圧/瞬断/PCM復帰 | Tab5終了条件、制御リセット、駆動の新しい手動許可 | 検出器/接続/仕様未完 |
| 回生による入力上昇 | 吸収先、過電圧遮断と分岐/信号への伝播 | 全体未統合 |
| 過電流・熱遮断後 | ラッチ解除経路と無意図再始動防止 | ICの機能仕様確認のみ |

## 追加仮定として扱う内部故障

TPS709 IN–OUT短絡について、入力電流が制限以下ならCTRL3V3を保護できないという前回の指摘は維持する。次の判断は、故障した制御出力が外部の独立停止回路を無効化できるか、許可信号の無給電時/過電圧時の伝播、負荷IC破損と駆動許可の関係を接続から調べること。その結果に基づき、出力過電圧保護、独立停止との分離、または非対応範囲としての明示を選ぶ。危険性が消えたとも、合格したとも扱わない。

実部品や接続が未確定な状態を#49へ移して設計完了にしない。#49へ渡せるのは設計条件を定めたうえでモデルが覆わない実挙動。必須ケースは未完、製作HOLD、#6/#24はオープンのまま。

## 終了条件

今回の要求分類は終了。次は正常起動の容量/充電条件と対地短絡の電流・エネルギーを優先する。内部短絡への保護を増やす前に、上記の故障影響範囲を確定する。元の要求・失敗記録・数値合格基準は変更しない。
