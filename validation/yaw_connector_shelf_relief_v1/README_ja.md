# 支持棚と金属板を通す配線出口候補

金属板の逃げと同位置・同断面（12.1×6.4mm、角R1.3）で支持棚にも開口を設けた。9.5×3.8mm、Z87〜97mmの直線予約通路で確認。旧支持棚は各ポートで72.2mm³交差し、新形状では支持棚・金属板とも通路から1.3mmの隙間となる。

公差・変形の既存配分0.8mm控除後は0.5mmで、基準値ちょうど。約3e-15mmの差は計算丸めとして事前に定めた数値許容1e-6mmで扱う。設計上の追加余裕はない。実ケーブルの束径・曲げ・端末保持がこの予約通路に収まることは未確認。

支持部は妥当な単一ソリッドを保持。外側への追加材料は0、片側の除去体積303.957mm³。ケース・板支持の8取付軸まわり半径3mmの対象領域は削っていない。ただし、これは締結耐力や支持棚の曲げ剛性を保証しない。現行revBには統合していない。

採否を決めるための次の確認は、開口と取付座を結ぶ残り断面の荷重・変形と、実ケーブルの出口・固定点。局所の隙間合格だけで製作リリースしない。
