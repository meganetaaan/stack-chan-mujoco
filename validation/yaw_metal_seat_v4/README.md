# 座面を確保する前側軸調整

前側固定軸をX=7.5から8.1 mmへ移動。頭逃げ穴との中心距離sqrt(5.6²+2²)=5.9464 mmとなり、半径和5.5 mmから約0.4464 mm離す。0.40 mmの既存境界公差予算を考慮した局所配置候補。工具の残余0.50 mm基準とは別で、座面が隣の穴へ落ちないための比較である。

板49.1×33×1 mm、X=−37.5..11.6。支持棚前端も11.6へ延長し、前座金の端X=11.1に公称0.5 mm残す。ケース・ホーン位置は維持。リブ切除なし。外形内への収まり、工具、ナット、全身周辺は未検証。

再現：build_yaw_metal_seat.py --relocated-axes --front-axis-mm 8.1 --out <新規先>。板/支持候補はv4、旧版は履歴。製造リリース不可。
