# REG0直列抵抗の選定比較

目的は3S低電池時の電圧降下と短絡発熱の両方を比較し、100Ω案を維持するか判断すること。
終了条件は候補抵抗の比較と、別途保護が必要かの判断。起動の仮想波形や未知の電池モデルは追加しない。

```sh
python3 software/sim/circuits/screen_bq76942_reg0_feed.py
```

54条件をcomparison.csvへ出力。入力の分類と適用限界はreport.json。
9V・20mA・ダイオード1V・REGIN5.8Vという**仮置き比較**では、
100Ωの利用可能VCEは0.198V、22.1Ωでは1.757558V。
VCEに1Vの設計余裕を割り当てる比較では100Ωが不足する。
この1VはFCX495の保証ドロップアウトでもユーザー合格基準でもない。
47Ωも比較し、22.1Ωを次候補とする。負荷を小さく仮定し直して100Ωを通す方法は取らない。

ただし22.1Ωは入力C短絡で約7.19W（12.6V・ダイオード降下ゼロ・初期抵抗下限）となる。
100Ωでも約1.59Wであり、いずれも常時短絡の保護として成立しない。
抵抗値を下げるだけでは製作可能にならない。主ヒューズより小さい故障電流で発熱し得るため、
制御電源分岐の故障遮断設計を必須残件とする。主FET OFFではこの分岐を遮断できない。

BAT端子/BREGの電源経路は別であり、この比較に通ってもREG0全体の成立を示さない。
ダイオードの25°C・指定電流における最大値を他温度/他電流の保証へ拡張しない。
実部品の電流予算、低温降下、BREG余裕、QのDC動作領域、熱設計、短絡遮断を先に確定する。
