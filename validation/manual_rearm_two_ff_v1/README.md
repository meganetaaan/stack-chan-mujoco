# 受付保持と投入保持の2段接続

SN74HCS74PWの両側を使う案へ更新。第1段DはHigh、CLKは解除継続タイマーの完了立上り、Qは受付済み。第2段Dは第1段Q、CLKはデバウンス/反転済みの押下立上り、Qは投入許可。両段CLRは故障・停止・監視無効・PORを含む優先クリア、PREはHighに固定する。

タイマーは押下でLowへ戻るが、それは第1段のクロック下降であり保持状態を消去しない。投入時の押下で第2段が受付済みを取り込む。タイマー出力をCLRへ結ぶ接続は禁止する。外部EN段はまだ未選定であり、論理Qをそのまま主電力の遮断保証にはしない。

デバウンス20/50/80 msと解除タイマー180/300/420 msの9組合せで、故障前押下の拒否、健全な解除後の新押下受理、停止での両段解除を確認した。これは離散時間の接続論理確認で、部品タイミングの保証ではない。

タイマー完了と押下が近接したときのsetup/hold、CLK/CLR回復時間、MR生成、プルアップ負荷、起動時の信号順序は未確認。旧単一DFF反例は履歴として保持し、この結果で書き換えない。#24は未完了。
