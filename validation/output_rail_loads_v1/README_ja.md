# 出力を経由する抵抗負荷

1 kΩクリア要求候補について、U3→R6、U_MONITOR_RX→R_MONITOR_RX_OFF、U8→R7→左右ENプルダウン／U10クランプの接続をアセンブリの配線別名も含めて照合した。

電源3.393 V、抵抗総合−1%、出力High上限を電源電圧とする計算では、R6と監視出力の各負荷は15.579 µA。U8経路は通常の二つの78.7 kΩプルダウンで77.804 µA、U10がクランプする条件では729.207 µA。後者を上限に取り、両者を二重に加算しない。

これらの小計は0.760364 mA。将来のシーケンサMCUがR_SEQUENCE_OFFをHigh駆動する負荷0.342727 mAも予約すると、前回の直結抵抗分を含むLOGIC3V3の条件付き抵抗負荷小計は **6.883758 mA**。

この値はIC供給電流の総計ではない。出力段内部電流、IC静止・動的電流、MAX6816内部プルアップ、MCU本体、漏れ・過渡電流は別途必要。予約したMCUは未統合であり、電源構成も未確定。各状態上限を独立に足した値で、同時に発生する状態を再現したものではない。R14のLowとMCU EnableのHighが同時に有効な通常状態だとは主張しない。

再現（出力先未作成）:

```sh
.venv-engineering/bin/python software/sim/circuits/audit_output_rail_loads.py --out /tmp/output-rail-loads
```

電源容量・熱・故障時動作の合格には使用しない。
