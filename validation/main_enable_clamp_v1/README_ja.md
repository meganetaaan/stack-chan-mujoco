# ENの独立低電圧クランプ候補

## 接続と判断

追加TPS3808G33DBVRをeFuse入力側5 Vから給電し、LOGIC3V3を監視する。RESET出力はMAIN_EFUSE_ENだけに接続し、ラッチのRESET_Nへ接続しない。U8出力との間に4.7 kΩを入れて競合電流を制限する。39 kΩプルダウンはEN側に残す。接続はmanual_rearm_revDへ統合した。監視電源へ2S電池を直接接続してはいけない。

[TI TPS3808 Rev N](https://www.ti.com/lit/ds/symlink/tps3808.pdf)の6.3、6.5を根拠に、監視電源が1.8〜6.5 Vで有効かつRESETが既に成立している場合を確認した。Low最大0.4 V／1 mAの条件を使用。3.3 V監視のしきい値・解除余裕は既存G33候補と同じで、余裕が増えたとは扱わない。

## 事前条件と静的結果

抵抗総合±1%、バッファHigh注入上限3.393 Vは設計比較条件。未規定の電源低下中出力をこの値で保証するモデルではない。通常時EN下限2.765 V、バッファ負荷上限78.83 µA。RESET成立時の保守的吸込電流0.7293 mA、EN上限0.4 Vで、最低消費状態へのしきい値0.59 Vより低い。直列抵抗なしの出力競合は認めない。

これにより有効な別電源を持つ監視出力が、High指令に優先して静的にENを下げる接続候補を得た。電源立上り・急低下・復帰、監視電源の喪失、出力故障時まで含めた合格ではない。

## 残る条件と解析の終了

- EFUSE_INPUT_5Vの動作範囲・過渡を確定する。SENSEだけ低下しVDDが正常という今回の条件と、両方が低下する場合を分ける。
- RESET伝搬とEN遮断までの時間を、制御電源の低下速度および許容エネルギーへ照合する。静的Lowから瞬時遮断とは推定しない。
- CTの100 kΩによる解除待ちは、新たな手動操作の代わりにはならない。監視が復帰しても指令保持が残れば再投入するため、停止記憶・再許可経路の確認を必須とする。
- 抵抗・バイパスの実品、入力未給電挙動、EN出力固着と独立停止の故障解析を完了させる。

今回の追加解析は静的電流・電圧収支で終了。未知の電源低下波形を仮定して成立扱いにしない。#24は未完了、通電試作は未許可。
