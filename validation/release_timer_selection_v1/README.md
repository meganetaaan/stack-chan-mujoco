# 安定解除確認タイマー候補

TPS3808系列をMR入力付き解除タイマーとして検討する。[TI資料](https://www.ti.com/lit/ds/symlink/tps3808.pdf)、SBVS050N August 2026、§6.6/7。CTをVDDへ接続した遅延は規定条件で180〜420 ms。最短180 msでもMAX6816候補の最大80 msより100 ms長く、追加のタイミングコンデンサー公差を持ち込まずに解除確認時間の条件を満たせる候補となる。

これは監視しきい値の型式・出力負荷・論理インターフェースまで選定した結果ではない。CT開放の12〜28 ms設定は今回の解除確認時間を満たさないので使用しない。

MRを健全かつraw/デバウンス済みボタン解除の両方が成立するときだけHighにする。押下・故障・監視不正でLowとして確認時間をやり直す。RESET解除出力は「受付保持」をセットする信号へ使い、主ENや投入ラッチのCLRへ直接つながない。ボタンを押すとタイマーRESETは再びLowになるため、その信号を投入保持のCLRへ接続すると正規押下も取り消される。

受付保持は健全な解除確認完了でセットし、故障/停止/電源不正でのみ消去する。投入保持は受付済みの新押下でセットする。受付保持と投入保持を分ける。MR生成の論理電圧・グリッチ、RESETのプルアップ負荷、POR、非同期解除競合は未解決。

MRの短いパルスやSENSEの過渡応答を無条件に検出すると仮定しない。最小パルス・遅延・電源立上り条件を実回路と照合する。停止要求はこのタイマーを経由せず、保持回路を直接解除する。

今回の終了は固定遅延設定の選択と接続上の役割の確定。しきい値型式とMR生成回路を確定後にピン統合する。基準を緩めたものではなく、既存の80 ms超という設計条件に部品の最短値を照合した。#24は未完了。
