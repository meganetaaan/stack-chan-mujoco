# 支持部上面の2 mm補強候補

金属サーボ取付板は1 mmを維持する。ねじ進入長の根拠を失うため、
樹脂との単純一体化は採用しない。

これまで支持部単体の外接寸法不変を比較条件にしていたが、これはユーザーの
「ロボットの外形を大きく変えない」より厳しいCodexの仮置き条件だった。
今回は形状生成前に、組立全体の外接寸法不変と全部品への追加干渉検査へ変更した。
変位0.20 mmなど構造の合否基準は変更していない。

既存支持部のZ89..91 mm、X-65..35 mm、Y中心±18 mmを切り出して
2 mm上へ移し融合した。棚だけでなくこの領域にある後部壁上面も延長する。
元の穴形状を保存し、4本の板固定ねじ周辺は追加材だけ半径3.3 mmを除去した。
これは工具適合の保証ではなく座金・ナット用の公称逃げ。

左右とも単一ソリッド、最新組立v5の全体外接寸法不変、固定部品への追加干渉なし。
メーカーサーボ形状まで3.0 mm、ポート予約通路まで1.3 mm。
追加体積は各4680.446 mm³。質量・慣性は材料未確定で未更新。
動作時・Tab5・電池の最新構成・工具・全公差・締結・造形性は未検証。
元の板と棚の接触平面は変えず、追加部分の穴逃げで元の締結厚を維持するが、
その周辺の座面幅と工具経路は別途確認が必要。

正式候補への採用・製造リリースはまだ行わない。
再現：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/build_yaw_upper_shelf.py --out /tmp/yaw-upper-shelf
```
