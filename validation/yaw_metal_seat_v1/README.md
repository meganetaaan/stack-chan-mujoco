# ヨーケースの埋込み金属取付板候補

既存サーボ位置・ホーン連結部を保ち、支持棚下面Z=88..89に42×30×1 mmの板を埋め込む案。ケース用ねじは金属板へ着座し、支持棚側にはφ5 mmのねじ頭予約を設ける。金属板は別の4本のM2通し締結で棚へ保持する構想。板/支持の4形状は有効な単一ソリッド、板と支持の体積交差0。

ねじ座面は従来Z=91から89へ下がる。PHS M2×8 TAPの下穴進入は8−1−4.5=2.5 mm（先端不完全ねじ・公差控除前）。これは必要掛かり長の合格値ではない。締付けトルク、下穴引抜き、許容挿入長は依然未確認。樹脂の薄い座面へケースねじを直接載せる前案とは荷重経路を変えた。

## 荷重経路と残件

ケース→指定TAPねじ/金属板の接触→金属板→別の4本の通し締結と支持座面→支持背面→胴体。棚への接触だけでは下方向の脱落を防げないため、別締結が必須。今回のCADに実ねじ/ナット/座金は含まない。接触だけで板が保持されるものとして解析しない。

SUS304は候補、板厚1 mmと密度8000 kg/m³は設計仮定。板は各約9.81 gで2枚約19.63 g。支持切除は各約1429.50 mm³だが、追加締結品を含む全身質量差は未確定。凍結モデルの荷重・慣性に自動反映しない。

通し締結穴の中心は板縁から2 mm、穴半径1.15 mmのため最小正味幅0.85 mm。これは強度合格ではなく、別締結の選定時に端距離・抜け・座金支持を確認すべき寸法。板曲げ、棚残厚2 mmの引抜き/クリープ、穴頭予約φ5の実ねじ適合、工具/組立経路も未確認。

## 次の判断と終了条件

まず板支持用の実締結品を選び、ねじ頭・座金・ナットが板/支持の縁から外れず、ケースと干渉せずに締結できるか1組で検査する。未成立なら穴配置または板範囲を変更し、材料値未確定の細分化解析を行わない。締結が具体化してから同時刻荷重による板曲げ・面圧・支持部反力を評価する。純正側面フレーム案は比較履歴として残し、今回は採用しない。
