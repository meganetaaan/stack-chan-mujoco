# 圧縮のみのレール接触：変形未達は解消せず

rail-seat支持部の保存3mmメッシュと荷重を再使用。後端固定、E=1120MPa、ν=0.35は変更しない。胴体レールは剛体、名目初期隙間ゼロ、摩擦なし。接触点は前のCAD足跡抽出を使用し、後端固定自由度と重なる点を除いた156個のZ自由度にだけ上向き反力を許容する。

手法はKの分解を再使用して接触自由度のコンプライアンスCを求め、非負反力rに対する凸二次形式 0.5 rᵀCr + g0ᵀr を最小化する。変位u=u0+K⁻¹r、隙間g=g0+Cr。r>=0、g>=0、r×g≈0を確認しており、全面固定や引張支持ではない。接触前解が保存変位場と一致すること、節点位置と順序も確認する。

事前の数値条件: 最小隙間−1e−7mm以上、反力−1e−9N以上、相補積最大1e−7Nmm以下、自由自由度残差1e−7N以下。1メッシュ・最大500最適化反復で終了し、応力収束のための追加細分化はしない。

18反復で収束。最大変位0.238165516mm（接触なし0.238077068mm）で、0.2mm枠を満たさない。レール反力合計2.78896N、最大節点反力0.46517N。隙間最小−1.13e−10mm、相補積最大2.35e−11Nmm、残差2.94e−11Nで上記条件は通過。節点反力から局所面圧や材料強度は判定しない。

結論: この保存荷重では、圧縮のみのレール接触を剛体・ゼロ隙間で導入しても変形問題を解消しない。最大変位がわずかに増えるのは荷重再配分であり、接触を入れれば全節点の変位が単調に減るとは限らない。この結果だけで他荷重の上限や下限を主張しない。

レールの摩擦係数や予圧を仮定して基準を通す追加走査は行わない。次の設計変更は支持部の主な曲げ経路を短くする/別の支持位置へ荷重を渡すことを対象とし、干渉・締結・胴体側強度も一緒に確認する。

限界: 節点接触・粗い1メッシュの比較解析であり、真の接触面積、胴体の変形、印刷公差、予圧、クリープ、最新全荷重は含まない。#18や製作可の証拠にはならない。

再現:
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/solve_yaw_rail_contact.py --out /tmp/stackchan-rail-unilateral
```

入力メッシュは `yaw_rail_seat_deformation_v1` の再現手順で生成する。保存変位場と節点が一致しないメッシュはスクリプトが拒否する。入力ハッシュ、数値検査はreport.json、接触自由度/隙間/反力はcontact.npz。
