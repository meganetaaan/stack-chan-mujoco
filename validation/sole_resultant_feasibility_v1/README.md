# 足裏圧縮接触の必要条件

全38系列について、足首合力と静的に釣り合う足裏荷重の圧力中心を計算。z=-16から-19 mmへモーメントを移してから、x=1−My/Fz、y=±6+Mx/Fzを使用する。Fz>1e-6 Nのサンプルを評価し、それ以外も件数に記録。足裏外接矩形を用いた必要条件であり、摩擦・穴・丸角を含む十分条件ではない。

直前の全体FEサンプル（左、2.447秒）の必要圧力中心は(10.684509,-18.411493) mm。左足裏の下限y=-18 mmより0.411493 mm外にある。非負の圧力の重心が支持領域の凸包外になることはないため、今回の静的な合力条件を保持したまま圧縮だけの分布へ修正することは不可能。

これは実ロボットの不成立証明ではなく、部品慣性などを省略して足首合力を床反力として扱った境界条件の不成立。許容幅を広げたり荷重を減らしたりして回避しない。次はMuJoCoの床接触力・位置と足部慣性を同時刻で取得し、自由物体の釣合いを検証する。従来の全体FEは簡略モデルの診断として保持し、補強の確定根拠にしない。

```sh
.venv-engineering/bin/python software/sim/structural/check_sole_resultant_feasibility.py --out outputs/sole_feasibility_repro
```

各系列の件数・最悪時刻・同時荷重・出典ハッシュをreport.jsonに保存。境界寸法は既存CAD生成コードbuild_fast_turn_feet.pyの86×48 mm、中心(4,±6) mmに対応。目標の強度検証は未完了。
