# ヨー支持候補の質量入力台帳

目的は、最新支持構成を全身の質量・荷重へ反映する際の二重計上と包絡形状の誤使用を防ぐこと。追加FE解析・歩行試験は行わず、現revAの52部品を過不足なく分類し、質量の確定に必要な入力を示した時点で終了する。

inventory.jsonの公称体積からmass_inputs.csvを生成した。左右支持の合計体積55.469 cm³、背面構造板32.132 cm³、ケース取付板3.174 cm³。密度ρ[g/cm³]を確定したとき、公称ソリッド質量[g]はそれぞれ体積係数×ρとなる。樹脂のインフィル、空隙、寸法変化、加工後のねじ穴を無視した製品重量の保証ではない。

ねじ・角ナットなど28部品は包絡CADの体積を質量計算へ使わない分類にした。角ナットは外接円、ねじは簡略化されており、密度だけを入れて実重量にしない。メーカー重量またはねじ形状を含む実体積が必要。

材料と製法は未確定なので密度・確定重量欄は空欄。ゼロ重量ではない。サーボ・ホーン・ケースねじ、胴体隅締結、脚・足、Tab5・電池・電装・配線はこの52部品に含まれない。凍結MuJoCoモデルの既存部品と置換関係を作り、重心・慣性を組立座標へ変換してから更新する。今回の体積を全て既存全身質量へ加算してはならない。

この台帳は#17/#18の荷重更新準備であり、全身質量更新や強度合格ではない。製作方法の確認後、材料証拠・有効密度と部品対応を埋める。

再現：`python3 software/sim/structural/audit_yaw_mass_inputs.py --out /tmp/yaw_mass_inputs`。未作成出力先を指定。出典inventoryのSHA256はreport.json。
