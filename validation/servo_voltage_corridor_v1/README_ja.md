# 設定電圧だけを下げる案の成立範囲

既存PLANの通常動作目標4.75V以上を維持し、比較OVPの最小検出5.175695V未満に収める。
4.75VはCodexの設計目標で、ユーザー要求やメーカー動作下限ではない。
今回この目標は変更しない。変更する場合はトルク・速度・電流と歩行負荷への影響が必要。

候補モジュールの負荷変動の典型値±0.45Vを比較に用いる。
下側を満たす設定電圧は4.75+0.45+配電降下以上、上側は5.175695−0.45未満。
配電降下ゼロでも下限5.2Vと上限4.725695Vで交わらない。
0.1Vの配電降下比較ではさらに狭くなる。誤差や温度変化をゼロとしても成立しない比較。

これは実機の過渡上限や必ず停止することを証明しない。典型値を最大保証としない。
結論は「設定電圧の変更だけ」を現時点の解決策にしないこと。
次の候補では既存電圧窓に対する過渡幅・誤差の予算を先に確認する。
容量追加ならモジュールの容量・ESR制限と制御安定性の根拠が必要。

再現：
```sh
.venv-engineering/bin/python software/sim/structural/check_servo_voltage_corridor.py --out /tmp/servo-corridor
```
