# 小さな関節目標差による旋回応答

追加22衝突形状を含むモデルで、参照歩容に一定の目標角差を加えた物理診断。
**強化学習方策・10 m受入ではない。** 各6秒、全11条件を保存した。

左右の膝目標角をそれぞれ+0.01/-0.01 radとすると、後半3秒の平均旋回速度は
+0.04391 rad/s。逆符号では-0.04680 rad/s。ゼロ補正は+0.000685 rad/s。
左右差の入力と旋回応答が確認でき、関節数・脚長・足外形を増やさない方向制御の設計に使う。
全11条件で6秒間の終了判定はなし。ただし長距離・ランダム化・停止までの安定性は未検証。

```bash
python probe_yaw_authority.py --design outputs/design_r6_base_collisions --out outputs/yaw_probe
```

`summary.json`、各条件の `report.json` と `states.npz` に実シミュレータの結果を保存する。
