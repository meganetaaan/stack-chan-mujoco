# 停止監視電源の負荷と発熱の机上集計

現行revKのSTOP_AUX3V3接続部品を抽出し、抵抗・IC・コンデンサ・供給元の分類が全参照を覆うことを確認。既存負荷から選定を見直す必要があるかを判断するための条件付き集計であり、全状態の保証値ではない。

結果は約1.466 mA。3S満充電12.6 Vと比較上の出力下限3.207 Vを使うと通過素子損失13.77 mW。資料のJEDEC熱抵抗212.1 K/Wによる温度上昇は2.92 Kだが、実基板の温度でも全損失でもない。TPS70933候補は維持する。負荷合計の不足を未知の一律安全係数で覆って合格とはしない。

抵抗は最小抵抗値と全電圧印加で計算。U10のMR内部プルアップは別に加算し、U11出力電流として再加算しない。R9はLOGIC3V3給電、電圧監視分圧器はサーボ変換器側給電のためSTOP_AUXには加算しない。CのDC漏れ、充電電流、IC動的消費電流、基板漏れは未計上。

資料：

- https://www.ti.com/lit/ds/symlink/tps3808.pdf （SBVS050N、6ページ）：IDD条件はRESET非アサート等。リセット中の保証をこの値から主張しない。
- https://www.ti.com/lit/ds/symlink/tps3700.pdf （SBVS187G、6ページ）：供給電流は指定電圧点での値。全電圧・出力負荷状態へ保証として補間しない。
- https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf （5〜6ページ）：静的電流4 µA、追加500 µAは指定入力電圧での値。全入力波形の上限ではない。
- https://www.ti.com/lit/ds/symlink/tps709.pdf （SBVS186H、4〜5ページ）：熱指標・電流条件。LDO自身のGND電流による損失は今回の通過素子損失に含まない。

再現：

```sh
python3 software/sim/circuits/budget_stop_supply.py --out /tmp/stop-supply-budget
```

この比較の再掃引は不要。次は起動・停止時の電流経路および入力の逆接/短絡保護を回路として具体化する。現物の基板温度・部品ばらつき確認は後続実測へ分けるが、電源全体の未完成設計を実測へ丸投げしない。
