# ブーツ埋込みナット座の局所FEスクリーニング：収束未達

左後部ナット座を8×8×3.2 mmの領域で切り出し、座面下面を完全固定、ナット空間底面へ下向き20 Nを与えた。PETG等方線形弾性 E=1120 MPa、ν=0.35。荷重面は実際のナット面より広く、接触解析でも予圧解でもない。切断した側面は自由境界であり、周囲の拘束は省略した。

1.0、0.7、0.5 mmの3メッシュで計算。最細では変位0.001418668 mm、最大絶対主応力2.207925 MPa。変位・応力の仮基準0.2 mm / 5.6 MPaは満たすが、最後2メッシュの最大主応力変化は約12.8%で10%収束条件を満たさない。全体スクリーニングは不合格。局所的な応力集中を除外して合格させていない。

各解で組立荷重の合力・モーメントを照合し、残差とひずみエネルギーも保存した。EPIC3/4の歩行荷重を用いた全機構解析ではなく、20 Nという仮の締結軸力に対する局所応答。適正予圧、局所接触、他の7座面、引抜き、クリープ、材料積層異方性は未確認。強度承認・製造承認なし。
