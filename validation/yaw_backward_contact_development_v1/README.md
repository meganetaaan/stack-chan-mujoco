# 後退時の接地と横速度の開発比較

同じ r8 モデル、205秒の凍結済み動作・切替プロトコルで、後退時の重心移動時間を比較した開発記録。胴体、脚長、足形状、物理条件、着地判定、合否閾値は変更していない。正式受入試験ではない。

## 完了した比較

| 後退の重心移動時間／歩行周期 | 開発条件 | 総合通過 | 物理異常なし | 運動指標通過 | 着地要件通過 |
|---|---|---:|---:|---:|---:|
| 25% | 311101〜311120 | 16/20 | 20/20 | 20/20 | 16/20 |
| 20% | 同じ20条件 | 15/20 | 20/20 | 15/20 | 20/20 |

25%は `fresh20/`、20%は `backshift02_paired20/` に全試行を収録した。失敗条件を差し替えていない。25%では後退区間の有効着地数が不足し、20%では5条件で後退の横速度RMSEが0.030 m/sを超えた。20%の固定条件と既知の開発難条件310613は205秒の全要件を通過したが、開発20条件全体の結果を優先し、正式評価の合格とは扱わない。

`*_audit_v2.json` は保存したMuJoCo状態から運動指標を再計算し、シードによるパラメータ、状態・接地イベント・実行ソースのハッシュ、イベント集計と報告の一致を検査した結果。物理サブステップの異常判定は記録された実行エンジンによるものであり、20 ms間隔の状態だけから再証明したものではない。

## 接地の診断

`yaw_backward_contact_trace_v1/` は310613の1 ms接地記録。右足は約261 msの離地後、6 ms接地、1 ms離地などの短いバウンドを経て約370 ms接地している。既存の厳密な着地判定は途中のバウンドでその離地に対応する着地候補を取り消す。`touchdown.png` と `touchdown.pdf` はこの実測シミュレーション記録を図示したもの。合格のために判定を緩和していない。

後退末尾の整定時間を15%、20%に延長した32秒試験では改善せず、重心移動時間を30%、35%にした試験では約20.43秒で歩行中断となった。20%と22%の短時間試験では着地が改善した。32秒試験には旋回が含まれないため、全動作の達成証拠には使わない。22%の205秒比較はこの記録作成時点で実行中。

## 再評価

リポジトリルートから、必要なPython依存関係を導入した環境で実行する。出力は未使用パスを指定する。

```sh
python assess_yaw_development_batch.py --batch validation/yaw_backward_contact_development_v1/fresh20 --out outputs/new_fresh20_audit.json
python assess_yaw_development_batch.py --batch validation/yaw_backward_contact_development_v1/backshift02_paired20 --out outputs/new_backshift02_audit.json
```

各試行は実際の状態、着地イベント、プロトコル、実行時のprobeソースを保持する。報告内の `outputs/` パスは実行時の履歴である。古いバッチ実行ソースは `batch_runner_used_for_fresh20.py`、位相変更前の生成ソースは `*_before_backshift.py` に保存した。正式試験用ツールは単体試験段階であり、そのテスト内の仮ラベルは実際の正式試験結果ではない。正式シード217000〜217019、218000〜218019での動力学試験は未実施。
