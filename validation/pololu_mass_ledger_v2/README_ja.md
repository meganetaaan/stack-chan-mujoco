# 現行電源取付候補の質量・幾何モーメント台帳

通し穴2.4mmの現行43部品を参照し、旧後部板・旧UBEC二台を置換する台帳を更新した。
部品の追加・削除ではないため、カタログ質量等を割り当てた小計422.732258gは不変。
これは全身質量ではない。未割当ての樹脂ブラケットは体積・一次モーメント・原点慣性の
密度係数を更新した。左右合計の体積差は−36.215023mm³。
造形密度を未確定のまま、実質量が何g減ったかは断定しない。

`reconciliation.json`で旧台帳との数値配分一致と、左右ブラケット以外の係数一致を確認。
電源回路243参照との対応は、レギュレーター2参照がカタログ質量に対応。
残る241参照は現行台帳との対応が未確認。これは241個すべてを新たに加算せよという意味ではない。
従来TTL・基板予約の範囲と照合してから置換・追加を決める。
基板の基材・銅・はんだ・配線・端子と、モジュール本体に含まれる部品を二重計上しない。

未解決項目は引き継いだ。M2ナット8点、ワッシャー8点、樹脂密度、電源部品配置と
質量分布が未確定で、全身質量・重心・慣性はnull、MuJoCo更新はfalse。
不完全な慣性で共通負荷データを再生成して強度合格にすることはしない。

再現：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/update_pololu_mass_ledger.py --out validation/pololu_mass_ledger_v2
python software/sim/structural/reconcile_current_power_mass.py
```

次は基板・ハーネスの構成と配置を確定し、質量台帳への対応を閉じる必要がある。
今回の差分は穴変更の反映まで。強度・歩行・製造の完了証跡ではない。

初回の台帳比較は浮動小数点の完全一致で失敗した。後部板のSTEP再出力に伴う
小計差−8.88×10⁻¹⁶kgを確認し、比較を相対1e−10・絶対1e−18の数値許容へ変更した。
これは質量や製造の合格基準ではない。実差分と比較許容値を`reconciliation.json`に残した。
文字列・部品名・分類は引き続き一致を要求する。
