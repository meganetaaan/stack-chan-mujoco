# 電池・変換器・トレーの質量台帳置換

旧2S電池仮置き103g、単一変換器20g、旧トレー6.904gを台帳から除き、Tattu3S候補76g、UBEC候補36g×2、現トレーPETG充実体7.837gへ置換した。STEPはpower_packaging_revAとハッシュ照合し、配置済みの座標を使用した。

質量差は+25.933g。ただしオフセットした部品なので質量差だけを加える方法は使わず、一次モーメントと原点回り慣性も引いてから追加した。更新後固定小計446.270gは胴体全体の質量ではない。未選定の密度項、ねじ・ナット、配線、保護基板等を含まない。

電池・変換器の内部重心と慣性は未公開のため、公称質量を一様なCAD形状へ配分する比較仮定。トレーは既存PETG候補の代表密度で算出した。実機の材料や中身がこの分布であるとはしない。

更新小計を、残した旧部品＋選定済み金属板/座金＋新搭載候補から独立に再合成し、置換結果と一致することを確認した。左右対称のUBEC配置はY一次モーメントで相殺するが、X/Z方向は変わる。ここから全身の重心を断定しない。

今回更新したのは台帳の固定小計で、MuJoCo本番モデルは変更していない。残る密度項・締結品・配線・制御基板の割当てと座標確認を終えてから、胴体慣性を置換する。電源候補の電気的な適合は別途未完了。

