# 故障解消後の解除確認を追加する設計

遅延押下反例への対策として、健全状態で未整形ボタン信号とデバウンス出力がともに解除を示す状態を連続確認してから、再許可受付を保持する段を追加する。電源/監視不正、故障、停止で受付と投入許可を同時に消去する。受付が成立する前の押下は蓄積しない。

解除確認時間はデバウンス最大80 msより長く、実回路のタイマー公差・経路差を含む最小値で満たす必要がある。今回の参照モデルでは1 ms刻みで80 msを超える条件としたが、81 msを製造タイマー指定にはしない。未整形入力のノイズは解除確認をやり直す方向へ作用させる。実入力保護/しきい値/信号同期は未実装。

20/50/80 msのデバウンスと、故障解消前3時点の押下を組み合わせた9ケースで、押しっぱなしによる再投入が起きず、その後の解除・新押下で投入可能なことを確認した。全アナログ条件、短い故障パルス、同時エッジ、部品故障の網羅ではない。

実装の機能分担は、解除継続タイマー→受付保持→新押下による投入保持。SN74HCS74の未使用側を受付保持へ利用する案を検討できるが、タイマー・リセット競合・PORを含むピン接続はまだ発行しない。D=High単一DFFの旧案は不合格のまま残す。

今回の終了条件は既知反例の論理対策確認まで。次は最小解除時間と停止優先を満たす実タイマー/ゲート回路を選定する。#24は未完了。
