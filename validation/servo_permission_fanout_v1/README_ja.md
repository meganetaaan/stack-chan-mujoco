# 許可信号の接続負荷と電源名の統合

POWER_ENABLE_COMMANDを既存revIとOVP接続案から抽出し、U3出力、U8入力、
新規U_PERMIT_L/R入力、既存R6=220kΩプルダウンの5端子を確認した。
新規受信部の電源名AUX_3V3は既存LOGIC3V3へ修正。別電源を暗黙に作らない。

[TI SN74HCS11 Rev.B](https://www.ti.com/lit/ds/symlink/sn74hcs11.pdf)
の軽負荷出力規定は20µA。受信3個×1µAとR6総合±1%の比較を使うと、
3.3V時は18.1515µAでこの試験負荷以下。20µAに収まる電源上限は3.7026V。
これは新たな電源許容範囲ではなく、選定済み電源仕様を照合するための境界。

[Nexperia 74LVC1G17](https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf)
の入力漏れ規定を比較に使った。電源立上り中、低電圧、入力遷移中、
配線容量や受信しきい値を含む論理伝達の合格ではない。
既存100kΩのSHDN側負荷は専用バッファ出力に接続され、U3へ直接加算しない。
逆に追加したバッファの電源消費とデカップリングはLOGIC3V3側の評価へ含める。

接続・入力ファイルのハッシュはreport.jsonへ保存。起動監視は未実装のまま。
