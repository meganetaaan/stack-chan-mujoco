# クリア出力の比較器代替案

TPS3700DDCRのOUTBを使う非互換の代替接続を定義した。INB−へクリア要求、OUTBへRESET_N、未使用INA+はGND、OUTAは開放とする。R4/R14の値は変更しない。現行revIには未統合。

現行の負荷比較38.573 µAに対し、メーカーのVOL規定点は0.25 V。OFF漏れの参照値0.3 µAを使うとRESET_N High比較は2.7424 Vとなり、旧U14の漏れを用いた2.69695 Vより改善する。ただしVOLは指定された電源・電流の試験点であり、3.207〜3.393 V全域の保証を新たに得たとは扱わない。

この案は新たな制約も持つ。出力Bは低電圧時にHi-Zとなり、電源投入後は最大450 µsの未確定期間がある。U7の独立リセットによる抑止を確認するまで置換しない。また、クリア解除側の駆動電圧は比較器の負方向しきい値未満にする必要があり、従来のAUP入力Low条件0.9 Vを流用できない。伝搬遅延・短い要求パルスの応答もロジックゲートと同等とはしない。

重要な読み分け：VOL表の1.3 V／0.4 mAを、UVLO中にOUTBがLowを保持する保証として使わない。UVLO時OUTBは開放という動作説明が適用される。

結論：静的な候補比較として保持するが、現時点では採用未決定。次の評価は独立リセット・駆動元・電源遷移を含めた成立確認に限定する。未知のしきい値や遅延を都合よく仮定した掃引は追加しない。#24未完了、通電保留。
