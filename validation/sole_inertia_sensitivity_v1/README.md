# 足裏慣性の荷重経路への影響

右足の元圧力中心は支持矩形から25.8 mmケースで0.13711 mm、25.95 mmケースで0.17233 mm外。単なる摩擦不足ではない。

候補TPU足裏STEPの体積・重心・慣性テンソルを使用し、記録した足部剛体運動から足裏単体の空間慣性荷重を計算。ヨークへ伝わる荷重は床荷重からその項を差し引く。密度1000/1200/1400 kg/m³は感度仮定であり材料仕様ではない。

25.8右の矩形超過は0.02245/0.000231/0 mmへ変化する一方、25.8左は0.05107/0.11736/0.18400 mm外に出る。25.95右も0.10360/0.09028/0.07709 mm外。慣性を含めても、全選定荷重を非接着の圧縮接触だけで成立させる証拠は得られない。

足裏保持機構は引張・せん断も伝える荷重経路として設計する必要がある。支持範囲を数値上拡張して合格にしない。現行慣性データは候補CAD全体で再計算した運動ではなく、この結果は感度診断。局所変形、丸角、摩擦錐を含む最終接合評価は未実施。

```sh
export LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu"
.venv-engineering/bin/python software/sim/structural/sole_inertia_sensitivity.py --out outputs/sole_inertia_repro
```

全仮定と荷重・圧力中心を保存。caccのMuJoCo重力規約を保ち、重力を二重加算していない。
