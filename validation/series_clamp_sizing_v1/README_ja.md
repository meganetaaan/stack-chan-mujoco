# 外部MOSFETによる直列クランプの設定候補

LT4363IMS-1#PBFを比較候補とし、出力帰還33.2k/10k、電流検出8.2mΩを仮設定した。抵抗の総誤差配分±1%を含め、メーカー試験点を適用した比較では出力5.285～5.737V、電流制限5.433～6.775A。通常上限5.25V、サーボ上限6V、既存モデルの脚別4.917Aを変更せず通過する。実部品の抵抗・MOSFET・タイマーは未選定、現行構成に未統合。

重要な設計負担は、12.6V流入時の直列MOSFET損失が比較上最大49.56Wとなること。1ms当たり49.56mJという換算は、許容時間を決めたものではない。初期温度を考慮した線形動作のSOAとタイマー最悪時間を対応させる。低いオン抵抗や単発エネルギー値だけでは選定しない。電流検出抵抗の比較損失は最大0.373W。

資料の試験条件と実回路の違いをplan.jsonに記録した。特に1µsのOV応答最大値はFBを0→1.5V、OUT=0Vとした条件であり、実際のクランプ波形の保証へ置き換えない。FB電圧精度も試験点からの比較で、全動作点の保証としていない。

次の終了条件: 候補MOSFETが該当電圧・電流・初期温度・故障時間で線形SOAを満たすか、満たせないため方式を棄却するかを判断する。タイマーを通りやすい時間に仮置きしない。低入力時のゲート駆動、逆流防止、始動と手動再始動の接続も採用条件に含む。下流からの回生は直列制限では吸収できず、負荷側吸収回路は別途必要。
