# 制御電源入力保護の部品検討

TPS26600を一つの候補として確認した。一次資料は[TI SLVSDG2G §7.5/§7.6](https://www.ti.com/lit/gpn/tps2660)。4.2..60 V動作、逆接・逆流阻止、調整可能な電流制限とスルーレートを備える。TPS709の前段に置く構想で、既存サーボ保護回路の置換ではない。

**選定で判明した制約:**

- UVLOをGNDへ接続して使う既定値は、立上がり14.25..15.75 V。3S満充電12.6 Vでは起動できない。外部分圧が必須で、各セルの低電圧保護の代用品にはならない。
- 既定OVPは立上がり31..34 V。後段TPS709の推奨入力上限30 Vより高いため、そのまま後段保護の成立を主張できない。OVP分圧と遮断遅延を検討する。
- RILIM=120 kΩで過負荷制限は85..115 mA（差電圧1 V）、短絡制限80..120 mA（差電圧5 V）。「1 Aで±5%」を100 mA設定に転用しない。
- MODE開放はTPS26600では自動再試行する遮断モード。ラッチ停止が必要な場合は402 kΩをRTNへ接続する電流制限モード等を選び、復帰方法を設計する。単に開放してラッチ停止と扱わない。

上の電流仕様は表の共通条件VIN24 V等を伴う。3S電源での最小制限電流を確定した結果ではない。初期容量の充電電荷94.919 µCに対して、仮に80 mA一定供給・20 mA一定負荷なら充電時間は約1.582 msだが、実部品の起動時間ではない。dVdT、LDOの起動、入力側容量、制限中のタイマ・熱と合わせて評価する必要がある。

**判断:** 機能として検討対象にできるが、現時点では採用・回路統合しない。上記の既定UVLO/OVPと故障復帰を未設定のままBOMだけ確定するのは不可。次の設計対象はUVLO/OVP分圧と停止復帰方式であり、未知の波形を仮定する追加掃引は行わない。資料の供給電流は有効時最大390 µA（共通試験条件下）で、採用時には3.3 V出力負荷ではなく電池側の待機負荷へ計上する。
