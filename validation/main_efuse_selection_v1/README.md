# 主経路の低抵抗eFuse候補

2026-09-21。TPS259823ONRGEを主経路の過電流遮断候補として保持する。主遮断システム全体の採用確定ではない。

一次資料：[TI TPS25982](https://www.ti.com/lit/ds/symlink/tps25982.pdf)、SLVSEI3D May 2026、型式表/電気特性/故障復帰。選択は7.6 V OVLO、Circuit Breaker型。5 V通常給電に3.7 V OVLO型を使わない。4.5 mΩ最大は2 Aおよび資料温度条件の規定で、典型2.7 mΩだけで計算しない。

## 電圧予算と適用境界

規定2 A点で素子降下は9 mV。部品単体では0.10 V予算より小さいが、全経路の適合ではない。既存1 A治具比較の配線降下0.066575 Vに4.5 mΩを比較適用すると合計0.071075 V。1 Aへの比較適用を全温度/全電流の実測保証とは扱わず、全身負荷・配線・追加逆流防止段・過渡は別予算とする。

内蔵OVLOのしきい値はサーボ6 V上限より高い。これだけをサーボ過電圧保護に使わない。回生バスが入力より高い場合の逆流、入力無給電時のOUT印加、オフ時の双方向隔離について、今回読んだ仕様から必要な保証は確定できていない。低抵抗と過電流機能だけで双方向遮断を証明しない。

## 保護設定

- RETRY_DLYをGNDにすると自動再試行なしの設定になる。ただし入力低下またはEN操作でも故障ラッチをリセットできる。電源喪失を跨ぐ停止記憶/新たな手動再許可は外部の既定オフ回路で設計する。
- EN/UVLOを浮かせない。入力・監視・手動許可の条件が成立したときだけ有効化する。外部回路を含む電源喪失時Lowの保証は未実装。
- ILIMは未選定。モーター側9.63 AをそのままDC遮断設定にしない。素子設定範囲・誤差、最小正常負荷余裕、配線/コネクタ保護、起動電流、短絡エネルギーを満たす値を決める。
- ブランキング、スルーレート、レイアウト放熱、入出力過渡対策は未確定。瞬時電流制限を理想スイッチに置換して合格を主張しない。

今回の終了は主経路候補を1型式へ具体化し、必要条件を抽出するまで。次は逆流/隔離を保証する段との組合せと手動許可回路を設計する。専用の低電流分岐保護としても未承認。#21/#22/#24は未完了。
