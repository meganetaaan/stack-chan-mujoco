# ヨーケース締結の上面工具アクセス候補

胴体上面へφ6 mm穴を8個追加。軸はメーカー図面/STEPで照合済みのケース取付軸。従来の外形範囲は全方向で変化0、単一有効ソリッド。切除体積407.150408 mm³。脚長やヨー軸位置は変更していない。

穴径の根拠は、仮工具径4 mm＋両側の既存公差予算0.40 mm＋残余0.50 mmから最小5.8 mm。呼び6 mmは片側0.10 mmの追加余裕を持つ設計候補であり、購入工具の保証値ではない。8経路とも公称半径隙間1.00 mm、公差予算後0.60 mmで既存残余0.50 mm基準を満たす。合否基準を緩和していない。

元の `yaw_case_mount_v2` の工具干渉8件は旧胴体の不合格として保持する。今回は部品形状の変更によって対象干渉を解消した。切除以外の変更はないため、既存部品との新たな体積干渉を追加しないが、穴縁・上面の剛性、応力再配分、外観、異物侵入、実工具/手の操作性は別に確認する。

この部品は `rear_joint_inset2_v1/body_shroud.step` を基にする。足候補や凍結MuJoCoを更新したものではなく、統合先での部品版管理が必要。
