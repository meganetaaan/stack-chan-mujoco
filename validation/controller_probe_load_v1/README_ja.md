# 現行制御電源の起動評価負荷との照合

196部品v4を対象に、従来の主許可インターフェース込みの部分予算へ、補助許可枝とクリア入力回路を追加する。64 MHz比較点は11.405141 mAから**12.129356 mA**へ変更。旧値を現行回路の評価に流用しない。

追加内訳はreport.jsonに保存。補助許可枝340.579 µA、クリア入力10 kΩの低状態363.636 µA、追加OD/Schmittの静的ICC計14 µA、入力漏れ割当計6 µA。抵抗は3.6 V・合成1%という設計側の比較条件を継承した。漏れと抵抗負荷には重複し得る保守的割当があり、同時に成立する実状態の再現ではない。

CTRL3V3直結の公称容量は10.3 µF。新規100 nF×2を部品表から抽出した。SYS側の1 kΩをOD出力が吸い込む電流は、SYS側電源の負荷でありCTRL LDOの電流には加えない。SYS予算の確認は別途必要。

[TΙ SN74LVC1G07 §5.5](https://www.ti.com/lit/ds/symlink/sn74lvc1g07.pdf)、[Nexperia 74LVC1G17 table7](https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf)のICCは指定入力・無負荷での条件値。中間入力、動的消費、既存論理回路・監視ICの未割当、MCU周辺回路、LDO接地電流、コンデンサー公差などは未完。ΔICC 500 µAも特定入力点であり全入力範囲の上限ではない。総最大電流はnullを維持。

再現: `python3 software/sim/circuits/reconcile_controller_probe_load.py`。
終了条件は追加回路の予算漏れと公称容量の対応解消。今回の出力は合否判定ではない。次の解析には全静的負荷と実行環境の整備が必要で、仮定電流を反復して起動合格にはしない。
