# 足裏・ヨーク界面の圧縮摩擦錐スクリーニング

丸角足裏25.8/25.95 mmの左右各最大モーメント時刻について、z=-19 mmの圧縮点力で6成分合力を保持できるか線形計画で検査。支持点はx23点、y13点の格子（x間隔86/22 mm、y間隔4 mm）と四分円16分割の境界。ねじ頭ポケット半径2.4 mmを除外。planのgrid_mm=4は公称値。

摩擦は|Fx|+|Fy|<=μFz、Fz>=0の内接ピラミッド。左は両系列とも試験μ=0.2,0.4,0.8,1.6で釣合い可能、0/0.1では不可。右は全試験μで不可。これは有限個の接触点と保守的摩擦錐での結果であり、連続面の不成立を証明しない。

床合力を足裏の慣性なしでヨーク上面へ伝える仮定を含む。最小摩擦係数の確定値ではなく、実材料の摩擦仕様にも使わない。LPの解は疎な点力となり、接触圧や構造応力として直接使えない。次は右足ケースの支持点離散化・圧力中心と、TPU足裏単体の慣性寄与を確認する。

```sh
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/screen_sole_contact_cone.py --out outputs/sole_cone_repro
```

全成功・不成功ケースをreport.jsonに保存。成功時の点力はnpzに保存し、合力残差1e-6以内を検証。強度合格は未判定。
