# 個別配線と共通遮断素子を合わせた電圧予算

目的：全身電源選定へ戻り、共通配線に割当可能な余裕を確認する。
新規の未知負荷シミュレーションは行わない。

既存比較の0.10V予算、枝1A・片道0.25m、接点往復40mΩ、
Alpha3051の20℃公称抵抗を維持。共通eFuseの4.5mΩを加算した。
枝配線は固定治具用候補であり、全身用可動配線へ採用した意味ではない。

共通2A（eFuse抵抗の仕様電流点）では残り24.43mV。
共通4.815Aの参考計算では11.76mV、他の損失をゼロとしても共通配線は
2.44mΩ以下となる。4.815AはDC最大の保証値ではなく、eFuse抵抗も
この電流での保証に読み替えない。どちらも実機不合格の証明ではない。

判定：現行部品を並べただけでは全身給電を製造リリースできない。
リップル、ヒューズ、逆流遮断、温度上昇、共通コネクタの余裕が未配分。
比較値が正であることを合格と扱わない。

次の設計順序は、#21のDC負荷包絡と供給精度・配電方式の選定、
共通経路の具体化、その後に#24の起動論理統合とする。
この計算は終了し、未知電流の掃引拡大や局所論理部品の追加を優先しない。
評価基準を緩和して電源を通す変更は行っていない。

再現：`python3 software/sim/circuits/check_distribution_headroom.py --out NEW_DIRECTORY`
入力資料とハッシュはreport.json。元の部品資料は入力JSONのsourceを参照。
