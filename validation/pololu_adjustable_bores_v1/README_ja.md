# 電源ブラケット：通し穴2.4mmの比較形状

## 変更と判断

現行43部品組立の左右ブラケットだけを変更した。8か所のねじ通し穴を
2.2→2.4mmとし、ナットの回り止め溝幅4.2mmを維持する。
除去体積は左右それぞれ18.107512mm³。両部品とも有効な連続1ソリッドを維持し、
旧形状の外側に新しい材料がないことをB-rep差分で確認した。
部品数・外形・基板位置・ねじ長・ナット型番は変更していない。

PCB位置誤差を各軸±0.1mm、追加の位置誤差を仮に±0.05mmとした感度例について、
各ねじ・ナット・スペーサーをXY各±0.09mm調整した32条件を比較した。
同じ配置で旧ブラケットは全32条件で体積重複0.01mm³を超え、新案は全32条件で以下だった。
基板穴との公称半径方向余裕も非負。基準を変更した結果ではなく、通し穴の変更による改善。

追加誤差±0.05mmは造形性能の認定ではない。穴と溝の偏心・サイズ公差を含めた
製造合格を意味せず、現行正式参照先や100部品統合CADはまだ置き換えない。
比較用の43部品組立、左右ブラケット、部品一覧をここへ出力する。

## 座面と残件

32姿勢のスペーサー投影座面は最小7.899453mm²。
前の±0.05mm調整の検査より穴径・姿勢の両方が変わっているため、
面積差を穴拡張だけの影響とは扱わない。
座面量は接触圧・クリープ・締付け保持の強度合格値ではない。
ナット回り止めのトルク、ねじの傾き、造形公差、工具と組立経路は未確認。

次の終了条件は、穴・溝の仕上がり限界と相対位置を指定して調整可能域を閉じ、
座面と締付けの成立を確認すること。未確認の造形精度を仮定して製造確定しない。
この比較では追加の穴拡張やメッシュ細分化を行わない。
