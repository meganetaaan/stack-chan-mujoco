# ブーツ締結部の軸方向アクセス：不合格

座面追加済みブーツ、新ヨーク、凍結r9足裏を組み合わせて確認した。直径2 mmのねじ軸包絡は全8穴で通る。一方、仮定した直径5 mmの工具包絡は全8穴で上側のブーツ壁に干渉し、下側も足裏に遮られる。上側干渉体積は約22.969〜180.641 mm³、下側は約58.709 mm³/穴。全体判定は不合格。

工具直径は選定済み製品の寸法ではなく事前宣言したスクリーニング仮定。全ての工具や組立順序が不可能という主張ではない。ただし現行の穴と座面だけでは締付け手順の成立を証明できない。

次の設計候補は、足裏を外した状態で下側から締める構成と、ブーツ側の回り止め付きナット保持。ねじ頭の収納、ナットの挿入・保持・引抜き強度、足裏の着脱方法、工具公差と組立順序を設計し直す必要がある。現時点で採用や製造承認は行わない。
