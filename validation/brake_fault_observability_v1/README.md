# 常時オン故障の観測信号修正

旧`brake_detector_logic_v1`は「実ゲートLowかつ枝電流High」を継続判定した。MOS短絡の一部には対応するが、選定中のゲートドライバがHighに固着する故障は見逃す。旧波形はその限定条件の証跡として保存し、広い故障対応の証明には使わない。

新しい回路の常時オン検出には**吸収指令がオフなのに枝電流が高い**という不一致を使用する。吸収指令はTPS3700 OUTAからUCC27517 IN+へ至る信号で、実MOSゲートとは別に観測する。これによりドライバHigh固着も論理上検出できる。7つの代表状態の比較をreport.jsonへ保存した。状態の信号値を割り当てた論理表であり、部品故障モデルや実故障注入ではない。

ただし、検出器出力の断線で指令自体がHighになった場合は正常吸収と同じ信号になる。指令/ゲート/電流の3信号だけでは、この状態を正常吸収から区別できない。故障検出には別のバス電圧観測または独立した熱/時間/エネルギー制限が必要。後者の時間を正常回生の継続上限なしに仮置きしない。

ゲート開放による吸収不作動、電流センサーLow固着も常時オン判定だけでは扱えない。指令オンかつ無電流を直ちに故障とすると、回生終了や立上り時に誤判定し得る。供給電圧・過渡時間・実センサー状態を含む別条件が必要。

## ラッチ回路へ渡す前の条件

- 吸収指令と実電流の有効性を監視する。監視用電源喪失を「異常なし」に置換しない。
- 正常なオフ遷移後のゲート放電、電流センサー整定、比較器遅れを含めて不一致継続時間を決める。旧1 msは実部品保証値ではない。
- ラッチ出力は上流の物理遮断へ接続し、残留回生用の検出器・ドライバ給電を同時に落とさない。
- 再給電時は停止記憶または既定の無許可状態から手動再許可へ戻す設計が必要。通電復帰だけで自動駆動しない。

この修正は検出ロジックの要求変更であり、しきい値や試験合格基準の緩和ではない。実比較器・タイマー・ラッチ・遮断器は未統合。#24は未完了。
