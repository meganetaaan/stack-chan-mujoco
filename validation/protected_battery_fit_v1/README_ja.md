# LB-020の現行胴体への配置比較

メーカー公称寸法の直方体を、現行電池の中心を変えず6方向で比較。99部品との静的検査。
事前計画はplan.json、形状入力ハッシュと結果はreport.json。

| XYZ寸法mm | 干渉部品数 | トレー以外の最小隙間mm |
|---|---:|---:|
| [70, 36, 24] | 12 | None |
| [70, 24, 36] | 6 | None |
| [36, 70, 24] | 9 | None |
| [36, 24, 70] | 5 | None |
| [24, 70, 36] | 1 | 5.4 |
| [24, 36, 70] | 1 | 5.4 |

全6方向で既存トレーと干渉し、そのまま交換は不可。24×70×36と24×36×70の2方向はトレーだけと干渉。
これはトレー再設計の候補を得た結果であり、保持強度、配線、充電端子へのアクセス、脚動作、公差、電池膨張の証明ではない。
次の配置作業はこの2方向から固定方法と配線空間を含めて選び、現行外形の維持を検査する。製作HOLD。

再現：`LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/screen_protected_battery_fit.py`。
