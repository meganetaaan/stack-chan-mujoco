# 吸収MOSFET候補と半導通時の設計条件

2026-09-21。AO3400Aを抵抗式吸収回路のローサイドスイッチ評価候補にする。製造リリースではない。メーカーはAlpha & Omega Semiconductorを指定し、同名の他社品へ無検証で置換しない。

## 一次資料と適用範囲

[AOS AO3400A datasheet](https://aosmd.com/res/data_sheets/AO3400A.pdf)、Rev 3.1 July 2023、p1–2。VDS絶対最大30 V、VGS±12 V。オン抵抗最大48 mΩはVGS=2.5 V、ID=3 A、接合25℃の条件。しきい値を完全オン電圧としない。高温/低ゲート電圧の抵抗や実装放熱をこの値で保証しない。資料のSOAは単発条件で、繰返し運転の承認ではない。

## 計算結果と判断

吸収抵抗の既存仮包絡Rmin=4.42714 Ω、バス6 V以下、抵抗健全という条件で計算した。48 mΩを用いる完全オンの比較損失は約0.0863 W。一方、抵抗直列の半導通では `P=VDS*(6−VDS)/R` となり、VDS=3 V、ID=0.6776 Aで約2.033 Wになる。シャント/配線の抵抗を省略した上側の負荷線であり、抵抗短絡や配線インダクタンスを覆わない。

完全オン時の低損失は採用を検討する根拠になるが、補助電源低下中の半導通に耐える根拠にはならない。1 ms等の従来仮置き検出時間をここで許容滞留時間として流用しない。低オン抵抗だけを理由に旧モデルの0.1 Ωを置換して合格を主張しない。

## 次の設計で確定する事項

- 実ドライバ出力下限から、ローサイドシャントによるソース上昇とGND差を引いたVGSを評価する。AUX3V3の電圧をそのままVGSとしない。
- ゲート駆動電源の低下/消失時に半導通へ滞留する時間を回路から上限化し、その負荷線をSOA・実装熱条件と比較する。ゲートをオフへ倒すだけでは回生吸収も失うため、負荷側から生きる制御電源または独立吸収経路が必要。
- 抵抗短絡、MOS短絡/開放、共通制御電源故障、抵抗の寄生によるVDS過渡を別故障として扱う。
- これらの回路が定まった後に限り、最大時間・温度・繰返し条件を先に固定して過渡解析する。典型Qgから保証スイッチ時間を作らない。

今回の終了条件は負荷線の算出と設計制約の抽出。追加の仮想回生波形は不要。部品候補は残すが、SOA/熱/故障時吸収は未確認で#22/#24を完了しない。物理測定は#49で、実回路と試験上限の確定後に扱う。
