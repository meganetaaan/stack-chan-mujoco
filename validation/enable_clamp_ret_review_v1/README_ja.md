# 停止原因とENを分離するRET案：採用保留

revDのU9出力をENから独立したRAIL_HEALTH_Nへ変更し、それをU7のMRへ伝える構成を検討した。EN側には2段のNPN抵抗内蔵トランジスタを置き、正常LowのENが停止記憶へ戻らないようにする。入力HighでQ1がON→Q2がOFF、入力LowでQ1がOFF→Q2がONとなる案である。U9が検出した低電圧をU7経由で保持許可へ確実に伝えることが目的で、追加待ち時間で反例を隠す案ではない。

比較部品はNexperia PDTC144ET、SOT23、端子1入力／2エミッタGND／3コレクタ。[メーカー資料](https://assets.nexperia.com/documents/data-sheet/PDTC144E_SER.pdf)の表8は原則25℃条件。内蔵R1は33〜61 kΩ、R2/R1は0.8〜1.2。VI(on)条件は3 V、VCE=0.3 V、IC=2 mA。VI(off)の0.8 VはIC=100 µAの条件で、完全な開放とは異なる。IB=0で規定されるICEOを、そのまま入力0.3 Vの状態に流用しない。

5 V側プルアップ10 kΩ±1%を仮置きすると、入力負荷の保守比較でHEALTH Highは3.637 V、U7 MRの内部プルアップ分を含むLow吸込は0.579 mA。この部分だけでは採用としない。Q2 OFFの比較に100 µAを用いると、既存U8の負荷は約178.5 µAとなり、レール近傍出力を保証する100 µA条件を超える。実際にこの電流が流れると予測したものではなく、現仕様点だけで従来の出力保証を維持できないという判断。

この2個のPDTC144ETを現revDへ追加する案は採用しない。回路が動かないと断定したのではなく、温度、低電圧遷移、OFF電流、入力駆動の根拠が不足している。典型SPICEモデルを追加して保証不足を埋めない。候補BOM・接続表は変更せず、次の部品比較には「ENを駆動できるだけでなく、停止原因を保持回路へ戻せること」「OFF負荷が既存出力保証に収まること」を要求する。
