# リセット出力の LVC 代替比較

結論：74LVC1G06GW + R4 75kΩを直流比較候補として残すが、revIへ単純置換しない。
100kΩ据置きと82kΩは従来のHigh比較値を維持できず、採用しない。

ユーザー要求は保護動作の成立であり、この品種・抵抗値はCodexの設計案。
3.207–3.393V、抵抗±1%、既存High比較値2.69695Vを変えず比較した。
4入力の漏れ各1µA、監視IC0.3µA、候補出力漏れ2µAを用いた比較で、
75kΩはHigh 2.729775V、Low時負荷49.997µAとなる。
2.69695Vは既存案との比較値であって、受信ICの保証閾値ではない。

メーカー根拠：Nexperia 74LVC1G06 Rev16.1、表6–7。
https://assets.nexperia.com/documents/data-sheet/74LVC1G06.pdf
Low出力0.1Vは100µA、電源1.65–5.5Vの仕様点。
漏れ電流の仕様点と実際の電圧は一致しないため、上記計算だけで保証判定しない。

重大な置換条件：入力Low上限は0.8V（旧AUP比較0.9Vから変更）、
入力エッジは10ns/V以下が必要。R14=100kΩによる入力開放時の立上りを
無制限に許せない。「Schmitt action」の記述だけではこの制限を解除できない。
入力駆動／整形と電源遷移の設計を追加せず、部品だけ交換してはならない。

追加設計の終了条件：実電圧範囲の受信閾値・漏れの根拠、入力駆動と開放時の
エッジ条件、クリア保持・解除順序を揃える。実装前に満たすべき机上課題であり、
#49の実測へ丸投げしない。現行BOM・回路・合格基準は変更していない。
