# 最新胴体の工具アクセスと顔ユニット組立順

**Tab5固定ねじは本体装着中に操作せず、顔ユニット単体で締結する。** 最新115部品CADに対し選定工具の公称包絡を検査し、この作業順を採用する。外形・脚長・CAD形状は変更しない。ねじ深さ・締結強度は未解決で、製作リリースは保留。

## 工具と検査前の条件

工具候補はWera **05118068001（2054 Micro、六角2×60 mm）**。メーカー表の軸径3 mm、軸長60 mm、柄長97 mmを用いる。全体寸法157×13×13 mmから、柄の回転を囲む半径13√2/2 mmの円柱を作る。円柱は実工具の詳細形状ではなく、公称外接形状を回転した包絡である。

出典：[製品データシート](https://hybris-media.wera.de/download/pdfgenerator-datasheets/en/05118068001.pdf)、[寸法表（Blade diameter等の列名を確認）](https://www.wera.de/en/tools/2054-screwdriver-for-hexagon-socket-screws-for-electronic-applications)。対応するSLH-M3の六角穴二面幅は2 mm：[NBK寸法表](https://www.nbk1560.com/products/specialscrew/nedzicom/miniaturescrew/SLH/SLH-M3/)。

差込量1 mm・直線進入50 mmは設計側の検査条件。対象ねじには六角穴の詳細がないため対象ねじだけを除外し、他の全部品と照合する。差込量・六角穴の適合を確認済みにはしない。数値上の交差体積閾値は既存と同じ0.01 mm³。条件は計算前に[plan.json](plan.json)へ出力する。

## 結果

| 操作 | 対象 | 結果 |
|---|---|---|
| 本体装着中のTab5固定ねじ操作 | 4本×他114部品 | 全4本で固定殻・後部プレートに干渉。選定工具による装着中作業は採用しない |
| 単体顔ユニットのTab5固定ねじ操作 | 4本×他9部品 | 交差フラグなし。各工具包絡と枠の公称最小隙間1.011 mm |
| 本体装着中の側面ねじ工具操作 | 4本×他114部品 | 交差フラグなし |
| 側面ねじを外側へ12 mm抜く | 4本×他114部品 | 交差フラグなし。元ねじと円柱近似の対称差体積も照合 |

合計1,404組。工具の軸・柄を進入量だけ延長して融合した領域で、直線移動と全回転角を覆う。離散姿勢だけの比較ではない。詳細数値・入力ハッシュは[report.json](report.json)、顔ねじの工具包絡は各`tool_sweep_*.step`。

「本体装着中不適合」はこの工具・直線経路に対する結果で、全種類の工具の不可能性を示さない。単体時の1.011 mmは造形・工具・取付公差や変形を引いた保証余裕ではない。手指、支持治具、配線、新電源基板は含まない。

## 採用する順序と未解決の工程

組立候補：

1. 造形枠の下穴とインサート工程を適格化し、顔ユニット用インサートを取り付ける。工程・保持力は未確認。
2. 本体と分離した枠にTab5を配置し、背面固定ねじ4本を締める。工具候補の経路は今回確認したが、有効雌ねじ深さ・底付き・必要掛かり・締付トルクが決まるまで実施承認しない。
3. 配線の接続と取り回しを行い、ユニットを本体へ配置する。配線・コネクターのアクセスと支持方法は未設計。
4. 側面4ねじを締める。工具経路は今回確認。樹脂座面・インサートの保持と組立トルクは別途必要。

取外し候補は電源・配線の切離し条件を確定したうえで、側面ねじを外し、顔ユニットを前方へ抜く。[40 mmの連続抜取り経路](../insert_carrier_removal_v2/README_ja.md)は同じ115部品版を検査済み。**40 mm後に作業台へ運ぶ経路や手の支持は未検査**であり、単体工具検査と合わせて整備手順全体の合格とはしない。

Tab5簡略穴とM3外径の未解決交差4件は今回も残す。メーカーSTL・公開寸法だけで有効ねじ深さを決めず、ねじ長さを根拠なく短縮して通過させない。

## #20との対応・次の終了条件

今回は「組立工具アクセス、組立順」の一部を具体化した。足裏、電池・基板、放熱、造形方向、治具、MuJoCoに渡す摩擦・位置ばらつきは本結果の範囲外で、#20をクローズしない。

次の設計検査は、配線切離し・ユニット支持を含む一連の脱着経路を定義した後に行う。終了条件は工具・コネクター・支持部が各工程で到達可能で、公差と変形を含む必要隙間が成立すること。工具形状や公差の実測確認は#48の実機側へ引き継ぐが、組立経路の未設計部分を実測任せにはしない。
