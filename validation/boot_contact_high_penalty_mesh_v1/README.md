# 高ペナルティ係数での局所接触メッシュ比較

1000000 N/mm³について1 mmと0.7 mmメッシュを追加し、保存済み0.5 mm結果と比較した。全3条件でソルバ完了・力の釣り合い・めり込み基準を満たす。最後2メッシュの変位差0.4228%、最大接触圧差1.6558%で事前の5%/10%基準内。

最細結果はvalidation/boot_contact_sensitivity_development_v1/h0.5_k1000000から再利用し、report.jsonにSHAを記録。既存の100000→1000000の変位感度0.7764%と合わせ、この局所モデルの選定条件での数値感度を確認した。初期低係数の不合格は保持する。

固定支持体と局所一次四面体・20 Nの仮荷重に限定。実ヨーク変形、ナット圧力再配分、開離・再接触、全身荷重、材料・クリープ・締結強度は未確認。製造承認なし。

再現はprobe_boot_seat_contact.py --mesh-mm <1または0.7> --penalty 1000000 --out <新規先>、次にevaluate_boot_seat_contact.py --source <生成先>。engineering環境と既存LD_LIBRARY_PATHを使用する。比較は最細/中間の量の比から1を引いた絶対値。入力デッキ・ソルバ出力・評価値を同梱。
