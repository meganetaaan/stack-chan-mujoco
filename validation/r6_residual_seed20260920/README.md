# 初回の学習済み残差PPO評価

**固定条件20/20、ランダム化条件12/20。目標未達。**
同一方策・同一モデル・同一受入基準で各20試行を実行し、失敗を除外していない。
固定87000–87019、ランダム化88000–88019。前進指令0.10 m/s、10 mを100秒以内、
停止を含む109.5秒の完了を要求する。固定条件もIMUノイズとバイアスが有効。

初回の32,768ステップ学習方策・設定は `policies/r6_residual_seed20260920`。
機体と電源の設計仮定、学習・評価・動画再生のコマンドは `docs/R6_RL_ja.md`。

- `fixed` / `randomized`: 全40試行の実現パラメータ、レポート、実MuJoCo状態・観測・行動。
- `*_state_audit.json`: 全試行のファイルハッシュ・保存状態・時刻・前進量を独立照合。
  物理刻みの接触判定を保存周期から完全再検証したという意味ではない。
- `policy_trace_verification.json`: 固定00の5,475行動を公開方策から再計算。
  最大誤差1.49e-8。初期重みから出力が変わっていることも確認した。
- `summary.json`: 失敗8件を含む要約。実機試行は0。

ランダム化の失敗は関節限界2件、自己衝突1件、前進距離／到達時間不足5件。
後者5件は終端の進行方向が約45–88度ずれており、横方向へ4.3–7.4 m移動していた。
現版の観測は胴体座標の速度・重力方向・角速度を含むが、方角・横位置は含まない。
この不足を次版の改善対象とする。単純な方策更新だけで解決したとは主張しない。

**これらの試行は次版の開発に参照した時点で、次版にとって未使用の受入データではない。**
次版の最終受入は事前固定した別シードで実行する。
