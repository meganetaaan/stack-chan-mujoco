# 下側締結・埋込みナットの収納候補

ブーツの各取付穴に4.4×4.4×1.8 mm、z=[−14.6,−12.8] mmの角形空間を設けた。足裏には半径2.3 mm、z=[−21.2,−19] mmのねじ頭収納を設けた。これは仮の収納条件であり、M2等の規格適合や購入部品への適合を宣言するものではない。

左右のブーツと足裏はすべて有効な単一ソリッドを維持。除去体積はブーツ109.477755 mm³/側、足裏146.247421 mm³/側。足裏外底z=−22に対し収納底z=−21.2の公称残厚は0.8 mmだが、荷重下の底付き・摩耗・印刷公差への成立は未検証。

想定順序は、ブーツ造形途中でナットを挿入し、足裏を外した状態でヨーク下から締付け、最後に足裏を装着する。印刷方向、挿入経路、ナットの実寸・材質、回り止め・引抜き耐力、屋根の造形、ねじ長、ねじ頭高さ、工具、足裏の着脱固定は未確定。CADの単一ソリッド確認だけでこの組立手順が実現可能とは判断しない。

次の設計判断は実部品寸法との照合、ナット挿入過程、底付き余裕と足裏保持方法の確認である。新しい金物を入れた干渉と強度も必要。製造承認なし。
