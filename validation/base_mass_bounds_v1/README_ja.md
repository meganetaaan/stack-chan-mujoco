# 胴体側の部分質量・モーメント統合

現行背面ワッシャ込みの固定小計661.228840gに、ねじ20本のカタログ質量12.36gを一度だけ加算し、部分小計673.588840gとした。旧base_print_massの小計や旧25gの配線・金物予約は追加しない。ねじの重心を外形中心へ決め打ちせず、既存の公称包絡内の分布範囲を合算した。

部分小計の重心範囲（CAD原点、mm）はX=-4.5312〜-4.2346、Y=-0.04018〜0.05377、Z=78.4466〜78.5611。これはねじ分布だけの条件付き範囲で、密度・カタログ質量・内部電装分布の公差を包絡しない。

ナット8個、配線、保護回路等の未割当てをゼロ質量と解釈しない。慣性行列の各成分の上下限は同時に実現するとは限らず、MuJoCoへ端点行列をそのまま設定してはいけない。全身質量と最悪荷重の更新は未完了。

確認：入力ハッシュ、現行revBとの対応、ねじ名20個の一意性、ワッシャとの重複なし、ねじ個別質量合計を実行時に照合する。

再現：
```sh
.venv-engineering/bin/python software/sim/structural/combine_base_mass_bounds.py --out /tmp/base-mass-review
```
