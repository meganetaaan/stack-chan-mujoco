# 停止電源出力コンデンサの資料評価

候補：GRM31CR71H475KA12L。メーカー資料2026-06-25版の2〜3ページで、4.7 µF・±10%・X7R・50 V・1206、L包装2000個を確認。取得資料のSHA256は要求JSONに保存。

判定対象は、部品の公称仕様だけで既定の実効2.2 µF以上とESR 0.2 Ω以下を証明できるか。結果は未証明。下記計算値を実部品の故障や性能不足と解釈しない。

初期容量下限4.23 µFに無バイアス温度係数の下限0.85を乗じた比較値は3.5955 µF。設計目標までの残る減少余裕は38.81%。これはDCバイアス・経時・実装の合計に許せる予算の目安であり、各仕様の同時成立保証ではない。

損失係数の規定は室温・1 kHz±10%の測定条件に限られる。DF上限から換算したESR上限約1.045 Ωは、必要な0.2 Ω以下を証明するには緩すぎる。実際のESRが0.2 Ωを超えるという意味ではなく、ループ安定性に関係する周波数・温度への外挿も行わない。

再現：

```sh
python3 software/sim/circuits/screen_stop_output_capacitor.py --out /tmp/stop-cap-check
```
