# 主線・セル監視の一体接続候補

## 判断

一体化のみでは逆接保護は成立しない。正式250参照回路へ未統合、製作HOLD。
主線逆接・一本抜けを評価対象から除かず、次はBQ入力保護と参照電位喪失時の経路を設計する。

## 配線案と検査範囲

ロボット側の論理端子をB0/B1/B2/B3の4本に統合する。端子番号・向きは未確定。
電池アダプターではXT30からB0/B3、バランス端子から中間B1/B2だけを取り出す。
バランスB0/B3は接続せず個別絶縁する。細いバランス線に主電流を流さない。
通常の4線バランスをそのまま合流すると、前回の逆接短絡がアダプター内に移るだけなので不採用。
アダプター自体の結線検査は必要だが、それを電気的保護成立とは扱わない。

事前の終了条件：4端子の全24置換×16開閉状態を列挙し、VSS参照喪失と負電位源を抽出する。
抵抗・IC・接触過渡を含まないため、この検査から安全合格を出さない。
再現：`python software/sim/circuits/screen_unified_cell_connector.py`。

384状態を保存。主線のみ逆転した割当て(3,1,2,0)では、VSS基準のB1/B2/B3は
それぞれ−2/−1/−3セル分になる（等セル電圧の例示、実入力ピン電圧ではない）。
重複GND線の直接短絡を除いても、入力抵抗・クランプを通る電流を未評価。
B0未接触時の電位は不定としてnullを出し、0Vと仮定しない。
一体ハウジングでも同時接触は保証しないので全開閉組合せを含めた。
この解析は端子間ブリッジ短絡、部分接触抵抗、IC内部経路を網羅しない。

## 次の設計判断

一体化は運用上の切離し改善候補として保持するが、これ以上の接続列挙は行わない。
BQの端子絶対最大定格・推奨接続手順・入力保護経路を照合し、上記反例を遮断できる回路か、
保護済み電池を用いて生セル監視をロボット外へ移す構成かを比較する。
終了条件は一本抜け・逆接時の電流経路と各部品ストレスの上限を説明できること。
未定の電池内部抵抗を仮定した過渡シミュレーションで合格を出さない。
