# 検出抵抗の実装変化を含む比較

[Vishay WSLP仕様書](https://www.vishay.com/docs/30122/wslp.pdf)のはんだ耐熱試験では、抵抗変化限度に百分率だけでなく0.5mΩの固定項がある。8.2mΩの検出抵抗では無視できない。

初期公差・温度変化にこの試験変化を加えた比較では、制限電流5.051〜7.331A、正方向誤差の残余1.192mVとなる。旧予算3.880mVの約69%を消費する。モデル負荷4.917Aは下限未満だが、他の検出誤差や配線が無条件に許容されるわけではない。

これは記載されたはんだ試験の変化を実装へ適用する条件付き比較で、実際のSMTリフロー工程の保証ではない。試験条件の同等性、経時変化、配線、IC閾値適用を確認する。負方向変化による7.331Aを含まない旧6.842AのMOSFET評価は、実装変化込みの証拠には使わない。

再現：`.venv-engineering/bin/python software/sim/circuits/screen_shunt_assembly_shift.py --out /tmp/shunt-assembly-review`。
