# U11電圧変換候補の選別

**TXU0101への直接置換は採用しない。** 現行revHは変更しない。

目的は、5 V給電・3.3 V入力の消費電流未保証を解消しつつ、3.3 V喪失時もU10のMRをLowに保持できるかを判断すること。動的モデルを作る前にDCと電源断条件で選別する。

[TI TXU0101 Rev A](https://www.ti.com/lit/ds/symlink/txu0101.pdf)の§4、§5.5による検討接続は、DBVの1=LOGIC3V3、2=GND、3=RAIL_HEALTH_N、4=CLAMP_MR_5V、5=LOGIC3V3、6=EFUSE_INPUT_5V。両電源の局所デカップリングが必要。片系電源断では出力がHi-Zとなるため、停止を意味するLowにはならない。入力電位と電源電圧が同じ条件の静止電流規定を、実際の入力電位へ無条件に適用することもできない。

[TI TPS3808 Rev N](https://www.ti.com/lit/ds/symlink/tps3808.pdf) p6を画像でも確認し、MR内部プルアップ最小70 kΩ、Low条件0.3VDD以下を使用した。

外付けプルダウンを追加する場合、既存の5 V系仮置き範囲4.75〜5.25 Vと電源断漏れ2.5 µAの独立上界を使うと、Low保持には抵抗実値18.387 kΩ以下が十分条件となる。一方、全電源範囲に記載された100 µA負荷のVOH規定を使うには、High負荷を抑える抵抗52.5 kΩ以上が十分条件となる。両条件は両立しない。強い出力駆動を使う別条件まで不可能と証明したわけではない。

この候補の単純置換検討はここで終了する。次は高負荷VOHの全使用電圧域での保証、または別回路方式を根拠として選ぶ。通常動作中のHighだけを確認して置換しない。部分的な電源低下、伝搬時間、全回路統合は#24に残る。

再現：`python3 software/sim/circuits/check_clamp_translator_screen.py --out /tmp/clamp-translator-check`（未作成の出力先を指定）。計算は十分条件の比較であり、波形シミュレーションや実機合格ではない。
