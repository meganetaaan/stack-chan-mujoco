# 足首ロール局所CAD可動範囲検査

r5aソースから再生成した足首ジンバル・ロールモータ包絡体と、凍結r9の足ヨーク・ブーツ・靴底STEPを照合した。回転原点はピッチ座標系(-26,0,-10) mm、X軸回り。ソースとr9のオフセット一致を検証した。±0.24/0.28/0.30/0.32/0.34 radおよび0の11姿勢、左右、全6部品対を検査。最近接点もピッチ座標系で保存した。

体積干渉0.01 mm³超は検出しなかったが、公差を含む隙間基準0.9 mm（残存0.5＋各面0.2）は未達。

- 左−0.28／右＋0.28 rad: ブーツとジンバルの隙間0.30 mm。
- 左＋0.34／右−0.34 rad: 同部品の隙間0.03943 mm。左側最近接点はブーツ(-55,19.4372,19.0132)、ジンバル(-55,19.4,19.0) mm。
- 中立: 足ヨークとモータ軸包絡体が0.88459 mm。軸・軸受の実部品と嵌合条件による別評価が必要。

可動域拡張を承認する根拠にはならない。現行上限付近でも外装の公差余裕が不足しており、ジンバルの後上端付近とブーツの逃げ形状を再設計する。今回の検査は脚全体、反対足、床、配線・締結部品を含まず、連続回転・弾性変形も未評価。元のソース形状と凍結メッシュの一致を全表面で証明したものでもない。

再現:

```sh
# engineering lockには今回必要となったtrimesh==5.1.0を追加済み
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" \
 .venv-engineering/bin/python software/sim/structural/screen_ankle_roll_cad.py \
 --out outputs/ankle_roll_cad_repeat
```

初回はtrimesh未導入でCAD生成前に終了したため、そのログも保存。依存を導入後、基準・入力ハッシュをplan.jsonに先に保存して検査した。ソフトウェアの関節限界は変更していない。
