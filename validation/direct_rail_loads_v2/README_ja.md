# 3.3 V系の直結抵抗負荷

1 kΩクリア要求候補のアセンブリから、各電源に直接接続する抵抗を抽出した。電源上限3.393 V、抵抗総合−1%、反対側端子0 Vという共通の仮定でI=V/Rを集計。互いに排他的な状態も同時にLowとして含む保守的な抵抗小計である。

| 電源 | 直結抵抗数 | 条件付き抵抗小計 |
|---|---:|---:|
| LOGIC3V3 | 11 | 5.78067 mA |
| STOP_AUX3V3 | 5 | 0.867863 mA |

R14単体の抵抗電流は3.42727 mA。既存100 kΩなら0.03427 mAなので増加は3.393 mA。信号入力漏れを加えた従来のGPIO電流3.42777 mAとは集計範囲が異なる。LOGIC3V3とSTOP_AUX3V3を同じ供給源とみなして合算しない。

**次に埋める負荷:** 出力端子経由のプルダウン等、ICの静止・動的電流、MAX6816内部プルアップ、未統合のMCUと周辺、基板漏れ、コンデンサ充電。report.jsonは各電源に接続するその他部品とピンも列挙するが、検出入力だけで接続するICやLDO出力も含むため、その個数を電源負荷IC数とみなさない。

1%は未選定抵抗にも適用した設計枠であり、実部品保証の証明ではない。電源範囲・温度・故障時負電圧は別途確認する。電源容量・熱の合格、完全な電流上限、通電承認ではない。

再現（出力先未作成）:

```sh
.venv-engineering/bin/python software/sim/circuits/audit_direct_rail_loads.py --out /tmp/direct-rail-loads
```

初回v1はRIGHT_U12を抵抗と誤分類するツール不具合で停止。分類を修正したv2を使用する。個別値と元アセンブリのハッシュをreport.jsonに保存。
