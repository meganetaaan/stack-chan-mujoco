# 胴体レール接触面の自由変位

前のリブ増厚案が未達だったため、形状の再走査に入る前に、正式比較候補rail-seatの支持条件を確認した。保存済みの同一荷重・後端理想固定の変位場を後処理し、新しいメッシュや固定条件は追加していない。

CADの接触平面Z=52.2にある291節点のうち、0.005mm下の胴体レール内に位置する166点を抽出。Z方向正は開離、負は静止したレールへの侵入。1e−6mmの診断用ゼロ幅で、103点が開離、52点が侵入、11点がほぼゼロ。範囲は−0.000564777〜+0.003444521mmだった。

結論: 現荷重でも全面が圧縮接触するとは仮定できない。全面をボンド固定して剛性を増やす評価は採用しない。一部接触の反力やその剛性効果は、この自由変位からは求まらない。レール自身の変形・初期隙間・ねじ予圧も含んでいない。

変位の符号を調べた値は数µm以下で、既知の造形公差保証はない。名目ゼロ隙間からの結果を実機の接触維持の証拠にしてはいけない。節点数の割合は接触面積割合ではない。

次にこの経路を剛性改善へ使うなら、レールと支持部の相対変位、初期隙間、圧縮のみ伝達する接触を含める必要がある。予圧で接触を維持する設計なら、プリント材の局所圧縮/クリープとねじ締結条件の成立が先に必要。現時点でレールに引張荷重や摩擦支持力を割り当てない。

本結果は `yaw_rail_seat_deformation_location_v1/field.npz` の左側保存荷重一例のみ。未採用の増厚案や全荷重包絡の結果ではない。#18の完了条件は満たさない。

再現:
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_yaw_rail_contact_motion.py --out /tmp/stackchan-rail-contact-motion
```

判定方法・終了条件はplan.json、抽出点と入力ハッシュはreport.json。FE変位場自体の仮定と限界は元解析に従う。
