主遮断FETのゲートRCと電流制限・過電圧条件を先に評価し、12軸負荷包絡に対して通常給電と遮断が両立する部品を選ぶ。既存比較値を通すために許容値を緩めない。追加解析の入力は選定判断に必要な範囲とし、終了条件は実部品・公差・SOA・遮断時間の採否を判断できること。次いでTab5枝と全電力予算を閉じ、#22の許容する根拠付き近似を含めた全レール再現モデルを整える。

PSpiceが使えればメーカー模型の追加照合に利用するが、未提供の実機特性が自動的に確定するわけではない。内部PCMしきい値、変換器の回生受入など資料にない値は保証値として創作しない。部品変更で設計側に必要な条件を満たすか、実機引継ぎが許される未確認事項かを個別に判断する。
