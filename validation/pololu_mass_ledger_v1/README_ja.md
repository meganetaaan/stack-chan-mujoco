# Pololu電源・取付機構を反映した質量台帳

## 結果

数値を割り当て済みの比較小計は **422.7323 g**。これは機体総重量でも測定値でもない。元台帳には外装・支持部の密度項や未確定部品が別枠で残り、今回も未確定値をゼロとして合格判定には使っていない。

| 台帳の変更 | 質量への算入値 |
|---|---:|
| 元の比較小計 | 445.2869 g |
| 旧UBEC 2個を削除 | −72 g |
| Pololu候補2個を追加 | +30 g |
| 後板を4穴追加版へ置換 | −0.194658 g |
| 新しい基板用M2ねじ8本 | +2.32 g |
| 新しい後板用M3ねじ4本 | +3.12 g |
| 新しいM3ナット4個 | +1.52 g |
| POMスペーサ8個 | +0.32 g |
| 以前に照合済みだが小計に未算入だった既存ねじ20本 | +12.36 g |

比較元との差−22.5547 gは、割当済み小計の帳簿上の差であり、ロボットの軽量化量とは解釈しない。追加台座・座金・M2ナット等の未確定質量を含まないため。

最初の更新で得た410.3723 gには既存ねじ20本がまだ含まれていなかった。元台帳の全内訳を調べ、既存ねじ照合レポートの名前と重複がないこと、照合対象yaw v7 inventoryのSHA256が現在と一致することを確認して12.36 gを追加した。旧「20本の質量照合が必要」という未確定項は更新し、重心/慣性未確認は維持する。

## 43部品の扱い

取付機構43部品を、数値割当25部品、密度係数10部品、質量未確定8部品に分け、未分類/重複がないことを検査した。

- 後板: 既存のA5052P-H34候補密度2680 kg/m³を使う比較値。元の後板を取り除いてから置換し、二重計上しない。
- 台座2個: 合計CAD体積13460.8554 mm³。密度・内部充填が未指定なので、均一材とした場合の質量・一次モーメント・原点慣性の密度係数だけ保存した。実際の印刷構造への適用は未確定。
- 座金8枚: 選定寸法のCAD係数を保存し、材種密度を未指定のままとした。
- 新M2ナット8個: 質量未確定。干渉用六角柱を実ナットの密度換算に使用しない。
- 新ねじ・M3ナット・スペーサ: 選定部品の公称カタログ重量。質量公差・質量分布の保証ではない。

台座の均一中実比較なら、合計質量[g]=13.4608554×密度[g/cm³]。これを実際のABS/PETGのフィラメント密度だけで印刷品重量と断定しない。インフィルや外周・内部の密度差で質量分布も変わる。

## 使用上の制限

Pololu、バッテリー、新規締結部品の実重心/慣性、印刷部品の有効密度、既存/新規M2ナット、配線・端子・保護回路・絶縁材等が未確定。既存台帳の分布仮定や未確定項も引き継ぐ。総重量/総重心/総慣性はnullを明記し、MuJoCo XML・荷重履歴・強度合否を更新していない。

## 再現

依存: CadQuery、NumPy。
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/update_pololu_mass_ledger.py --out validation/pololu_mass_ledger_v1
```
内訳からの積上げと、独立した差分式の一致を1e-12 kg以内で確認。これは帳簿の整合性確認で、実重量や強度の検証ではない。
