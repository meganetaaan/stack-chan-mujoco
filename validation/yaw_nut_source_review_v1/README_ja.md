# 取付板ナットの部品仕様照合

2026-09-22確認。目的は既存PTS A56202の有効ねじ長・保証荷重を公開仕様から確定できるか判断し、一つの六角代替品について置換で不確実性が減るか確認すること。追加のFE解析はしない。

| 公開仕様 | 現候補A56202 | 比較A93402 |
|---|---|---|
| 形状 | DIN562角ナット | DIN934六角ナット |
| 呼び | M2×0.4 | M2×0.4 |
| 材料表記 | A2 | A2 |
| 二面幅 | 3.70..4.00 mm | 3.82..4.00 mm |
| 高さ | 0.80..1.20 mm | 1.35..1.60 mm |
| 有効ねじ長・保証荷重 | 製品ページに記載なし | 製品ページに記載なし |

出典: [A56202](https://www.pts-uk.com/products/nuts/square-nuts/metric-a2/a56202)、[A93402](https://www.pts-uk.com/products/nuts/hexagon-full-nuts/metric-a2/a93402)。同社の別サイズにA2-70表記があっても、このM2品へ転用しない。A2だけで強度区分を確定しない。

寸法からの導出: 六角の理想外接半径は最大4/√3=2.3094 mm（現角ナット4/√2=2.8284 mm）。現在の座金上面Z91.9に置くと高さ最大の頂面Z93.5、現10 mmねじの先端Z98まで4.5 mmある。ただし最大高さが0.4 mm増すため、既存1.2 mmナット包絡の干渉検査は流用できない。六角外形は回転方向に依存せず半径2.3094 mm円内に収まるが、工具包絡は別に必要。

**選定判断:** A93402への変更は保証荷重の欠落を解決しないため、正式BOM・CADは置換しない。寸法比較のみで採用候補を増やさない。現角ナットも製造リリースしない。

接触解析へ進む条件は、M2の注文品に適用される機械的性質・保証荷重または有効ねじ形状と強度資料を持つ締結品を特定し、要求締結力と照合すること。現保存荷重から得た総引張力の下限9.3895 Nは、各ねじの最大負荷・必要予圧の代用品にしない。予圧なしで接触解析を行うなら、離間・滑りを許し、締結成立を証明したものとは扱わない。

本確認は公開製品ページの範囲であり、メーカーが資料を提供できないという断定ではない。照会・購入は実施していない。#17/#18の未完了条件として保持する。
