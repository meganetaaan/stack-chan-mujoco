# 回生吸収と電源故障の適用範囲

結論: 4.7Ω AC10は回生吸収の未検証候補として残すが、電池電圧流入の保護を兼ねるとはしない。共通バス用の古い回路を左右の独立電源へそのまま組み込まない。

ユーザー要求である歩行性能と、部品由来のサーボ6V制約は維持する。旧試験の1A・約20msと960µFはCodexの仮置きであり、EPIC4の回生上限を示すものではない。仮置きの入力から保護回路全体を合格にしない。

4.7Ω±5%の1枝は6Vで、理想スイッチを仮定して1.216～1.344Aを吸収する。抵抗損失は7.295～8.063Wで、メーカーP70=8.4W以内という限定比較になるが、プリント部品を含む筐体での熱・取付・繰返しを保証しない。2枝でも合計最大2.688Aであり、電池故障電流の上限は未確定。通常サーボ負荷やeFuseの設定電流を電池故障電流の上限に置き換えてはならない。

旧1A注入を他の負荷なしでコンデンサだけに受け、5.25Vから6V以内とするには、電荷保存から実効容量26.67mFが必要。960µFで十分とはならない。ただし26.67mFを実機の必要容量として採用する根拠もない。これは古い試験条件の意味を確認する計算である。

設計への反映:

- レギュレータ故障・電池電圧流入: 上流遮断または直列電圧制限と、遮断までのエネルギー処理を設計する。
- モータ回生: LEFT/RIGHT_SERVO_BUSそれぞれの遮断器より負荷側に、上流停止後も働く吸収経路を置く。古い共通回生回路を使うために左右バスを短絡しない。
- サーボ個別の切断: 脚の吸収器から切り離される可能性を残し、個別切断の回生を評価対象から除外しない。

今回は既存試験と部品の適用範囲を確定するところで終了。追加の注入波形を作って上限の代用にはしない。実際の動作・停止状態から回生電荷/エネルギーを抽出し、電池故障側の遮断条件とは別々に選定へ用いる。Issueは未完了。
