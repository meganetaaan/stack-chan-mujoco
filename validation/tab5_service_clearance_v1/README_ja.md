# Tab5取り外し経路の公称CAD確認

電池交換案の前提であるTab5の前方取り外しについて、通過体積と現行部品の
重なりを確認した。解消したい不確実性は、固定を解除したTab5が本体形状に
引っ掛かるかである。終了条件は、対象部品すべての連続通過体積との重なりを
記録することとし、実物の取り外し成立までは本解析の完了条件に含めない。

Tab5 STEP全体の外接箱を本体+X方向へ17 mm動かす連続掃引箱を使用。
終点ではTab5背面X=69 mm、本体前端X=64 mmを超える。5 mmは終点設定用の
仮置きであり、製造公差や安全余裕の合格基準ではない。

対象のヨー支持組立、新トレイ、候補電池、旧変換器、TTLインターフェースには
体積重なりなし。最小距離はヨー支持組立との0.4 mm。
外接箱は実形状を包含するため、含めた公称形状についての非干渉を確認できる。
公差込みの通過保証ではない。既存の可動部0.5 mm基準とは用途が異なるため、
その基準を変更したり、この結果をその合格として扱ったりしない。

固定ねじの解除、ねじ込み深さ、工具、手指、電源・信号線の切離しと余長、
印刷誤差・変形、新UBEC配置は未確認。電池保持ストラップも未設計であり、
交換手順と通電試作は未承認。#5・#6の完了を意味しない。

再現はリポジトリルートで、未作成の出力先を指定する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_tab5_service_clearance.py --out /tmp/tab5-service-clearance-check
```

入力ファイルのSHA-256と全対象の結果は`report.json`に記録。
