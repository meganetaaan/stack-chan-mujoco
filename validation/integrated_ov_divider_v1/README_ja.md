# 統合保護OV分圧の端点比較

35.7kΩ/10kΩ±0.1%初期公差で、基準1.176〜1.224Vと漏れ±0.1µAを比較。
検出範囲5.36237〜5.60600V。通常上限5.25Vは既存の設計目標で、電源の保証ではない。
抵抗値は接続候補へ記載したが、実型番の選定・採用は完了していない。

3S満充電12.6Vが変換器出力へ現れる比較では、OVLO端子は約2.7622Vとなる。
資料SLVSGG6Dの推奨範囲0.5〜1.5Vを超える。絶対最大6.5V以内であることを
正常な遮断動作の保証と読み替えない。漏れ仕様も0.5〜1.5Vの条件なので、この計算は
異常端子電圧の問題を示す外挿であり、保証上限ではない。
