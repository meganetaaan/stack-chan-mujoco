# 統合した電圧監視停止ノードの静的比較

## 判断

204部品v6のRAIL_HEALTH_NにはU7のMR、U9のRESET、U11入力、左右TPS3700の計4出力、R9が接続されている。接続先を全列挙して、漏れ・内蔵プルアップを含む電流比較を行った。**10 kΩを維持**し、R9の部品を既存採用品TNPW060310K0BEEAへ具体化する。並列出力による電流分担を合格根拠にしない。

要求は異常検出が停止へ伝わること。10 kΩ±1%、3.6 V負荷比較、受信側3.0 Vの比較点は設計条件でありユーザー指定ではない。1%は初期公差だけでなく総変動の設計割当で、実基板の温度・経年込み保証ではない。

| 比較項目 | 結果 |
|---|---:|
| 1出力が吸い込む比較電流 | 0.417565 mA |
| TPS3700の表記条件 | 1.8 V給電・3 mAでVOL最大0.25 V |
| TPS3808の表記条件 | 1.8〜6.5 V給電・1 mAでVOL最大0.4 V |
| 3.0 VでMRのLow上限 | 0.9 V |
| 3.0 VでU11の下降しきい値最小 | 0.88 V |
| 開放時Highの比較値 | 2.97475 V |
| 3.0 VでMRのHigh下限／U11上昇しきい値最大 | 2.1 V／1.71 V |

電流はR9最小9.9 kΩ、U7のMR内蔵プルアップ最小70 kΩ、四つのTPS3700出力300 nAずつ、U9出力300 nA、U11入力1 µAの合計で計算した。Low電流はノード0 Vとし、HighではMR内蔵プルアップの助けを無視する。一つの出力だけが異常を通知する場合を比較し、他の出力との分担を期待しない。

[TI TPS3700 §6.5](https://www.ti.com/lit/ds/symlink/tps3700.pdf)、[TI TPS3808 §6.5](https://www.ti.com/lit/ds/symlink/tps3808.pdf)、[Nexperia 74LVC1G17 §10](https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf)が一次資料。漏れの表記試験点はreport.jsonに残す。その値をノード全範囲へ割り当てる部分は比較仮定であり、TPS3700の3.3 Vでの全条件保証を作り出していない。

## 残件と終了条件

今回の目的は出力数の増加によりR9の変更が必要かを判断すること。静的比較で変更を要求する結果はなく、抵抗値の探索は終了する。全静的範囲、電源断時の漏れ、ノード容量、監視IC起動待ち、リセット・遮断までの時間、STOP_AUXとSYSの給電順序は別途確認が必要。製作HOLDを維持する。

再現: `python3 software/sim/circuits/screen_health_node_static.py`。回路過渡シミュレーションではない。
