# OVLO分圧抵抗の値変更だけでは保護条件を満たせない

## 設計判断

現在の35.7kΩ/10kΩが不適合なだけでなく、**単純な2抵抗分圧のままでは、既存の6.0V保護条件と12.6V入力故障時のOVLO推奨上限1.5Vを同時に満たす抵抗比は存在しない**。型番未設定のOV抵抗4個を埋める前に検出/保護の構成を決める。抵抗比の追加探索は終了する。

TI TPS25981 SLVSGG6D（2026年9月）6.3/6.5では、OVLO上昇閾値1.176..1.224V、端子推奨最大1.5V。絶対最大6.5Vを動作保証範囲として代用しない。5.25Vの正常上限、6.0Vサーボ上限、3S由来12.6V回り込み故障は既存設計条件であり、今回追加したユーザー要求ではない。

q=1+R上/R下とすると、誤差も漏れもない公称状態ですでに以下の必要条件が矛盾する。

| 条件 | 必要な比 |
|---|---:|
| 正常5.25Vで最小閾値を越えない | q > 5.25/1.176 = 4.464286 |
| 最大閾値でも6.0Vまでに検出 | q ≤ 6.0/1.224 = 4.901961 |
| 12.6V入力でも端子1.5V以下 | q ≥ 12.6/1.5 = 8.4 |

12.6Vから端子を守る比では、最大閾値の検出電圧が少なくとも10.2816Vになる。6Vまでに検出できる比では、対応可能な故障入力は理想状態でも最大7.35294Vに限られる。この数値を故障想定の緩和に使わない。

左右の現接続・値をassemblyから読み、q=4.57、公称12.6V時OVLO=2.757112V、端子1.5Vに達する入力6.855Vと確認した。ここでの5.37432..5.59368V検出帯は抵抗公差・漏れ・過渡を含まず、以前の公差込み評価を置き換えない。

## 次の設計への制約

追加のクランプ/信号変換、または入力電圧を制限する別の保護経路が必要。既存TLV431案には低電流時の精度・分圧負荷・過渡、既存window-monitor案には応答時間の残件があり、この不成立証明だけでどちらかを採用しない。出力側回生、動作中と停止中、電源喪失/復帰も別途成立させる。任意の電圧上昇率を仮定して6Vを保証した扱いにしない。

今回の終了条件は、比の区間交差と現回路の読み取りを一度実施すること。動作シミュレーション・抵抗値掃引・基準変更はない。最新資料の全項目再監査ではない。#6/#24と製作保留を維持。
