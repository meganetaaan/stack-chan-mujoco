# 制御電源の供給方式・パッケージ候補

LOGIC3V3は停止監視用STOP_AUX3V3とは別のレギュレータで供給する。停止用入力の1 kΩ抵抗を制御用20 mA負荷へ共用すると、それだけで約20 Vの電圧降下を要求して成立しない。したがって既存停止用分岐への追加給電は採用しない。

候補はTPS70933DRVR（WSON6）。入力はサーボ遮断の上流から独立分岐する構想だが、逆接・分岐故障・電池低電圧対策は未設計。仮ネットLOGIC_PROTECTED_INPUTを実装済み電源とみなさない。部品番号・端子案はlogic_supply_candidate.json。

[TI TPS709 RevH §6.3–6.5](https://www.ti.com/lit/gpn/tps709) の基板条件付き熱抵抗はDBV 212.1℃/W、DRV 73.1℃/W。仮定Vin12.6 V、Vout3.207 V、負荷20 mA、周囲85℃では、負荷経路の損失0.18786 W。接合温度参考値はDBV124.846℃、DRV98.733℃。LDO自身のGND電流損失を除いてもDBVは推奨接合上限125℃まで約0.154℃しかないため、20 mA枠の制御電源候補にはDRVを選ぶ。これはDBVの絶対的な不適合ではなく、仮の85℃環境での選定判断。

DRVは露出パッドと基板放熱面を必要とする。表の熱抵抗を実基板の保証値とせず、PCBと組立方法の確認を残す。LDO自己電流の負荷依存値、電源精度、最小負荷、実効出力容量、起動、短絡熱、ピーク負荷を評価するまで通電承認しない。

DC精度は3.3 V品で±1%、ライン変動最大10 mV、負荷変動最大50 mVの個別条件がある。これらを単純加算すると従来3.207..3.393 V枠と同じ幅になるが、同時適用の条件確認なしに全域保証とは主張しない。部品の150 mA定格を12.6 V入力での実装可能電流と読み替えない。

計算はP=(12.6−3.207)×0.020、Tj=85+P×表の熱抵抗。実機特性を仮定した追加過渡シミュレーションは行わず、供給方式とパッケージの選定に限定した。
