# 取付板締結部の公称積層確認

統合比較v2の52部品を読み、体積と部品順を照合して8箇所を確認した。これは寸法公差・ねじ山を含まないCAD外形の確認である。

全8箇所で頭下面Z88、板上面Z89、座金下面Z91、座金上面／ナット下面Z91.9、ナット上面Z93.1、ねじ先端Z98となる。公称締付け区間3.9 mm、ナット外形高さ1.2 mm、先端突出4.9 mm。ねじ頭と板下面、座金とナットの公称面位置は一致する。板と座金の間の2 mmは支持部の棚に対応するが、このスクリプトは棚の局所接触面積を検証していない。

**接触解析への入力:** 締付け区間を10 mm（ねじ全長）として扱わない。1.2 mmのナット外形全体を有効ねじ長とみなさない。現在の円柱形ねじモデルとナット包絡形状では、面取り・不完全ねじ・ねじ公差を確認できない。メーカーの最大締付けトルクをそのまま組立トルクまたは保証予圧に換算しない。

**未確定条件:** 公差を含む締付け区間、ナット有効ねじ長・保証荷重、ねじの有効断面・伸び区間、座面と樹脂の接触剛性、摩擦と組立予圧、樹脂クリープ後の残留予圧。これらを決めずに任意の予圧を加えた接触解析を合格証拠にしない。4.9 mmの突出だけを理由にねじを短縮しない（全長公差・ねじ部・工具アクセスの再確認が必要）。

