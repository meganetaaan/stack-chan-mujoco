# 高精度変換器LMZ31710の机上比較

2026-09-21。目的は、現行5 V±3%電源の配線降下予算0.10 Vを改善できる候補かを判断すること。新規シミュレーションは行わない。

TI LMZ31710を比較候補として残すが、現時点ではBOMの確定電源へ昇格しない。10 Aという製品表示と基準精度1%だけから、全身に5 V±1%を保証できると判断しない。設定抵抗・ライン/負荷変動・温度・動的変動と実入力範囲を合わせて評価する必要がある。

## 設計を左右する条件

- 調整範囲は0.6〜5.5 V。PVINと制御用VINの条件は別で、入力下限2.95 Vの記載を単一電源の5 V出力動作へそのまま適用しない。
- 許容スイッチング周波数/出力/電流の組合せがある。資料Table 7では12 V入力・600 kHzで5 V/10 Aを含むが、これは2S電池の全範囲での保証を意味しない。実電池下限とドロップアウトの確認が必要。
- SENSE+で配線降下を補償する機能はあるが、メーカーはヒューズ等の非線形/周波数依存部品を補償ループに含める用途を想定していない。サーボ端子まで無条件にセンス線を延ばして保護素子の降下を消す設計にはしない。
- モジュールは10×10×4.3 mmだが、コンデンサ・放熱銅箔を含む必要実装面積は別。熱特性値を小さい任意基板へ移植しない。

## 判断

既存の電圧目標4.75〜5.25 Vは維持する。精度改善の可能性はある一方、最小試作に新規基板と熱設計が必要になる。したがって外部電源による単関節評価を優先し、全身搭載用には入力範囲/設定/実装面積が確定した時点で比較する。現在のPololu候補を根拠なく置き換えない。

追加解析の入口は、具体的な入力範囲・設定抵抗・周波数・外付け容量・基板熱条件の1案が揃うこと。未定条件の組合せを増やすだけの解析は行わない。回生吸収と遮断は別回路の問題として残る。
