# 停止回路自身の電源範囲

左右EN/UVLOを接続する前に、旧手動復帰回路のU10を確認した。TPS3808G01DBVRのVDD/SENSEはEFUSE_INPUT_5Vへ直結される。現在の統合revAではこの外部ネットを左右変換器へ接続しておらず、実回路が既に過電圧になるという判定ではない。

このネットを変換器出力へ単純に割り当てる案は採用できない。既存の3S入力貫通故障ケースでは12.6 Vとなり、TPS3808の推奨最大6.5 V・絶対最大7 Vを超える。停止回路を、停止すべき過電圧で規格外にしない構成が必要。

出典: TI TPS3808 SBVS050N（2026年8月改訂）6.1/6.3。
https://www.ti.com/lit/ds/symlink/tps3808.pdf

次に選ぶのは、独立に保護した停止回路用電源、または3S故障電圧まで定格を満たす停止回路。通常5 Vだけの動作比較を追加してこの不足を埋めない。U11、他の入力ピン、停止出力の電圧範囲も同時に確認する。

TPS259813L用のEN/UVLOしきい値は `schematics/power/integrated_enable_interface.json` に分離した。出力OFFのしきい値と最低消費状態のしきい値は異なる。旧TPS259823用の合格結果を流用しない。
