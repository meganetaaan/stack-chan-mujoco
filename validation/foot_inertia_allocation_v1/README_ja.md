# 足部の旧慣性の置換範囲

再現: リポジトリ直下で `.venv-engineering/bin/python software/sim/structural/audit_foot_inertia_allocation.py`。

旧 `feet_cad_v2/report.json` の3部品を平行軸の定理で合成し、r9の慣性JSONと負荷取得に用いた凍結MJCFを直接照合した。左右とも質量・重心・慣性6成分が丸め誤差の範囲で一致した。凍結MJCFのハッシュも所有関係の監査時と一致する。

| 旧部品 | 片足の質量 |
|---|---:|
| ヨーク | 17.819066 g |
| 外装 | 22.860970 g |
| 旧足裏 | 15.327421 g |
| 合計 | 56.007457 g |

足首ロールbodyの旧慣性はこの3部品だけであり、モーター・ホーン・ねじ等の残余質量を含まない。現行の硬質3部品50.392843 gを56.007457 gへ加算してはならない。接地部と金属部品、組立に必要な他の締結部品を含めた新しい足部の合成値で、bodyの慣性全体を置換する。

モーターの可視形状は親の足首ピッチbodyに属するが、親の慣性内訳は別途確認が必要。この監査で親bodyの質量配分までは証明していない。旧CAD生成関数の現存コピーは保存済み生成時ハッシュと異なるため、現存コピーにある密度値を旧部品の製品仕様として扱わない。

現行CADの接地部材料・金属部品等の未確定分があるため、まだモデルへ部分質量を投入していない。印刷後質量、強度、最新構成での運動負荷を確認した結果でもない。
