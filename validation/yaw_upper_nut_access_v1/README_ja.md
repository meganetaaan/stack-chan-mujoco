# 上面補強によるナット工具空間の閉塞

既存工具予約（外径8 mm、先端内径5.8 mm、Z91.9から上方）と支持部を比較。
v5では体積干渉0、v6では8箇所すべてに15.177〜17.659 mm³の干渉。
上面補強の逃げ半径3.3 mmは座金・ナットには足りてもこの工具には不足する。

予約形状は購入済み・選定済みの実工具ではないため、全工具で組立不可能という
結論ではない。ただし既存の工具条件では組立未成立。細い工具を仮定して通さず、
AF4 mmナットに適合する工具の外径・先端深さ・柄・必要トルクを確認した後に
必要な逃げ形状を決定する。元部品を切らず追加材だけで逃がせるかを確認し、
変更があれば剛性・工具の進入経路を再評価する。
今回の変形・動作隙間通過を製造承認にはしない。

再現：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_yaw_upper_nut_access.py --out /tmp/yaw-upper-nut-access
```
