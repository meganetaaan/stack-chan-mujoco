# Tab5着脱枠の荷重配分：比較用、強度合格ではない

## 結論と次の設計判断

固定部を「重量÷4」だけで評価しない。Tab5と枠の偏心が生むモーメントにより、静止時にも上下の締結に逆向きのXせん断が生じる。圧入インサートの抜け/回転だけでなく、耳の曲げ、固定殻の座面、締付け後の保持を同じ荷重経路として扱う。今回の条件付き配分値を抜け試験の合格荷重や製造締付けトルクにしない。

## 入力の由来

- ユーザー要求：Tab5を顔として保持し、ABS/PETGによる製作を検討。TPUも部分的に使用可。特定の荷重倍率・締付けトルクは指定されていない。
- 部品公称値：Tab5の質量118.4 g。既存メーカー出典は`docs/prototype/engineering/prototype_decision/DECISION_ja.md`。
- 設計比較仮定：Tab5重心を外形中心(58,0,88) mmとする。枠は圧入前CADに均一中実PETG密度1270 kg/m³を適用し29.222 g。インサート、Tab5取付ねじ、配線等を含む完成質量ではない。ABSや実インフィルへの適合を示さない。
- 4支持点は(42,±58,88/112) mm。剛な枠と同一等方剛性の4点支持を仮定する。殻/耳の実剛性、摩擦、座面離間、穴隙間は含まない。
- EPIC4の左右各3秒記録を固定したまま使う。最新重量で再実行した歩行ではなく、落下・保護停止も対象外。

## 算定と結果

各部品重心の世界座標を2回差分して、基体座標で`m(g-a)`を求める。支持点中心へ`r×F`を移す。回転慣性による偶力は含まない。端点の影響を避け最初と最後の各2点を集計から除く。

力・モーメントの釣合い行列A（6×12）の最小ノルム解を用い、等剛性仮定での4点配分を求める。6つの独立な単位荷重でA×B=Iを照合、誤差7.11e-14以下。これは代数の照合であり支持仮定の妥当性検証ではない。

- 静止時：合計鉛直力1.448 N、Y軸モーメント0.02277 Nm。各点の鉛直分担0.362 Nに加え、上下で逆向きのX力0.474 N。
- 既存旋回記録：軸方向絶対値最大0.162 N、せん断ノルム最大1.254 N。両者は別時刻であり、合成して架空の同時荷重を作らない。
- 全時系列と同時ベクトルをNPZ、代表時刻・入力ハッシュをreport.jsonに保存。

最小ノルム解は保守的な上限ではない。支持剛性の違い、片当たり、予圧の喪失で配分は変わる。小さい値を理由に材料・締結の根拠不足を解除しない。

## 強度判定に必要な量と追加作業の終了条件

| 故障 | 必要な評価量 | 次作業の終了条件 |
|---|---|---|
| インサート抜け・回転 | 外力による軸力に加え、締付け軸力の上下限、回転抵抗、残存保持力 | 組立トルクと摩擦の根拠から予圧範囲を定義し、同じ造形工程の保持能力と比較できること |
| 耳根元の割れ | 断面力・曲げモーメント、積層方向、正味断面、荷重経路 | 締付けと外力の双方を含む断面需要を算出し、材料許容値または試験へ渡す必要能力を特定すること |
| 固定殻の座面変形 | 頭部/接触パッドの面圧、局所たわみ、クリープ後の残存予圧 | ねじ頭からパッドまでの圧縮経路と有効座面を確定すること |
| 滑り・周辺との接触 | 接触部滑り、枠と固定殻の相対変位、公差を引いた実隙間 | 全動作と公差を含む隙間予算へ変位を接続すること |

まず最新部品の質量/慣性・全体動作荷重と締結条件を揃える。これらが欠けたまま局所FEの細分化を続けない。追加解析を行う場合は、どの配分/接触不確かさを解くのかを先に限定し、局所ピーク応力のみを終了判定にしない。

#48へ渡す実測は同条件造形品の抜け・回転・クリープ・着脱後保持。数値合格基準は未確定であり、本レポートの1.254 Nを転記しない。机上の設計荷重・締結条件未確定を実測Issueへ丸投げせず、#17/#18に残す。製作HOLD、Issue未完。
