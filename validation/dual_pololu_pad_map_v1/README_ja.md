# Pololu電源穴の信号・座標対応

結論：メーカー写真・ピン配置図とDXFを照合し、18個の端子穴を対応付けた。左右基板の大径電源穴8点について機体座標と接続先を `power_connections.csv` に保存した。配線・保護回路の製作リリースではない。

## 根拠と向き

- [メーカー製品ページ](https://www.pololu.com/product/5671)と[写真一覧](https://www.pololu.com/product/5671/pictures)
- [ピン配置図0J13942](https://a.pololu-files.com/picture/0J13942.1200.jpg)
- [5V部品面0J13901](https://a.pololu-files.com/picture/0J13901.1200.jpg)
- [5V裏面印字0J13903](https://a.pololu-files.com/picture/0J13903.1200.jpg)

部品面を上に、端子列を手前に置き、Xは右・Yは奥。基板左下を原点とする。ピン配置図を反時計回り90度回転した向きで、大径穴は左からVIN、GND、GND、VOUT。裏面を見て端子列を手前に保つと左右が反転し、VOUT、GND、GND、VINになる。裏面表示用Xは43.18−Xであり、これを機体座標へ直接代入しない。

DXFの非対称な小径クロス位置(1.143,7.62)と端子列/取付穴を部品面写真で照合した。小径クロス自体の信号は図に明示されず、未割当・使用禁止として保持した。4取付穴は電気端子として扱わない。信号判読は目視、座標・網羅性検査はスクリプトであり、画像認識や実機導通検査の結果ではない。

|大径穴|基板X mm|基板Y mm|接続候補|
|---|---:|---:|---|
|VIN|7.62|2.54|DRIVE_BATTERY_PROTECTED|
|入力側GND|12.61999|2.54|入力側共通リターン|
|出力側GND|30.56001|2.54|出力側共通リターン|
|VOUT|35.56|2.54|各脚REGULATOR_OUT|

GNDは基板内で共通。入出力それぞれに近いGND穴を使う候補で、帰路の配線/接点抵抗は未評価。末尾桁はDXFの値であり製造精度を表さない。穴径もクロス記号の幅から保証しない。プロジェクト独自のパッドIDはメーカーのピン番号ではない。

## 再現と終了条件

リポジトリ直下から：

```sh
python software/sim/circuits/check_pololu_pad_map.py --out validation/dual_pololu_pad_map_v1
```

18端子+4取付穴+1未割当で全23クロスを重複なく覆い、7機能信号が既存接続候補に一致し、選択8電源接続で左右VOUTを短絡しないことを検査した。部品写真による向き/信号確認を含め、この資料対応の不確実性に対する作業は終了する。

## 残る判断

- 既存機能接続候補v1と旧DXF報告の `physical_pad_mapping_verified=false` は当時の記録として保持。本報告が資料上の対応付けを補足し、実機確認済みにはしない。
- 配線径、接続方式、はんだ盛り/曲げ/張力逃がしの空間を未選定。現行CAD干渉確認には含まれない。
- 上流保護/遮断と回生・過電圧処理は未成立。保護後入力というネット名だけで上流保護が存在するわけではない。
- 実物の型番/版、印字、無通電でのGND導通と電源短絡不在を、配線前と配線後に確認する。通電には別途保護回路・電流制限・試験条件の成立が必要。
- 本結果によるIssue完了、基準変更、正式ポインタの更新は行わない。
