# セル監視ハーネスと主電源逆接の条件付き反例

**正極側の逆接保護だけでは、4線バランス端子を別接続する構成全体を保護できない。**
現行ネットリストには主コネクターはあるが、セル監視コネクターは未選定。
従って、この反例を「現在の実配線で短絡が確認された」とは扱わない。
通常の4線3Sバランス端子をそのまま追加する案の検査である。

仮定した接続：バランス端子B0をCELL_B_MINUSへ直結し、B1/B2/B3を各セルタップへ接続。
現行主コネクターの負極端子とBQのVSSはCELL_B_MINUS。
主電源の正負を逆に配線すると、電池B3→主負極線→CELL_B_MINUS→バランスB0線→電池B0の
経路ができる。この経路は正極側ヒューズ・理想ダイオード・主FETを通らない。

| 接続状態 | 明示した配線だけでのB0–B3短絡 | 判断の範囲 |
|---|---|---|
| 主電源正常＋バランス接続 | なし | 正常動作の証明ではない |
| 主電源逆接＋正常バランス接続 | あり | このハーネス案では正極側保護で止められない |
| 主コネクターを抜きバランス接続 | なし | セル線は残り、完全切離しではない |
| 主電源逆接、バランス未接続 | 配線だけではなし | IC内部・ボディダイオード・過渡を含む保護は別途 |

電流値や発熱を未知の電池抵抗で計算しない。配線経路の反例であり、SPICE結果ではない。
抵抗・IC内部を勝手に導線扱いせず、主正極側の部品を経由しない経路だけで判定した。

## 設計への反映

未選定セルコネクターへB0を無条件で直結する案を、主電源逆接保護付きとして採用しない。
主電源と監視線を別々に挿抜できる構成の故障条件を先に確定する。
B0線だけを削除して解決したとも扱わない。主逆接時には他のセル入力とVSS間に
逆電圧が生じ得るため、端子定格・入力経路の評価が必要。
キー付き一体コネクターの検討は可能だが、キーは誤配線の電気的保護を保証しない。

次の設計作業は、主線・監視線を一体として接続／切離す方式と、セルタップの保護を
具体的な端子・回路へ落とすこと。全接続状態、一本抜け、逆接を対象に経路を評価し、
保護成立か残留リスクかを明示するまで#21・#24を閉じない。
実測Issueへの移管だけでは、この設計欠落は解消しない。

再現：`python software/sim/circuits/audit_cell_tap_disconnect.py`。
4ケースと条件、現行ネットリストのハッシュは`report.json`。
製作HOLDを維持する。
