# ヨー支持の圧縮リミッター：寸法成立の入口

**市販の公称2mmパイプスペーサを、現行棚へ無選別で追加する案は採用しない。** 圧縮リミッター方式そのものの棄却ではなく、棚厚と長さを対応させない組立の不成立である。

[ミスミのメーカー資料](https://th.misumi-ec.com/th/pdf/el/1885.pdf)にM2用SP-S2、L=2mm、SUS303、外径4/内径2.2mm、L±0.1mmの記載がある。これは寸法比較用で、圧縮リミッターとしての荷重定格は取得していない。正式BOMへの追加・穴拡大は行わない。

## 判定

v4の接触面記録から棚の挟み厚を読み、v5でも取付板・支持・8座金の部品記録が不変であることを確認した。全8箇所で公称棚厚はZ91−89=2mm。

- スペーサが2.1mmなら、公称棚に対して0.1mm長い。金属に着座しても樹脂に圧縮締付けを与えられない。
- 1.9mmなら、公称棚を0.1mm（幾何学上5%）縮めてから金属へ着座する必要がある。この5%を造形材の許容値としない。
- 実造形厚・平面度・金属の弾性圧縮・座面のめり込みを含める前の必要条件である。造形の±0.2mmという既存仮置きを、根拠なく棚厚の実公差へ転記しない。

[SPIROLの設計指針](https://www.spirol.com/product/compression-limiters/)も、樹脂とリミッターの双方に着座し、長さと樹脂厚を管理することを求める。同社の一般的な樹脂圧縮率やボルト保証荷重の割合を、今回の造形ABS/PETG・低頭M2ねじへ自動適用しない。

## 締付け力と運動荷重を分ける

想定する金属側の締付け経路は、ねじ頭→取付金属板→リミッター→座金→ナット。リミッターが追加の締付け力を受けても、ロボットの荷重は板と造形棚、棚と座金、穴周囲などを通る。樹脂の保持/引抜け/せん断が不要になるわけではない。既存接着境界FEにリミッターだけを足して締結成立の証拠にはしない。

## 次の製作仕様に必要な管理

まず使用材料・造形方向・工程と棚面の仕上げ方を定める。局所厚さと平面度の範囲、スペーサの実長、両者の測定不確かさを用い、8箇所を個別に照合する。無選別の同長品を前提にせず、長さ選別/仕上げまたは棚側の加工を設計に含める。

棚厚区間を[t_min,t_max]、スペーサ長区間を[L_min,L_max]、金属の最大圧縮量をδとすると、必要な樹脂圧縮量の比較範囲は

- 下限：t_min−L_max
- 上限：t_max−L_min＋δ

下限が負なら未締付けの組合せがある。上限は実材料/工程に適用できる許容圧縮量以下である必要がある。下限0以上は必要条件に留まり、必要保持力・締付け力の成立を別に確認する。許容圧縮量、δ、予圧を仮置きして今回の案を通さない。

終了条件は、実部品と加工条件に対してこの区間と座面荷重が成立するか判断できること。現状は材料/工程入力待ちで、追加メッシュ・接触予圧走査は行わない。材料/工程を確認する質問を提示済み。実機の測定・加工は今回の対象外であり未実施。
