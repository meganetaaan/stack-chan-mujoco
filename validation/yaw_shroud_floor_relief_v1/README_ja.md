# 外装横桟の局所逃げ案：接続が切れるため不採用

元の左右干渉は支持棚下端と外装横桟のZ49.9..52.2 mmに集中。外接領域へ1.3 mmを加えた2個の局所切欠きを試作した。

干渉は左右各370.875 mm³から0へ減り、公称隙間1.3 mm、仮配分0.8 mm控除後0.5 mm。外形は不変、後部四隅の取付座周囲半径6 mmの材料も削っていない。しかし形状が4ソリッドに分断されたため、事前の単一ソリッド条件に不合格。切り離された横桟と左右レールを自動削除して合格扱いにはしない。

分離部分は中央横桟96.480 mm³と左右各784.610 mm³のレール。主外装110339.076 mm³。これらは加工クズとみなせない。

## 原設計の意図

`board/mechanical/design/r5a_source/cad/build.py` は、Z51の横桟と左右レールを旧上部クレードルにつなぐ外装側延長として作成している。`software/sim/mujoco/build_yaw_dynamics_candidate.py` はさらに、後部レールと上部棚をつなぐ直立支持を作成している。したがって今回の位置は、単なる不要外装の余肉と断定できず、荷重経路の意図を持つ。

ただしコード中の接続意図は、別部品の製造可能な接合形状・接触・締結を証明しない。52部品組立では外装と支持が別ソリッドのまま体積重複しており、そのまま製作できる根拠にはならない。

## 次の設計判断

横桟を残すなら、支持底面との接触座と組立方向を定義し、体積重複を実際の接触または締結に置き換える。横桟を撤去するなら、後部板への経路だけで成立することを確認する必要がある。現状の棚単体解析は後部取付座を理想固定したモデルであり、横桟接触を含まない。片方の仮定で得た値を別の荷重経路へ転用しない。

**判断：局所切欠き案を不採用とし、現行外装を変更しない。** 剛性・締結を伴う接合構成の見直しが必要。製造リリースなし。

