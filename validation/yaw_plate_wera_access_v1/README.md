# 実工具候補の全長包絡による再判定

Wera 2069 Micro、05118126001、対辺5.5 mm。メーカーPDFで刃部長60 mm、柄長97 mm、刃部外径7.8 mm、製品寸法157×13×13 mmを再確認（PDF表示日16.09.2026）。出典 https://hybris-media.wera.de/download/pdfgenerator-datasheets/en/05118126001.pdf 。空洞深さ8 mm/円筒内径6.4 mmは既存仮定であり、メーカー保証ではない。

ナット後面X=−53から刃部を置き、柄全体を最大外径13 mm円筒で包絡。刃部が細くなる効果だけではなく、柄がX=7..104へ達することを含めた。対象には追加金属板/締結に加えてTab5、電池/トレイ、胴体を含む。

## 判定

柄を含む保守包絡は金属板、前側の板固定ねじ頭/軸、Tab5、電池/トレイと交差する。実柄が全長一様φ13ではないため、これは実工具の衝突を確定したものではない。しかし現在の証拠では組立順序を保証できず、この工具へ交換するだけの案は未成立。

元の局所φ8工具での隙間0.827 mmを、実工具刃部φ7.8で約0.927 mmにできることは工程全体の成立証拠ではない。未公表形状を都合よく細くして通さない。Tab5/電池を後付けしても金属板/ねじとの包絡交差が残るので、単に後付け部品を増やして解決した扱いにしない。

次は背面ナットを工具なしで保持できる金属製のナット保持部、または支持単位の組立順序変更を比較し、内側へ長い柄を通す依存を減らす。樹脂の保持強度、ねじ荷重経路、脱落防止を含めて具体化する必要がある。追加の同じ包絡掃引は行わない。

実行：check_yaw_plate_rear_access.py --wera --out <新規先>。この結果のplan.jsonは従来計画を継承し、実工具寸法と追加対象は本README/報告tool_model/入力ハッシュで補足する。生成器は以後のplanにも明示するよう更新した。全身強度・製造リリースは未確認。
