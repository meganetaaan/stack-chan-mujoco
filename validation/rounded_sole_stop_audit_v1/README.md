# 丸角足裏候補の停止箇所

2.801秒、右足首ロール=-0.2800285055 rad、可動域下限=-0.28 rad、超過2.85055e-5 rad。元モデルの同時刻は-0.2783355992 rad、差-0.0016929063 rad。候補の指令値=-0.260776734 rad。停止判定を緩和していない。

左右とも同時刻は右足支持・左足非接触。右足4接触の位置と荷重を保存。候補の床反力世界z=8.71852 N、元8.47137 N。形状と接触計算の影響が混在するため、単一時刻の比較で原因を断定しない。

既存STLの丸角接触点には30度刻みに対応する座標が見られ、次はSTL分割精度と解析CADとの幾何誤差を確認する。可動域を拡大して停止を回避する方針ではない。姿勢参照・制御余裕の検討も、荷重条件が確定した後に行う。

```sh
.venv-engineering/bin/python software/sim/actuator/audit_rounded_sole_stop.py --out outputs/rounded_stop_repro
```

候補と元モデルの慣性・可動域一致はrounded_sole_collision_v1/collision_plan.json参照。構造強度・旋回性能の合格ではない。
