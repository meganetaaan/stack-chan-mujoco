# 枝電流センサーの静的しきい値予算

INA180A1（利得20）と各枝の低側0.1 Ωシャントを候補とする。TI一次資料SBOS741H（July 2022）p8では利得誤差の適用出力範囲が0.5 V〜VS−0.5 V。以前の理想検出0.1 Aでは出力0.2 Vとなり、この利得誤差をそのまま適用できない。

新案は公称0.3 A、比較電圧0.6 V。事前計画の誤差和を用い、入力オフセット500 µV、ドリフト100 µV、電源変動換算92 µVを加算。利得±1%、シャント総誤差±1%・比較電圧総誤差±2%を用いる。後者2つは未選定部品への要求配分で、実部品保証ではない。

結果: しきい値電流0.281356〜0.319203 A、比較電圧0.588〜0.612 V。監視開始電源3.0 V以上では比較点が利得規定範囲内。事前の0.25〜0.35 A予算内だが、全電流範囲の精度保証ではない。ゼロ近傍や飽和時に同じ利得誤差モデルを流用しない。

0.1 Ωシャントは1 A時に0.1 V・0.1 Wを追加する。既存波形の回路にはまだ挿入しておらず、MOSソース電位・ゲート実効電圧・回生吸収への影響を次に検証する。帯域・ノイズ・ゲート測定誤差・無給電出力・比較器/ラッチ/遮断は未検証。
