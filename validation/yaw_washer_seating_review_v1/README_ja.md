# 主固定座金の着座判断

## 結論

現行の内径3.2・厚さ0.5 mmの鋭角座金CADでは、実ボルトへの全面着座は未確認。工具経路合格と座金着座を分ける。首下形状を確認しないまま面取り加工値を発行しない。追加のメッシュ解析は不要。

## 出典の再確認と修正

メーカーPDFをUser-Agent付き直接取得で保存し、図を確認した。M3のda最大3.6 mm、r最小0.1 mmはあるが、Web抽出に現れた「最大丸み」の補助図・式は保存版にはない。したがって前回のr最大0.30 mmという値を、メーカーが保証する形状から円弧比較仮定へ変更した。旧記録は経緯として残し、正本rear_bolt_candidate.jsonを訂正した。これは合格条件緩和ではなく、過大な根拠付けの撤回である。

## 寸法への影響

仮に半径0.30 mmの円弧とした場合でも、中心一致の鋭角座金は約0.0764 mm浮く計算になる。穴の遊びでねじ軸に片寄るとこの値は最大0.30 mmへ変わる。45度面取りの必要脚長も約0.0757→0.1757 mmとなる。円弧仮定下の感度であり、実部品の浮き量や加工指示ではない。中心一致だけで面取りを決めることはできない。

## 残る机上判断と終了条件

実座金の内径・厚さ・面取り公差と、採用ボルトの首下包絡を組み合わせ、許される偏心全域で座金と頭座面が着座することを確認する。必要ならメーカーがボルト用と明示する座金へ置換し、締結厚さ・頭下支持面積・板の面圧を更新する。一組の適合する仕様が得られればこの幾何検討は終了する。材質・締付け力・クリープの評価は別に残る。

#48には接触痕、隙間、締付け後の浮きと残留変形の確認を引き継ぐが、机上未確定の部品適合を実測だけで埋めた扱いにはしない。ねじ・座金の購入や製造リリースは行っていない。
