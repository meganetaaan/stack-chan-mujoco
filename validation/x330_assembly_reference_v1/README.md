# メーカー公式X330組立資料

ROBOTIS-GIT/emanualのコミット0807b1b5f7472bbbbb2c9751f1d3406678e86d37から組立図2点と参照Markdownを取得した。元URL・SHA256はmanifest.json、配布ライセンスはLICENSEに保存。図は変更していない。画像の縮尺から未記載寸法を推定してはいない。

確認できる構成:

- ケース前面・背面へのフレーム固定: M2タッピングねじを使う図。
- 反対側支持: アイドラーホーン、アイドラーキャップ、M2.6×6タッピングねじを使う図。
- 樹脂ホーンの組立例: フレームとホーン部に各3Tの表示があり、PHS M2×6 TAPを可、M2×8 TAPを不可としている。

上記はHNX330-N101金属ホーンの寸法図ではない。金属ホーン商品ページのPHS M2×4と混同しない。キット付属品、実使用本数、ねじ込み量、締付トルク、耐荷重、各穴座標はこの組立概念図から確定できない。

この資料により反対側をメーカーのアイドラー構成で支持する選択肢を設計台帳へ追加した。既存の半径2.45 mm・長さ5 mm包絡円柱は依然として実アイドラー形状ではなく、干渉評価の置換が必要。軸位置・脚長の変更や可動域拡張は行っていない。

再取得はmanifest.jsonの各source_urlをfile名へ保存し、SHA256を照合する。CAD STEP/PDFの取得不成立とは区別し、本フォルダは画像資料の取得証跡とする。
