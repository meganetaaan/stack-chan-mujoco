# 主許可インターフェース負荷を含む起動プローブ

最新の静的負荷比較に合わせて、CTRL3V3の抵抗負荷を298.899 Ωから289.343 Ωへ変更した。3.3 V時の既知部分電流は11.405141 mA。9 V/12.6 Vの両回路で旧版との差分がRloadだけであること、抵抗から逆算した電流が予算に一致することを確認した。モデル端子順も生成時に再照合した。

追加分は主許可出力のプルダウンと受信入力漏れの配分。受信側バッファと100 nFはSYS__LOGIC3V3側なので、このCTRL枝へ容量や消費電流を重複追加しない。SYS側と全機の負荷予算は未完。

**過渡解析は未実行。起動/保護は未合格。** 抵抗負荷は3.3 V時の部分予算にだけ一致し、MCU低電圧動作・起動順序・許可信号の時間変化を表さない。立上り前から追加負荷を抵抗として配分する比較条件であり、実波形ではない。モデル・温度・上流回路などの限界は[旧プローブ](../pack_startup_pspice_v1/README_ja.md)から継続する。製作HOLD。

```sh
.venv-engineering/bin/python software/sim/circuits/export_pack_startup_pspice.py --efuse-zip /path/to/slvmbr3b.zip --ldo-zip /path/to/sbvm571.zip --include-main-interface-load
```

旧版は履歴として保存。追加フラグによりv2へ出力する。負荷比較が参照したインターフェース/元予算/システム接続のハッシュを検査し、古い比較結果なら生成を止める。メーカーZIPとLIBは再配布せず、manifestに取得元とハッシュを保持する。

対応PSpice環境で50 ms終端まで完走し、有限の電圧・電流が得られることを互換性確認の終了条件とする。完走だけで部品許容値・最悪条件を満たしたとは判定しない。旧ngspiceの互換性失敗を同じ設定探索で繰り返さない。
