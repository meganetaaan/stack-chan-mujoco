# ポリマー併用案：単純な容量置換を採用しない

今回の目的は、容量下限とESRを同時に確認し、75µF不足の解決として単独置換できるかを判断すること。結果は**T520C157M010ATE055の単独置換は採用しない**。混成案も未適合で、現MLCC候補を削除しない。

[メーカー型番別仕様](https://search.kemet.com/component-documentation/download/specsheet/T520C157M010ATE055)を取得できた。150µF±20%、10V/105°C、ESR55mΩ(100kHz/25°C)、リプル1.7A/45°C・1.19A/85°C・0.425A/105°C。外形上限6.3×3.4×2.8mm。150µA漏れは追加消費であり、定常給電予算から省略しない。

[メーカーシリーズ仕様2026-08-20](https://content.kemet.com/datasheets/kem_t2076_t52x-530.pdf)の初期/耐久条件を使えば、初期下限120µF、耐久変化−20%を重ねた比較96µFになる。しかしこの値は全温度・周波数・バイアス・実装条件での実効容量保証ではない。耐久試験後の容量条件と、動作中の制御ループ容量を区別する。典型シミュレーションの曲線も保証値にしない。

## ESRが制約になる

前回のXC枝残余65.69394mVを**全て瞬時ESR降下へ配分する仮比較**でも、55mΩなら許容電流変化は約1.19444A。モデル比較の全脚電流4.947702Aがこのコンデンサだけへ移る仮比較では、ESR降下272.124mVとなる。これは実ロボットの負荷ステップや混成回路の失敗を証明するものではないが、「容量96µF>75µFだから単独置換可」という判断はできない。

65.69mVはOEM線・PCB・はんだ等が未算入の残余なので、1.194Aも設計許容値ではない。混成時の電流分担は各素子の周波数特性、配線インダクタンス、制御応答から決まり、容量比だけで分配しない。リプル定格はDC負荷電流と比較せず、各コンデンサのRMS電流で評価する。

## 構成判断

TI TPSM63610 §7.3.4は最低COUTを超えて追加する容量としてポリマー/セラミック/混成を説明する。これを、局所75µFの保証がないMLCCを任意のポリマーで無条件に代替できる根拠にはしない。今回の部品は追加蓄電の比較候補に留め、型番確定BOMへ追加しない。

Panasonic16SEPG150Mも確認したが、[メーカー掲載](https://na.industrial.panasonic.com/products/capacitors/lineup/polymer-capacitors/series/91189/model/138382)はNRFNDであり、今回新設計の優先候補にしない。NRFNDを製造中止とは読み替えない。

次はセラミック局所容量の下限を確保できる構成を優先し、追加ポリマーは必要な過渡/エネルギー包絡が決まってから選ぶ。候補を追加するだけで実効容量の設計不足を閉じない。試作HOLDと既存基準を維持する。
