# ヨー配線候補の端末・占有寸法

3芯0.25mm²のCF98.PLUS.02.03INIを経路比較の優先候補とする。外被径5mm、カタログ質量29g/m。15導体には片側5本が必要で、無隙間の一列でも幅25mmとなる。断面積相当の円径11.18mmは面積からの下限であり、実際の束径や必要穴径ではない。

SEH-001T-P0.6の適用範囲は0.05〜0.33mm²、絶縁外径1.0〜1.9mm。0.25mm²は断面積の範囲内だが、ケーブル外被径と各芯の絶縁外径は別であり、直結圧着の適合は未確認。4芯0.34mm²案は記載の断面積範囲を超える一方AWG22表記との関係もあり、無検証で適合としない。

曲げ寿命条件をロボットの複合ねじりへ転用しない。次の経路設計では各芯の端末適合、5本の固定と引出し、曲げ・ねじりの分離を確認する。全身用の購入・製造リリースではない。
