# 統合v4の締結接触面抽出

左右の板―支持棚2面と、8本の締結それぞれの頭―板、棚―座金、座金―ナット24面、計26箇所を抽出した。接触面のSTEPと面積を保存し、外接長方形を面全体の接触域として使うことを避けるための入力資料とする。

| 公称CAD界面 | 抽出面積 mm² |
|---|---:|
| 板―支持棚（片側） | 1449.151867 |
| ねじ頭―板（1本） | 7.186393 |
| 支持棚―座金（1本） | 28.015152 |
| 座金―ナット包絡（1本） | 20.988167 |

**この面積を実座面積として接触解析へ直結しない。** 特にナットは四角ナットの外接円柱包絡であり、抽出された座金―ナット面には実際の四角形の外側が含まれる。座金も面取り・公差を持たない公称CADで、既存 `yaw_plate_washer_v1` の公差・平坦面を考慮した面積とは異なる。上記20.988167 mm²や28.015152 mm²を実座圧や許容予圧の根拠にしてはいけない。`report.json` の1/面積はCAD公称面の平均圧係数のみであり、強度判定値ではない。

## 次のモデルへ渡す条件

- 接触面には法線圧縮と離間を扱う。面が一致していることを接着・引張り伝達・摩擦容量の証明にしない。
- ねじ頭からねじ軸・ナットねじ部・座面へ連続する引張り経路を別に持たせる。板―棚面だけの圧縮では保存荷重が釣り合わない。
- ねじ伸び区間は全長10 mmではなく、既存の公称締付け区間3.9 mmと頭/ねじ込み部の変形を分けて定義する。
- 実ナットの座面・面取り・有効ねじ長、ねじ/ナット保証荷重、実座金平坦面、樹脂工程の許容値、締付け後とクリープ後の予圧が未確定。任意値を与えた接触解析の追加はしない。
- 製造公差によって26面が同時に接触するとは限らない。現在は形状対応表であり、実接触・耐力の保証ではない。

## 検査と終了条件

52部品の順序・体積を元inventoryと照合し、同一Zの水平面同士を交差した。全26面で正の面積を確認し、STEP書出し・再読込みの面積一致を1e-6 mm²以内で確認した。面積以外の強度判定・追加FE・形状変更は行わない。今回の抽出で、包絡CADを実接触モデルへそのまま流用できない箇所が特定できたため終了する。製作保留、#17/#18未完了。
