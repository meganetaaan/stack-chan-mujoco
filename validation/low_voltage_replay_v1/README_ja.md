# 低電圧直結構成の入口評価

## 判断

5V±5%は既存設計目標で、ユーザーが指定した電池/給電方式ではない。電源と保護の複雑さを減らす選択肢として、サーボ側を単セル相当3.7..4.2Vで動作させる構成に検討余地があるか、保存済みトルク・速度対で確認した。現構成や基準は変更していない。

左右の7秒旋回負荷取得データ、各7000時刻×12軸について、5.0/4.2/3.7Vの3動作点で既存端点近似モデルを再計算した。全ケースでブリッジ電圧・既存モーター電流上限を超える関節時刻は0。5V再構成が保存済みmotor_terminal_Vと一致することも確認した。**既存のトルク・速度対だけを理由に3.7V案を除外する根拠は得られなかった。**

これは低電圧の全身運動を再実行した結果ではなく、90°を3秒未満で旋回できる証明でもない。保存7秒データ自体が旋回精度の合否試験ではない。近似モデルの必要電圧比較を性能合格へ読み替えない。

## 要求・仕様・仮定

- ユーザー要求：外形を基本的に維持し、歩行・後退・左右旋回を成立させる。電池選定は委任。
- メーカー仕様：XL330-M288-T/XC330-M288-Tの動作電圧3.7..6V、推奨5V。3.7Vでの端点も公表。
- 設計仮定：単セル相当3.7..4.2V、既存端点近似・電流上限。具体電池は未選定で、3.7Vを電池開放電圧やセル保護閾値として指定したものではない。
- 従来目標4.75..5.25Vは据置き。この候補は従来電圧目標を満たさず、将来採用する場合は歩行性能・使用可能エネルギー・故障対策を根拠に設計変更として扱う。過去の不合格を合格へ変更しない。

## 構成を変える場合の条件

サーボ用の多セル降圧器を省く構成なら、その降圧器が多セル電圧を出力へ通す故障経路を除ける可能性がある。ただし電池自体の過充電・短絡・逆接、配線電圧降下、回生過電圧と遮断後の電流経路は残る。Tab5・ロジックは別途適合する給電経路が必要で、現3S用LDO/保護を単セルへそのまま転用しない。

次の判断は、同一指令・同一モデルでの3.7V閉ループ旋回（まず左右各1ケース）と、サーボ端子3.7V以上を保つ電池/配線/遮断の電圧予算。指令を遅くして通したり、現行質量変更を無視して最終性能を保証したりしない。10m/20試行の最終要求、実物の熱・連続トルク・電池使用可能容量は別途未確認。

今回の終了条件は3電圧での既存データ照合のみ。電池購入、正式構成変更、保護回路削除、製作リリースなし。
