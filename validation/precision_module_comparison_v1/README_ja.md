# 電圧精度改善と保護群分割の比較

## 判断

**次の詳細設計はPTH08T240W×2＋TPS25948系の片脚1系統保護を優先する。** 現Pololu品のまま保護を片脚2群へ分割する案も比較したが、未割当の電圧降下余裕が小さい。まだ回路・CADを置換せず、型番末尾、周辺部品、停止入力、熱と配置を確定する。

| 比較構成 | 保護・接点・共通給電線を除いた残余 |
|---|---:|
| PTH08T240W＋片脚1個の逆流防止内蔵IC | XL枝46.35 mV／XC枝40.95 mV |
| Pololu維持＋片脚2保護群 | 群ごと11.51 mV／8.81 mV |

両案とも4.75〜5.25 Vの既存端子目標を維持。正の残余は全体合格ではなく、OEM枝配線、基板、はんだ、温度による抵抗増加、動的変動に使える比較予算。

## 根拠と設計への影響

[TI PTH08T240W資料](https://www.ti.com/lit/gpn/pth08t240w)の169 Ω設定は公称5.005 V。温度・線路・負荷・設定を含む±1.5%で4.929925〜5.080075 Vとなる。脚注2の条件内の設定抵抗公差をさらに加算しない。既存5 V±3%品からの改善であり、端子目標の緩和ではない。

同資料の5 V動作には入力7〜14 V、出力容量最低330 µF、入力電解220 µFとリップル条件、ESR等の適合確認が必要。9〜12.6 Vという電池DC比較範囲は入るが、投入過渡が14 Vを超えない証明は未完。10 A表記だけで筐体内熱設計を合格にしない。

INHIBITは開放で運転、Lowで停止。現在のPololu向けプッシュプルENA回路を流用せず、低漏れオープンドレインと既定停止を設計する。リモートセンスは保護遮断より手前を初期候補とし、遮断後のサーボ端子へ安易に接続しない。

分割案は各脚の3XL＋3XCを2XL＋1XC、1XL＋2XCに分けた電流比較。各群に2本の放電抵抗を残すため、放電部品・消費も増える。未知の実容量を単に半分にして合格とはしない。負荷配置の具体化は未実施。

[TPS25948の抵抗](https://www.ti.com/lit/ds/symlink/tps25948.pdf)は20 mΩを用いたが表記電流は3 A。約4.948 Aの片脚案では比較適用であり実電流での保証ではない。温度、回生、短絡、電圧監視、突入は別途確認する。

## 次の終了条件

PTHの注文可能品、容量・ESR、INHIBIT、3S投入条件と実装形状を具体化し、現候補より製作に進めるかを判断する。5 Vでの過渡制御資料を別出力条件から外挿しない。製作HOLDを維持。
