# モデルのDC電流包絡と実機設計値の区別

drive.pyの電圧・電流制限式とcatalog.jsonから解析的に導出した。
|V端子|≤V電源、|Iモーター|≤I制限、I電源=V端子×Iモーター/V電源+I待機より、
I電源≤I制限+I待機。したがってモデル内の消費上限は片脚4.917A、12軸9.834A。
既存2旋回の記録も包絡内にある。記録内最大値を上限とするより広いが、
全軸同時に到達することや最小の上限であることは証明していない。
回生側9.426Aも同じ不等式から得た緩い包絡で、持続時間・回生エネルギーの指定ではない。
これだけでブレーキ抵抗を選定しない。

ユーザー要求は12軸適合。0.735/0.870AはCodexの解析制限で、
メーカーのDC最大・連続定格や、実装済みハード保護ではない。
この包絡にはモデル外の内部回路損失、PWM電流、突入、故障、Tab5、
補助回路、変換損失を含まない。必要な実機余裕を根拠なく一律倍率で埋めない。

設計への適用：#21の通常動作モデルの比較には片脚4.917Aを条件付きで用いられる。
D42V55F5のtyp電流と比較して定格適合とはしない。最終電源選定は
実装する電流制限とDC負荷の根拠、電源の保証範囲、保護との協調を揃える必要がある。
従来の4.815A比較を歴史資料から消さず、待機を加えた包絡と明確に区別する。

再現：`python3 software/sim/circuits/derive_model_dc_envelope.py --out NEW_DIRECTORY`
解析式・入力ハッシュはreport.json。記録との照合は補助検査で、数学的包絡の証明ではない。
