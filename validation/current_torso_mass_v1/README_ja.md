数値70件だけの小計は0.409712198 kg。**全胴体・全機質量、保証下限/上限ではない。** 旧0.422732258 kgとは集計範囲が異なり、軽量化を示さない。新STEPに含まれない旧モーターケース・旧電池ねじも小計から除外し、report.jsonの除外表に残した。モーターが不要になった意味ではなく、全機を集計する際の別割当が必要。

新しい枠の樹脂量には圧入前の22,855.096 mm³を使用する。圧入後表示の穴拡大は樹脂の再配分を近似した形状なので、その差を質量減として扱わない。均質材料の体積係数は造形内部構造や実効密度が未確定であり、そのまま完成品重量や慣性にしない。ベルトやインサート・ナットの干渉用外形から材質密度で質量を捏造しない。

全機荷重更新を阻む入力は、造形仕様と材料割当、22部品の質量、モーターと脚・足の完全な対応、制御/保護基板・配線・端子・絶縁・固定部品の配置、質量ばらつき/重心/内部慣性とMuJoCo座標対応。今回の集計だけでは強度再解析を開始するための全身入力は成立しない。全身mass/COM/inertiaはnull、製作HOLD。
