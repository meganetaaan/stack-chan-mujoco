# 後部M3ねじの突出部分と周辺部品

前段のねじ長さ・裏板厚さ・座金厚さの端点から、裏板出口の最小X〜先端の最大Xを包む円筒を8本生成した。独立端点の合併なので単一組立より広い包絡となる。半径は公称M3の1.5mm。

中立姿勢の電池・トレー・ストラップ・左右UBEC・Tab5・TTL、および左右ヨーモータケースとカプラの計11形状に対し88組を検査した。事前に既存CAD検査と同じ交差体積0.01mm³以下を判定条件とした。交差は全て0、最小距離14.453mm（左側ねじと左ヨーカプラ）。

これは突出部分と列挙した周辺部品だけの結果であり、支持部・ねじ穴・裏板との接触判定ではない。カプラの回転、穴位置公差、ねじの傾き、配線、モータ内部は含まない。全身の動的干渉、製造公差での保証隙間、ねじ強度は未確認。
