# X330ケース固定図面

ROBOTISダウンロード一覧のPDF項目1986から取得したメーカー原図。日付28-May-20、A4、単位mm、FOR REFERENCE ONLY。取得URLとハッシュはsource.json。原図を変更していない。

ケースの四隅取付位置は16×30 mm配置、M2タッピングねじ指定。前面Detail Aに3.5 mm、背面Detail Bに4.5 mmの断面寸法が示される。これらを総穴深さ/安全なねじ込み長/引抜き許容へ読み替えない。ホーンの4穴・PCD12・深さ3.0(Max.)の注記はケース四隅の穴ではない。

既存のヨー姿勢へ座標変換すると、背面座面Z=88 mm、X=−27.5/+2.5 mm、Yは左18/34、右−34/−18 mmがケース固定の候補軸になる。これは図面から導いた公称座標であり、個々のSTEP穴軸と照合する前に支持棚を穴加工しない。

次は4軸がケース内部の組立ねじと混同されていないかCADで照合し、棚上方からの工具経路を確認する。棚3 mmとPHS M2×8 TAPの組合せでは名目5 mmがケースへ入るが、図面に5 mmの許容挿入長が保証されているわけではない。使用本数、ねじ座面、取付板厚、締付け条件を確定するまで製造リリースしない。
