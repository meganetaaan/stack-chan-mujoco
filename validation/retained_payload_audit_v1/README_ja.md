# 保持された旧搭載物割当の照合

慣性台帳v2の保持項目10件を分類した。電池103g、変換器20g、TTL基板12gの
計135gは、現在選定された電装構成の実質量ではない。保持項目という語を
確認済みの物理部品と読み替えない。

左右別変換器・監視回路・配線を追加する際には対応する旧割当の質量、
一次モーメント、原点慣性を除いてから加算する。質量差だけで重心を更新しない。
配線・締結の旧25gは台帳v2ですでに除去されているので、再度差し引かない。
ヨーモーターの幾何包絡とカタログ質量の部品境界も照合が必要。

この分類で新しい全身質量を捏造せず、旧モデルと荷重波形は変更していない。
電池・基板選定と配置、造形工程、締結・配線が確定するまで、
部分質量432.696580gを全胴体の確定質量として荷重再生成に使わない。

再現：`python3 software/sim/structural/audit_retained_payloads.py --out NEW_DIRECTORY`
