# 電流異常の継続判定と保持：行動モデル

INA180候補の静的誤差側（利得19.8、シャント0.099 Ω、入力オフセット−692 µV）と仮10 µsフィルタを使い、0.612 V超・ゲート0.4 V未満の状態を1 ms積分してラッチする単独回路。比較器/タイマー/ラッチICは未選定で、実回路の保証遅延ではない。

試験波形は20〜40 msに指令オンで1.1 A、50 msに0.5 msだけ指令オフで1.1 A、70〜90 msに指令オフで1.1 A。最初の2条件ではラッチ0、72 msで1、異常終了後92〜100 msでも0.99999以上を保持。最終モデルの振幅最大1で事前上限1.01以下。

初回の定電流ラッチは時間離散化で1.125までオーバーシュートした。初回ファイルをconstant_current_latch_attempt/に保持し、1 Vへ一次応答する充電へ修正して再実行。初回の下限だけの判定を最終回路の合格とはしない。

これは信号条件の実装案であり、実電流センサー負荷、比較器公差/ノイズ、電源喪失時挙動、遮断素子、モータへの影響は含まない。ラッチの解除回路も未実装。上流ENや電力経路とは未結合で、検出→遮断→残留エネルギー→復帰の全体検証は残る。
