# ヨーサーボ下方挿入の連続包絡

メーカーCADの既存背面アイドラなし構成を、最終姿勢からZ方向−100 mmまで覆う直方体に包絡した。姿勢間を含む連続経路であり、離散点検査ではない。最終ケース上端88 mmは開始時−12 mmとなり、胴体底面より下から入れる候補。左右各7対象で包絡の体積交差は0。

## 公称経路と公差判定を区別する

支持棚とは最終姿勢で接触するため距離ほぼ0。この解析は意図した座面接触を体積で区別しており、棚とケースの締結・面圧・平面度は検証しない。

胴体との公称最小隙間は左0.868452 mm、右0.431425 mm。既存の2面公差予算0.40 mmを差し引くと、左0.468452 mm、右0.031425 mm。既存の残余0.50 mm基準に両側とも未達。**公称経路は確認できるが、公差込み組立ゲートは未達**。公差を緩めて合格にしない。

直方体包絡は実サーボを過大評価するので、この隙間不足は実サーボの衝突を証明しない。ただし現在の証拠で製造公差に対する余裕は保証できない。メーカー寸法公差と造形能力が未確定なため、同じ仮定のサンプル数を増やさない。

## 設計への反映

支持を先に締結→サーボを下方から挿入→連結部・脚・電源部を取り付ける順序を候補に残す。全工程の成立は未確認。次の設計はケースの実固定方法と工具経路を先に決め、必要なら胴体開口を局所修正する。外形・脚長を変更する必要があるとの証拠はない。

対象は支持、胴体、背面板、Tab5、電池とトレイの候補形状のみ。支持締結ねじ、四隅締結、作業者の指/工具、ハーネス、先付けした反対側サーボ、連結部・脚はこの検査に含まない。したがって機械全体の挿入経路証明ではない。
