# 選定金属板の公称質量・慣性

## 製作判断への影響

| 対象 | 公称質量 |
|---|---:|
| A5052-H34背面板2 mm | 86.114 g |
| A5052-H34ねじ付き裏板3 mm・左右合計 | 10.908 g |
| SUS304サーボ座板1 mm・左右合計 | 25.171 g |
| 金属板5点合計 | 122.192 g |

旧r9モデルの背面カバー36.026 gを背面板だけで置換すると50.088 g増える。全身質量の増分ではなく、対応が確定した一部品の差分である。他の板は新規構成に加わるが、旧支持体の除去・新支持体の追加・配線締結25 g予約の配分を済ませず、122 gをそのまま旧モデルへ足してはいけない。

金属化で剛性を得る判断には、この重量増を含む荷重・重心の再評価が必要。軽量化穴を追加するかは荷重経路と板の変形を比較して決める。重量だけを理由に現在の厚さや強度基準を変更しない。実物全体の強度・旋回性能を旧軽量モデルで合格とはしない。

## 根拠と計算範囲

A5052密度2.68 g/cm³は[UACJ/UEX押出材資料の材質表p5（泉メタル掲載）](https://www.izumi-metal.co.jp/cms/wp-content/uploads/2025/06/UACJ_UEX_type.pdf)の5052比重から採った計算用参考値。押出材の形状・調質・強度を板へ転用したものではない。SUS304の7.93 g/cm³は[日本製鉄資料の参考物性](https://www.nipponsteel.com/assets/pdf/product/grade/nssc_series/ferrite/S007_SPEC36.pdf)。いずれも選定板材ロットの保証幅ではない。

既存の密度非依存幾何モーメントへ密度を掛け、5点の中心慣性を共通重心へ平行軸移動して合算した。report.jsonの重心は金属板5点だけの重心であり、胴体全体・全身の重心ではない。単位はkg、m、kg·m²。

公称CADはタップ下穴形状であり、完全ねじ形状・面取りの除去量や板厚公差を含まない。公称重量であって最大重量でも実測重量でもない。ねじ・ナット包絡からの質量推定は行わない。

今回の問いは「選定板材による重量増を旧モデルで無視できるか」。終了条件はこの5点の公称入力を算定して置換差分を明示すること。未知の造形密度で歩行シミュレーションを繰り返すことはしない。次の全身荷重更新には造形条件、残りの部品質量と配線予約の整理が必要。
