# 手動復帰回路R1〜R14の実部品候補

現行revHの14本をVishay TNPW e3、初期±0.1%、TCR±10 ppm/Kの注文型番へ対応した。値・ネットは変更しない。1 MΩのR11のみ0805、他13本は0603。選定表は`schematics/power/manual_rearm_resistors.json`、ネット付きBOMはresistor_bom.csv。メーカー符号表との適合確認であり、在庫・購入の確認ではない。

[メーカー資料28758、10-Apr-2026](https://www.vishay.com/docs/28758/tnpw_e3.pdf) pp2〜4を根拠とする。0603の抵抗範囲上限は332 kΩ、0805は1 MΩ。Bは0.1%、Yは10 ppm/K、EAは5000個リールのメーカー包装コード。試作に5000個購入する意味ではなく、小口調達は未確認。

比較温度−40〜125°C、25°C基準の最大差100 Kは既存のCodex仮条件。一般モード8000 hの変化0.1%を比較に加え、初期・温度・経時の倍率を乗算すると上側+0.3003001%、下側−0.2997001%。±1%基準は緩めず維持する。最大5.25 Vを各抵抗へ全印加した損失比較は最大5.882 mW。

目的は値だけの抵抗を実部品へ具体化し、従来の総合誤差仮定との対応を調べること。終了条件は全14本の値・ネット対応、注文符号、温度／経時の条件を明示すること。上記の比較は基板膜温度、はんだ付け・湿度・汚れ、要求寿命の複合保証ではない。余った誤差枠を根拠なく他の誤差へ配賦しない。負荷寿命の比較モードを守れる実装熱設計は未確定。

```sh
python3 software/sim/circuits/select_manual_rearm_resistors.py --out /tmp/manual-rearm-resistors-review
```

新規出力先を使う。現行assemblyの値・参照番号を照合し、1本でも欠落／変更すれば停止する。接続図はrevHのまま、部品選定表を追加する。コンデンサ・スイッチ・未実装監視部まで選定完了とはしない。
