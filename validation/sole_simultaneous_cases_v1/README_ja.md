# 同時刻の足裏荷重ケース

旧25.95mm配置の7000時刻から、左右の各符号付き力・モーメント成分の最小／最大と、
力・モーメントのノルム最大を選択し、重複を除いた23ケースを出力した。
接触位置・各接触力・接触偶力は同じ時刻のものを保持。配列と接触記録の時刻・合力を照合した。
選択ルールと照合閾値は実行前にplan.jsonへ保存する。

```sh
.venv-engineering/bin/python software/sim/structural/select_sole_load_cases.py --source validation/rounded_sole_load_audit_v1/local25.95 --out /tmp/sole-cases
```

## 設計への使い方と停止条件

これは旧構成での荷重経路の検討入力。最新質量を反映した強度合格データではない。
別時刻の力最大とモーメント最大を合成しない。各ケースを足裏の自由物体図に適用し、
足裏自身の慣性と重力、ヨーク面の圧縮反力、傘部とねじ座面の引張側反力を区別する。
床反力の合計をそのまま固定ねじ1本の引張荷重として扱わない。

次の構造評価では、座面とヨークの相対変位、開口、傘部の抜け方向反力、
座面の面圧と曲げ、残留変形による干渉を観察する。
材料・締付け・接触条件が未確定のまま局所応力のメッシュ収束を追加しない。
この23ケースだけで最悪応力を網羅したとは判断しない。

強度判定を進める前に、最新構成の質量・慣性、保持部の材料／造形方向、
座面・ワッシャ・締付け条件を確定し、対応する動作荷重を更新する必要がある。
旧構成の荷重を質量比で拡大して新構成の歩行成立と置き換えない。
