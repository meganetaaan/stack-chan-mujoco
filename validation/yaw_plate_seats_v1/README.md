# 金属板支持締結の座面・リブ干渉

固定8組について、公称座面の面積と、ねじ頭/軸対支持・板の交差を検査。座面は平面領域へ厚さ0.01 mmの環状プリズムを入れ、交差体積/厚さで面積を求めた。接触応力解析ではない。

上座金（半径3、内半径1.15）の公称面積は約24.12 mm²、下面頭（半径1.9、内半径1.15）は約7.19 mm²。16座面とも欠損面積0.001 mm²以下の数値基準内。板の端距離を広げた効果は確認できるが、面圧・座面平面度・ねじ首下丸み・クリープは未評価。

**ねじ頭が全8箇所で支持リブと干渉するため、現在の組立は不成立。** 後側4箇所の交差は各7.350973 mm³、前側4箇所は各7.186272 mm³。ねじ軸と板/支持の今回交差は基準内。サーボだけに対する前回32比較の成功を、支持リブを含む締結合格へ拡張してはならない。

次はリブ形状と固定軸の関係を確認し、軸位置または取付方向を変更する。頭逃げを切る場合は、リブ根元の正味断面と工具の連続経路を先に定義する。干渉体積が小さいことを強度への影響が小さい根拠にはしない。未成立の締結に任意のプリロードを与えて構造解析を追加しない。
