# LTC4365のOV分圧と応答時間条件

比較値100kΩ／10kΩ、抵抗誤差±0.1%、基準492.5～507.5mV、漏れ±10nAの
全16端点を計算した。抵抗型番・温度変化・経年変化は未確定。
結果は静的検出5.40666～5.59366V。ただし漏れ仕様の試験点はVIN34V、OV端子0.5Vであり、
すべての条件に適用できる保証として拡張しない。

[ADI Rev.B](https://www.analog.com/media/en/technical-documentation/data-sheets/ltc4365.pdf)
の故障伝搬時間は入力過駆動50mV、VIN=VOUT=12Vの条件。
この分圧では端子50mVは電源側約0.55Vに相当する。
最悪の検出基準に50mVを加えた電源電圧は6.14466Vで、サーボ上限6Vを超える。
さらに実際の5V動作と仕様の12V条件は異なる。
従って、静的検出上限5.59Vと資料の高速応答を組み合わせただけでは保護を保証できない。
これは過電圧検出IC自体の不適合断定ではなく、当比較の保証根拠が不足するという結果。

この比較抵抗を製造BOMへ登録しない。後段FETの電荷・遮断時間・電源の過渡条件を
含む構成が確定するまで、未知の上昇速度を仮定した波形を追加して合格にしない。
100kΩ／10kΩはユーザー要求ではなく、約5.5Vで静的な検出余裕を比較するための仮置き。
5V正常域と6V上限は変更していない。

再現：`.venv-engineering/bin/python software/sim/structural/check_servo_ov_threshold.py --out <新規出力先>`。
全端点はreport.jsonに保存。温度・経年・実部品の抵抗公差を含む最終計算ではない。
