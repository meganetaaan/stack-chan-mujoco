# EPIC4保存データの脚別回生抽出

左右旋回それぞれ7秒、12軸のDC電流・電力から、左右の独立電源バスごとに電荷・エネルギーを積分した。個々の負電流の合計と、同じ脚の消費を相殺した正味の戻りを区別する。左右の脚をまたいで相殺しない。

4組すべてで正味バス戻りは0だった。個別サーボの負電力を合計したエネルギーは5.50～7.24mJ/脚/記録だが、同じ脚の他サーボが消費している。この結果は「吸収回路不要」ではなく、保存された定常旋回記録では吸収器へ電流が流れる条件を評価できないことを示す。

電流・電力は区間開始時の値というexport schemaに従い、N区間の矩形積分を用いた。時刻間隔・列数・有限値・左右各6軸を検査した。データとschemaのハッシュはreport.jsonに記録。

次の評価は停止・給電遮断時の状態を対象にする必要がある。ただし制御停止を単に電流ゼロへ置き換えると回生も消えてしまうため、モータ逆起電力、ブリッジの停止状態、電源端子の経路をモデルに対応させること。今回の小さい観測値を実機上限や旧1A試験の置換値にはしない。最新の質量・機構・故障状態は本記録に含まれない。
