# 接触領域の切分けによる積分監査

保存変位 `sole_projected_contact_probe_v1/fields.npz` を固定し、master/slave三角形の交差領域をさらにg<0の半平面で切った。各領域内の隙間gは一次関数。圧力p=max(−k g,0)は接触領域で一次なので、切分け後の三角形頂点平均×面積で圧力を積分できる。新しい平衡解を求めたものではない。

固定3点積分の合計20 Nに対して20.121397 Nとなり、差0.606984%は事前の積分誤差基準1%以内。接触投影面積は20.15447 mm²。連続なP1圧力場の最大値4.71041 MPaは以前の隙間監査と整合する。積分点ピーク3.74808 MPaより大きく、ピークを積分点の値だけで判断しない。

縁落とし面の接触投影面積は8.71846e-5 mm²、負担力1.48331e-4 N。固定3点では0点だったが、根元の細い領域では接触が生じる。この線形化された保存変位モデルの結果であり、実際の接触拡大を実証したわけではない。

総接触力の積分誤差基準は満たすが、局所力配分・剛性積分・圧力ピークの空間収束を保証しない。再積分で力が20 Nからずれるため、この圧力場を新しい平衡解として使用しない。次は切分けた積分領域を接触解法にも反映するか、同等の積分収束を検証する。材料仮定・歩行荷重等も未完了。
