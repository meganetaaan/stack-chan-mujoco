# 嵌合方向の訂正と再検査

JST図面3ページを目視確認し、メーカーSTEPの断面と照合。端子3本の断面積は3×0.64²=1.2288mm²で、native Z=-10,-8,-7.3mmに存在する。これが基板側の端子であり、嵌合側はnative -Z、現行ヨー配置ではrobot +Zとなる。

v2で使った横方向±Yは誤り。そこで得た438.998mm³を実挿入方向の障害・支持部削除量として使わない。v3は上向き10mmの仮作業空間で再検査し、4ポートそれぞれ支持棚76mm³、取付板38mm³の交差を得た。側壁だけでなく棚と板が検討対象になる。

10mmは引き続き仮予約で、実ハウジングの嵌合深さ・ケーブル出口形状ではない。実接続不可とはまだ断定せず、JSTの嵌合後寸法と基板基準面を対応付ける。取付前の組立可否と、完成後のケーブルの逃げを分けて判断する。今回、支持部・取付板は変更していない。

再現は`locate_yaw_connector_obstacles.py --step メーカーSTEP --out 新規出力先`。v2の再現には訂正前コミット44867bbを使用する。
