# リブを避ける金属板固定候補

`yaw_plate_axis_shift_v1`の軸移動に対応し、板48.5×33×1 mm、X=−37.5..11、取付軸X=−34/7.5・Y=中心±10とした。支持棚の前端をX=10から11へ1 mm延長して座金を受け、下面ポケットも拡張。リブ形状を直接切除せず、ケース・ホーン・脚長を維持する構想。

4部品は有効な単一ソリッド、板/支持の体積交差0。板は各12.5381 g（仮密度）。現在の全身外形・周辺部品への適合や、全締結の座面/工具再検査は未完。旧v2での確認をそのままv3の合格へ転用しない。ケースねじの名目下穴進入2.5 mmも保持強度の証明ではない。

再現：`build_yaw_metal_seat.py --relocated-axes --out <新規出力先>`。フラグなしはv1、--wide-plateはv2。支持/板の正本候補をv3とするが製造図ではない。次は同じ8締結をv3上で座面・頭/軸/ナット・工具まで統合検査する。
