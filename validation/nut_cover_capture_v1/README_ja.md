# ナット蓋の6軸方向拘束確認

4個の蓋について、Tab5装着状態から±X/±Y/±Zへ1mm平行移動した形状を検査。
24ケースすべてで物理的なストッパーとの交差が生じた。
+XはTab5、−Xは後端ストッパー、±Y/±Zは枠のレール・壁が止める。
摩擦や締付けで止まるという仮定は使用していない。

開始位置は既存の干渉検査で非干渉を確認済み。移動後の交差は実使用時の干渉不良ではなく、
その位置まで剛体を障害物へ貫通させずに直線移動できないことを示す。
1mmは拘束確認用の探索距離であり、許容がたや公差の合格値ではない。
交差体積閾値は1e-6mm³。入力ハッシュと全ケースはreport.json。

## この結果で証明しないこと

移動と回転を組み合わせた抜け経路、弾性変形、レール破損、造形ばらつき、Tab5の実ケースとの差は含まない。
Tab5は現行の簡略CADを使用しており、ケース背面の未再現凹部を無視して蓋を確実に止められるとは断定しない。
1mm移動時の交差量を保持力へ換算しない。6軸の検査だけで全方向の抜け止め成立とも扱わない。
公称片側隙間0.1/0.2mmを実プリンターで安定して出せる根拠もまだない。

配置と単純軸方向拘束の探索はこれで終了する。次はTab5実形状との照合、蓋・溝の製造寸法と
必要な掛かり代、レールの荷重と変形限界を決め、未確定物性での解析を重ねない。
製作HOLD。#17〜#20の組立・保持強度・製造図の完了条件は未達。
