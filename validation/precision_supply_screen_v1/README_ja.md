# 精度を改善する電源構成候補

TPSM63610RDFRを左右各1個、出力V+を分離する案を比較候補に追加する。
最終採用ではなく、既存BOMを置換しない。8A連続と10Aピークを区別し、
モデル内全軸9.834Aを1個で連続供給できるとは扱わない。

一次資料： https://www.ti.com/lit/ds/symlink/tpsm63610.pdf
SLVSGU1A、電気特性表のFB範囲0.985–1.015Vを用いる。
本文7.3.2の±1%表記を根拠に範囲を狭めない。
100k/25k、初期公差±0.1%、FB電流±50nAの比較で4.9121–5.0881V。
抵抗の温度・経時変化は未計上で、完全な出力保証ではない。

既存の枝1A・固定治具用配線と共通4.917AのeFuse比較を差し引くと、
下限4.75Vまで73.42mV残る。0.10Vだった元の配電予算を改善する方向だが、
リップル・過渡・温度・追加保護をまだ引いていない。条件を緩めた合格判定ではない。

次の採否条件：選定電池の最低端子電圧でのドロップアウト、出力容量と安定性、
基板放熱、各レール回生・逆流、実部品BOMを確認する。
EVMの熱抵抗をロボット筐体へそのまま転用しない。
回生電流を電池へ戻せる保証も未確定なので、ブレーキ回路を省略しない。
これらの机上条件が揃うまで製造リリース不可。

再現：`python3 software/sim/circuits/screen_precision_supply.py --out NEW_DIRECTORY`

## 追加の採用ゲート確認

同資料8.2.1.1の5V例は入力約6V未満でドロップアウトする。
動作入力下限3Vを、5V出力維持の下限に読み替えない。
6.6の過渡例は24V入力・0→4A・1A/µs・実効100µFでtyp150mV。
静的な残り73.42mVだけでは過渡適合を裏付けられない。
この異なる条件の例をロボットの最大降下や不合格の証明にも使わない。

採用前提を`schematics/power/precision_supply_adoption_gate.json`に固定した。
まず電池/BMSの型番、負荷時の変換器入力最低電圧、負荷変化速度の根拠が必要。
未知の負荷ステップを選んで容量を増やす解析は行わない。
この候補の低電圧・過渡適合は未確認のままで、最終BOMへの採用は保留。
