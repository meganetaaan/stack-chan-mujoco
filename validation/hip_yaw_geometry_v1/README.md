# 股関節ヨー追加候補：脚全体のCAD回転と運動学

股関節ロールの前に鉛直ヨー軸を置く候補を、既存の脚長・足形状のまま調べた。仮の軸線は胴体座標X=-25 mm、Y=±22 mm。ケース収納診断と同じく、TTL基板の包絡を上方12 mmへ移し、20×34×26 mmのケースをZ=75 mmに追加した。ケース中心と出力軸の関係は未確定であり、これは実モータ取付済みの機構ではない。

基準脚姿勢を維持したまま、各脚と既存の股関節ロールモータ・固定ブラケットを一体で回すと、±3度でも固定ブラケットの後方ブリッジが胴体支持部と干渉した。そこで左右ブラケットのX<-34 mmの部分を除去する候補STEPを生成した。各483.84 mm³を除去し、それぞれ単一の有効なソリッドとして残っている。

**この除去により旧固定支持との接続がなくなる。新しいヨー軸受・回転支持・モータ取付を設計するまで、荷重を支えられる組立品ではない。** 干渉を避ける形状検討の一段階であり、このSTEPだけで製作しない。

切除後は19標本中16標本で体積交差がなかった。残る左−6/右+6度、左−12/右0度、左−12/右+12度では左右の脚部品同士が干渉する。±3度の全標本は干渉なし。ただし標本間の連続掃引、他の股関節・膝・足首角、接触余裕、実際の支持部品は未検証。独立した関節範囲を指定するだけでは自己衝突を防げないことを示す。

## 運動学

`stackchan_rl/yaw_kinematics.py` は各脚の旧5軸の前にヨー軸を追加する候補用計算。軸位置は呼出側で指定し、旧脚寸法を変更しない。ゼロヨー角で元の全リンク座標と足裏座標が一致する。胴体が鉛直を保った条件で、足裏位置とヨー角から6関節を解く。非鉛直の胴体や指定したヨー制限外は拒否する。

左右計60条件の順運動学→逆運動学の往復、ゼロ角の一致、制限超過・胴体傾斜の拒否を3テストで確認した。これは計算の確認であり、質量・慣性・モータ・接触を含む12軸MuJoCoモデルや歩行実績ではない。

## 再現

```sh
.venv-cad/bin/python screen_hip_yaw_sweep.py --design outputs/design_r6_base_collisions --mount validation/battery_mount_review_v2 --out outputs/new_yaw_sweep.json
.venv-cad/bin/python screen_hip_yaw_sweep.py --design outputs/design_r6_base_collisions --mount validation/battery_mount_review_v2 --trim-cradle-rear --out outputs/new_yaw_sweep_trim.json
python -m unittest tests.test_yaw_kinematics -v
```

CAD元データの生成は `docs/REPRODUCE_MOUNTED_ja.md` を参照。体積交差の検出閾値は0.01 mm³。出力JSONに全干渉ペア・体積・ソースハッシュを保存した。
