# 荷重推定の解析解照合

静止、自由落下、90度傾けた静止、一定角速度2rad/sの旋回を照合。
重力の符号・座標変換・向心加速度を、解析解と比較した。
比較許容差は実行前に静止/落下1e-7N、回転1e-6Nに設定。
これは計算法の数値誤差の判定で、機構の許容荷重ではない。
4ケース合格。回転の最大成分誤差1.18e-8N。

初回はSciPyのEuler角配列APIの形状不一致で停止し、結果なし。
回転ベクトル配列で入力するよう修正し、判定値を変えず再実行した。
抽出関数を共用化した後の左右実履歴のreport.jsonは既存結果と完全一致。

再現:

```sh
.venv-engineering/bin/python software/sim/structural/check_battery_force_estimator.py --out /tmp/battery-force-check-new
```

滑らかな既知運動での検査に限定される。接触衝撃、停止履歴、電池の回転モーメント、
更新後の全身運動、実機強度は検証していない。
