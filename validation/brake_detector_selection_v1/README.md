# バス給電のTPS3700吸収指令候補

2026-09-21。TPS3700DDCRを各吸収枝に1個、合計2個追加する評価案。既存の電池低電圧監視用TPS3700とは別部品であり、流用配線しない。

[TI資料](https://www.ti.com/lit/ds/symlink/tps3700.pdf)、SBVS187G February 2019、§5/6.5/6.6/7。内蔵基準を使用し、VDDを遮断器より負荷側のバスへ接続する。A側のINA+が上昇しきい値を超えるとOUTAが高インピーダンスになるため、バスへのプルアップからUCC27517のIN+をHighにできる。IN−はGNDのまま。B側の逆極性出力をこの接続へ置き換えてはいけない。

## 分圧候補

上127 kΩ、下10 kΩ、各初期±0.1%を置く。呼び吸収開始5.48 VはCodexの設計候補で、ユーザー要求ではない。狙いは通常上限5.25 Vで吸収を持続させず、6 Vまでの過渡余裕を残すこと。従来波形が合格するよう基準を変更したものではなく、新回路を未検証として扱う。

しきい値規定範囲と入力電流±25 nAを組み合わせると、開始5.411980〜5.548250 V、解除5.288908〜5.493348 V。入力電流の表の試験点は実分圧点と異なるため比較条件であり、保証された全誤差包絡とはしない。抵抗の温度係数・経年変化・実型番は未確定。上下限は独立包絡であり、同一個体のヒステリシス幅ではない。最小ヒステリシスを典型5.5 mVから保証しない。

## 動的条件と故障

電源1.8 V超から出力が正しくなるまで最大450 µsの起動条件がある。低電圧から回生でバスが立ち上がる際に、検出器とドライバが先に起動することを確認する必要がある。入力10 mVオーバードライブ等の条件で示された遅延を、ゆっくりしたしきい値通過や全電源電圧へ無条件に流用しない。立上り時間の典型値も保証時間にしない。

プルアップ10 kΩは仮値。検出器の漏れ、ドライバ内部プルダウン、入力電流・容量、基板漏れを含めてHigh電圧/立上りを確認する。Low側も出力電流と論理しきい値を照合する。入力RCは遅延を増やすため無検証で追加しない。

分圧上側の断線は吸収不作動、下側断線は入力の過電圧リスクを生む。OUTA断線はプルアップで常時吸収、OUTA短絡は吸収不作動となり得る。枝ごとの部品分離だけで共通バス/GND故障への独立性を証明しない。常時オン検出と電源遮断の実回路は引き続き必要。

今回の終了条件は固定分圧の公差計算とピン接続の確定案。追加回生波形は生成していない。次に抵抗/プルアップ/ゲート抵抗の実部品、入力負荷、実容量を確定し、起動と過電圧応答を回路として検証する。#22/#24は未完了。
