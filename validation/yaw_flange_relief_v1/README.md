# フランジ面取りの余裕・断面比較

最短距離点はヨー連結部のホーン取付フランジ上面外縁Z=62 mm。外周半径8 mmの上端0.6 mmに45度面取りを加えた1案だけを比較した。凍結モデルは変更しない。

4組の中立隙間は0.534242→0.958506 mm。既存公差予算0.40 mmを引いた残余は約0.558506 mmで、既存残余0.50 mm基準を満たす。各連結部の切除量は8.821592 mm³で、有効な単一ソリッド。

しかし、PCD半径6 mm/穴半径1.1 mmに対し、上面の穴外側残り幅は8−6−1.1=0.90 mmから7.4−6−1.1=0.30 mmになる。これは上端の最小幾何幅であり、断面全体が0.30 mmになるという意味ではない。面取りによる座面/接触面の減少、穴周辺の抜け・積層割れを未検証のまま合格とはできない。面取りの体積が小さいことは保持強度の根拠ではない。

## 判断

**中立隙間の条件は通るが、製作候補には採用しない。** 原因位置と断面への代償を確認したため、この局所面取りの寸法掃引やメッシュ細分化は終了する。純正側面フレーム案を続けるなら、ホーン周囲の締結面を維持できる連結構成と胴体支持をまとめて変更する必要がある。現行フランジの薄肉化だけで干渉判定を通さない。

強度・動作範囲・実ねじ/公差・プリント方向は未確認。結果JSONのclearance_passは中立距離だけを表し、manufacturing_release/strength_verifiedはfalse。
