# 電池切離し後の残留電圧・出力容量エネルギー

Issue #24に向けた特性確認。既存の連続LDO・回生吸収・EN結合モデルを使い、7.4 V電池を80 msで理想スイッチにより切り離した。電池端子を0 Vに強制する短絡とは区別する。スイッチのRON=1 µΩ、ROFF=1 TΩは試験治具の仮定であり、実装する遮断素子の仕様ではない。サーボ負荷はゼロとし、回生も与えない。既存の制御系消費・バス監視回路は残した。

測定時刻、数値確認条件、限界は実行前のplan.jsonに保存。電圧はngspice内部時間点からmeas FINDで測定し、100 µs間隔の表示波形から極値を推定していない。観測時刻以外での交差時刻や単調性は判定していない。

|切離しからの時間|駆動バス V|EN V|出力容量800 µFのエネルギー mJ|
|---|---:|---:|---:|
|切離し1 ms前|5.143602|1.601070|10.5834|
|1 ms後|5.136143|0.021888|10.5527|
|20 ms後|4.924353|0.021620|9.7004|
|120 ms後|3.954938|0.021619|6.2570|
|920 ms後|0.351269|0.019890|0.0494|

ENが停止側でも、20 ms後にバス約4.92 Vが残る。このモデルだけでも、電池切離しと即時の駆動電圧消失は同一ではない。実サーボのトルク消失時刻・保持/脱力挙動はこの電圧から決められない。Coutエネルギーは0.5*C*V(rail)^2であり、他の容量・インダクタ・モータ・機械のエネルギーを含む全残留エネルギーではない。

今回は特性測定のみ。安全電圧、放電期限、再投入条件の製品判定基準は未確定で、保護合格とはしない。次の設計では制御仕様と停止時の挙動を合わせて基準を定め、放電経路、回生中の遮断、外部からの逆給電、再投入、故障時の開放/短絡を評価する必要がある。理想・行動電源の残存、実部品の低電圧時挙動、部品公差、出力容量の実総量・温度、遮断素子と電池の特性は未保証。この結果でIssue #24は閉じない。

再現（リポジトリルート）:

```sh
.venv-engineering/bin/python software/sim/circuits/run_disconnect_residual.py --out outputs/disconnect_residual
```

ngspice42を使用。表示波形はdisplay_trace.dat.gzとして可逆圧縮。manifest.jsonは保存ファイルのSHA-256と圧縮前波形のSHA-256を記録する。
