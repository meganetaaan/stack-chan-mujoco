旧丸角足裏モデルをXMLで確認。左右ankle_rollボディは葉ボディで、従来質量は各56.00746g。

これは可視形状の所属確認であり、親のinertial内訳も更新前に照合する必要がある。

足裏siteのzは−22mmで、現在の足部CADの外形・接地高さと対応する。

全身の質量配分やすべての形状・座標変換を検証済みとはしない。

置換対象を確定して接地材・足部締結品の寄与と合成する。
