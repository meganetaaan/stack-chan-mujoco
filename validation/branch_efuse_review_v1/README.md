# 分岐保護TPS25947の採否

2026-09-21、#21/#24。机上審査で分岐用採用を判断し、適合しなければシミュレーションへ進まない。

**現構成へのTPS25947の各軸挿入は採用見送り。** 回生経路と電圧降下が既存案に適合しない。

TI SLVSFC9C（2026年5月版）のp1/4/9を確認。TPS259470LRPWは電流制限・ラッチ停止、TPS259474LRPWは遮断・ラッチ停止の候補となるが、いずれも逆電流を遮断する。したがって、サーボ側の回生を上流の共通ブレーキへ戻す経路として使えない。分岐より下流の吸収器または別の回生経路が必要。「逆流保護あり」を「モーター回生保護あり」と解釈しない。

オン抵抗45 mΩの最大値は3 A等の規定条件付き。1 Aの試算点へ同抵抗を適用すると、前段で算出した接点・250 mm線材の66.575 mVに45 mVが加わり111.575 mV。0.10 V予算を超える。これは1 Aでの保証値を主張する計算ではなく、この仕様から現予算の最悪適合を立証できないという判断。公称抵抗だけでは5 mV程度の余裕しか残らず、採用根拠にしない。

TPS259472の「5.7 Vクランプ」も採用理由にならない。規定上限はクランプ閾値6.2 V、指定条件での出力6.12 Vで、サーボ6.0 V以内を保証できない。さらに入力側過電圧対策であり、負荷からの回生吸収の代用ではない。

次の方式は、通常運転中に共通ブレーキへ回生を戻せる低抵抗の分岐保護と、全系遮断後もサーボ側へ残る吸収経路を設ける構成とする。素子未選定。遮断・電源喪失・復帰の全状態でエネルギーの行先を図示してから選定する。閾値緩和や未知回生の追加掃引で本部品を通さない。
