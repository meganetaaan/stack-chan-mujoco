# 標準ホーン取付面に合わせた足ヨーク候補

メーカーSTEPの標準出力ホーン・アイドラーホーンを用い、前耳x=3..6 mm、後耳x=−29..−26 mmへ移した。耳厚は3 mm。足底板と取付穴を保持し、脚長・回転軸は変更しない。軸から6 mmの4穴に半径1.1 mmのフレーム側クリアランス穴を配置。ホーン側の公称CAD穴半径は0.8 mmだが、製造公差・ねじ仕様の確定値としては扱わない。

左右とも単一有効ソリッド、前側接触145.739 mm²・後側125.664 mm²、ホーンとの重なり体積0で、事前の局所形状基準を満たした。取付ねじ長さ、締付・抜け止め、取付部強度、動作時干渉、メーカーアイドラーの支持容量は未検証。これはHNX330-N101金属ホーンへ適合確認したものではない。

v2/v3は同一CADに対して前側接触を0と誤判定した検査結果。原因は前側の平面自体がZ=6.5である一方、トリム境界の外接範囲が6.49936付近まで及び、外接箱で平面を選択できなかったこと。v4ではBRepの基底平面の法線・位置を使い、同じ接触面積・重なり基準で再検査した。形状や基準を緩めてはいない。初回はCadQueryの行列変換が非直交として拒否されたため、同じ剛体変換を軸角回転で実装した。

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" \
 .venv-engineering/bin/python software/sim/structural/build_native_horn_yoke.py \
 --out outputs/native_horn_yoke_repeat
```

形状体積は片側約363.356 mm³増加。材料密度を確定して質量台帳へ反映する必要がある。次は実ケースとキャップ・ねじを含む組立および連続可動域を検査する。凍結モデルと可動域設定は未変更。
