# 電源モジュール取付穴の公差：固定軸モデルの反例

**結論：固定された公称ねじ軸と公称穴だけでは、組立性を保証できない。**
共通STEPで体積重複がなかった結果は維持するが、公差適合の合格には拡張しない。

[メーカー寸法図](https://www.pololu.com/file/0J2217/d42v110fx-step-down-voltage-regulator-dimensions.pdf)の
穴位置公差±0.1mmを各座標の独立範囲と解釈し、対角の2穴が外側へずれるケースを計算した。
この解釈は設計上の仮定で、真位置公差の規定を追加したものではない。
穴径2.18mmは図面公称、ねじ径2.0mmはモデル包絡であり、実測径や確定した公差限界ではない。

公称ピッチ38.862×25.4mmでは、対角距離は46.426448mm。
外側変位後は46.703317mm、差は0.276870mm。
同径の丸穴2個で吸収できる穴中心間距離の差は最大で穴径−ねじ径＝0.180mm。
基板全体を平行移動・回転しても穴間距離は変わらないため、この条件では不足する。
したがって、基板全体を少しずらすだけでは必ず解消するとは言えない。

この対角ケースだけを吸収する追加自由度は各ねじ最低0.048435mm。
これは最終的な長穴寸法や造形公差ではない。穴径・ねじ径の限界、印刷位置誤差、
ポケット内のナット移動、スペーサーと座面、接触余裕を含む値に置き換える必要がある。
現行ポケットやスペーサーに既に遊びがある可能性を否定しないが、その実効量は未証明。

次は基板の穴を加工せず、ねじとナットを独立に位置合わせできる保持方法を検討する。
終了条件は4穴の全公差範囲で位置合わせでき、締結後の座面・保持・部品隙間を同時に満たすこと。
結果を通すためにメーカーの公差やねじ包絡を小さくしていない。
追加のメッシュ解析は不要。公差の定義と締結幾何の判断を先に行う。

再現：`python software/sim/structural/screen_pololu_hole_tolerance.py`。
条件は`plan.json`、数値と入力ハッシュは`report.json`。
実物の組立不能を証明するものではなく、現状の設計保証が不足する反例。
