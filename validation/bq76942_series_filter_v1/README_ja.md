# 入力フィルタ：単一C故障を考慮した直列化候補

前案の100nF×2並列を、100nF×3並列のバンク2組を直列にする案へ変更する。
部品は確認済みのC1206C104J3GACAUTOを使用。各フィルタの中点は外部へ接続しない。
接続は `schematics/power/bq76942_series_filter_candidate.json`。
元の候補JSONは故障記録を再現するため残し、この代替案を別ファイルで管理する。

判定条件は解析前に、単一C短絡で端子間の理想直流短絡が生じないこと、
正常・単一短絡・単一開放で初期公差込み容量がTI推奨0.1〜1µFに収まることとした。

| 状態 | 初期±5%込み合成容量 |
|---|---|
| 正常 | 142.5〜157.5nF |
| 1個開放 | 114〜126nF |
| 1個短絡 | 285〜315nF |

2並列バンク×2直列では正常時に95nFまで低下するため、今回の3並列を選んだ。
単一短絡で片側バンクが短絡しても、もう一方が直流経路を遮る。
実部品には漏れがあり「放電ゼロ」の証明ではない。残存バンクの各Cには全セル電圧が
かかるとして評価する。25V定格に対し通常4.2Vは範囲内だが、接続過渡・誤配線は別評価。

4入力合計24個（前案8個）。典型質量合計0.864g、寸法上限の部品本体面積合計146.88mm²。
パッド・間隔を含む実装面積ではなく、基板に収まる証明ではない。
この増加を隠して製造BOMを確定しない。

再現：

```sh
python3 software/sim/circuits/screen_bq76942_series_filter.py
```

正常1・開放6・短絡6の13ケースを計算。全ケースが上記の限定した条件を満たす。
Cの温度・直流バイアス・漏れ、抵抗パルス、RCの連成遅延、IC内部故障、
両バンクを跨ぐはんだ短絡・共通原因故障は未検証。回路全体の保護合格ではない。
容量計算だけの追加解析はここで終了し、次は入力電流・漏れと実装配置へ進む。
