# Tab5の最寄り部品

`software/sim/structural/identify_tab5_near_parts.py --out <新規出力先>`を
CadQuery環境で実行する。入力ハッシュと組立内全52ソリッドの距離を保存する。

最小距離0.4mmを持つ部品は胴体外装body_shroudである。
元STEPが組立のソリッド0と双方の差集合0で一致することを確認した。
「ヨー支持組立との距離」を「ヨー可動部との距離」と読み替えない。
これはTab5と固定外装の組付け・取り外しの公差予算として扱う。
可動部に定めた0.50mmを、この箇所の不合格判定へ無条件に転用しない。
必要な公差・変形・取付け誤差が未確定なので、0.4mmで十分とも判定しない。
