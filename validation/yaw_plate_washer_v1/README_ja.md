# ヨー支持板専用ワッシャー候補

SCW-YAW-PLATE-WASHER-01 A-candidateを作成。外径6.35〜6.40 mm、内径2.30〜2.35 mm、厚さ0.85〜0.95 mm、縁面取り半径方向最大0.05 mm。材質SUS304・切削加工は提案で、材料証明と加工能力は未確認。厚さの限界には面形状の変動を含める。

採用時の数量は8。足部のSCW-SOLE-SPACER-01は2個のまま変更しない。現行BOMとrevBの10個構成は未変更で、この候補を追加購入数量として二重加算しない。

## 確認結果

公称2 mm軸・最大穴隙間で0.175 mm偏心し、最大対辺4 mmの角ナットがねじと同軸という前回の条件では、平坦外周の支持余裕は0.12157 mm（旧候補-0.07843 mm）。この余裕を未確認のねじ／ナット公差まで含む保証とはしない。

現行組立から対象の旧ワッシャー8個だけを除去した形状に対し、新ワッシャー公称形状の追加干渉は8か所ともなし。足部や他部品を変更して合格させていない。

棚側は外側配線開口を設けた支持棚を使用。最小平坦外周半径3.125 mm、最大平坦内周半径1.225 mmの環状面を0.01 mm深さで検査した。8軸×8偏心方向で、最大0.17434 mm²の支持されない環状面積が残る。主に偏心した内周と棚中央穴の関係によるもので、外径を増やしただけでは全面接触を保証できない。これは方向サンプルであり連続公差の最大欠損保証ではない。

**判断：既知のナット外周不足への対策候補として保持し、製造リリースは保留。** 面積の小ささを根拠に強度合格にしない。ねじの実分担・予圧、ナット座面、棚穴の仕上がり、部分接触圧、ワッシャー曲げ・棚のクリープを接触モデルと試験計画へ対応付ける。完全支持の旧仮定をそのまま転用しない。

## ファイルと再現

specification.jsonが提案寸法、washer_local.stepが部品原点の公称CAD、左右各軸のSTEPが組立位置。公称CADは鋭角であり、面取りの最大影響は数値確認側に含めた。report.jsonに64箇所の偏心検査、plan.jsonに事前条件と終了範囲を保存。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/design_yaw_plate_washer.py --out validation/yaw_plate_washer_reproduce
```

未使用出力先を指定する。元組立・支持棚はハッシュで記録される。
