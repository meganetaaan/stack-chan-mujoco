# 硬質保持部用キー穴の拡大比較

入口半径4.2→4.6mm、スロット半幅3.0→3.4mmへ拡大した左右ヨークSTEP。
既存外形を増やさず、各側194.368mm³を除去。双方とも有効な単一ソリッド。

境界位置誤差各±0.2mmという旧仮置きを変えず、半径隙間は公称0.6mm、
最悪比較0.2mmへ増える。一方、保持頭の横かかり代は公称1.0→0.6mmへ減り、
同誤差で残る比較値は0.2mm。これは保持強度の合格値ではない。
軸方向隙間は旧0.2mmのままで、誤差込み比較は−0.2mm。従って本候補は組付け適合未達。

±0.2mmは工程能力の実測ではない。穴を拡大したことを理由にこの仮置きを小さくせず、
造形・寸法測定で妥当性を判断する。0.6mmも設計比較値で、ユーザー指定の基準ではない。
穴を広げるだけでは全方向の嵌合・保持を解決できないことを確認した比較版として残す。

次は軸方向と保持かかり代を同時に確保する形状を検討する。薄くなった保持部の
強度評価前に現行製作候補へ置換しない。既存の公称挿入経路は材料除去で狭まらないが、
連続経路・公差適合を証明するものではない。

再現：`software/sim/structural/build_rigid_sole_keyhole.py --out <新規出力先>`をCadQuery環境で実行。
