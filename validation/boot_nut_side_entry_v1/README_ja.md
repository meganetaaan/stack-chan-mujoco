# 外装ナットの印刷後挿入候補

目的は印刷途中のナット封入をなくし、ねじ穴の仕上げをナット挿入前に行える形状にすること。片足4箇所の既存ナット室を外側Y方向へ開いた。開口幅4.4 mm、高さ1.8 mm、Z=-14.6〜-12.8 mm。ねじ頭受け面や通過穴径は変更しない。

片足の除去体積41.184 mm³。左右とも単一の有効ソリッド。受け面Z=-14.6 mmより下の材料除去は0。公称4×4×1.2 mmナットを外側から挿入する全8経路について、並進経路全体を覆う直方体と外装の体積交差0を確認した。離散姿勢だけの検査ではない。

## 組立候補の順序

1. ナットを入れずに外装とヨークを印刷する。
2. 両部品を分離した状態で通過穴を仕上げる。仕上げ径公差・工具・治具は設計未完了。
3. 穴の通過と位置合わせを確認する。
4. ヨークと外装を合わせ、外側からナットを挿入する。ねじがかかるまでナットを保持する工具の空間は未確認。
5. 下側からねじを挿入して締結する。締付けトルクと緩み止めは未確定。最後に足裏を取り付ける。

## 判定の限界

- 購入ナットの寸法と造形公差は未適合。幅4.4 mmに既存±0.2 mm/面を適用すると4.0 mmになり、公称最大包絡との余裕がゼロ。公称挿入合格を公差後の合格へ拡張しない。
- ねじを外すとナットが開口から脱落し得る。組立・整備時の回収が必要で、封入ナットとして扱わない。
- 壁を開けたため以前の局所FE結果は転用できない。ナット受け部の曲げ・割れ・クリープ、側壁剛性、ねじ保持を未確認。
- 組立全体はrevDで検査した。印刷後の実物適合や工具の掃引空間を確認したものではない。
