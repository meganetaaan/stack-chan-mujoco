# 直列クランプのゲート駆動方式

LT4363 Rev.CのMOSFET選定節は、VCCが9V未満の場合にロジックレベルMOSFETを要求している。したがって前回の2候補に対し、5V給電のまま7V規定のオン抵抗を使う評価は進めない。

4.5Vのオン抵抗が規定されるPSMN2R4-30YLDを比較に追加した。25℃の最大3.1mΩを既存モデルの4.917Aへ適用すると、通常時の損失約75mW、降下約15mVとなる。ただし温度・ゲート負荷を含む最終保証ではない。

この部品は最大熱抵抗1.42K/Wで、ベース125℃固定・49.56W連続という比較では接合195.4℃となり175℃を超える。短いパルスでの使用まで不適合と断定する結果ではない。SOA曲線、過渡熱、初期温度、タイマーの整合が必須。

制御ICだけを電池から給電してゲート駆動を増やす案は、単純な配線変更としては採用しない。VCC−OUTがMOSFET損失を推定するタイマーに使われ、ENOUT判定にも影響する。電池の下限を9V以上に引き上げるだけで済ませず、使用可能エネルギー・電源順序・故障検出を再評価する必要がある。

タイマー容量はメーカーの最低10nFを制約として追加した。10nFを採用したわけでも、特定の遮断時間を保証したわけでもない。判定を通すために容量ゼロや極端に短い任意タイマーを使わない。

SOA図の取得は引き続き未完了（今回のメーカー別公開URLもHTTP403）。曲線の数値は推測せず、パルスSOA合否はnullとした。部品選定・全体試作は保留。
