# ヨー支持ナット―ワッシャー座面の偏心確認

対象は現行revBの支持ねじ8か所：NBK SLH-M2-10、PTS A56202、SCW-SOLE-SPACER-01。底側のねじ頭が板を受け、軸の引張りがナット→ワッシャー→樹脂棚上面へ伝わる。これとは別に板から棚下面へ圧縮を伝える経路がある。

支持ねじ軸はX=-34,8.1 mm、Y=各脚中心±10 mm。板下面Z88、棚上面Z91、ワッシャー公称厚0.9 mm、ナット公称包絡Z91.9..93.1。これは公称配置であり完全ねじの係合長ではない。ねじ先端が十分突出することだけでは、ナットの実ねじ山・面取り・荷重能力を保証できない。

## 結果

機械加工ワッシャーの提案下限外径5.95 mmと最大縁面取り0.05 mmから、平坦部の外半径は2.925 mm。最大対辺4 mmの角ナット包絡の角半径は2.82843 mmで、中心一致なら余裕0.09657 mm。

ワッシャー最大内径2.35 mmと公称2 mm軸から偏心0.175 mmを許すと、ナット角方向の余裕は**-0.07843 mm**となる。したがって、既存の中心一致CADだけからナット外周全体の支持を保証できない。角包絡は実ナットの面取りを含まないので、これを実接触面の欠損量・破損・耐力不足と断定もしない。

この限定した条件の外周包絡を支持するには、同じ縁面取りでワッシャー下限外径が少なくとも6.10685 mm必要。ただしこれは推奨製造寸法ではない。実ねじ軸径、ナットねじ隙間、ナット実座面、受け側の支持幅を含めた決定が必要で、径を増やした際の棚側座面・ねじ工具との干渉も確認する。

## 判断

現行のワッシャー公称径とナット中心一致をもって座面確認完了にしない。次の構成判断は、(1)角ナット実座面と公差を取得して評価する、または(2)ヨー用ワッシャーを足部品と分けて設計し、偏心時の座面と棚側の支持を確認する。足部のワッシャー寸法を一括変更しない。厚い市販ナットへ替えることだけでは、この偏心問題や実予圧は解決しない。

ねじ係合長、組立予圧、クリープ後の保持、板・ワッシャー曲げ、座面圧の許容値は未確認。既存のメーカー最大トルク0.3 N mをこの樹脂締結の組立指定へ転用しない。製造リリースなし。
