# 手動復帰revHの数量BOM

現行入口JSONが参照する43部品の組立と、選定済み抵抗表を照合し、同じ型番をまとめた数量BOMを生成した。IC14個と抵抗14本は型番候補あり。コンデンサ14個とSW1は未選定と明示した。型番候補があることは調達可能性・回路適合・製造リリースの証明ではない。

総合候補BOMで欠落していたU3 SN74HCS11、U5 TPS3808リリースタイマー、U13 PG受信バッファを追加した。抵抗・コンデンサの数量も記載した。旧説明の「U9がENを直接クランプ」を現行の原因信号出力へ修正した。U10がENを駆動する接続は変更していない。

B3U-1000Pと追加3 kΩ・生信号受信段は未統合の別案であり、SW1の選定完了や43部品への加算には使わない。このBOMは主電源経路・回生吸収・起動監視・外部停止を含まない。全機の必要数、共通電源と複数駆動レールの関係は別途確定が必要。

再現：`python3 software/sim/circuits/build_manual_rearm_bom.py --out /tmp/manual-rearm-bom-check`（未作成の出力先）。抵抗参照の対応漏れと数量を検査し、元組立と選定表のSHA-256を記録する。出力のCSVとJSONを保存済み結果と比較できる。
