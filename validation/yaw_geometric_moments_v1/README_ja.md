# 密度未指定の重心・慣性入力

ヨー支持組立revAの形状から、材料に依存しない重心と体積慣性を抽出した。目的は、材料決定後のMuJoCo質量更新に必要な位置・テンソルを用意すること。形状変更、材料密度の仮置き、追加構造解析は行わない。既存52部品のinventoryが完全一致し、形状を変えていないことを確認した。

geometric_moments.jsonの単位は、重心がm、質量係数がkg/(kg/m³)、重心まわり慣性係数がkg·m²/(kg/m³)。採用密度ρ[kg/m³]を掛けると、均質な公称ソリッドとしての質量・慣性になる。変換係数は体積mm³→m³が1e-9、体積慣性mm⁵→m⁵が1e-15。

全52部品のうち24部品は公称ソリッドの材料計算対象、28部品はねじ・ナット等の包絡であり実重量計算から除外する。樹脂部品のインフィル・空隙が非均質なら、単一有効密度で重心や慣性まで正確になるとは限らない。製法と内部構造を確定して適用を判断する。

重心は組立CAD座標系。凍結モデルbaseの部品集計と同じ座標基準を使い、ワールド上の初期姿勢を部品重心へ加算しない。各部品を平行軸の定理で共通原点へ集計し、新しい合成重心を求めてから、その重心まわりの慣性へ戻す。

移動した2×3×4 mmの直方体で体積・重心・中心慣性の解析解を照合し、全テンソルの正の固有値と主慣性の三角不等式も確認した。CAD数値処理の確認であり、実部品の重量・強度・歩行性能の証明ではない。

