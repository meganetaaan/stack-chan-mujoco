# 手動再許可ラッチの実部品候補

**更新：下記のD=High直接接続はデバウンス遅延反例で不合格。`../manual_rearm_delayed_press_v1/README.md`を参照。部品検討の履歴として保存する。**

SN74HCS74PWの片側Dフリップフロップを評価候補にする。[TI資料](https://www.ti.com/lit/ds/symlink/sn74hcs74.pdf)、SCLS782D、§5/6/8。給電範囲2–6 V、正エッジでDを取り込み、CLRは非同期LowでQを解除する。Schmitt入力はゆっくりした入力に対応するが、機械接点のバウンス除去そのものではない。

## 論理接続候補

VCCは上流側の監視済み3.3 Vロジック電源。1Dと1PREをVCC、1CLKを整形済み手動押下信号、1CLRを停止優先のクリア信号へ接続する。1Qは投入許可。未使用の第2回路はCLRをLow、PREをHigh、D/CLKをGNDに固定し、出力は未接続とする。クリア入力の生成回路とEN出力段は未選定。

押下信号がHighのままCLRを解除してもクロック正エッジは生じず、新たな押下なしにQは立たない。これは`manual_rearm_logic_v1`の意図を実現する部品構成案だが、入力の有効性とタイミングが前提。電源立上りでCLKが意図せず立ち上がる場合をクリアで覆う必要がある。

## 採用確定までの条件

- 電源投入/低下時のQ初期値を部品の自然状態に期待しない。監視器が有効になる前からENをオフへ保持する外部段が必要。
- CLR解除とCLKの間隔、最小パルス幅、Dのsetup/holdを規定給電と温度で満たす。非同期解除と押下が同時なら投入しない要求を、理想論理だけで保証しない。
- デバウンス回路を部品化し、押下/解除両方の波形を確認する。1回の物理操作から複数エッジを生成しない。
- 別電源の故障信号を入力へ直結してロジック電源が落ちた際に逆給電しない。入力定格と電源シーケンスを含むインターフェースを設計する。
- Q短絡HighやEN出力段故障をこのラッチは覆わない。eFuse内蔵保護とは別の停止経路を含めて評価する。

今回の終了は型式と論理ピン接続の選定まで。POR/監視/デバウンス/EN出力段が揃う前に理想DFFの追加シミュレーションで採用承認しない。#24は未完了。
