# G030電源シーケンサ実行接続の検査

MMIOアダプターをGPIO初期化・電源状態処理・期限処理へ接続した。
アクセス異常を保持し、検出した呼出し内でCLEARを要求する。

再現（出力先は未作成ディレクトリ）：

```sh
python3 software/sim/circuits/check_g030_power_runtime.py --out /tmp/g030-runtime-check
```

C11ホストコンパイラとArmターゲット対応clangが必要。
11シナリオ、211読出し・160書込みを模擬コールバックで確認した。
起動異常、読書き中の異常、正常観測に戻った後の故障保持、
無効な期限設定・欠落タイマーを含む。Cortex-M0+オブジェクト生成も通過。
実MMIOソースはArm向けにコンパイルするが、故障注入は代替コールバックを使う。

起動クロック・RTC・リマップ設定、資格済み入力、実時刻源、
ウォッチドッグ、最終リンク、実機端子・遅延は未検証。
Enable書込み後の検出では一時的なパルスが残り得る。
ソフトウェアのアクセス異常検査は電気的なバス故障検出ではなく、
独立したハードウェア遮断の代用にはならない。
通電試作HOLDおよびIssue未完了を維持する。
