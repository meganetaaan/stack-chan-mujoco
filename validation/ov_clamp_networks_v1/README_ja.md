# OVLOクランプの抵抗負荷と電流比較

再現: `.venv-engineering/bin/python software/sim/circuits/compare_ov_clamp_networks.py --out /tmp/ov-clamp-new`

目的は、TLV431AI追加時に検出用分圧回路の負荷が変わる問題を解消できるか判断すること。既存の通常上限5.25 V、サーボ上限6 V、OVLO推奨上限1.5 Vは変更しない。TLV431の推奨カソード電流下限0.1 mAを用いる。抵抗±0.1%は初期値の比較で、全温度・経年保証ではない。

35.7k/10kを維持し、クランプ帰還1k/20kを追加する案は、抵抗負荷だけでも検出電圧7.358～7.691 Vとなり棄却する。帰還10k/200kなら5.562～5.814 Vだが、未クランプ端子が1.5 Vになる入力条件で利用可能カソード電流は最小20.6 µAにとどまる。12.6 V時だけ電流を確認しても、そこに至る途中の端子制約は証明できない。

分圧を3.57k/1kへ変更する2案は、この限定比較では検出電圧と電流を満たす。帰還10k/200k案は検出5.386～5.624 V、条件付きクランプ1.276～1.337 V、利用可能電流最小207.7 µA。これは製造採用の判定ではない。電流消費・抵抗損失も増える。

TI SLVS139Z (June 2024) の基準電圧範囲は10 mAで規定されている。本回路の低い動作電流で同じ範囲を保証できるとはしていない。動作開始前のカソード電流、容量負荷安定性、応答遅れ・オーバーシュートも未確認。基準電圧、帰還電流の比較値と適用限界はreport.jsonに記録した。

終了条件: 単純追加案の可否と、次の候補に必要な抵抗変更の特定まで。本比較の追加抵抗掃引は終了する。次は低電流域での端子電圧保証が得られる方式・部品を確認し、得られなければ監視回路からOVLOを制御する方式等へ切り替える。実測Issueに未完成の設計判断を移さない。現行revMは変更せず、#6は未完了。
