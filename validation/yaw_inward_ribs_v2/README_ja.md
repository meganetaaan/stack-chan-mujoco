# 支持リブ内側増厚案：ねじ干渉で不採用

直前のrail-seat支持部は、保存荷重による最大変位0.238077mmが既存0.2mm枠を超える。外形を維持して左右リブ厚を5→6.5mmへ増やす一案を評価した。材料・荷重・合格基準は変更していない。v1とv2は同じ形状で、v2だけ干渉部品を個別特定する診断を追加した。

試験前条件は単一有効ソリッド、外形不変、追加部分と既存部品/メーカーサーボ形状との重なり0.01mm³以下、予約コネクタ通路1.3mm以上。両側とも単一ソリッド、外形変化0、サーボへの追加部分の隙間1.5mm、通路1.3mmを確認した。

しかし左/右のplate_2_screwとplate_3_screwへ各0.827276mm³重なった（計4本）。このねじは取り除いたり小さくしたりしていない。固定アセンブリのソリッド数と部品別体積を在庫データと照合してから、対応するねじ名を割り当てた。

結論: 現案は組立不可。追加FEは実行しない。次に形状を変更するなら、4本のねじ周辺の座面/工具経路を避けた増厚にする。干渉が解消した後に、同じ保存荷重と0.2mm枠で一度比較する。保存荷重だけでは最新全機体の強度・動作を保証しない。

左右追加体積は各2160mm³。採用しないため正式部品表・全機体質量には加算していない。

