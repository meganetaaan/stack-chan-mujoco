# 電源取付部の調整量を制限する寸法

## 判断

現行の公称寸法では、まずブラケットの直径2.2mm穴が調整量を制限する。
PCB穴径2.18mm、ねじ包絡2mmなら両方の半径隙間の合計は0.19mm。
各軸同量の対角ずれEについて、必要条件はsqrt(2)E≤0.19mmである。
PCB穴位置の±0.1mmを差し引くと、追加の位置誤差は各軸0.034350mm以下。
これは公称サイズ・穴と溝の同心を仮定した上限で、造形能力や製造合格値ではない。
穴径・位置の誤差、溝の偏心、ねじ径の限界を考慮すれば利用できる量は減り得る。

固定軸の反例、32姿勢の公称配置成功、この上限計算は矛盾しない。
32姿勢で位置を調整できたことは、任意の製作誤差を吸収できる証明ではなかった。

## ナット溝の拡幅にも制約がある

選定ナットの対辺公称4mm、対角最小4.32mmは
[Bossardメーカー表](https://media.distrelec.com/Web/Downloads/_t/ds/1088211_eng_tds.pdf)に基づく。
平行な壁を持つ開放溝では、実際の対角寸法以上に幅を広げると平面内で自由に回転できる。
したがって対角最小より狭いことが回り止めを検討するための必要条件になる。
それだけでトルク保持・傾き・脱落・樹脂変形の成立を保証するものではない。

造形位置誤差を仮に各軸0.1mm追加する感度例では、必要な溝幅は4.272721mm以上。
対角最小4.32mmまでの幅は約0.047279mmしかない。
この±0.1mmはプリンター性能の認定でもユーザー要求でもなく、設計判断用の感度入力。
狭い幅の範囲に入ると仮定して公差を決定することはしない。

## 次の設計判断

現行の保持形状を製造確定にしない。まず次を比較する。
- 穴の位置・径を仕上げ工程で管理し、現行の回り止め溝を維持する方式。
- ナットを工具で保持して締結し、位置合わせと回り止めを別の手段に分ける方式。

後者は工具の挿入経路と締付け反力、前者は加工基準と検査方法を成立させる必要がある。
単に溝を広げる変更や、未知の造形精度を合格条件へ置く変更は採用しない。
この計算は必要条件の判定までで終了。追加のFEや公称姿勢の細かい走査は行わない。
