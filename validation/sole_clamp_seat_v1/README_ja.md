# 足裏の上下保持用座面候補

旧0.9mmスペーサーを外し、外径6mm・内径2.3mm・厚さ0.3mmの金属ワッシャ形状で
保持部を挟む構成へ変更した。実型番・材質・板厚公差・端部処理は未選定。
ねじ座面Z=-19.9mmを維持し、ワッシャ上面Z=-19.6mm、樹脂上面Z=-19mmとした。
従って樹脂座面は公称0.6mm。接地面とねじ頭の公称隙間0.8mmを消費しない。

左右とも整列状態でヨーク・ブーツ・ねじ・ワッシャとの交差0。
下へ0.05mmずらすとワッシャと約1.206mm³交差し、旧スペーサーと違って
保持部の上下移動を直接受ける接触面ができた。接触環の公称面積は24.1196mm²。
この交差は幾何上の拘束確認であり、剛性・破断荷重・締付けの証明ではない。

荷重経路はねじ頭→金属ワッシャ→樹脂座面→ヨーク→ナット。
従来のスペーサーを並存させて樹脂を迂回する荷重経路へ戻さない。
挿入・スライド完了後にワッシャ・ねじを取り付ける。脱着順と工具は未検証。

薄い樹脂座面の曲げ、押抜き、座面圧縮、積層方向、予圧の散らばり・クリープが残る。
±0.2mm境界誤差の旧仮置きを単純に両面へ適用すると厚さの減少は最大0.4mmなので、
公称0.6mmをそのまま強度評価へ使わない。強度判定前に実加工公差と残厚を定める。
片側1箇所の固定で足裏全体の回転・たわみまで止まると断定しない。
製造リリースせず、座面を厚くする変更も既存外形・頭沈みと合わせて比較する。

再現：`software/sim/structural/build_sole_clamp_seat.py --out <新規出力先>`をCadQuery環境で実行。
