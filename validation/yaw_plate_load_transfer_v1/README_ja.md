# 金属板から支持棚への荷重伝達：引張り経路が必要

## 結論

保存済みEPIC4荷重の1ケースは、金属板と棚の圧縮接触だけでは釣り合わない。引張りを受け持つねじ・座面・ナット・棚の経路を明示する必要がある。既存の面全体への分布荷重や完全接着を実締結の証明には使わない。

荷重原点[-5,26,62] mmから、4本の支持ねじの中心[-12.95,26,89] mmへ移すと、Fz=7.4599 N、Mx=-369.7757 N mm、My=-139.3369 N mmとなる。圧縮力だけで必要な作用点は[X,Y]=[5.728,-23.569] mm。棚の接触外接範囲Y9.5..42.5 mmから大きく外れる。

孔や開口を埋めた外接長方形を仮想接触域としても圧縮のみの釣合いは不成立。4本の支持ねじ軸に負Z方向の力を許すと、必要な合計引張り伝達の理想的下限は**9.309 N**。この下限は、Mxについて最も有利な圧縮位置Y9.5と引張り位置Y36を使う式 `(369.7757 - 16.5*7.4599)/(16.5+10)` とも対応する。実際の接触域が狭い場合や、ねじ荷重の分担制約がある場合は必要量が増え得る。

この9.309 Nは締付け予圧、各ねじの最大荷重、必要耐力や安全率ではない。線形計画の解で1本に引張りを集中させる結果も、実物の分担予測ではない。等軸剛性と剛板を仮定する別の診断では4軸の符号付き軸力は[9.455,-9.034,12.764,-5.725] Nとなるが、これも実荷重の保証値ではない。

## 設計への反映

追加の樹脂補強を重ねる前に、金属板の曲げ、接触の離間、支持ねじの引張り、座面／ナット保持、支持棚への伝達を同じモデル・組立図で対応付ける。締結予圧と保持能力を未確定のまま、完全接着モデルで0.2 mm以下になったことを合格にはしない。既存の棚単体解析は同条件の形状比較として残す。

評価したのは保存荷重1ケースのFz/Mx/Myの静的必要条件だけ。Fx/Fy/Mz、摩擦・せん断、全荷重包絡、最新質量、材質・ねじ強度、接触剛性は未評価。製造リリースなし。
