# 胴体・ヨー支持部revC・電源取付部の統合候補

**製作HOLD。** 100部品を同じ座標系のSTEPへ統合した。
ヨーrevCの52部品から旧後部板1点だけを取り除き、電源取付組立43点、
電源モジュール包絡2点、電池・トレイ・Tab5・TTL各1点を加えた。
組立経路の検査で一時的に外したヨー側の後部ねじ・ワッシャー16点は、
最終状態では必要なので残した。挿入時の部品集合を最終BOMと取り違えない。

## 今回の検査と判断

異なる部分組立の部品間を静止した最終配置で検査した。
同一部分組立内部の組合せは今回再検査していない（payload同士は検査）。
事前フラグ値は体積重複0.01mm³超、近接距離0.5mm未満。
0.5mmは取付面やねじ穴にも一律適用する合否基準ではなく、今回の見落とし防止用抽出値。

- 包絡箱の距離で0.5mm以上を示せた組合せ：2686組。
- 形状距離0.5mm未満：40組。そのうち体積重複フラグ：16組。
- 16組はすべて電源モジュール包絡と同側のねじ／スペーサー。
  穴や下面部品を表さない包絡との重複であり、実部品の干渉とも無干渉とも断定しない。
- その他の24組には固定面の接触や、ねじと板穴の距離0.2mmが含まれる。
  ボア・座面としての適合、公差、締結後の保持は別評価。
- 外装とTab5の公称距離は0.4mm。公差・変形後の余裕は未確認。

判定のために包絡を削ったり、フラグ値を緩めたりしていない。
`report.json`に全近接組合せ、部品名、参照ファイルのハッシュを保存した。
この結果は追加の最終配置比較であり、既存の連続組立経路検査や全身動作検査の代用ではない。

## 次の不確実性と終了条件

1. モジュール包絡の16重複を、メーカー形状・取付穴・下面部品の実形状で再評価する。
   各組合せについて、接触・ボア・実部品干渉・資料不足のどれかを明示して終了する。
2. 外装とTab5の0.4mmに、公差と相対変位の配分を与える。
   根拠のない公差を置いて合格にせず、保持方法と干渉余裕の設計判断を行う。
3. 電源保護基板、配線、足revE、脚全体は未統合。100部品を全身BOMとは呼ばない。
   完成機の質量・重心・慣性、動作干渉、強度の更新にはそれらが必要。
