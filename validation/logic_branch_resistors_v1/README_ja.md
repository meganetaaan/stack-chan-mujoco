# LOGIC入力保護 抵抗選定

目的は、120kΩがTPS2660の推奨上限に位置する問題を解消し、分圧抵抗も具体的な発注コードにすること。試験前条件は、従来の抵抗総合±1%枠を維持し、RILIMの全範囲を5.36k〜120kΩ内に収める。118kΩの一候補だけを評価し、電流・起動合格をこの検算の終了条件に含めない。

メーカー資料: https://www.vishay.com/docs/28758/tnpw_e3.pdf （28758、10-Apr-2026）。0603、B=初期±0.1%、E=±25ppm/K、EA包装を選定。抵抗範囲・標準数列・型番構成から発注コードを作った候補で、流通在庫は未確認。

工学的仮定: 抵抗膜温度−40〜125℃、25℃基準。初期公差と温度変化を乗算すると0.9965025〜1.0035025倍。総合±1%枠に対し残りは約±0.64975%相当で、工程・経年変化を収める必要がある。これは全寿命保証ではなく、実基板の温度も未検証。

RILIMを118kΩへ変更。初期＋温度範囲117.587〜118.413kΩ、総合設計枠116.82〜119.18kΩで推奨範囲内。旧120kΩは公差上側で範囲外なので採用しない。TIの公称式によるIOLは約101.695mA、旧案より1.695%増える。これは公称値であり、ICばらつき込みの上下限ではない。旧120kΩ評価点のIOL/ICB/ISCLを118kΩの保証値へ換算していない。

分圧器の公称値と総合±1%枠は変更しないので、既存 `logic_input_window_v1` の条件付き静的計算は変更不要。工程・経年・温度・3SでのIC適合、起動、異常時は未完。部品選定の進展であり、#22〜#24の合格ではない。

再現（リポジトリルート）:

```sh
.venv-engineering/bin/python software/sim/circuits/check_logic_branch_resistors.py --out validation/logic_branch_resistors_v1
```

結果は `report.json`。スクリプトは現行候補の抵抗値と選定条件を読み、抵抗範囲のみ検算する。
