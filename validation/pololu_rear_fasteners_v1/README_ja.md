# 電源台座の後板締結候補

## 構成と変更理由

M3×12低頭ねじ4本、M3六角ナット4個、外径7・内径3.2・厚さ0.5 mmの座金8枚を選定候補とした。部品番号・メーカー/自社ブランド供給元の寸法出典は `docs/prototype/mechanical/pololu_mount_fasteners/rear_candidate.json`。

従来の穴高さ108/115 mmでは穴ピッチ7 mmと座金外径7 mmが一致し、隙間0となる。0.5 mmの基準を維持して、試験前に下側穴を107 mmへ移し、8 mmピッチとした。左右のYは元台座と同じ32.016/-29.984 mm。旧台座の2穴/側を形状上で埋め、新しい位置で直径3.4 mmを開け直した候補を生成した。実部品を穴埋め改造する指示ではない。

候補後板にも同じ4穴を追加。除去体積を4×π×1.7²×板厚2 mmと照合し、既存穴と重複せず全板厚を貫通したことを検証する。正式後板と正式機構の参照先は変更していない。

## 締結積層

機体X方向の外側から、ねじ頭、座金(-64.7〜-64.2)、後板(-64.2〜-62.2)、印刷台座フランジ(-62.2〜-58.2)、内側座金(-58.2〜-57.7)、ナット(-57.7〜-55.3)の順。ねじ先端は-52.7 mm、ナット端から公称2.6 mm突出。これはねじの有効噛合いや底付きの公差判定ではない。頭部の最外位置はX=-66.7 mm。

ねじの本体は直径3 mmの円柱、ナットは最大公称対辺5.5・高さ2.4 mmの六角柱。座金は輪形状。ねじ軸と通し穴、同一締結組の接触は意図したものとして空間距離基準から除外するが、体積重複0.01 mm³以下は全組に適用する。ねじ山・面取り・頭下丸みは未モデル化。

## 検査範囲と限界

締結16部品と固定機構52点(後板を候補へ交換)、新台座2点、電池・トレイ・Tab5・TTL、左右電源モジュール外包形状の比較、および締結部品相互を検査する。1080組で不合格0。意図しない接触相手との最小隙間0.5 mm、追加穴の除去体積72.6336 mm³。検査結果はreport.json。基板側M2部品の個別比較、工具経路、組立順序、追加穴の応力・後板座面・樹脂クリープ、締付トルク、緩み止め、公差は未確認。

供給面では、ナットの取得ページに複数の相互排他的な在庫状態文言が含まれ、取得テキストだけで在庫/廃番を断定しない。座金カタログの最低注文数は100。発注可能性と少量調達は未確認で購入は行っていない。寸法候補を、そのまま調達・製作可能と判定しない。
