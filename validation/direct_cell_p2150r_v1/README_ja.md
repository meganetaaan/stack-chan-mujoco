# 既製保護付き単セルの比較候補

**単セル案を続ける場合は、P30B裸セル＋自作保護よりも、Keeppower P2150Rを先に適合確認する。まだ最終採用ではない。**

[メーカー製品ページ](https://www.keeppower.com.cn/products_detail.php?id=654)は、保護回路内蔵、連続最大15A、最大Ø21.6×74.5mm、重量70gを記載している。重量は最大値とは明記されていない。4.2V上限、2.5V終止、標準CC-CV充電2.5A。内蔵保護は過充電・過放電・過電流・短絡。詳細値はcell_candidate.jsonに分類して保存した。

既存9.834A比較値は15Aを下回るため、先の8A評価基板のような公称電流だけによる除外理由はない。ただし実際の全軸最大電流の保証、突入・回生、保護閾値/遅延/復帰、端子電圧の保証とは別。P30Bのセル特性をこの製品に流用しない。5000mAhをサーボ最低電圧以上で使える容量とは扱わない。内部セル/保護IC/遮断側は公開ページから確定していない。

## GNDと保護の構成判断

共通GNDがあることだけを理由に高側遮断へ限定する必要はない。一般的な低側保護では、CELL−とPACK−を区別し、Tab5・USB・通信・外部電源の共通GNDを全てPACK−側へ接続すれば、共通GND自体は保護の迂回路にならない。CELL−や内部金属外装への別接続を作ると、この前提を破る。参考：[TI BQ297xxの低側保護回路、図9-1](https://www.ti.com/lit/ds/symlink/bq2970.pdf)。これは回路からの判断であり、P2150R内部回路を推定したものではない。

完成電池は分解/加工せず外部の正負端子のみを使う。着脱充電を候補方針とし、搭載状態での充電経路を追加しない。サーボ停止用スイッチは別途設け、電池保護の自動復帰を再始動許可として使わない。全機器の共通GNDは電池外部負端子側で統一する。

## 製作前に残る条件

- 電池保持・接点部品の寸法、電流容量、抵抗、抜け止め。裸の電池端子へ配線を直接はんだ付けする設計にはしない。
- 適合する外部充電器と逆挿入対策。
- サーボ最低3.7Vを満たす停止電圧と使用可能容量。内蔵2.5V終止とは別。
- 停止/電池遮断時の回生・負荷側過電圧、Tab5別給電、通信経由の回り込み。
