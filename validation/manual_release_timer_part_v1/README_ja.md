# 解除確認タイマーの実部品候補

TPS3808G33DBVRをピン単位の候補へ具体化。CTは100 kΩを介してVDDへ接続する。メーカー指定の40〜200 kΩ内であり、CTの直結や開放に置き換えない。RESETの100 kΩプルアップと負荷50 pFの規定条件では180〜420 ms。既存要求のデバウンス最大80 ms超を100 msの時間余裕で満たす。実配線の出力負荷とクロック入力条件は未確認。

G33の監視しきい値3.07 V、公差±1.5%、最大ヒステリシス2.5%を保守的に積算すると解除電圧上限3.19395125 V。想定電源下限3.207 Vとの差は13.04875 mVのみ。静的な無配線降下条件では成立するが、ノイズ・過渡・実LDO条件を含む保証ではない。この余裕を増やすために電源下限や合格基準を変更しない。

MRへ「健全・生ボタン解除・整形後解除」のANDを入力する。どれかが失われればタイマーをやり直す。MR用実ゲートは未選定。タイマー出力を受付DFFのクロックへ使い、投入DFFの停止優先クリアは別系統で維持する。ボタンを押すたび投入ラッチまで消す配線にはしない。タイマーだけで低電圧時の安全な出力を保証しない。

今回の終了条件は型番・接続・時間範囲・監視電圧の机上照合。追加の仮想回生や機械負荷シミュレーションは不要。次はMRゲートと独立クリアの実装、電源変動予算を確認する。受動部品は値のみで型番未確定。#24は未完了。
