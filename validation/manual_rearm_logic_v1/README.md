# 主遮断器の手動再許可：論理仕様

電源復帰や故障ラッチ解除だけでENを再有効化しないための回路要求。3状態と5入力の全96組合せ、3つの代表時系列を確認した。これはハード回路を設計するための参照論理で、EPIC #7のファームウェアではない。

状態はWAIT_RELEASE（初期/異常後）、READY（健全時のボタン解除確認済み）、ENABLED（投入許可）の3つ。入力は上流電源有効、上流監視有効、確定故障、停止要求、手動ボタン。電源/監視無効または故障/停止は他の入力より優先し、WAIT_RELEASEへ戻る。健全状態でボタンを離してから、新たに押した場合だけ投入許可する。

電源復帰時にボタンが押されたままならWAIT_RELEASEに留まる。故障中の解除操作は再許可に使わない。故障解消時にボタンが離れていればREADYへ進めるが、その後の押下が必要。ENABLEDでボタンを離しても投入を維持するため、停止操作は別入力で扱う。

## 実回路に要求すること

- 電源投入/低下時の初期状態を部品仕様で保証し、データ保持が不定な間はENを物理的にLowへ保持する。
- 上流監視有効にはセンサー電源・整定・判定回路の有効性を含める。負荷側バスの起動完了を投入前の前提にして、起動循環を再導入しない。
- 押下/解除の両方に有効なデバウンスと最小時間を定める。今回のBoolean入力は既に整形済みという仮定であり、接点バウンスの合格ではない。
- 停止優先、非同期入力、電源喪失のアナログ挙動を確認する。単一の理想ラッチの置換で完了扱いにしない。
- この論理の許可とは別に、過電流・過電圧・熱・監視喪失で遮断できる実経路が必要。制御素子短絡やEN固着を今回の論理表は覆わない。
- TPS25982の内蔵ラッチは入力低下/EN操作で解除されるため、この外部再許可要件の代用にしない。
