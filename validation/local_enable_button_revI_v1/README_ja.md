# revIの実接続に結び付けたボタン電流比較

旧比較は組立ファイルを読まない計算だった。今回はSW1/U1/U15/R15の型番・ピン接続と、BUTTON_RAWに接続する全端子を確認してから同じ比較を実行した。接続追加や極性変更があれば評価は失敗する。組立SHA-256も結果へ保存した。

条件付き接点電流は1.089449〜1.249410 mAで、旧比較の値と一致する。1 mAを維持するための追加流出漏れ予算は制限側条件で約89.452 µA。これは基板漏れをその値に設定してよいという指示ではなく、既存の電源・抵抗・接触抵抗仮定から導いた比較値である。汚損・保護素子・実受信入力の漏れを確認する際の制約として使う。

[Nexperiaの仕様](https://assets.nexperia.com/documents/data-sheet/74LVC1G17.pdf)で±1 µAは入力5.5 VまたはGNDでの試験条件。実入力電位とPCB漏れを含む完全な保証とは区別する。またボタン候補の周囲温度範囲−25〜70°Cを記録し、ICの−40〜125°Cをボタンまで含めた回路全体の使用可能範囲としない。ユーザー要求や合格基準は変更していない。

再現：`python3 software/sim/circuits/check_local_enable_button.py --assembly schematics/power/manual_rearm_revI/assembly.json --out /tmp/local-button-revI-check`。追加の動的シミュレーションは行っていない。接触抵抗の経年変化、受信の全電圧条件、配置・入力保護、全停止回路は未確認であり通電保留を維持する。
