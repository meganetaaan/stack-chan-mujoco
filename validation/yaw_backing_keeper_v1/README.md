# ねじ付き背面板の仮保持候補

左右各2本のNBK SLH-M2-10を背面から入れ、ねじ付き金属板へ固定する。軸は支持中心Y、Z=64/76 mm。1本の摩擦だけに回り止めを依存せず、離れた2軸で位置を拘束する構想。支持を胴体へ入れる前に組み、主M3ねじを4本とも掛けてから本締めする工程候補。

支持にφ2.3通し穴とφ4.2の頭逃げ、金属板へ2箇所M2×0.4貫通タップの下穴を追加した。旧中央穴は残した。座面X=−60.9、頭背面−62.2、先端−50.9、金属板入口−53.5なので公称下穴進入2.6 mm、板前面からの先端引込み0.4 mm。先端不完全ねじ・公差を引く前の値。

4ねじとも支持・背面構造板との公称体積交差0。支持/ねじ付き板は有効単一ソリッド。ねじ山の意図した嵌合は実モデル化していない。

**頭背面と構造板前面は公称同面で、公差余裕は0。** 寸法ばらつきで頭が構造板に当たり、支持座面が浮く可能性があるため、この候補を組立承認しない。座面をさらに下げる場合はねじ先端引込みが減るため、ねじ長/頭高さ公差とタップ有効長を一緒に予算化する。公称交差0を製造公差の合格へ転用しない。

仮保持ねじ/金属板ねじ山/支持座面の強度と、主M3締結時の反力は未評価。仮保持を走行荷重の主経路にしない。工具経路も全身未確認。背面板へ組む前のベンチ組立を想定するが、手での位置合わせ・取付・主ボルトの穴合わせは未証明。
