# 足裏固定ナットの候補と組立上の阻害要因

2026-09-21。PTS A56202（M2、ピッチ0.40、A2、DIN 562）を寸法候補として選定。資料の二面幅3.70〜4.00 mm、厚さ0.80〜1.20 mmは既存4×4×1.2 mm包絡内。ただしA2という材質呼称だけで薄ナットの保証荷重やねじ山せん断強度を確定しない。

## 寸法・荷重への影響

既存ナット室は4.4×4.4×1.8 mm。呼び室に最大ナットを入れると幅方向総隙間0.4 mm、高さ余裕0.6 mm。最薄ナットでは高さ余裕1.0 mmとなる。締付け前の傾き・位置ずれを考慮する。

前の仮定公差を各内壁位置±0.20 mmとして適用すると最小室幅は4.0 mmで、最大ナットとの差はゼロ。これは干渉なしを保証する組立隙間ではない。公差を径/幅で指示するのか面位置で指示するのかを製作図で固定する必要がある。

最大厚さ1.2 mm/ピッチ0.4 mmの3ピッチ分という公称包絡に対し、最小厚さ0.8 mmでは2ピッチ分しかない。面取りや不完全ねじを引く前の値であり、有効ねじ山数や許容予圧の保証ではない。20 Nの仮定解析やねじメーカー最大トルクをナット強度の証拠に使わない。

## 新たに明確になった組立条件

`validation/sole_wide_seat_v1/build_sole_slide_lock.py` は8×8 mmボス内部に4.4 mm角の室を作り、室上に0.8 mmの屋根を残す。ねじ穴は直径2.3 mmであり、幅3.7 mm以上のナットは完成状態の穴を通して挿入できない。室側面の最小呼び壁厚も1.8 mmあり、横からの開口は生成されていない。

したがって現CADは、**造形途中のナット封入工程が成立する場合の候補**である。完成後にナットを入れる組立順としては不成立。部品重複検査が通っても組立可能の証明にならない。

製作判断は、封入工程の実証を行うか、後挿入・交換可能な開口/蓋構造へ変更するか。封入なら積層高さ、ナット浮き、ノズルとの隙間、停止再開時の層接合を手順化する必要がある。完成後交換できないことも明示する。隙間を広げるだけでは組立経路は解決しない。

## 現時点の結論

ねじ/ナットの呼び寸法候補は揃ったが、全固定部の製造リリースは保留。ナット室公差と封入/後挿入工程を設計判断の優先事項とする。#48の局所嵌合試験片にはナット室がなく、この問題を評価できない。別のナット室試験または交換可能構造のCADが必要。追加の接触FEは不要。
