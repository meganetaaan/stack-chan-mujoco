# 外装前端を分離したTab5取付枠候補

固定側をX<=46mm、着脱枠をX>=46.3mmとして元の外装から分離。
Tab5背面4軸Y±60/Z52,124mmに半径3.5mm、X48..52mmの座を加え、半径1.65mmの通し穴を設けた。
分割位置・0.3mm隙間・座厚・穴径は設計仮置き。造形公差やねじ長さの合格値ではない。

## 結果

固定側と枠は各1個の有効ソリッド。相互の体積干渉0、隙間0.3mm。
LB-020電池・ベルトを含む周辺部品への体積干渉なし。胴体の外接範囲は不変。
fixed_shell.stepとcarrier.stepを出力。正式外装は置換しない。

枠とTab5を一緒に22.7mm前方へ移動する連続外接包絡は、2本のベルトだけを衝突候補として検出。
枠の開口を外接箱が埋めるための過大評価かを解消する目的で、追加の分離検査を実施した。
終了条件は、各ベルトのYZ外接範囲を全X方向に延長した柱と枠が交差せず、Tab5がベルトより前にあること。
両ベルトとも柱と枠の交差体積0、Tab5はベルトの前側に位置するため、+X移動中も両者の分離が保たれる。
従って公称形状では枠とTab5を一緒に引き出せる。他部品は最初の包絡検査で除外済み。
追加検査は公差・変形・配線を保証しない。

## 固定設計の残件

現時点では枠を胴体へ留めるねじ・受け・位置決めを設けていない。0.3mmの隙間があり荷重経路は未完成。
Tab5を枠へ先にねじ止めし、その後枠を外から解除できる締結で胴体へ固定する構成を次に具体化する。
枠の主要機能はTab5保持で、電池交換時にヨー支持や後部板を外さないことを目指す。
Tab5ねじの掛かり深さとトルク、枠の対胴体締結、位置決め、ねじ脱落防止、工具・手の空間、
配線切離しを確定してから強度・変形を評価する。単一ソリッドを強度の証拠にしない。
製作HOLD。部品質量、MuJoCo、正式候補ポインターへは未反映。
