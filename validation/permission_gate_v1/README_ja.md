# EN指令取消の実ゲート接続

## 結果

revFの接続表からU3第2ANDゲートとU8入力を照合した。8通りの論理入力、および起動監視要求がHighに残る状態での停止→復帰→新操作を確認。許可取消・RESET_N LowのどちらでもPOWER_ENABLE_COMMANDはLow、復帰だけではHighに戻らない。

これは前回まで未実装だった「指令回路が許可取消を反映する」という条件を、実部品のピン接続へ具体化したもの。IC故障・伝搬遅延・電源遷移まで保証する検証ではない。前回revDの失敗記録はそのまま保持する。

## 負荷と未確認条件

U8入力の220 kΩプルダウンと入力漏れを含む出力負荷比較は16.58 µAで、HCSの20 µA規定点以下。RESET_N入力はU3.1、U3.5、U6.1、U6.13の4個になった。既存100 kΩ±1%比較ではHigh下限2.7727 V、Low吸込上限38.27 µA。旧3入力の2.8737 Vから101 mV低下する。抵抗値を変更して基準を通してはいない。

HCS入力漏れは6 V端点の規定を用いた比較で、無給電時の保証ではない。全電圧域の受信しきい値と外部故障出力の負荷を照合するまで、RESET_Nの電気適合は未確認。先の静的結果をそのまま全回路合格に流用しない。

## 終了条件と残件

今回は実ピンへの接続、要求固着High時の取消論理、新たな負荷の評価までで終了。次に必要なのは実PG受信・起動期限・故障保持の回路、短い停止パルス捕捉、両電源喪失時の挙動。#24は未完了、通電保留。
