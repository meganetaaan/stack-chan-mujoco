# LOGIC保護枝のバイパス候補

保護IC入力と保護出力/LDO入力に、各2個のGRM31C5C1H104JA01Lを並列配置する。100nF単独は±5%の初期公差で0.1µFを下回るため採用しない。候補の全4個を接続表とcapacitor_bom.csvに追加した。STOP枝のコンデンサは変更しない。

判定条件は各位置0.1µF以上。初期公差と資料に明記された25〜125℃の温度係数を含めた範囲は189.43〜210.63nFで、この範囲だけは条件を満たす。低温側まで同じ温度係数と仮定しない。DCバイアス・工程・経年・実装寄生・起動/短絡時の過渡電圧は未検証で、完成回路の合格ではない。

一次資料:
- Murata型番別資料（2025-01-10）: https://search.murata.co.jp/Ceramy/image/img/A01X/G101/ENG/GRM31C5C1H104JA01-01A.pdf 。100nF±5%、50V、C0G、温度係数±30ppm/℃の表記範囲は25〜125℃。無極性のセラミック候補であり、電解コンデンサの逆電圧条件を持ち込まない。50V定格をサージ抑制機能とは扱わない。
- TPS709 section8.1.1: https://www.ti.com/lit/gpn/tps709 。入力コンデンサは安定性には必須でなく、0.1〜2.2µFを推奨。出力側の安定性容量要件とは別。
- TPS2660 section7.3: https://www.ti.com/lit/gpn/tps2660 。IN/OUT外付け容量0.1µF以上。

フィルム2.2µF案も確認したが、入力に必須ではなく高さ13mmとなるため今回は追加しない。過渡応答で不足が判明した場合だけ容量を増やす。判断基準を下げたのではなく、入力と出力の容量要件を区別した。

配置は保護ICとLDOを近接させ、各GND帰路を短くする。共用した出力側ペアが両ICに近接できない場合は、LDO直近に追加する。PCBは未作成なので現時点で配置適合を主張しない。

12.6Vで各ペアの初期充電は最大約2.654µC（上記条件のみ）。入力側ペアはeFuseの突入制限より手前にあり、充電をeFuseが制御すると仮定してはいけない。出力側ペアの電荷は後段3.3V出力容量の充電に追加される。

再現:
```sh
.venv-engineering/bin/python software/sim/circuits/check_logic_branch_bypass.py --out validation/logic_branch_bypass_v1
```
終了条件は一候補の容量範囲と接続記録。次は放電経路と起動/短絡の統合評価であり、容量だけの反復探索は行わない。
