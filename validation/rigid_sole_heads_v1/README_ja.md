# 保持頭の軸方向位置変更候補

頭の厚さ1.5mm・半径4mmを保ち、底面を−15.8→−15.4mmへ上げた。
接地高さと足の外周は変えず、軸部を0.4mm延長。左右とも有効単一ソリッド、
位置合わせ後のブーツおよび拡大キー穴ヨークとの交差0。各側体積は39.408mm³増える。
材料を割り当てる前なので、この体積を実測質量とは扱わない。

軸方向の公称隙間0.6mmに対し、旧境界誤差各±0.2mmを維持すると残り0.2mm。
半径方向の候補はrigid_sole_keyhole_v1と組み合わせる。
誤差は仮置きのままであり、造形工程の実測能力を示さない。

隙間拡大は保持かかり代や軸の曲げ、足裏の上下遊びに影響する。
挿入に必要な隙間を確保できても、固定後のガタ・接地安定性・引抜き強度は未確認。
既存ねじによる滑り止めだけを上下の締付け保持とみなさない。
次は荷重経路と拘束方向を明示し、浮き・脱落・変形を判定する。

再現：`software/sim/structural/raise_rigid_sole_heads.py --out <新規出力先>`。
