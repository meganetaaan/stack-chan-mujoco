# 締結部品の質量枠スクリーニング

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" \
  .venv-engineering/bin/python software/sim/mujoco/audit_fastener_allowance.py \
  --out validation/fastener_allowance_development_v1/report.json
```

背面4組とヨー支持8組について、各組のボルト・ナット・内外ワッシャー、合計48個の既存CAD包絡体を集計。密度8000 kg/m³を明示的な仮定とし、既存25 g枠以内を判定基準とした。

結果26.1058 g、枠との差は−1.1058 g。これは包絡体と仮定密度によるスクリーニング不成立であり、購入部品の実質量が25 gを超えると証明したものではない。ねじ溝や六角穴等の省略があり、ヨーナットは外接円筒である。最新背面板との取り付け位置整合も本計算では検証していない。

元BOMは25 g枠を「配線およびその他締結部品」と定義し、電池トレーねじ2本を別計上している。本計算もその2本を除外する。配線・コネクタ・モータ固定・Tab5固定等はまだ未集計。従って25 g枠を維持した候補質量だけを最終負荷解析へ渡すことはできない。

次の質量台帳では既存25 g一括枠を外し、明示的な締結部品群と、別途根拠を持つ配線・残部品枠へ置換する。現時点ではMuJoCoモデル、旧BOM、元負荷記録を変更していない。新規部品を25 g枠に単純加算すると重複を生むため、それも最終設計として採用しない。
