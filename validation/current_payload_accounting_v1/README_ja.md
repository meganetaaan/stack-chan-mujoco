# 現行電装・配線の計上区分

旧電池・単一変換器・トレイは置換済み。残る旧割当て7項目は現在の部分小計に含まれる。特にTTLインターフェース12gと電池ストラップ1.2gは「未計上」ではなく「仮割当ての置換が必要」。実部品を選んだ際は旧質量・一次モーメント・原点慣性を除いてから追加する。

左右12軸の配線表には36個の端子接続があり、重複がないことを確認した。ただし線種、実経路長、質量、可動リンクへの配分は未確定。固定治具用の片道0.25mをロボット配線長へ流用しない。コネクタ・圧着端子・引張り止め、電池／配電／Tab5／USB配線、UBEC本体に含まれない保護基板と部品も別項目とする。

この区分で重複加算を防止する。質量の追加やMuJoCo変更は行っていない。次の配線設計は全可動域の経路・余長・固定点を決める単位で行い、それから電圧降下と質量を同じ長さから計算する。

再現：
```sh
.venv-engineering/bin/python software/sim/structural/audit_current_payload_accounting.py --out /tmp/payload-accounting-review
```
