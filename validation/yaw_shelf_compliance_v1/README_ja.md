# 配線開口前後の樹脂支持棚比較

現行候補と外側ポート開口候補に同じ保存荷重を与え、変形増加を比較する。解析前に plan.json に荷重・比較条件・終了条件を保存した。新旧各2メッシュの計4解析に限定し、局所応力の収束を目的とした追加細分化はしない。

EPIC #4の保存済み左脚荷重（時刻2.661秒、7000サンプル中の既存選択ケース）を使用。最新の全身質量を反映した最大荷重ではない。原点は[-5,26,62] mm。金属板接触面Z89を荷重面とし、後部取付座X=-62.2を理想固定する。旧解析のZ88面は板を埋め込む前の条件のため流用しない。

樹脂E=1120 MPa、ν=0.35は比較用仮定で、使用するABS/PETGの保証物性ではない。全面に力・モーメントを保存する分布荷重を与えるが、面の離間・摩擦・ねじの予圧を解かない。実際の荷重伝達や支持剛性の上下限保証ではない。クリープ、積層方向の破壊、ねじ抜け、背面構造の柔軟性は未評価。

評価量は最大変位と外力仕事。最大応力は補助出力として残すが合格判定には用いない。細粗メッシュの最大変位差10%以内は今回の比較採用条件で、実機許容変位ではない。以前の0.2 mm配分を緩和・置換するものではなく、その達成証明もこの比較では行わない。

再現（リポジトリルート、未使用出力先）:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/compare_yaw_shelf_relief.py --out validation/yaw_shelf_compliance_reproduce
```

メッシュは再生成する。元形状・荷重のハッシュ、各計算の釣合い結果をJSONに保存。製作承認、強度保証、Issue完了には別途全体の証跡が必要。

## 結果

| 形状 | メッシュ mm | 最大変位 mm | 外力仕事 N mm |
|---|---:|---:|---:|
| 開口前 | 3 | 0.28056 | 2.88501 |
| 開口前 | 2 | 0.28579 | 2.92650 |
| 外側ポート開口後 | 3 | 0.27966 | 2.92108 |
| 外側ポート開口後 | 2 | 0.28460 | 2.95911 |

全4条件で荷重保存・数値釣合い・エネルギー整合を確認。細粗の最大変位差は開口前1.86%、開口後1.77%。細メッシュで開口後の最大変位は0.42%減、外力仕事は1.11%増。いずれもメッシュ変更による差と同程度以下であり、「開口で変形が改善した」等とは結論しない。開口で荷重面の形状・分布も変わるため、純粋な材料除去のみの効果ではない。

開口の有無によらず最大変位は従来の0.2 mm配分を超える。このモデルから配分の成立を主張できず、配分は変更しない。一方、全体最大変位は対向部との相対変位そのものではなく、この値だけで接触が起こるとも断定しない。開口の取り消しだけでは今回の変形を解消しない。

**判断：開口案の製造リリースは保留。** 次の設計判断では、対向面と固定部の相対変位を特定し、棚から背面構造への荷重経路・締結モデルを合わせて見直す。旧応力ピークを狙ったメッシュ細分化は終了する。実材料の許容値と最新荷重が未確定なまま、応力値を合格根拠にはしない。
