# 電源制御出力のレジスタ反映

Cコアの要求をPA8（給電許可）、PA11（クリア）、PA12（保持資格）へ変換する処理を追加。
3端子のセット・リセットを1回のBSRR書込みで行う。
他の端子を変更せず、タイマー実行フラグはGPIOへ出力しない。

全256要求符号×8初期出力値、計2048組合せを模擬レジスタで検査した。
未定義ビット、許可とクリアの同時要求、クリアなしの保持資格要求は、
給電禁止・クリア要求に置き換えて失敗を返す。
書込みが反映されない場合は失敗を返し、クリアへの書込みを試みる。
再度の書込みも失敗する故障には独立した遮断回路が必要。

ODR読み戻しはラッチの確認であり、実CLR端子の観測には使用しない。
単一レジスタ書込みでも、実端子の遅延差がゼロとは保証しない。
呼出し側は失敗を記憶し、自動的に許可を再試行してはならない。
初期化成功・端子所有・実MMIO接続・タイマー実装は別の前提である。

再現：

```sh
python3 software/sim/circuits/check_g030_gpio_outputs.py --out /tmp/g030-output-check
```

ホストとCortex-M0+向けコンパイルを確認。実機・回路の過渡検証ではない。
