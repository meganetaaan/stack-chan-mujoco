# 裏板の素材厚さとねじ長さの軸方向確認

## 判定

主M3×8本の板からの突出は1.32〜2.28 mm、保持M2×4本は0.47〜0.73 mm。対象の公差範囲で先端は板を貫通する。しかし**ねじ保持力、完全山長さ、全公差での周辺干渉は未合格**。板厚候補を変える必要があるかは、この確認だけでは決まらない。

3 mm裏板の素材厚さ2.87〜3.13 mmと、SNS-M3-16の長さ15.65〜16.35 mmを組み合わせた。保持ねじの長さとその他の部品は公称値。座面接触・支持体の加工公差は未確定で、この数値を最悪実機範囲としない。

裏板の支持体側接触面X=-53.5 mmを固定する。厚さ公差は反対面だけを変え、ねじ頭座面は変えない。この条件では、薄板化で突出量が増えてもねじ先端の絶対位置は変わらない。したがって板厚公差0.13 mmを、そのまま既存の先端対隣接部品の隙間から引かない。ねじ長さ公差・座面位置変動は先端位置を変えるため、別に扱う。

素材の最小厚さ2.87 mmは完全山長さではない。入口／出口の面取り、不完全山、ねじ先端形状を含めた加工図と保持計算が必要。これらがない状態で雌ねじ抜けの合格や試験締付けトルクを決めない。#17/#18の机上残件として残す。

