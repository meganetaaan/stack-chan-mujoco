# 直列MOSFET候補の選定条件

PSMN1R0-30YLEとPSMNR67-30YLEを比較候補として記録した。両者とも線形用途向けで、取り付けベース125℃のSOA図がある。評価点は既存クランプ設定からVDS=7.315V、ID=6.775A、49.56W。故障の継続時間は未決定。

ベースを125℃に固定できると仮定し、最大接合部―ベース熱抵抗だけで計算すると接合温度はそれぞれ158.2℃、147.3℃。これは基板の放熱性能でもSOA合格でもない。一定ベース温度を維持できる保証や、線形動作の局所発熱を代替しない。175℃未満という理由だけで選定しない。

両候補のオン抵抗最大値は最低でもVGS=7Vで規定される。一方LT4363の低入力時のゲート駆動は4V条件で4.5Vの最小値しか示されていない。実際の4.75～5.25Vで7V以上を保証できる根拠は未確認。ゲート電荷の4.5V試験やゲートしきい値からオン抵抗を保証しない。通常損失・電圧降下を確定する前にゲート駆動の適合を解消する必要がある。

SOAの図は本文から存在・温度・単発条件を確認できたが、この実行環境で図の視覚確認ができず、評価点の合否を読んだとはしない。メーカーPDFの直接保存はHTTP403、配布サイトの保存は応答が完了しなかったため約68秒で終了した。数値の読み取りや外挿は行っていない。SOA判定はnullのまま保存した。

次は適用できるゲート駆動条件と高温SOAを確認し、その後にタイマーを設定する。今回の比較候補は未採用で、既存MOSFETへの置換やPCB変更は行わない。単発アバランシェエネルギーを直列クランプの許容エネルギーとして使わない。

メーカー資料は `schematics/power/series_mosfet_candidates.json` 参照。熱抵抗比較は `125 + 49.55993372507982 * Rth(j-mb,max)` で再現可能。部品表の採用版ではない。
