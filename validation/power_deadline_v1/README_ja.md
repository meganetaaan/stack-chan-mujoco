# 起動期限カウンターと実行処理の接続

起動を実際に要求する最初のSTART処理で時刻を記録し、期限到達を記憶するCコードを追加。
期限0や2^31以上は不正として起動を拒否する。任意の既定待ち時間は設けない。
状態制御へ渡すSTARTUP_EXPIREDはこの処理が生成し、外から渡された同ビットは使用しない。

32 bitカウンターの桁あふれ、時刻の後退、期限到達後の保持、再開始、
期限と両PG成功の同時発生を検査した。同時なら期限を優先してCLEARへ進む。
10 tick等の値はコード境界検査の入力であり、実際の起動期限や時間単位ではない。

前提は更新間隔が2^31 tick未満であること。同じ時計が停止したことは検出できず、
独立した監視が必要。実時刻源・周波数誤差・原子的な時刻読出し・起動期限は未確定。
電源投入からの全停止遅延を保証するものではない。

再現：

```sh
python3 software/sim/circuits/check_power_deadline.py --out /tmp/power-deadline-check
```

Cortex-M0+向けコンパイルも確認。ボード起動・実時間動作は未検証。
