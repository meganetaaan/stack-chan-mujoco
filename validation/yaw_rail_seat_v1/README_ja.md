# 外装横桟を残す支持底面の接触座候補

外装横桟上面Z52.2 mmに支持棚の底面を合わせた。支持棚のZ52.2未満を除去し、外装・横桟・レールは変更しない。前回の外装切欠き案とは異なり、支持経路を意図した部材を切り離さない。

左右とも単一有効ソリッド、外形拡大なし。外装との重なりは各370.875 mm³から0、公称接触面積は各165.354 mm²。各支持で662.975 mm³を除去した。4本の後部ねじ軸は従来位置を維持し、軸周囲半径3.5 mm、X-62.2..-53.5の保護領域の除去量は0。半径3.5 mmは幾何確認範囲で、ねじ座面の許容値や必要強度を証明する数値ではない。

接触面積は上下0.01 mmのスライスの共通投影から求めた公称値。後部ランド外縁の一部は切り落とされるため、旧支持形状の強度値をそのまま流用しない。

## 接合として残る条件

この界面は圧縮のみを受ける接触座であり、正の隙間を必要とする非接触部ではない。引張りや摩擦保持を保証せず、離間を許すモデルが必要。製造誤差で面が浮いたり、接触面と後部ねじ穴が同時に合わなかったりする可能性を残す。座面の仕上げ・高さ基準・必要な調整方法と、穴の位置／隙間を同時に定義するまで組立承認しない。

後部ねじと横桟の荷重分担、外装全体の剛性、接触圧、クリープ、予圧、組立挿入順序は未評価。棚単体の旧0.237657 mmという値にも横桟の支持効果は含まれず、今回の切削形状と一致しない。改善したと推定して合格にはしない。
