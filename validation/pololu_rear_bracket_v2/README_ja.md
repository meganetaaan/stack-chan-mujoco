# 電源台座 — ヨー固定ねじの局所逃げ

## 結果

v1で特定した既存ねじとの干渉を、台座下面の局所切欠きで解消した。基板位置・取付穴・後板固定穴・外形は変更せず、基準も体積重複0.01 mm³以下、意図しない部品との公称隙間0.5 mm以上のまま。113組を検査し不合格0、最小隙間1.0 mm。後板との距離0は意図した接触位置であり、保持力や接触面積の証明ではない。

左右4本ずつの既存plate screwの軸周囲に半径4 mm、Z94〜99 mmの逃げを設定した。実際に材料が除去されるのは左plate_0と右plate_1のみ。左73.9894 mm³、右143.0377 mm³を除去し、台座体積はそれぞれ6885.9023/6816.8540 mm³。

切欠き上面Z99からレール上面Z102.065まで3.065 mmを残した。v1のZ99以上の材料が全て残ることを形状差で確認し、各台座は有効な1ソリッドである。基板固定穴と後板までの幾何学的な連続性を保持するが、これだけでは荷重下の剛性・強度を保証しない。

## 基準と限界

半径4 mmと残厚3 mm以上はCodexの設計仮定。穴周辺の工具アクセスの証明でもABS/PETG造形品の許容断面でもない。逃げを作る前にplan.jsonへ設定した。公称0.5 mmの干渉基準は緩めていない。最小1 mmの隙間には印刷・取付公差と変形の追加評価が必要。

ねじ軸・ナット・ワッシャー、ねじの噛合い、締付荷重、基板銅箔との絶縁、台座の造形方向、切欠きと後板固定部の応力、配線と冷却は未確認。後板への穴加工も未適用。FEへ進む前に実際の締結構成と荷重を決める必要がある。製作リリース=false、Issueの完了条件は未充足。
