# 足部慣性更新による同一軌道上の荷重差

旧モデルとfoot_inertia_model_v2に同じEPIC4記録のqpos/qvel/qaccを与え、MuJoCoの逆動力学（mj_rne）で一般化力の差を求めた。慣性更新だけの影響を取り出す比較であり、歩行制御は調整していない。

左右旋回各7000区間で、関節トルク差の最大絶対値は左旋回0.002070N·m、右旋回0.002064N·m。全関節の最大値・符号・時刻はreport.json、全時系列はleft.npz/right.npzに保存。全身並進重力差が質量差×重力と一致する独立確認も通過した。

計算の範囲:

- 密度と金属包絡の仮定はfoot_inertia_model_v2から継承する。
- qaccは保存qvelの差分。最大値抽出では片側差分となる両端を除外したが、接触による速度変化や標本化誤差は残る。
- 出力は慣性・コリオリ・重力に由来する一般化力の差。接地反力、外力、受動力を新モデルで再計算した支持荷重ではない。
- 新しい慣性による歩行軌道の変化、最新衝突形状、電装搭載質量は本比較に含まれない。

したがって差が小さいという理由で旧強度解析をそのまま承認しない。完全な搭載質量・形状を反映した動作と関節界面荷重を、最終強度評価へ入力する必要がある。

再現: `.venv-engineering/bin/python software/sim/structural/compare_foot_inertial_loads.py --out /tmp/foot-load-delta-new`
