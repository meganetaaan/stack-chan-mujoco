## CADと寸法の結果

半径3.5mmの環状接触座を|Y|61..62.2mmに追加。4点とも固定側との公称隙間0、体積干渉0。
枠は有効な単一ソリッド。ねじ・ナットと印刷2部品の16組の体積干渉0。
ねじ先端|Y|54mm、最大厚ナット内面55.4mmなので公称突き出し1.4mm。
面取り・不完全ねじ部・長さ公差を含む有効掛かりの保証ではない。
金属8部品の公称質量合計4.32g。正式質量台帳へ未反映。

頭部を外へ置くため全幅は128→132mm（片側2mm、全体3.125%増）。胴体・脚長は変えない。
ユーザー要求は大幅な外形変更の回避であり、これまでの外接範囲厳密不変は設計側の制約だった。
今回は薄い外装へ2mmの座ぐりを掘る代わりに小さな頭部突出を明示した候補とする。
機能・強度の合格基準は変更していない。頭部を含む全身干渉・動作・工具の評価は未実施。

## 残件

公称接触は造形ばらつきを吸収しない。実寸調整方法、面圧、締付け量とクリープ、緩み止め、
ナット挿入・脱落防止、側方工具進入、ねじ解除後の枠引出しを確認する。
ナット包絡は最大寸法の単純六角形で、面取り・ねじ山は省略。ねじ頭にも六角穴形状は未反映。
板厚・座面の圧縮を含む荷重経路評価前に製作可とはしない。製作HOLD。
