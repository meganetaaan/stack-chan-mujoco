# 金属板支持用締結の配置比較

既に部品カードで確認したNBK SLH-M2-10、PTS A56202、特注SCW-SOLE-SPACER-01（φ6、厚0.9 mm公称）を各8個使う比較。スペーサーは新用途の剛体座金候補であり、市販座金や締結承認品とみなさない。調達数量は今回BOMへまだ加算しない。

ねじは下面から、頭Z=86.7..88、板/支持Z=88..91、座金91..91.9、最大厚ナット91.9..93.1。ねじ先端98、突出4.9 mm。四隅8組の頭/軸/座金/ナット包絡とメーカーサーボの32比較は公称0.9 mm隙間基準を満たす。ナット包絡は最大対角を覆う円筒で、実ねじ山は未モデル。

取付板縁から座金外周までの公称0.5 mmは、支持棚の形状・実座面接触まで含む判定ではない。次は実ナット工具、長いねじ先端、ケース用TAPねじ頭、支持/胴体との相互干渉と組立順序を照合する。短いねじへの変更は実品仕様を確認してから決める。締付けトルク・プリロード・板曲げ・樹脂の面圧/抜け/クリープは未検証。

再現：`check_yaw_plate_fasteners.py --out <新規出力先>`。実行環境は他CADスクリプトと同じ。配置確認のみで製造リリースしない。
