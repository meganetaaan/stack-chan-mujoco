# v7形状へ揃えたヨー質量台帳

旧yaw_inertial_ledger_v2の24形状項をv7の幾何モーメントへ置換した。
金属5部品は以前の候補密度（アルミ2680、SUS304 7930 kg/m³）を維持し、
取付座金8個も同じSUS304比較密度、残り11個は密度係数として残した。
補強の増分だけを旧台帳へ足す方法は使わず、旧各項を置き換える。

従来の機器予約を含む密度割当て済み小計は0.419354 kg。
旧小計0.420337 kgとの差には取付板等の形状変更が含まれ、
密度未割当ての支持部の重量増はこの小計に含まれない。
この値を全身重量・確定重量と解釈しない。

ねじ20本の旧カタログ質量合計は照合未完の参考欄へ分離し、新小計へ加算しない。
ナット8個は質量未確定で、回転包絡を密度換算しない。
電池・変換器・トレイの旧予約は名称付きで保持し、次の置換対象とする。
配線と保護回路も未割当て。旧25 g一括枠を戻して不足を隠さない。

原点モーメントを同一座標で合算し、完全な台帳になってから重心慣性と
MuJoCo body座標へ変換する。モデルXML・荷重履歴は未変更。
材料の実密度・造形内部分布・実測重量を仮定で確定しない。

再現：
```sh
.venv-engineering/bin/python software/sim/structural/update_yaw_v7_inertial_ledger.py --out /tmp/yaw-v7-ledger
```
