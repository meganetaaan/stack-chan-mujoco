# 外付けナット・ねじの連続ロール隙間下限

既存中立CAD距離から、ロール±0.34 radの全角度を覆う保守的下限を評価した。新たな細分姿勢サンプルは不要。ナット・ねじの全点の回転移動量は `2*rmax*sin(0.34/2)` 以下であり、固定相手との距離は中立距離からこの値を引いた値以上となる。rmaxにはCAD外接箱のYZ端点から得る上限を使用する。

既存メーカー部品割当で足部と共回りすると仮定した部品3/9/10/11/12は相対姿勢が変わらないため中立距離を保持。他のサーボ構成部品とジンバルは固定相手として計算。

左右のナット・10 mmねじとも、公称隙間下限は全対象で1.1 mm以上。最小下限7.670 mm。中立検査だけだった新固定品について、仮定した足首ロール範囲の連続幾何確認へ進んだ。

これは部品運動割当の仮定に依存する。メーカーCADの公差、たわみ、ケーブル、他関節/全身姿勢を確認したものではない。工具は動作時に外すため対象から除外。ヨーク/足裏全体の干渉合格ではない。数値が十分離れているため、この対象に追加サンプルや角度細分化は行わない。

再現：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/bound_external_nut_roll_clearance.py --out outputs/external_nut_roll_bound_new
```

判定条件をplan.jsonへ先に保存。元距離・CADのハッシュはreport.jsonに記録。#19全体の完了や実機安全の保証ではない。
