# ヨーク全体の静的スクリーニング（変位不合格）

EPIC4左足系列の取付面中心モーメントノルム最大サンプルを使用。力とモーメントは同時刻の値を保持し、反対符号の等価荷重をz=-19 mmへ移して底面へ分布。ホーン面付近を剛体固定した二次四面体モデル、E=1120 MPa、ν=0.35、名目メッシュ3 mm。

最大変位0.762626 mmは事前基準0.2 mmを超える。最大絶対主応力4.47947 MPaは仮の許容値5.6 MPa以内。メッシュ収束未確認であり強度合格ではない。

境界条件の限界：ホーン環状領域は座標条件で近似し実接触・ねじ剛性を省略。底面の荷重は合力を保つアフィン分布で、足裏ポケットの非接触部を除外していない。引張方向の局所トラクションが生じ得るため、非接着足裏の接触圧とは異なる。ヨーク慣性、ブーツによる剛性寄与、実床反力分布も省略。この結果だけで実機の変位や破損を断定しない。

次は変形位置と接触境界を確認し、補強候補を評価する。現在の剛体固定モデルでも大きく変形することは、全体剛性を優先して確認する根拠となる。

```sh
export LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu"
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/screen_full_yoke.py --out outputs/full_yoke_repro
```

plan.jsonに入力ハッシュ・時刻・荷重・事前基準、fields.npzに変位・応力・反力を保存。
