# 起動入力・停止電源の抵抗候補

Vishay TNPW e3の発注表から、78.7 kΩをTNPW060378K7BYEA（左右各1個）、30.1 kΩをTNPW060330K1BYEA（1個）とした。0603、初期±0.1%、TCR±10 ppm/K。発注記号EAはメーカー5000個リールであり、試作向け切り売り調達は別途必要。

一次資料: https://www.vishay.com/docs/28758/tnpw_e3.pdf （2026-04-10、1〜4頁）

25°C基準、膜温度-40〜125°Cの比較では、初期誤差＋TCRは0.1%＋10 ppm/K×100 K＝0.2%。既存の総合±1%予算を緩めず維持し、はんだ付け・経時・環境への残り0.8%を確定前の予算として残す。膜温度を実測した結果でも総合公差の合格でもない。

3.393 Vを抵抗に直接印加する保守的な計算P=V²/(R×0.99)で、78.7 kΩは各0.1478 mW、30.1 kΩは0.3864 mW。GeneralモードのP70=0.110 Wとの比較は小さいが、実基板温度でのディレーティング確認は必要。0.210 WのAdvanced値を無条件で採用しない。

型番を電源統合revEへ適用し、16コーナーの信号負荷計算を再実行した。抵抗値と総合公差仮定を変更していないため、High下限2.767407 V、出力負荷上限75.958 µA、断線後定常入力7.9487 mVは維持される。

構成再現は `software/sim/circuits/localize_servo_enable_pulldowns.py`。型番は `schematics/power/stop_enable_resistors.json` を読み込み、値と参照名の一致を確認して適用する。
