# 直列クランプのタイマー選定条件

[LT4363 Rev.C](https://www.analog.com/media/en/technical-documentation/data-sheets/4363fb.pdf)の典型式で、既存の12.6V故障・クランプ最低5.285Vの比較点を評価した。TMRは通常0.5Vから警告1.275V、遮断1.375Vへ進む。過電圧では警告後に電流が変わるため、全区間を単一電流で計算しない。

容量10nFで典型約1.111ms・一定故障電力比較55.1mJ。12nFでは約1.333ms・66.1mJ。保証最悪時間・実故障エネルギーの上限ではない。最低容量10nFを下回ってSOA判定を通すことはしない。12nF・総合±5%なら最低11.4nFとなるが、これは容量設計候補で部品未選定。

電気特性表の警告電流は3/5/7µA、説明式は6µAで一致しない。実電圧差での保証電流、警告区間、容量公差、ゲート放電を含む最大時間が未確定なので、典型式だけでMOSFETを認定しない。次のSOA判断はミリ秒領域で行う。

LT4363-1のラッチ解除では通常のクールダウン完了後のリセットと、途中でSHDNを操作する場合を区別する。12nFの説明式では途中解除のLOW保持は12msとなり、100µsパルスだけを無条件に再起動仕様へ転用しない。

再現：`.venv-engineering/bin/python software/sim/circuits/size_series_clamp_timer.py --out /tmp/series-timer-review`（未存在の出力先）。
