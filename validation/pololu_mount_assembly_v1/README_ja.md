# 電源取付機構の統合候補

## 成果物

- `mount_assembly.step`: 後板1、左右台座2、基板側M2ねじ/ナット16、POMスペーサ8、後板側M3ねじ/ナット/座金16の計43部品。
- `inventory.json`: 各部品の名称、品番対応、体積、位置、入力SHA256。
- `bom.csv`: 上記取付機構だけの数量表。ロボット全体や電源回路のBOMではない。電子基板、配線、保護回路は含まない。
- `report.json`: 既存検査で別々だった部品間の統合検査。

後板と台座は最新のM3締結案(穴高さ107/115 mm)、基板側M2締結は既存のナットスロット案を取り込む。POMスペーサは選定候補の外径4・内径2.1・長さ3 mmで新しくモデル化した。STEPの並び順だけで品名を割り当てず、体積区分・外形座標・取付軸との対応を確認して識別する。

## 判定

基板側M2と後板側M3の相互、M2と変更された後板/台座、スペーサと締結部/後板/台座の584組で重複なし。意図しない相手との最小隙間5.165 mm。0.5 mmの公称基準を通過した。

この5.165 mmは追加の統合検査範囲だけの値。機体全体の最小隙間ではなく、既存の台座と機構の1 mm、後板締結の0.5 mm等を置き換えない。ねじとナットの接触・通し穴、スペーサの座面は意図したものとして距離基準から除外したが、体積重複判定は除外していない。内径2.1とねじ径2の公称半径差0.05 mmは部品公差込みの組立可能性を保証しない。

## 残る事項

メーカー共通基板モデルと5V実部品の差、基板銅箔・絶縁、全固定部品の公差、工具と組立経路、座面・ねじ山の保持、樹脂クリープ、締付トルク、緩み止め、追加穴と台座の強度、配線・冷却、質量/重心への反映は未完了。既存の固定機構検査は形状が変わらない範囲の証拠であり、本統合検査だけで機体全体の再検証済みとは扱わない。

3Dプリントするのは左右台座。後板は既存の金属板候補の追加穴案であり、TPU化しない。形状の適合を確認した比較候補で、製造図面の公差指定や工程確定を伴うリリースではない。正式機構の参照先とIssue状態は変更しない。
