# LB-020の2本ベルト経路・位置決めガイド

## 構成候補と結果

電池とトレー床を一緒に囲む2本のベルトをY=±20mmに配置する。
ベルト幅10mm、厚さ包絡1.5mmを仮置きし、幅11mmのガイドで横方向の移動を制限する。
2本化は傾きに抵抗するための設計判断であり、1本破断時の保持を保証する冗長設計ではない。
ガイドは横位置決め用。ベルトの張力は閉じたループと床に伝わり、ガイドを張力アンカーとは扱わない。

事前計画plan.jsonに対し、結果はreport.json。
トレーは有効な単一ソリッド（6900.995mm³）。電池・各ベルトとの体積干渉0。
トレーと2本のベルト包絡について他98部品との0.01mm³超の体積干渉はない。
tray.stepとstrap_0.step、strap_1.stepを保存。
これは角張った経路包絡の検査。実ベルトの曲げ半径、閉じ部の厚さ・重なり・端部は含まない。
実ベルト未選定のためこの包絡を製作図や完成BOMとして使用しない。

## 強度解析前に確定する評価量

| 失敗モード | 必要な評価量・入力 | 現状 |
|---|---|---|
| 上方向への抜け・回転 | 電池並進力と回転モーメント、2本の位置、ベルト伸び・閉じ部の保持力 | 新102g電池の負荷再計算と実部品許容値が必要 |
| 前後左右への移動 | 壁高さ、接触圧、滑り量、ガイドの横荷重・破損 | 摩擦だけに保持を依存させない。公差込みの拘束を未評価 |
| 電池の損傷 | 初期張力、接触面積、端部半径、局所圧縮量 | 電池の許容圧力が未入手。張力値を任意に設定しない |
| トレーの脱落 | 床から腕・ねじ・相手材までの荷重、穴面圧、腕変位、ねじ抜け | 単一ソリッドであることから強度を推定しない |
| 閉じ部の剥離・緩み | 重なり長さ、剥離方向、繰返し、温度、クリープ | 実ベルト選定後に公表仕様と実測対象を分ける |

TPU緩衝材を追加する場合は厚さ・圧縮特性・クリープと空間を別途反映する。
現状のベルト上面は電池上面に接触するため、後からパッドを追加しても寸法が変わらないとは扱わない。
次は実ベルトと閉じ部の選定、配線出口・ベルト装着/交換経路を確定する。
その後に荷重伝達と変形を解析し、最大応力の細分化だけで完了とはしない。
保持力や圧力の根拠がない状態でFEを追加しない。正式トレーポインターは据置き、製作HOLD。
