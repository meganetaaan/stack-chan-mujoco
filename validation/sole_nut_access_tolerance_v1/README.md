# 幅4.8 mmナット室の公差・挿入経路比較

既存側面開口案に対し室と開口の幅を4.4→4.8 mmへ変更。上下座面と室高さ1.8 mmは保持。左右STEPを保存した。目的は仮定境界公差±0.20 mmでも最大幅4.00 mmナットの挿入余裕を得ること。材料強度を合格にする変更ではない。

最小室幅4.8−2×0.2=4.4 mmとなり、最大ナットとの差は総幅0.4 mm（中央配置で片側0.2 mm）。側壁の呼び厚さは(8−4.8)/2=1.6 mmに減る。室高さは同じ公差解釈で最小1.4 mm、最大厚1.2 mmとの差0.2 mm。位置誤差/傾き/造形荒れを別に加算すれば余裕を消費するため、これだけで工程保証とはしない。

ナット外接箱を挿入8 mm全区間へ延ばした12×4×1.2 mmの掃引包絡を作り、ヨーク/ブーツとの交差体積を確認。左右とも0で、最大ナットの公称直線挿入はサンプリング間も含めて干渉しない。工具・ねじ・他の全身部品・公差はこの連続検査の対象外。

## 採否

**挿入余裕は改善したが、回り止めの公差余裕が小さいため確定採用しない。** 最小幅3.7 mmの理想正方形ナットの対角は約5.233 mm。最大室幅は5.2 mmとなり、差は約0.033 mmしかない。実ナットの角形状・面取り・樹脂変形を無視して回り止めが成立すると判定できない。この対角比較は平面内回転の必要形状確認であり、傾いた回転や開口側へのずれを保証しない。

次の設計では挿入隙間だけでなく、最小ナットに対する回り止め面と工具による保持を寸法条件にする。室の一律拡大を続けず、幅の上限/下限または独立した回り止め形状を決める。古い閉室FE結果は流用しない。
