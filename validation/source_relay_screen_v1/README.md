# 主遮断器の接点式候補：5 V出力側でのG5LE採用見送り

2026-09-21。目的は、無励磁で開く接点式リレーを現在の5 V配電へ挿入できるかを確認すること。終了条件はメーカー仕様と既存電圧予算の比較1件。リレー一般を不適合とする評価ではない。

対象はG5LE標準形のNO接点案。メーカーの[仕様書](https://components.omron.com/us-en/system/files/2025-01/datasheet_pdf/K100-E1.pdf)では接触抵抗最大100 mΩ。AC側の大きな定格をDC遮断能力へ流用しない。標準形の抵抗負荷30 VDC・8 Aという条件も、モーターや容量性負荷の突入/故障遮断を保証しない。

D42V55F5下限4.85 Vからサーボ通常下限4.75 Vまでの予算は0.10 V。既存治具の1 A比較点では、接点だけで最大値による比較降下0.10 V。配線・コネクタの既存比較0.066575 Vを加えると合計0.166575 V、端子は4.683425 Vとなり通常下限を下回る。実機負荷電流の予測ではなく、仕様上限で設計を承認できるかの判定である。既存2旋回の小さい電流を最大値と置いて適合扱いにはしない。

**この部品を現在の5 V出力側遮断器として採用しない。** [国内G5LE-1A DC5製品ページ](https://www.fa.omron.co.jp/product/item/G5LE-1A_DC5/)には2026年3月受注終了も記載されており、その発注型番を新規調達BOMへ追加しない。

リレーを変換器入力側へ移す案は電圧降下の条件が変わるが、出力コンデンサー・変換器・逆給電がサーボへつながったまま残る。負荷側を物理的に切り離す機能と同じものとして置換しない。無励磁開放も接点溶着故障を覆わない。

次の主遮断器設計は、実部品の高温抵抗と配線を含めた低損失経路、制御電源なしでの既定オフ、逆向き電流、故障時SOA、突入・容量放電を一体で確認する。既存EN停止だけの合格には戻さない。今回追加の動的シミュレーションは不要。#21/#24は未完了。
