# RESET_N共通線の負荷予算

100kプルアップのまま任意の故障出力を追加してよいとは判断できない。通常電源での比較ではDFFのCLR2入力、AND1入力、監視RESET出力の合計漏れ3.3 µAを使用。100k±1%は未選定抵抗の仮予算で、温度・経年の保証ではない。HCS入力漏れは6 V端点の規定を比較に用いており、全電源電圧・全入力状態の保証に拡張しない。

追加漏れ0／1／5／10 µAの場合、High電圧下限の比較値は2.8737／2.7727／2.3687／1.8637 V。これは合否しきい値ではなく、故障出力を選ぶための電圧予算。しきい値を仮置きして合格にはしない。Low保持の比較電流は外部電流源を除き約37.27 µAで、監視出力の通常電源での規定1 mA条件内。

起動時0.8 V・15 µAの監視RESET保証条件を使うための必要条件では、プルアップだけで最大8.08 µAを使い、残りは6.92 µA。ただしこの電圧ではHCS入力が定格電源範囲外なので、通常時3 µAを引いて起動負荷適合済みとはしない。電源傾斜・全ファンアウト・主電源の既定OFF段を含む検証が残る。

抵抗を小さくすれば通常High電圧を改善できるが、起動時のRESET負荷が増える。今回、数値を通すための抵抗変更は行わない。次の故障出力部品は、Low駆動・Off漏れ・無給電時状態を揃えて比較する。#24は未完了。

再現：`python3 software/sim/circuits/check_rearm_reset_fanout.py --out <未作成ディレクトリ>`。今回は机上端点予算で終了し、未知の起動漏れを仮定する過渡掃引は行わない。
