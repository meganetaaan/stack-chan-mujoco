# 高精度電源案の動作モードと内部電源

部分接続案を `schematics/power/precision_mode_candidate.json` に保存。完全なコンバータ回路ではなく、未選定EN/RT/FB等を浮かせて通電してよいという意味ではない。

## 設計判断

SYNC/MODE(pin15)を、そのモジュールのVIN1/VIN2と同じ保護後入力へ接続する。別電源MCUから駆動せず、入力が有効な間はFPWMを選択する。SPSP(pin14)はAGNDへ固定し、最初の比較案ではスペクトラム拡散を使わない。これはEMI合格を意味しない。

VLDOIN(pin5)はAGNDへ接続し、内部LDOをVINから給電する案にする。出力へ接続するとVIN消失時に出力残留/回生との電位関係を追加評価する必要があるため、初期案では出力バイアスを使わない。変換器の主電力経路を逆流遮断したことにはならず、FPWM回生処理は別途必要。VCC(pin6)は外部負荷へ使わない。

## メーカー仕様との照合

[TI SLVSGU1A](https://www.ti.com/lit/ds/symlink/tpsm63610.pdf)の表5-1はMODEのHigh選択、表6.5はHighしきい値1.7Vを示す。MODEの連続絶対最大は36V。入力とMODEを同一点に置く案なので、メーカー起動入力3.7VでHighしきい値との差は2.0V。3S満充電の比較12.6Vは36V未満。ただしこれらは端子電圧の静的照合だけで、5V出力が3.7V入力で成立する意味ではない。入力の負スパイク/過渡や上流保護は未成立。

§7.3.11はVLDOINをGNDにしてVINから内部給電する動作を説明する。内部LDO損失増加を熱設計へ含める。VOUTバイアス時の典型効率グラフをこの案へ流用しない。

モード抵抗を機械的に100kΩとしない。資料の内部プルダウン100kΩは典型値で、VCCから100kΩを介した場合は分圧とVCC範囲の評価が必要になる。今回は外部クロックを使わないため入力直結のHigh選択案とし、内部抵抗の典型値を保証下限として使わない。

## 起動・停止への影響

起動中にモードが確立する前は前回のFPWM精度範囲を適用しない。サーボ給電許可は出力資格確認後に行う必要がある。EN入力のUVLO・再投入方針は未選定であり、入力直結で電池下限まで起動させる実装はしない。

コンバータの過電流/熱保護は自動復帰を伴うため、サーボ側手動復帰の代替ではない。下流eFuseと許可回路を残す。未使用PGをeFuse PGと結合しない。

本作業の終了条件はモード/バイアスの部分接続を選び、精度表と異なるモードや別電源注入を設計に混入させないこと。次はEN/UVLO、動作周波数、実効容量と熱を具体化する。机上判断が残るため実測Issueへ移管して完了扱いにしない。
