# 後部ワッシャー厚さを含む軸方向評価

SNS-M3-16の長さ15.65〜16.35mm、既存裏板厚さ2.87〜3.13mm、新ワッシャー案厚さ0.45〜0.55mmの端点を8本×8条件で評価した。裏板入口と後板の座面を固定し、座金が厚くなるとボルト先端が負X方向へ移る。

試験前の判定は、この3変数の範囲でねじ先端が裏板を貫通すること。64条件で突き出し1.27〜2.33mm、先端X=-49.10〜-48.30mmとなった。他部品の厚さ、印刷誤差、締付け圧縮、実座面は公称のままであり、全積層の合格とはしない。完全ねじ山長さ、周辺との隙間、締結強度は未確認。保持用M2ねじはこの座金変更の対象外。

再現：`.venv-engineering/bin/python software/sim/structural/check_rear_washer_stack.py --out /tmp/rear-washer-stack-review`（未存在の出力先）。
