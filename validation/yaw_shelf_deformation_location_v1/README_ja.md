# 支持棚の変形位置と補強対象

目的：外側ポート開口後の支持棚について、背面だけを厚くすればよいか、前側の棚・リブも見直すべきかを判断する。前回の3 mmメッシュ、同じ保存荷重・材料仮定・支持条件を1回だけ再使用し、場データを保存した。追加細分化なし。

## 結果

| X方向の診断区間 | ひずみエネルギー割合 |
|---|---:|
| 後側 X < -50 mm | 23.30% |
| 中間 -50 ≤ X < -30 mm | 23.80% |
| 前側 X ≥ -30 mm | 52.90% |

区間は原因を調べるための便宜上の分割で、個々の部品・壁の分類ではない。積分点で計算したエネルギー総和がソルバーのひずみエネルギーと一致することを確認。

最大変位位置は[11.6,18.5,91.0] mm、変位ベクトルは[-0.0300,-0.0988,0.2599] mm。取付面節点に剛体移動・回転を最小二乗で当てはめた後も、最大0.0972 mm、RMS 0.0332 mmの変形が残る。これは節点等重みの診断であり、実際の金属板を取り付けた面の変形保証ではない。

**判断：背面のみの増厚を先行させない。前側の棚・リブの曲げとねじれを減らす補強候補を優先する。** 外形・サーボ位置・工具経路・配線出口を保ち、現行金属板との荷重伝達も合わせて確認する必要がある。エネルギー割合は補強効果の保証や破壊確率ではない。

全体最大変位をそのまま接触方向の相対変位とは扱わない。製作承認やIssue完了の条件は未達。実荷重更新、造形材料、締結・接触を含む評価は引き続き必要。

## 再現

リポジトリルートで未使用出力先を指定する。前回の3 mmメッシュが存在すれば読み込み、なければ同じ設定で再生成する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/locate_yaw_shelf_deformation.py --out validation/yaw_shelf_deformation_location_reproduce
```

plan.jsonに事前の評価範囲、report.jsonにメッシュハッシュ・診断値を保存。field.npzは変位・応力・荷重・反力の再利用用データ。
