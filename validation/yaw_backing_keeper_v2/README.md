# 仮保持ねじ座面の1 mm移動

座面をX=−60.9から−59.9へ変更し、頭背面は−61.2。背面構造板前面−62.2との公称隙間1 mmを確保した。支持の座ぐりを深くした以外のねじ長/板位置は維持。支持・構造板とのねじ包絡交差0、支持/金属板は有効単一ソリッド。

先端は−49.9、金属板前面−50.5から0.6 mm突出する。report.jsonのnominal_thread_entry_mm=3.6は入口から先端までの距離であり、板内に3.6 mmのねじ掛かりがあるという意味ではない。板内の軸方向かかりは最大3 mm、面取りと不完全ねじを除く有効長は未確定。

旧0.4 mmの先端引込みは幾何記録であり、ユーザー要求や合格基準ではなかった。今回も周辺との0.90 mm隙間基準を維持し、突出の影響をyaw_keeper_tip_v2で別に確認した。基準を緩和して通していない。

頭側は既存2境界公差予算0.40 mmと頭高さ増分0.10 mmの仮定を引くと0.50 mm残る。いずれも実製法・購入品の保証公差ではないため、実部品公差適合は未確認。座ぐり下の支持残厚、ねじ山抜け、仮保持時反力、組立工具も未評価。

再現：build_yaw_backing_keeper.py --seat-shift-mm 1 --out <新規先>。フラグなしはv1を再現。
