# クリア駆動入力の不適合スクリーニング

## 判定

194部品v3の10 kΩプルアップからSN74LVC1G07へ直接入力する構成は、適合候補として採用しない。CTRL電源が安定したままMCU出力がLowから高インピーダンスへ移るケースで、入力容量の代表値4 pFだけでも0.8→2.0 Vの平均は21.798 ns/V。部品の10 ns/V条件を超える。これは個体すべての故障予測ではなく、現設計を適合と認定できない根拠である。

## 要求・仕様・仮定

ユーザー要求は起動・停止と保護が成立すること。10 ns/Vは[TI Rev.AG §5.3](https://www.ti.com/lit/ds/symlink/sn74lvc1g07.pdf)の部品条件。10 kΩ、安定3.3 V、漏れなしの一次RCは設計側の比較条件。4 pFは同§5.5の代表値で最大保証ではない。MCUと配線の容量を加えていない。入力速度条件を緩和していない。

計算は `V(t)=VCC*(1-exp(-t/(R*C)))`、しきい値区間の時間差を電圧差で除す。平均で既に超過するため、その区間全体を10 ns/V以内にはできない。このモデルで平均条件を満たす容量は約1.835 pF以下。実容量の上限値とは扱わない。

## 修正と終了条件

[196部品v4](../../schematics/power/protected_pack_system_candidate_v4/README_ja.md)では、遅い入力の立上り・立下りを許容する74LVC1G17GVを前段に追加。非反転なので要求極性は維持。旧194部品は失敗履歴として残す。[Nexperia 74LVC1G07](https://assets.nexperia.com/documents/data-sheet/74LVC1G07.pdf)は冒頭のSchmitt-action記述があっても§9に10 ns/V制限があるため、単純置換で解決したとはしない。

この旧入力のRC解析追加は終了。次の確認は、新バッファ出力からOD入力への速度・DC適合、MCUリセット時の端子状態、OD出力側のRC、電源投入・低下・喪失時のリセット保持と電流予算に絞る。追加段の採用だけで回路全体を合格とはしない。
