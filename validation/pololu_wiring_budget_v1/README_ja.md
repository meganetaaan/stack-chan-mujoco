# 5V電源候補の配線余裕：保護素子込みの再評価

結論：現候補を「太い電線を付ければ成立」として配線設計へ進めない。XC330枝では保護素子とサーボ側接点の比較降下だけで91.5338 mVを使い、残りは8.4662 mV。Alpha Wire3079の片道100 mm共通給電線は、OEM枝線などをゼロ扱いしても比較予算超過となる。50 mmでも合格ではない。

## 要求・仕様・仮定

ユーザー要求は製作へ進める構成の判断であり、端子4.75 V下限、特定電線、長さの指定はない。4.75 Vは従来の5V±5%という設計配分で、本評価では変更しない。

- [Pololu5671](https://www.pololu.com/product/5671)の5V±3%から静的出力下限4.85 V、端子までの配分100 mV。負荷過渡を含む最悪電圧保証ではない。
- [TPS25981](https://www.ti.com/lit/ds/symlink/tps25981.pdf)の8.4 mΩは3A条件。4.917Aへの適用は比較仮定。
- [SiSS80DN](https://www.vishay.com/docs/77684/siss80dn.pdf)の3mΩは25°C・VGS2.5V条件。現在の113部品接続候補を確認し、各脚1個を算入した。旧LTC4365案の2個を重複計上しない。実ゲート電圧/高温適合は未確認。
- [JST EH](https://www.jst-mfg.com/product/pdf/eng/eEH.pdf)の環境試験後20mΩ/接点を従来と同じく使用。OEM片端切断案なので各枝の電源往復2接点。
- 電流4.917A/脚、XL枝0.752A、XC枝0.887Aは既存モデル条件付き比較値。実機最大値や制限保証ではない。
- [Alpha Wire3079](https://www.alphawire.com/products/wire/hook-up-wire/premium/3079)は比較用14AWGすずめっき銅/PVC線。抵抗2.8Ω/1000ftは20°C公称で最大保証ではない。外径0.138±0.004inch、曲げ半径5D。外径上限3.6068mmから曲げ半径18.034mm。関節可動線の寿命保証ではない。

## 算式と結果

各枝の残余 = 100mV − 脚合計電流×(eFuse抵抗+逆流FET抵抗+共通線往復抵抗) − 枝電流×2接点抵抗。

共通線は脚合計電流、枝線/接点は個別枝電流で扱う。既存20.3376mΩという単一ループ換算値を全配線へそのまま割り当てない。

|3079片道長|XL枝の残余|XC枝の残余|判定|
|---|---:|---:|---|
|0mm|13.8662mV|8.4662mV|未算入損失あり・未適合|
|50mm|9.3493mV|3.9493mV|未算入損失あり・未適合|
|100mm|4.8323mV|−0.5677mV|XC比較条件で超過|

XC枝で50mm共通線を使うと、残りを全てOEM枝線に配分しても往復4.4524mΩ以下が必要。PCB銅箔、はんだ、その他接続、高温、動的降下へは余裕ゼロの上限であり、これを完成品の許容抵抗にしない。OEM線の抵抗は不明のため、この計算だけでOEM線自体を不合格ともしない。

## 判断と終了条件

本作業の終了条件は保護/接点を含めた残余を両モータ種で数値化し、選定前の配線候補を絞ること。未確定パラメータを仮定した過渡解析は追加しない。

3079片道100mm案は現比較条件では採用しない。50mm案の採用も保留し、配電板を電源近傍に配置する案で実経路長を求める。ただし短縮だけで不足を解消した扱いにはせず、OEM枝抵抗・保護段抵抗と同時に確認する。これが満たせなければ電源精度/設定または低損失保護構成を見直す。4.75V下限の引下げ、無根拠な5.3V版への置換は行わない。

3079はBOM選定に追加しない。被覆径と曲げスペースが大きく、今回の値はCAD経路設計への入力に限る。はんだ盛り、基板下のはみ出し、熱/許容電流、張力逃がし、実装作業性は未確認。
