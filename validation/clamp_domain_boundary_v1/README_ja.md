# クランプ原因信号の電源境界と代替案

対象：revHのU9 RESET→RAIL_HEALTH_N→U7 MR／U11入力、U11出力→U10 MR。前回のTXU0101直接置換不採用後、部品追加を避けるためのR9接続変更と、開放出力による電圧分離を比較した。現行回路の変更は行っていない。

## 単純変更で完了しない理由

|案|利点|採用前に必要な根拠|判断|
|---|---|---|---|
|R9の上端のみ3.3 Vから5 Vへ変更|U11の入力を自身の給電電圧に近づける|U7 MRから3.3 V電源への逆給電、電源断・復帰時の動作|未採用|
|5 V原因信号をU10 MRへ直結し、別のオープンドレイン段でU7へ伝える|停止の原因を共有しながらプルアップ電源を分けられる|入力の遷移時間、出力漏れ、部分給電、伝搬と短パルスの照合|方式候補。実装部品は未確定|
|U9とは独立した同型監視ICでU10だけ制御|電圧変換を省略できる|独立したしきい値・遅延のばらつきにより、電力クランプだけ作動して許可が残るケースを防ぐ必要|同型品追加だけでは採用しない|

[TI TPS3808 Rev N](https://www.ti.com/lit/ds/symlink/tps3808.pdf) pp4–6を確認した。MRの推奨電圧は0〜6.5 V、絶対最大は7 Vであり、5 V信号そのものを定格違反とはしない。一方、MRはVDDへの内部プルアップを持つ。入力定格は逆給電電流や無給電時の機能保証ではない。内部抵抗の公表値を逆方向の等価抵抗として使い、逆給電上限を保証する計算は行わない。

[TI SN74LVC1G07 Rev AG](https://www.ti.com/lit/ds/symlink/sn74lvc1g07.pdf) pp3–6も確認した。DBVは1=NC、2=A、3=GND、4=Y、5=VCCの非反転オープンドレイン品。5 V帯の入力遷移には5 ns/Vの制限がある。抵抗で立ち上がる監視出力を、容量・波形の根拠なく直結しない。電源断IoffはVCC=0の条件であり、部分電圧全域の保証へ拡張しない。静止電流規定も入力5.5 VまたはGNDの条件であり、今回の容量監査を完了させる根拠にはならない。

## 次の設計判断と終了条件

単純プルアップ変更およびSN74LVC1G07単体の直結検討はここで終了する。次の候補は、同じ原因信号で許可取消と電力クランプの両方を駆動し、電源間を分離する構成に限定する。採用判定には次を揃える。

1. 実使用電圧での入力・出力レベルと負荷電流。
2. 抵抗立上りを受けられる入力特性、または根拠のある最大容量・立上り時間。
3. 片側無給電・部分低下時の漏れと停止側の状態。
4. クランプ作動だけで手動許可が残り、自動で再給電されないこと。

判定を通すために信号容量や許容電流を仮置きして波形掃引はしない。机上設計の残件は#24に残す。#49へ渡すのは選定後の実装波形・消費電流の照合である。
