# ナット保持用スライド蓋候補

## 構成と検査結果

左右各2個のナット開口を、X38.4..51.8mm、厚さ0.8mm、高さ6mmの蓋で覆う。
枠側に滑りレールと後端ストッパーを追加し、前側から差し込む。
溝と蓋の片側隙間は厚さ方向0.1mm、高さ方向0.2mm。これは設計仮置きでプリンター精度の保証ではない。
ねじ先端を通す穴は径3.4mm。主ねじの予圧は接触座とナットで受け、蓋を締付け座には使わない。

枠は有効な単一ソリッド。蓋・枠と現行統合CADの部品との体積干渉なし。
従来のナット内向き1mm移動は4箇所とも蓋へ交差し、同じ直線脱落経路を遮る。
Tab5と側面4ねじを除いた状態では、蓋の前方20mm連続包絡に干渉なし。逆順の挿入経路も同じ領域となる。
これは任意回転・斜め抜けを含む全方向の保持証明ではない。

## 組立順の候補

枠単体へナットを入れ、4蓋を前方から差し込む。その後Tab5を枠へ固定し、枠を胴体へ取り付ける。
Tab5が蓋の前側抜け口を塞ぐ意図だが、実ケース形状・公差込みの閉塞量はまだ確認していない。
交換時はTab5と枠を一体で外す。ナット蓋の交換はTab5を枠から外して行う。

## 残件と終了条件

次の保持評価は、Tab5装着後の蓋の前方移動限界、後端・上下・内外の拘束量を測り、
公差・変形後にも開口から外れないことを確認する。単に摩擦があるという仮定で合格としない。
蓋0.8mm・保持リップ1mmのABS/PETG造形、層方向、曲げ・クリープとナット保持荷重は未確認。
手での差込み/取外し、蓋の紛失防止も未解決。TPUへの置換は保持剛性を別途評価して判断する。
今回の挿入経路と直線逃げ遮断の検査で一旦終了し、未確定物性によるFEは追加しない。
正式統合CADへ未反映、製作HOLD。
