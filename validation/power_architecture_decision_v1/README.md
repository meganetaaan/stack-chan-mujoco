# 全身電源構成の机上比較

2026-09-21。目的：D42V55F5一台、左右分離二台、大容量一台のどれを次の回路選定へ進めるか。新規の仮想負荷シミュレーションは行わない。終了条件は電流の定義、電圧降下予算、構成固有の保護条件を整理し、候補の採否/保留を決めること。

## 電流予算の訂正

9.63 A = 6×(0.735+0.870) Aは**モーター側の電流設定上限の合計**。DC側供給ピークでも実装済み保護上限でもない。`docs/prototype/ACTUATOR_MODEL_ja.md` と `LOAD_INTERFACE_ja.md` が両者を区別している。従来判断書で「全軸電流上限」と省略した箇所はこの意味に限定する。

既存左右旋回記録を再集計すると各脚のDC消費ピークは0.336〜0.425 A、回生総和ピーク0.0187〜0.0247 A。低い値は既存モデルと未達軌道の値であり、電源を0.5 Aで選べるという結論ではない。全動作、起動、拘束、PWMリップル、基板損失、実測誤差を包絡しない。実機同定まで9.63 Aを実DC最大値として保証も棄却もできない。

## 比較と判断

| 構成 | 判断 | 理由・残条件 |
|---|---|---|
| D42V55F5×1、12軸共通 | 全身用の確定採用は見送り | 5〜8 Aはtyp値。現状の負荷記録だけで起動/故障/熱を保証できない。単関節評価候補は保持 |
| D42V55F5×2、左右別5 V | 次の回路構成候補として保持、製造リリース不可 | 一脚のモーター電流和4.815 A。DC側最大の根拠を別途必要とし、二台の熱・入力容量・質量・各レール回生吸収が増える |
| D42V110F5×1 | 比較候補追加、選定保留 | メーカーは5 V/typ11 A（42 V入力条件）の製品を提示。入力/放熱依存であり2S電池での保証値ではない。基板面積1.25×1.7 inch。大容量化だけでは短絡/回生/配線を解決しない |
| 電流制限可能な外部電源 | 最小単関節試験の第一候補を維持 | 吸収能力・保護・配線の仕様確認は必要。自立電池構成の達成とはしない |

**新たな判明点：電流容量だけでなく配線電圧降下が厳しい。** D42V55F5の5 V±3%から下限4.85 V、従来の端子目標4.75 Vまで0.10 Vしかない。仮に一脚4.815 Aを設計上の試算点にすると、供給線・戻り線・接点・遮断素子を含む経路抵抗は20.77 mΩ以下が必要。この値でも過渡降下・リップル・補助電流の余裕はゼロであり、採用可能な配線定格ではない。先に配線長/接点/遮断素子の実仕様を割り当てる必要がある。5.3 V版へ変更して通常電圧目標を超える方法では解決しない。

左右分離案では出力V+を接続しない。既製3線デイジーチェーンで左右レールを短絡しないハーネス構成が必須。信号/共通GNDの接続は逆給電・接地電位差を別途確認する。片脚側の故障で両脚を停止させる方針、各レールの回生吸収/残留放電、EN以外の遮断経路を回路図へ落とす。既存一レール用のブレーキ抵抗2個/放電抵抗2個をそのまま全身分離案のBOMへ流用しない。
