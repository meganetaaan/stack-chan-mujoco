# ヨー固定用ナット8個の質量影響

選定済みPTS A56202の最大外形4×4×1.2mmを材料が占める場合の体積は19.2mm³/個。密度上限を設計仮定8000kg/m³と置くと8個で1.2288g以下となる。穴・面取りによる減量を見込まない。既存CADの外接円筒26.4016mm³は衝突判定用であり、金属体積として採用しない。

密度8000はA2のメーカー保証値ではなく、質量影響を評価するための明示的な条件。673.588840gの部分小計への最大追加は約0.1824%。この条件付き評価ではナット質量の細分化を続けず、配線・保護基板等の未割当てを優先する。購入品の質量・密度が条件を外れる場合は更新する。

加算結果674.817640gは完成した胴体の保証上限ではない。元の部分小計自体の材料・電装分布は比較仮定で、他の未計上品も残る。ナットの重心・慣性は未割当て、モデル変更なし。

再現：
```sh
.venv-engineering/bin/python software/sim/structural/bound_yaw_nut_mass.py --out /tmp/yaw-nut-review --density-ceiling-kg-m3 8000
```
