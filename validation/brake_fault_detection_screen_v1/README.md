# 固着オン検出条件の保存波形評価

電圧だけでは固着オンを検出できないため、枝電流とゲート電圧を組み合わせた条件案を事前plan.jsonに定義。補助電源3 V以上、バス4.75〜5.25 Vで監視し、ゲート0.4 V以下かつ枝電流0.1 A以上が1 ms続けば検出とする。

100 µs間隔の保存表示波形で、正常ケースは両枝とも検出なし。主枝固着は起動から6.4 msで主枝のみ検出、両枝固着は6.6 msで両枝検出。これは故障発生からの保証遅延ではない。故障は起動時から存在し、電圧による監視開始待ちを含む。

枝電流は既知のモデル抵抗と端子電圧から再構成しており、実電流センサーを評価していない。サンプリング間のイベント、センサー誤差、比較器・ゲート実しきい値、ブランキング、ノイズ、全温度・電源条件は未評価。補助電源消失後は監視条件外で、停止後の回生保護を代替しない。

検出条件の候補を絞るためのオフライン評価。リアルタイム保護や誤検出不在を保証せず、遮断・ラッチ・復帰回路は未実装。次にセンサー/比較器の誤差予算と検出から遮断までの回路を具体化する。Issue #24は未完了。

```sh
.venv-engineering/bin/python software/sim/circuits/screen_brake_fault_detection.py
```

report.jsonに対象波形のハッシュと測定間隔を保存。正常比較は指定した1ケースに限られ、全歩行・起動・異常条件を網羅していない。
