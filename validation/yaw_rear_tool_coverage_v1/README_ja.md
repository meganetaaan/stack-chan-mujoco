# 背面工具モデルの適用範囲監査

8本すべての旧rear_keyはX=−92.7〜−67.7 mm、直径3 mm・長さ25 mm。ねじ頭背面X=−67.7 mmで終わり、頭内への差込みは0 mmだった。ソケットと柄を含まない。旧円柱の隙間結果は保存するが、実工具で締付け可能という証拠にはならない。

M3主固定の工具候補はWera 2054 05118070001（2.5 mm六角、刃長60 mm、刃径4 mm、柄長97 mm）。メーカー資料を2026-09-21に確認：
https://hybris-media.wera.de/download/pdfgenerator-datasheets/en/05118070001.pdf

実工具の刃径は旧円柱より1 mm大きい。六角先端と丸軸を分け、選定ボルトのソケット深さ／先端有効長／柄最大径を確認してから挿入経路を評価する。旧円柱を伸ばすだけでは、差込み部を丸軸として誤判定する恐れがある。工具の定格トルクと組立トルクの適合も未確認。

次の評価は背面主固定8本に限定。実工具寸法とボルト仕様に基づく1案について、接近・差込み・回転時の包絡を確認し、成立または設計変更箇所が確定したら終了する。工具の選定未完を試験#48だけへ移管せず、#17/#19の机上残件として保持する。内側長柄ナット工具は現行ねじ付き背面板で不要になったが、外側工具の検証を代替しない。

再現：CadQuery環境で `software/sim/structural/audit_yaw_rear_tool_coverage.py --out <output>` を実行。plan.json、report.jsonに対象・終了条件・元CADのSHA256を保存。製造リリース／組立成立はいずれも未承認。
