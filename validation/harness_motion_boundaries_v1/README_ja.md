# 可動配線の境界割当て

現行MuJoCoのモーターケース形状を保持するbodyと、12軸個別配線表を照合した。胴体の配電点からリンクの親子関係に沿って引く前提では、片脚あたりの関節通過導体数は次のとおり。

| 関節 | 導体数 | 下流サーボ数 |
|---|---:|---:|
| 股ヨー | 15 | 5 |
| 股ロール | 12 | 4 |
| 股ピッチ | 9 | 3 |
| 膝 | 6 | 2 |
| 足首ピッチ | 3 | 1 |
| 足首ロール | 0 | 0 |

左右対称。ヨーサーボ配線は胴体内に留まる。足首ロールの0は配線不要という意味ではなく、現行モデルではケースが関節の親側にあり、その関節を越えないことを示す。実コネクタの位置と組立図での確認は必要。

この構成の優先判断はヨーを通る15本の線材・束径・余長・固定点。既存の剛体隙間スクリーニング1.008mmを配線の収納空間として転用しない。DATAを共有する等の配線削減は接続方式の変更なので、勝手に線を間引かない。

本結果は経路の接続関係であり、製作長・曲げ・干渉・疲労・質量を確定したものではない。線材の選定と実コネクタ基準面、固定点、全可動域の余長を対応付けてから経路を確定する。現在の完成条件を緩めない。

再現：
```sh
.venv-engineering/bin/python software/sim/structural/map_harness_motion_boundaries.py --out /tmp/harness-boundaries-review
```
