# 後板側M3ナットの工具アクセスと組立順序

## 結論

**後板側M3締結を、電源基板の装着前に行う順序へ変更する。** 基板を先に装着する旧順序案は採用しない。

Wera 2069 Micro 05118126001(AF5.5、軸外径7.8・長さ60 mm、全長157 mm、ハンドル最大幅13 mm)の外形予約で、4軸の連続直線進入を検査。後板・台座・M3締結だけの切り離した組立段階は外形スクリーニングを通過。共通Pololu STEPを装着した段階は4軸ともモジュールと干渉した。工具出典: https://hybris-media.wera.de/download/pdfgenerator-datasheets/en/05118126001.pdf

共通モジュールSTEPには5V版との部品高さ差が残るため、全4軸の干渉量を5V実物の断定には使わない。report.jsonのpcb_layer_overlap_mm3でPCB板厚領域への干渉も分けて確認する。少なくとも低い2軸はPCB層そのものが軸経路を塞ぐ。

## 検査条件

工具先端X=-57.7(ナット座面側)から+Xへ70 mm退避する連続掃引。軸とハンドルの円柱掃引を和集合として扱う。対象ナットとねじはソケット内部形状が未指定のため除外し、相手座金は工具先端面との接触のみ許容、体積重複は禁止した。他部品には0.5 mmの隙間基準を維持。部品の逃げ追加や位置変更で結果を合わせていない。

外形の進入可否を確認しただけで、工具の掛かりは未確認。ねじ先端はX=-52.7なので、先端面からの必要なソケット内部深さは公称5.0 mm以上に公差・底付き余裕を加えた値。メーカー資料から有効ソケット深さ、入口面取り、使用トルクは確認できていない。手の空間と反対側の六角レンチも未評価。

## 改訂した組立順序案

1. 機体から切り離した後板へ、空の台座をM3ねじ・座金・ナットで取り付ける。この段階では電源基板、M2締結、スペーサは付けない。
2. 後板側締結の保持と工具掛かりを成立させてから、基板用ナットを台座の横スロットへ差し込む。
3. スペーサと基板を載せ、M2ねじを上から導入して固定する。仮保持・締付トルク・絶縁は別途確定する。
4. 組み立てた後板ユニットを機体へ取り付ける。ユニット全体の挿入経路、後板本来の固定ねじ、配線の経路は未検査。

この順序は全製造工程の成立を示さない。特に前回のナット挿入経路は後板M3部品を相手に含まないため、工程2へそのまま完全合格を移さない。保守時に後板M3締結へ再アクセスする場合も、基板を外す必要がある設計案として扱う。

## 再現

依存: CadQuery。公式STEPを取得しSHA256を検査する。
```sh
curl -L https://www.pololu.com/file/0J2219/d42v110fx-step-down-voltage-regulator.step -o /tmp/pololu-reg34c.step
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_pololu_rear_tool_access.py /tmp/pololu-reg34c.step --out validation/pololu_rear_tool_access_v1
```
製作リリース=false、Issue未完了。

追記: `validation/pololu_nut_insertion_v2`で、工程2のナット挿入へ後板M3締結16部品と他のM2ナット7個を追加して確認した。全8経路の公称形状は通過。造形公差・仮保持・手工具・工程4の機体装着は未確認のまま。

追記: `validation/pololu_rear_unit_insertion_v1`で工程4の単純な後方水平挿入は不採用となった。最終位置の30 mm手前で台座と既存ヨー固定ねじが衝突する。工程1〜3の公称確認は、工程4まで成立した製造手順を意味しない。
