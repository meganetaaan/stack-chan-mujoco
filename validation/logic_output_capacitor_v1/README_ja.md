# 制御電源出力コンデンサの限定選定

比較候補T520A226M010ATE080を[メーカー個別仕様](https://search.kemet.com/download/specsheet/T520A226M010ATE080)で確認。22 µF±20%、10 V、−55..105℃、ESR80 mΩ（100 kHz・25℃）、漏れ22 µA（25℃・5分後）。後半のシミュレーション図はメーカー自身が仕様ではないと明記しており保証値にしない。

初期容量17.6..26.4 µF。現回路のLOGIC3V3直結100 nFは15個、合計1.5 µFで、初期±5%を加えた総量は19.025..27.975 µF。この段階ではTPS709の1.5..47 µF範囲および設計目標2.2 µF以上に収まる。左右PG回路C12/C13はvalue_F欄がないが注文コードから計上した。MCU・未設計受信回路の容量は含めていない。

**判断:** 初期容量だけの比較候補として記録し、正式BOMや現アセンブリの出力容量は置き換えない。温度全域の容量・ESR、TPS709との組合せ安定性、総容量・起動・極性・実装条件が必要。漏れ22 µAは25℃条件の参考値で、負荷電流予算の温度全域上限に代用しない。容量を増やせば前述の不確実性が解消するとはみなさず、追加の容量掃引はしない。

KEMETのシリーズ資料URLは取得できなかった。個別仕様から分からない条件を推測して埋めない。Panasonic 16TQC22MYFBはメーカー表示がNRFNDのため新設計候補に採用しなかった。STOP_AUX3V3の既存容量選定とは独立した検討である。

計算は22×(1±0.2)+15×0.1×(1±0.05)。report.jsonに対象参照番号を保存。電源の合格・製造リリースには使用しない。
