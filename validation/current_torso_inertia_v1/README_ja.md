# 最新胴体の部分慣性集計

現行115部品をSTEP体積で対応付け、数値質量78点＋均質PETG比較7点の計85点について、質量・一次モーメント・原点まわり慣性を加算した。残る30点はnullのまま保持し、全体集計関数が未割当を拒否することを確認した。モーター・脚・配線/制御基板などCAD外の割当も別途必要。

比較部分の質量0.672388822 kg、重心はCAD座標で(-2.412,0.046,78.191) mm。重心まわり慣性の対角は(0.00158596,0.00208982,0.00232064) kg m²。非対角成分と全部品項はreport.json。これらは全身や完成胴体の値ではなく、未知分の追加で重心・慣性が変わる。下限/上限でもない。

各部品内部はCAD形状への均質質量分布を仮定した。電子部品・電池・ねじ等の内部分布や重心を実測確認した値ではない。枠は圧入前形状に統一し、樹脂再配分後の慣性を保証しない。MuJoCoのボディ座標への変換は未適用で、XMLは変更していない。

検証は移動した20×40×60 mm直方体と、200 mm離れた二つの10 mm立方体の解析解。単位変換、重心位置、平行軸項を含む慣性誤差は1e-12 kg m²未満。テンソルの対称性・正の固有値と、先の部分質量小計への一致も確認した。これらの数式検査は材料/部品の実分布や強度成立を保証しない。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/build_current_torso_inertia.py
```
