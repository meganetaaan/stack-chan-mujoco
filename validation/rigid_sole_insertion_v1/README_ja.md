# 硬質保持部候補の挿入経路

現在の分割後保持部を剛体として、既存ヨーク・ブーツに対して検査した。
元のkeyhole経路（X+8mmで下方から8mm上昇、次にX方向へ8mmスライド）を
0.5mm刻みで検査。左右それぞれ34姿勢のすべてで公称交差体積0。
スライド止めのねじ・スペーサー・ナットは位置合わせ後に取り付ける手順を前提に除外。

従って「旧TPU形状だから挿入に必ず柔軟変形が必要」とは判断しない。
元の挿入方式を残せる可能性があるため、全面的な形状作り直しよりも
連続経路と公差・保持部強度・ねじ取付けの確認を先に進める。

離散姿勢の検査なので途中を含む連続非干渉は未証明。公差による嵌合不足、
保持頭の積層方向・破断、固定ねじ、工具アクセス、接地シート貼付け順は未確認。
この結果だけでPETG製造へリリースしない。追加解析はこれら残件の解消に限定する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_rigid_sole_insertion.py --out /tmp/rigid-sole-insertion-recheck
```
