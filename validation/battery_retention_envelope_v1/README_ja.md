# 電池保持ベルトの通過体積候補

## 判断

トレイと電池を一緒に巻く着脱式ベルトを検討対象にできる。
公称CADではベルト包絡とヨー支持組立の距離4.386 mm、Tab5との距離8.8 mm。
電池・トレイには接触するが体積重なりはない。ベルト部品の選定・保持成立は未完了。
ABS/PETGの閉じた輪を電池へ押し込む設計ではない。

## 仮定と解析の終了条件

幅10 mm、厚さ1 mm、Y中心0の矩形環はCodexの配置検討用仮定。
電池底を支えるトレイの下面Z63.5、外側X15.8/42.2、電池上面Z95に沿う。
実際の柔軟ベルトは角で曲がるため、この形状は製作図ではない。
バックル、面ファスナー重なり、縫製、端末、緩衝材を含まない。
対象部品の体積重なりと距離を得ることをこの配置検討の終了条件とした。
形状寸法を強度や電池の許容面圧の根拠にはしない。

## 次の設計判断

- 外せるベルトの実部品仕様、重なりと端末の操作空間を確定する。
- 横ずれ防止ガイドを設計する。現状は摩擦だけでY方向のずれを防げると仮定しない。
- 電池メーカーの許容締付け情報と保護パッドを確認する。情報がなければ許容圧力を創作しない。
- 保持荷重を共通の停止・旋回荷重から求め、ベルト・ガイド・トレイ・固定ねじの経路で評価する。
- ベルト解除後は既存の電池交換経路を使う案。閉じたままの取り出しは要求しない。

これらは残る設計作業であり、実機Issueへ移しただけで完了とはしない。
保持強度・通電試作・#5/#6の合格を表すものではない。

## 再現

リポジトリルートから未作成の出力先を指定する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_battery_retention_envelope.py --out /tmp/battery-retention-new
```

元の生成と再実行で全4対象の重なりと距離が一致。入力ハッシュはreport.jsonに記録。
