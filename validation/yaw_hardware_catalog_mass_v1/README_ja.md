計20本で12.36 g。SLHは金属板固定8本と背面板仮保持4本、SNSは背面主固定8本へ対応させた。component_masses.csvに組立部品名を列挙し、inventoryのSHA256をreport.jsonへ保存。対象名の選別は末尾_keeperおよび_plate_*_screwをSLH、_rear_*_boltをSNSとし、数量12／8を照合した。

これらはメーカーの公称値であり、実測値や保証上限ではない。ねじ山と六角穴を省いた包絡CADから密度を掛ける方法より、部品選定に直接結びついた質量根拠となる。形状分布までは得られないため、包絡の中心・慣性を単純に公称重量へ比例補正して確定値とはしない。

前回の包絡28部品のうち20本に公称重量を割り当てられた。残る角ナット8個と、材料／加工条件が未定のソリッドは未確定。凍結モデルの電池ねじ0.30 g仮値は別の部品割当なので、この0.23 gへ一律変更しない。配線・締結25 g予約との再配分も引き続き必要。

今回の終了は採用済み型式と組立数量への公称重量の対応まで。全身モデル・重心・慣性・荷重は変更せず、#17/#18完了や締結強度の合格とは扱わない。SLHのカタログ最大締付けトルクを樹脂座面への推奨トルクへ流用しない。
