# BQ76942 3S入力と監視対象設定

データシートRev.B表16-3は、セル入力1・2・10を実セルへ接続するよう指定する。
本案は物理セル1→VC1−VC0、セル2→VC2−VC1、セル3→VC10−VC9とする。
VC2〜VC9はIC側で直接接続する。外部セルタップ同士を短絡する指示ではない。

| IC信号 | パッケージ端子 | 接続先（入力RC後） |
|---|---|---|
| VC0 | 16 | セル積層負極、基板上VSSへのRC接続 |
| VC1 | 15 | 物理セル1正極 |
| VC2 | 14 | 物理セル2正極 |
| VC3 / VC4 / VC5 / VC6 / VC7 / VC8 / VC9 | 13 / 12 / 10 / 8 / 6 / 4 / 2 | VC2と同一ネット |
| VC10 | 48 | 物理セル3正極 |

入力RCの値・品番と実コネクタのピン順は未確定。この表はハーネス製造図ではない。
Vcell Mode（0x9304、2バイト）はビット0・1・9を立てる0x0203。
初期値0x0000は「全入力をセルとして扱う」であり、監視OFFではない。
設定0x0007は入力3の短絡を監視し、物理セル3が接続された入力10を対象外にするため不適合。

再現：リポジトリルートで

```sh
python3 software/sim/circuits/check_bq76942_3s_mapping.py
```

異なる3セル電圧を与え、対応と未使用差動入力のゼロを検査した結果はreport.json。
理想接続の検算であり、セルモデル、RC誤差、検出遅延、開線、IC内部動作、実配線は未検証。
未使用NC端子8本は開放候補。その他の48端子全体の処理は未完了。
内部バランスは初期候補では無効とし、設定ビットの確定が必要。
