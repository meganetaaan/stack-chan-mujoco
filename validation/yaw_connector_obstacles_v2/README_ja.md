# ヨーコネクタ周辺の障害部品

左右2ポートずつを現行revBの構造8部品と照合。コネクタ本体の最小距離3.1mmを決めるのは固定ヨー支持部と取付金属板だった。

各コネクタの公称外側面から外向きに10mm、断面はコネクタ包絡の10×9.2mmとする直線の作業空間を仮置きした。全4ポートで固定支持部と約438.998mm³交差し、この作業空間をそのまま確保する案は成立しない。金属板との距離は3.1mmを保つ。

10mmはCodexの検討用予約であり、JSTの挿入ストロークでもケーブル曲げ半径でもない。包絡断面も実ハウジングより大きい可能性があるため、実接続不能の証明にはしない。逆にコネクタ本体だけの交差0を接続可能の証拠にも使わない。

次は実EHR-3嵌合形状を同じ座標へ配置し、干渉するなら支持部の局所逃げを設計する。取付前に挿入できても完成後に線材を挟む場合は不可。支持部を削る場合は荷重経路と強度評価へ戻す。ねじ類・ケーブル・工具全体は今回の8部品比較に含まれない。

v1は近傍距離だけ、v2は作業空間を追加。再現：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/locate_yaw_connector_obstacles.py --step /path/to/XL-XC-330.stp --out /tmp/yaw-port-review
```
