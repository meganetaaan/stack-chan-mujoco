# 胴体接触座に合わせた支持部の変形比較

最新比較アセンブリv2の左支持部（`yaw_rail_seat_v1`）を、変更前の深リブと同じ保存済み荷重・3 mmメッシュ・背面固定条件で評価した。胴体接触面を接着または引張支持にはしていない。接触による荷重分担もモデル化していないため、実組立の変形を保証する解析ではない。

事前計画どおり、最大変位が既存配分0.2 mmを超えた時点で終了した。結果は **0.238077 mm**、変更前 **0.237657 mm** に対し約0.18%増。外力仕事は2.701439 Nmm（変更前2.692463 Nmm）。力残差2.92e-11 N、仕事・ひずみエネルギー整合は合格。形状変更による小差はメッシュ誤差と分離できない。

**判断:** 干渉解消の削除後も0.2 mm配分は未達。局所最大応力の収束を目的とした細分化は実施しない。この計算から実際の部品間隙間が失われるとは断定できず、相対変位を評価する組立モデルが必要。接触支持を加える場合は一方向接触として荷重分担・離間を扱い、固定条件の追加だけで合格にしない。

単一の旧荷重、等方弾性E=1120 MPa、ν=0.35、理想背面固定という限界がある。造形材の許容値、締結の滑り・予圧、最新全荷重、座屈、破断は未確認。#18の完了・製作承認には使用しない。
