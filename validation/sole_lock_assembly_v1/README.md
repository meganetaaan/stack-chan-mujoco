# 別体スペーサー式足裏の組立順序検査

ナット埋込み済みヨークとブーツに対し、足裏をx=8 mmの位置で下から挿入→x=0まで滑らせる→下からスペーサー→下からねじ、の順を検査。左右計160部品対・姿勢チェックで重複0.01 mm³超過なし。全結果とSTEPハッシュをreport.jsonに保存。

これは完成形状の確認だけでなく組立途中の離散姿勢を検査したもの。ただし連続掃引、公差、変形、サーボや他フレーム・配線を含む全組立は未検証。ねじ山をモデル化しておらず、ナットへのねじ込みは円筒包絡の通過確認に限定。工具先端の実製品適合も未確認。

ナット埋込み工程を先に完了し、ブーツ用ねじを固定してから足裏を取り付ける。取外しは固定ねじとスペーサーを除去後、足裏を8 mmスライドして下へ抜く候補順序。取外し時の摩擦・摩耗・変形を保証しない。

次は固定部の負担荷重と締付力を定義し、筒座・ボス・TPU孔・傘保持部の強度を評価する。現状態は製造リリース前。
