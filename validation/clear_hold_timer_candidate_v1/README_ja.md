# クリア保持タイマーの部品候補

TPS3808G01DBVRをCT開放で使う候補を定義した。データシートの遅延12〜28 msを用い、未知のRC定数を仮定した掃引は行わない。主電源の起動期限とは別のタイマーであり、この遅延を正常起動時間の根拠へ流用しない。

MRは「両方の実CLR端子が有効Low」と確認された信号RESET_LOW_VALIDで駆動する。U14への要求信号を直接接続する案ではない。RESET_LOW_VALIDの生成回路は未設計で、この候補もrevIへ未統合。SENSEとVDDは3.3 V系、RESETはCLEAR_HOLD_DONE、CTは開放とする。

MRに10 kΩ±1%の既定Low抵抗を置く。MR内部プルアップ最小70 kΩ、比較電源上限3.393 Vで、無駆動時の抵抗分圧は3.393×10.1/(70+10.1) = 0.427828 V。比較下限電源のMR Low条件0.3×3.207 = 0.9621 Vより低い。外部からの漏れ、部分給電、出力端子開放故障の全てをこの比較で覆うものではない。High駆動時は3.393/9.9 kΩ = 342.73 µAの抵抗負荷があるので、無負荷VOHだけで駆動元を選ばない。

タイマー出力は前回のHighが残っている可能性がある。各要求の前に出力Lowを実際に観測してから、その要求に対応する新しいHighを認めることを契約へ追加した。Lowへ戻る遅延の代表値だけから待ち時間を決めない。CLRのLow保持だけでなく、ARMED／ENABLE_PERMISSION両方のLow、健全電源、次クロックまでの回復時間も別途必要。

部品の遅延規定は100 kΩ・50 pFの試験条件を伴う。実際の負荷と観測経路の成立を確認するまでは、12 msを物理CLR保持の保証として使わない。この検討は候補選択と接続条件の具体化までで終了し、次は観測・要求ごとの再初期化回路を設計する。#24は未完了。
