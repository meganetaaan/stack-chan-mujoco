# Tab5枠：回転慣性を含む荷重配分

## 判断

v1で省略した回転慣性の偶力を追加した。左右旋回記録で最大せん断は1.25437→1.25555 N、軸力絶対値最大は0.16200→0.15968 N。今回の仮定では最大せん断の変化は約0.094%で、固定部の構成を変更する根拠にはならない。局所FEの細分化へ進む理由にもならない。未知の締付け軸力・実造形保持・支持剛性を先に扱う。

## 入力と方法

ユーザー条件、比較密度・重心、支持位置、等剛性配分の仮定はv1を継承。Tab5の重心回り慣性を質量0.1184 kg、12×128×80 mmの均一直方体で近似する。枠はCADの体積慣性に密度1270 kg/m³を適用する。いずれも実測慣性ではなく、インサート・取付ねじ・配線等を含む完成品ではない。

基体姿勢の前後時刻の相対回転から世界軸の角速度を求め、時間微分した角加速度とともに基体軸へ回転する。各部品の重心回り慣性を合算し、支持に作用する偶力`−(Iα + ω×Iω)`をv1の`r×F`へ加える。各重心の並進加速度はすでにv1と同じ位置の2階差分に含まれるため、平行軸慣性をさらに加えて二重計上しない。

最初と最後の各3点を集計から除外する。力・移送モーメント・回転偶力・合計モーメントを別々にNPZへ保存。ピーク成分の時刻を保持し、別時刻の最大値を同時負荷として合成しない。

## 検証と結果

- 任意軸の等速回転と等角加速度回転の解析解に対して、偶力の最大誤差は7.3e-13 Nm未満。
- 主慣性軸加速時の反作用符号、および既知の非主軸回転でのジャイロ項を独立した数値例で確認。
- 6つの単位荷重に対する4点配分の力・モーメント釣合いも照合。
- 回転偶力の最大ノルムは左0.01511 Nm、右0.01555 Nm。最大せん断の発生時刻は両方0.018秒。
- 記録は7000標本、時刻0.001〜7.000秒。v1説明の「3秒」は誤記で、元データに合わせて修正した。

## 限界と終了条件

本追加の目的は回転慣性の省略が配分の判断を変えるかの確認であり、解析解照合と同一記録での比較を終えたため、ここで終了する。新しい物性や支持条件なしに同じ計算を反復しない。

等剛性の最小ノルム配分は保守的上限ではない。古い全身の動作を固定しており最新質量の運動ではない。姿勢差分の誤差・衝撃ピークの未捕捉、実重心と慣性、座面離間、予圧・摩擦・クリープの不確かさを解消していない。材料許容や設計安全率を決定しておらず、1.256 Nを試験合格値にしない。v1で定めた抜け/回転・耳根元・座面・相対変位の評価を継続する。製作HOLD、#17/#18未完。
