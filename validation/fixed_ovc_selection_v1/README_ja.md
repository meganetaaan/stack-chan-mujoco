# 固定クランプ内蔵eFuseの部品適合確認

TPS259472xのOVCSEL開放（公称5.7V）を6V上限のサーボ電源用として棄却する。メーカーSLVSFC9C May 2026 §6.5はクランプ開始最大6.2V、出力クランプ最大6.12V（10mA条件）を規定する。公称値で選ぶと適合判断を誤る。低電流の仕様でも超過するため、追加の過渡シミュレーションでこの構成を通そうとしない。

OVCSEL接地の公称3.8V設定も、現行通常電源4.75～5.25Vの置換としては使用しない。定格5.5Aや電流制限値だけを見て採用しない。入力過電圧時の熱、全負荷での出力、過渡応答、再始動条件の検証へ進む以前に電圧適合を満たしていない。

これはTPS259472の当該設定についての判断で、すべてのクランプ内蔵ICが使用不能という結論ではない。外部FETを使う精密な直列制限方式などは別評価とする。既存のTPS25981構成も未認定のままであり、この棄却により合格へ繰り上げない。

根拠: https://www.ti.com/lit/ds/symlink/tps25947.pdf p8–9。数値は `schematics/power/fixed_ovc_screen.json` に保存。判定基準6Vは変更なし。
