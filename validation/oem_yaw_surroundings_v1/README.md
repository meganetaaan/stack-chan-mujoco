# 純正側面フレームの周辺部品確認

4枚のFPX330-S101と、上面工具穴付き胴体、Tab5、電池/トレイ、変換器、TTL基板、背面板、ヨー連結部、他のフレームを中立姿勢で照合した。対象48組の体積交差は0。既知の支持棚との干渉は別の `yaw_oem_side_frame_fit_v1` に保存し、今回の対象から除いたことを合格化の根拠にはしない。

追加の未達：各フレームと同側ヨー連結部の最小隙間は約0.534242 mm。既存公差予算0.40 mmを引くと残余約0.134242 mmで、基準0.50 mmに未達。4組とも公称0.90 mm基準不合格としてreport.jsonに保存した。他の今回対象は同基準内。

## 設計判断

純正フレームを使うには、支持棚変更に加えてヨー連結部との余裕確保も必要。中立姿勢から不足しているため、現状のまま可動域サンプリングを増やさない。幾何上は少なくとも約0.366 mmの追加隙間が必要だが、これは回転・変形を含む必要切除量ではない。連結部の薄肉化だけで解決せず、連結部の断面と荷重経路を保てる局所形状変更を設計してから動作範囲を検査する。

外形や脚長の拡大が必要という結果ではない。一方、純正部品の採用だけでケース締結から胴体までの荷重経路が成立したともいえない。支持変更・連結部余裕・ねじ/工具・ハーネス・強度が未完で、製造リリースはfalse。

入力STEPのハッシュ、事前plan、対象ごとの距離/体積を保存。姿勢は中立のみ。再現は未使用出力先を指定する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_oem_yaw_surroundings.py --out validation/oem_yaw_surroundings_repeat
```
