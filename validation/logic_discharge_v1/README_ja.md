# 電源再投入時の放電候補

BATTERY_RAW-GNDへ100kΩ、TNPW0603100KBEEAを追加する候補。RTNへは接続しない。電池を接続したまま電源が消える回路ではなく、外部電源を全て切り離した後の放電経路である。共通電源の入力容量や逆流が不明なので、待ち時間を取扱手順として確定しない。

試算前に決めた条件は、初期12.6V、抵抗総合±1%、目標3.5V。目標はメーカーPOR上昇下限3.9V−ヒステリシス上限0.3V=3.6Vを下回るための工学的選択。時間要求はユーザー指定がないため新設しない。一次資料: https://www.ti.com/lit/gpn/tps2660 Table7.5、section9.3.5.1。電圧条件だけではリセット保持時間や再起動の安全性を証明しない。

モデルは C dV/dt = Ibackfeed − V/R。逆流を一定とした場合、平衡電圧Ibackfeed×Rが目標以上なら抵抗だけでは目標へ到達できない。0/10/40µAは診断用の仮定で、実回路の上下限ではない。

結果: R最大101kΩで、3.5V到達には持続逆流が34.653µA未満である必要がある。逆流なしでは容量1µF当たり約0.1294秒、直近コンデンサだけなら約27.25ms。しかしUBEC等の共通電源容量・逆流を含まないのでロボットの再投入待ち時間には使えない。他の回路が消費する電流を有利に仮定していない。

12.6V時の追加消費上限は127.27µA、抵抗損失1.604mW。停止時電池消耗にも加算する。大きな放電能力や短絡保護を持つ部品ではない。

再現:
```sh
.venv-engineering/bin/python software/sim/circuits/size_logic_discharge.py --out validation/logic_discharge_v1
```

終了条件は一つの放電抵抗について、容量当たり時間と許容逆流を算出すること。次は共通入力の容量・逆流経路の統合確認。未選定の回路を実機だけの後続Issueへ移して完了扱いにはしない。
