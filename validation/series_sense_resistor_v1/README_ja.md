# 直列保護の電流検出抵抗候補

[Vishay WSLP仕様書](https://www.vishay.com/docs/30122/wslp.pdf)の注文体系からWSLP25128L200FEA（8.2mΩ、初期±1%）を候補化した。発注可能性・在庫確認前で、回路本体には未統合。

端子を含むTCR±75ppm/Kを使い、25℃基準から仕様記載の-55〜155℃を比較範囲とした。素子単体のTCRを代用しない。この温度範囲はロボット周囲温度の要求追加ではない。

初期公差と温度変化の積を考慮すると抵抗8.039〜8.363mΩ、既存IC比較条件で電流制限5.381〜6.842Aとなる。モデル片脚負荷4.917Aより大きい。検出抵抗損失最大0.376WはP70定格3Wより小さいが、基板放熱や70℃超のディレーティングは未評価。実装の合格とはしない。

旧総合±1%の仮置きは、この部品の全温度範囲には適用できない。保護MOSFETの一定故障電力比較は49.56Wから50.05Wへ増える。後続SOA評価では更新値を使う。経時変化・はんだ付け変化・配線寄生抵抗とIC閾値の適用範囲は未確定。

再現：`.venv-engineering/bin/python software/sim/circuits/select_series_sense_resistor.py --out /tmp/series-sense-review`。
