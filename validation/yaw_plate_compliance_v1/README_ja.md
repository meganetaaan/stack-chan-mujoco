# 外側ポート開口前後の取付板変形比較

目的は金属板の開口による変形増加を調べること。実機負荷での強度合格判定ではない。解析前に plan.json を保存し、左板の新旧形状、2段階メッシュ、2種類の固定条件、面外力・2方向曲げの単位荷重に範囲を限定した。

材料は比較用の等方線形 E=193000 MPa、ν=0.3。メーカー保証値ではない。ねじ軸周辺の上面半径2.5 mmを固定／荷重領域とする。領域は面要素の重心で選ぶため、実効面積はメッシュ依存。全面固定と面外のみ固定を比較するが、これらは実締結剛性の上下限を保証しない。

出力の external_work_Nmm は各単位荷重に対応するコンプライアンスの比較に用いる。応力最大値は補助出力であり合格指標としない。荷重・モーメント保存、自由節点残差、仕事とひずみエネルギーの整合を検査する。細粗メッシュで10%以内の変化を比較採用条件とした。この10%は数値比較上の仮置き基準で、部品の許容変形や安全率ではない。

締結予圧、接触の離間、ねじの柔軟性、樹脂棚の変形、塑性、疲労、材料証明を含まない。片側部品の比較であり全身の強度・干渉確認には代用しない。追加解析は実荷重・支持条件の根拠が揃った段階で別計画とする。

再現（リポジトリルート、未使用の出力先を指定）:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/compare_yaw_plate_compliance.py --out validation/yaw_plate_compliance_reproduce
```

元STEPのSHA256は report.json、比較結果は comparison.json。メッシュは同コマンドで再生成する。

## 結果と判断

24条件すべてで数値釣合い確認を通過。自由節点残差の最大は1.88e-12 N。細粗メッシュによるコンプライアンスの差は最大2.42%で、事前の比較採用条件10%以内。

| 支持仮定 | 面外力 Fz | 曲げ Mx | 曲げ My |
|---|---:|---:|---:|
| 全方向固定 | +2.42% | +4.17% | +0.70% |
| 面外固定＋最小面内拘束 | +2.15% | +3.79% | +0.57% |

数値は細メッシュでの開口前比。変形増加の小さい条件ではメッシュ差と同程度以下のため、細かな増加率を実機の確定値としない。2メッシュは漸近収束・誤差上限を保証しない。板単体の今回の条件に大きな剛性低下は現れず、外側ポートのみの開口を候補として維持する。強度合格・現行組立への採用・Issue完了の根拠にはしない。

次の判断対象は、開口した樹脂支持棚の荷重経路と、実線材の曲げ・保持・挿抜に必要な空間。板の局所最大応力を目的とした追加細分化は行わない。
