# 統合電源ボタン制御ICの一次選別

LTC2950-1を既存の再許可・起動監視回路の置換候補として調べた。根拠は[ADI LTC2950-1/-2 Rev D](https://www.analog.com/media/en/technical-documentation/data-sheets/295012fd.pdf)、電気特性表と注3。2.7〜26.4 V動作、ボタン整形・EN保持・KILL機能を持つ。

起動直後は400〜650 ms（典型512 ms）、KILLとPBを無視する。この時間はユーザーの要求や本機の許容異常継続時間ではなく、ICの固定仕様。したがって、独立停止を含む現回路全体の直接置換は採用しない。KILLへ停止を集約しても起動期間の停止要件を満たせない。

独立ハードウェア停止を残して操作系だけを簡略化する可能性は否定しないが、故障中の操作、起動後の新操作要求、電源喪失、出力既定OFFの適合確認が別途必要。650 msの給電を許可するよう基準を変えない。起動にそれだけのエネルギーを許容できる根拠が未確定のため、この案の回路シミュレーション・BOM追加は行わない。

今回の終了条件は固定の停止無視時間が全置換に適合するかの一次確認まで。現行候補revFと未完了の判定を維持する。
