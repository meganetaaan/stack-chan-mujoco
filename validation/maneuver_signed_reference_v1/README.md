# 現行10軸の後退参照軌道の開発診断

前進用の関節軌道生成器に負の歩幅を与え、学習済み補正なしで実MuJoCoを動かした開発診断。正式な205秒の動作切替評価ではなく、旋回・停止・ばらつき耐性は未検証。受入試験用seedは使用していない。

物理モデルは `assets/r6_mounted_battery`。関節参照と静的重力補償だけを使用し、ルートへの外力や姿勢拘束はない。既存の関節逸脱・自己衝突・転倒・保護停止の検査を残す。固定条件seed310001、24歩、周期0.27秒、制御周期20 ms、計7.48秒。速度は2秒以降の実ルートX位置の直線回帰であり、旋回を考慮したbody座標速度や正式合格判定ではない。

| ケース | 参照速度 m/s | 重心前方オフセット mm | 実行時間 s | 実測X速度 m/s | 結果 |
|---|---:|---:|---:|---:|---|
| forward | 0.10 | 0 | 7.480 | 0.11093971 | 短時間診断完走 |
| backward | -0.05 | 0 | 7.480 | -0.0038299 | 短時間診断完走 |
| backward_m1p5 | -0.05 | -1.5 | 7.480 | -0.0059810 | 短時間診断完走 |
| backward_m3 | -0.05 | -3 | 3.387 | -0.0434512 | self_collision |
| backward_m6 | -0.05 | -6 | 0.000 | None | Analytic IK exceeds configured joint limits |
| backward_p3 | -0.05 | 3 | 7.480 | 0.00096722 | 短時間診断完走 |

後方3 mmでは右膝モータと右足首ロールモータが衝突した。終了時の侵入深さは約0.0167 mm。判定を緩めず失敗として保存した。後方6 mmは逆運動学が1.36秒の参照姿勢で可動域超過を検出し、物理試験を開始していない。重心調整だけで継続後退を成立させたとは言えない。次の検討では歩行周期・姿勢・補正制御と、このモータ間クリアランスを扱う。

## 再現

`docs/REPRODUCE_MOUNTED_ja.md` の手順で元のCAD入力を `outputs/design_r6_base_collisions` に生成する。RL実行環境に加えSciPy 1.18.1が必要。各reportのruntimeに実際のバージョンを記録した。

```sh
python probe_signed_reference.py --cad-design outputs/design_r6_base_collisions --speed -0.05 --com-forward-offset-mm -3 --out outputs/new_backward_probe
```

表の参照速度とオフセットを変更して各ケースを再現する。出力先は毎回未使用のディレクトリを指定する。各ケースにreport、ソーススナップショットを保存し、物理実行ケースには参照軌道、config、MuJoCo積分状態・観測・action・トルクのNPZも保存した。

旧ResidualEnvは+0.10 m/s専用の初期化条件を持つため、本診断は初期化後にcommandを明示的に差し替え、fingerprintに診断用変更を記録する。これは汎用の動作切替インターフェースではなく、このスクリプトで再実行するための診断アダプター。旧factoryから保存configを直接読み込む用途には対応しない。
