# ナット工具の柄と上方進入経路

メーカー公表寸法で軸φ5.7×60 mm、柄φ13×97 mmの包絡を作り、
工具先端をZ91.9 mmから組立最高点より5 mm上まで連続掃引した。
これは工具包絡に限る比較で手の空間は含まない。

完成52部品では全8軸が胴体と接触／干渉し、公称0.90 mm隙間条件を満たさない。
同側支持・取付板・4組のねじ／座金／ナットだけを残した事前組立段階では、
対象座金以外のチェック対象は0.90 mm以上。工具先端と対象座金は0 mm。
したがって両段階とも検査全体の合格はfalseのまま保存した。

この座金との0 mmは、工具底をナット座面に一致させた比較姿勢に由来し、
実工具が座金へ体積侵入する証明ではない。対象ねじ／ナットだけは
未定義ソケット内部と重なるので検査から明示的に除外し、座金は除外していない。
ソケットの入口面取り、ナット掛かり、突出ねじの底付き、先端位置を
実寸法で定めるまで、都合よく工具を浮かせたり座金を除外したりして合格にしない。

組立順は板と支持部を胴体外で先に締結する方向が候補。
完成後の増締めには取外しが必要になる可能性がある。
先締結後の支持部取付経路・反対側のねじ工具・手・配線は未検証。
修正支持部はv6組立の左右支持だけをメモリ上で置換し、元の50部品を保持した。
正式候補への採用やIssue完了ではない。

再現：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_yaw_nut_driver_stages.py --out /tmp/yaw-driver-stages
```

現行CADのねじ先端Z98、比較工具先端Z91.9から、必要な軸方向空間は公称6.1 mm（底付き余裕・公差は別）。ナット上面Z93.5、厚さ1.6 mm、突出4.5 mmとも整合する。メーカー工具資料のソケット深さは未確認なので、この寸法を満たすとの仮定は置かない。
