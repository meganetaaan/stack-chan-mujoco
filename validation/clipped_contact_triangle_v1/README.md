# 部分接触三角形の力・剛性積分

`clipped_contact_triangle.integrate`は三角形頂点の一次隙間をg=0で切り分け、g<0領域の一次形状関数積を積分する。返す力は−k M g、接触エネルギーはk gᵀM g/2、復元力の符号を反転した接線剛性はk M。接触境界でg=0のため、力の一次微分に境界移動項は残らない。初期座標・微小変位の鉛直接触用。

切り分け後の三角形では形状関数積は二次式なので、3点積分で多項式次数として正確に積分できる。これは元の三角形に固定した3点で正負を判定する方法と異なる。丸め誤差や実CAD近似誤差がゼロという意味ではない。

事前許容値: 解析解誤差1e-12、力の中央差分と剛性の差1e-8。基準三角形(0,0),(1,0),(0,1)で一様圧縮、非接触、g=x−1/2の部分接触、全面接触の行列を検証。部分接触の解析値は面積3/8、力合計5/48、エネルギー7/384（k=1）。すべて合格。最大解析値誤差2.22e-16、最大接線誤差2.20e-11。

```sh
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/check_clipped_contact_triangle.py --out outputs/clipped_triangle_check
```

実形状への組立、複数面の投影、非線形反復、メッシュ収束、実接合強度はまだ検証していない。次に既存のmaster/slave重なり三角形へ本処理を適用する。単体検証の合格でIssueを閉じない。
