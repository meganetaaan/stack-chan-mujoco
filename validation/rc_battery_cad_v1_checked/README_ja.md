# 候補電池の公称静的CAD照合

22×60×30mmの箱を旧中心(29,0,80)mmに配置。
現行ヨー支持の組立STEP全体（生成ねじ等を含む）と、出典を持つ個別部品、
旧r9の保持搭載物を比較した。計38比較には組立と個別部品の重複があるため、
38個の独立部品を評価したという意味ではない。

検出した重なり：旧battery_tray 159.6mm³、旧battery_strap_envelope 30.42mm³。
現行ヨー支持の組立全体とは体積重なりなし。他の旧搭載物とも公称箱の重なりなし。
組立位置の判定は組立STEPを優先し、個別出典形状の結果のみで組立を保証しない。

判定：旧トレイ・ストラップ流用は不適合。胴体外形や脚長を変更する前に
22mm厚の電池を保持できるトレイとストラップ経路を設計する。
体積しきい値1e-6mm³は数値上の重なり報告用であり、許容干渉量ではない。

電池公差・膨張・緩衝材・配線出口・端子・取出し経路は未評価。
旧変換器と通信基板を保持した照合であり、新UBEC搭載の証明ではない。
battery_candidate.stepはこの照合用箱で、製作用電池CADではない。

初回実行は在庫表の生成部品にsource=nullがあったため、比較開始前に失敗。
組立STEP全体も読み込むよう修正して再実行し、生成部品を検査対象から落とさなかった。

再現：
```
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_rc_battery_cad.py --out NEW_DIRECTORY
```
