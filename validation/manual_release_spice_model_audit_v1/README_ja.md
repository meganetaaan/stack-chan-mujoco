# メーカー簡易SPICE出力段の適用範囲監査

## 判断

TI SCLM296の簡易SPICEモデルを、HCS11→LVC1G34のエッジ適合判定には使わない。モデルを結果に合わせて修正せず、メーカーIBISモデルによる実負荷評価を次の方法として維持する。

## 証拠

モデルはデータシートから自動生成した汎用ロジックモデルで、25°Cの典型動作を想定している。出力は理想的な内部ステップに、電圧依存抵抗を接続する形式。2 VのHigh側抵抗は1500 Ω。50 pF負荷と導通スイッチ0.01 Ωを含む一次RCの10〜90%立上り時間は約164.79 nsとなる。一方、現行データシートの同じ負荷条件では2 Vの典型9 ns・最大17 ns。モデルの遅延段はエッジ開始を遅らせるだけで、この立上り時間を短くしない。

4.5 V、6 Vも一度照合した。上限以内の点もあるが、モデルの3.3 V抵抗は問題のある2 V値から補間されるため、そのまま定量評価に流用しない。これは実ICの動作不良や、全用途でのモデル無効を示すものではない。

## 再現と限界

https://www.ti.com/lit/zip/sclm296 を取得し、`python3 software/sim/circuits/audit_hcs11_spice_output.py --archive <zip> --out <未作成ディレクトリ>` を実行。ZIPのSHA256、モデルから抽出した抵抗、6比較を保存する。今回は出力段の解析式による監査であり、PSpice全回路実行と称しない。モデル自体の再配布やパラメータ書換えは行わない。
