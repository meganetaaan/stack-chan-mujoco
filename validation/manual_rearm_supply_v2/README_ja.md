# revIの電源負荷集計

現行入口を読む `--current` を追加し、U15とR15を集計した。R1〜R15の全抵抗が集計対象になっていることを確認し、未対応の抵抗が増えた場合は失敗する。以前のrevH参照は履歴再現用として残す。

3.3 V系のIC試験条件付き参照値合計は76.4 µA、抵抗独立上界合計は2.868568 mA。revHとの差はU15の参照値4 µAと、R15による3.393 V / 2.970 kΩ = 1.142424 mAである。5 V系の集計は不変。抵抗をそれぞれ最大電圧で評価するため、直列経路の二重計上と同時に成立しない状態を含む。

これらを足して回路全体の保証消費電流とはしない。U11の入力条件、監視ICの内部負荷、MAX6816の押下時内部プルアップ、充放電、未完成の監視・停止回路、LDO損失等は残る。`qualified_total_current_A`はnullを維持する。R15の追加電流は電源容量に無視できると決めつけず、完全な負荷表へ引き継ぐ。

再現：`python3 software/sim/circuits/audit_manual_rearm_supply.py --current --out /tmp/manual-rearm-supply-v2-check`（未作成の出力先）。v1との差分が追加2部品に一致することを確認済み。元の部品仕様・試験条件と限界はv1のREADMEも参照。
