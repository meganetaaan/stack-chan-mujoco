# ヨーケース固定穴候補と未達条件

図面の16×30 mm軸をメーカーSTEP背面ケースで照合し、左右8軸すべて一致。支持棚Z=88..91にφ2.3 mmの通し穴を設けた候補STEPを作成した。穴径は設計仮定であり、購入ねじ/造形公差を含む適合値ではない。両支持は有効な単一ソリッド。

## ねじ掛かり

メーカーSTEPのケース部品0には四隅の半径0.8 mm円筒が元座標Z=−15..0にある。背面部品2の同軸穴は半径1.0 mm、Z=−19.5..−15。背面入口から4.5 mmはφ2通し部分であり、図面Detail Bの寸法と一致する。

棚3 mm＋背面通し部4.5 mmに対して、指定PHS M2×8 TAPの公称長では下穴へ入る長さは8−3−4.5=0.5 mm。先端不完全ねじや公差を引く前の値であり、有効掛かり長/引抜き強度は保証しない。この締結構成は未リリース。単純に全長を延ばす前に、ねじ座面を下げる構造とメーカー指定のねじ形状・進入限界を照合する。

## 工具経路

半径2 mm、Z=91から上方50 mmの工具予約は、全8軸で胴体と交差（各22.619467 mm³）。他の対象Tab5/電池/トレイ/変換器/TTL部品との今回の経路基準は通る。工具は実品ではないが、胴体を閉じたまま上から直線工具を入れる現在案は不合格として残す。支持とケースを胴体外で組む案には、背面支持締結の工具順序との整合確認が別途必要。

穴位置が確認できたことを固定成立と取り違えない。残る判断はケース固定の座面構造、十分なねじ掛かりの根拠、上面工具アクセス/組立順序、棚穴周辺の強度。追加FEは未実施。

v1は背面入口を半径0.8 mmと誤認したため加工前に停止。failure.jsonに保存し、v2で半径1.0 mmへ訂正した。入力メーカー形状を変更して検査を通したものではない。
