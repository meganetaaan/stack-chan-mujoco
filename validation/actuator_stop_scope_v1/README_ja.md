# 停止・遮断解析のモデル適用範囲

CurrentPositionBankは、構築時の一定電源電圧で端点特性を当てはめた準静的モデル。電流ループの時定数は巻線インダクタンスではなく、蓄積磁気エネルギーを表していない。停止解析へそのまま適用しない。

今回、stepにpower_stateを明示できるようにし、energized以外は状態更新前にNotImplementedErrorとする。構築後のvoltage変更も禁止した。抵抗・逆起電力係数などを旧電圧で当てはめたまま電圧だけ変える矛盾を防ぐ。既存呼出しはenergizedのままで、歩行計算の数式は変更していない。

停止解析に必要な情報:

- Torque Enable=0、内部Shutdown、電源低下・喪失それぞれのブリッジ状態。単にトルクゼロとはしない。
- 巻線電流とインダクタンス、還流・整流経路、制御電源喪失時の遷移。
- 負荷側容量と給電断後の電圧、残る回転・落下の機械エネルギー、個別配線切断。

ROBOTIS XL330マニュアルのTorque Enable(64)とShutdown(63)はトルク停止の設定・動作を説明するが、この情報だけから上記の電流経路や遮断時間を特定できない。参照: https://emanual.robotis.com/docs/en/dxl/x/xl330-m288/#torque-enable64 。XC330を含む全実機状態の解析成立を主張しない。

実機特性が未確定でも、エネルギー収支からの保守的な上限評価は別途可能。ただし「停止時電流をゼロにしたモデル」で吸収量ゼロを得る方法は採用しない。回路の部品選定に必要な範囲を超える未同定モデルの詳細化は避ける。

検証: `.venv-engineering/bin/python -m unittest discover -s software/sim/actuator/tests -v` — 9件成功。未対応状態の拒否が電流・温度・参照位置を変えないこと、電圧の事後変更拒否、既存の両方向電力収支・負荷出力等を確認。これは停止モデルの完成ではない。旧解析のハッシュは当時のdrive.pyを指す履歴として保持する。
