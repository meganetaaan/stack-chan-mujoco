# CLR Low検出の選定前条件

目的：実CLR Low観測を保持タイマーへ渡すためのしきい値を決める。現行の出力保証とラッチ入力仕様を確認し、部品の代表値に合わせた検出器の選定は行わない。

[TI SN74HCS74 Rev D](https://www.ti.com/lit/ds/symlink/sn74hcs74.pdf) p5は負方向入力しきい値の最小を、VCC=2 Vで0.3 V、4.5 Vで0.9 V、6 Vで1.2 Vと規定している。現行3.207〜3.393 Vの連続範囲を単純な直線補間でメーカー保証に変換しない。0.3 Vも現行電源で明示された保証値ではない。

[Nexperia 74AUP1G06 Rev12](https://assets.nexperia.com/documents/data-sheet/74AUP1G06.pdf) pp6–7の−40〜125°Cでは、全電源範囲のVOL最大0.11 Vは20 µA負荷の条件。現行R4=100 kΩ±1%では、抵抗だけでも3.393/99 kΩ = 34.273 µAでこの条件を超える。4入力の比較漏れ4 µAとU7出力漏れ0.3 µAを足す既存比較は38.573 µAになる。したがって、0.11 Vを現行回路のLow上限として検出器を選ばない。従来の0.36 VもVCC=3 V・2.7 mAの規定点であり、全使用条件の実測値ではない。

負荷を20 µA以下とするためR4だけを増やすと、同じ比較漏れ条件で必要な抵抗実値は少なくとも3.393/(20−4−0.3) µA = 216.115 kΩとなる。220 kΩ±1%ならLow負荷比較は約19.879 µAだが、High比較値は3.207−222.2 kΩ×(4+0.3+0.75) µA = 2.08489 Vへ下がる。現行100 kΩの比較2.69695 Vより余裕が減るため、Lowの検査だけを通す目的で抵抗は変更しない。この数値もHigh受信適合を断定するものではない。

今回の調査はここで終了。検出器の採用には、(1)出力Low保証、(2)観測器の誤差込みしきい値、(3)ラッチ入力Lowの成立、(4)追加漏れを含むHigh復帰を同じ条件で照合する。基板の両CLR端子を観測する配線、部分給電、グリッチ、保持時間との接続も残る。メーカー規定点の間を設計仮定として扱うなら、保証値とは分けて根拠・影響・後続確認を記録する。

接続・抵抗・合格基準は変更していない。現行回路の不動作を実証した結果ではなく、検出器を保証値だけから選ぶには証拠が不足するという判断である。#24は未完了、通電保留。
