# revIの抵抗15本の部品候補

R15にTNPW06033K00BYEA（3 kΩ、0603、初期±0.1%、10 ppm/K）を追加した。メーカーのTNPW e3資料の抵抗範囲・E系列・発注コード体系に基づく候補で、在庫・見積は未確認。EAは梱包コードで、部品必要数ではない。

既存14本の値・型番と回路接続は変更していない。既存の温度・一般モード経時比較を含む最大偏差は約0.301%で、接点電流評価の総合±1%枠を維持した。実装温度・複合環境・基板漏れまで保証した結果ではない。全抵抗へ5.25 Vを印加する比較で最大約9.215 mWだが、R15の接続先は3.3 V系であり、この値は実消費電力の予測ではない。

再現：`python3 software/sim/circuits/select_manual_rearm_resistors.py --current --out /tmp/manual-rearm-resistors-v2-check`。全15本の接続と抵抗値を照合する。旧revH用選定表は履歴として維持する。
