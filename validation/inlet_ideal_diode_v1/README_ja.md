# 電池入口の逆接保護：理想ダイオード候補

主電流のヒューズ後にLM74700QDBVRQ1とCSD18540Q5BTを追加した。
ヒューズ出力はCELL_POS_FUSED_RAW、FETのソース側。ドレイン側の
CELL_POS_FUSEDから既存電池保護へ接続する。ENはANODEへ接続。
VCAPコンデンサーはGNDではなくANODE基準。入力100nF、出力とVCAPは
各100nF×2のC0G候補とし、初期公差だけならデータシート推奨最小を上回る。
配置・過渡・実効容量は未適合判定。

単一P-MOSのゲートをGNDへ落とす案は採用しない。出力が正電圧に保持された状態では
VGSが負のままで、入力を逆接してもチャネルが逆向きに導通し得るため。
理想ダイオード候補は電圧差を検出してゲートを制御するが、その遮断過渡を今回証明していない。

## 今回の確認範囲

ピン対応とソース／ドレインの向き、VCAP基準、直接配線による迂回がないことを検査した。
VGS4.5V・25°CのデータシートRds最大3.3mΩを仮に適用した場合、8.6Aの導通損失は
0.244068W。これは高温抵抗、理想ダイオードの電圧調整動作、基板放熱を含まない条件計算。
熱適合や全負荷時の損失上限とはしない。

入力−12.6V、保持出力+12.6Vの静的差は25.2Vで、FETの60V定格内。
配線インダクタンスによる過渡や、ゲートを切るまでの逆流は含めない。
TVSと実際の容量・配線を含む過渡評価が必要。

ENをLowにしても正方向のボディダイオードは残るため、主電源遮断や予備充電スイッチには使わない。
セル監視線は別経路となる。入口素子があることをもって、全誤配線・全逆接の成立とはしない。
上流へのエネルギー返送を阻止するため、回生・保持容量の放電先も別途必要。
このIC自体の消費はBQの下流遮断では止まらず、低電圧後の電池消費予算に追加する。

## 残件と終了条件

入力が逆極性・出力に残留電圧あり・セルタップ接続ありの経路を確認し、
実配線の過渡、FETゲート・電圧・熱の限界、TVS、低電圧後の消費を閉じる。
未知の電池内部抵抗で短絡シミュレーションを回して合格とはしない。
部品接続候補の追加までで、#21–24は未完了。
