# 電源基板配置候補と交換経路

v3の配置領域を追加した場合について、Tab5と電池の前方（+X）取り外し経路が基板領域に干渉しないことを確認した。さらにTab5を取り外した状態で、基板・部品領域自身を前方へ引き出す経路を既存7群と比較し、公称干渉がないことを確認。全18比較の最小距離は1 mm。

各部品の境界箱を、初期位置から最も後ろの面がX=69 mmになるまで延長した連続掃引領域を使用。離散フレームでの見逃しを避ける。体積交差がないことが今回の基準であり、公差・変形込みの交換手順合格ではない。

電池の経路では既存の前提（Tab5とベルトを外し配線を切り離す）を継承。この検査は新しい基板による妨害の有無を追加確認したもの。既存部品同士の取り外し手順を新たに証明したものではない。基板自身の取り外しではTab5のみを障害物から除外し、電池・ベルト・UBECなどは残した。

再現：

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_power_board_service.py --out /tmp/power-board-service
```

基板は未配線の配置領域であり、固定具、コネクタ、配線、はんだ面、手や工具の作業空間を含まない。従って、この位置を次の部品配置・取付設計候補として維持する判断に限る。実機の交換性を完了扱いにはしない。
