# BQローカルホストの電源監視候補

**製作HOLD。** TPS3808G01DBVRをホストNRSTへ接続。電池側86部品、全体209部品。
独立停止・監視回路全体や設定ソフトの完成ではない。

一次資料：[TI TPS3808 Rev.N](https://www.ti.com/lit/ds/symlink/tps3808.pdf)、
6.5/6.6/7.3.1/7.3.4および端子表。
MCUのNRST内蔵プルアップ25〜55kΩは
[ST STM32G030 DS12991 Rev.6](https://www.st.com/resource/en/datasheet/stm32g030f6.pdf) Table53。

## 事前の判定条件と設計選択

ユーザー要求は起動・異常時の保護成立。今回の局所的な設計判定条件は、
(1)正常REG1下限3.0Vで復帰可能、(2)MCU動作下限2.0Vより上に下降しきい値がある、
(3)NRSTの静的Low入力条件とRESET負荷の整合、の3点。
これは全体の安全条件や元Issueの完了条件を置換しない。
特にBQとの通信が3.0V未満でも適合するとは主張しない。

既存SYS系のG33版はしきい値がREG1下限より高くなるため流用しない。
G01可変版に上57.6kΩ、下10kΩを使う。外付け抵抗の総変動±1%は設計割当で未認定。
ICしきい値±2%、SENSE電流±25nAを含む16隅点を事前に定めて計算。

| 評価 | 結果 |
|---|---|
| 下降しきい値 | 2.636〜2.842V |
| ヒステリシスを含む復帰上限（保守計算） | 2.927V |
| 正常下限3.0Vとの差 | 72.7mV |
| 下降下限とMCU最低2.0Vとの差 | 636mV |
| NRSTプルアップ合成最小 | 19.96kΩ |
| 3.6Vでの抵抗性吸込み負荷上限 | 180.4µA |
| 分圧抵抗の電流上限（3.6V） | 53.8µA |

NRSTの旧外付け10kΩは、MCU内蔵25kΩとの並列で約7.14kΩになり、
TPS3808の推奨最小プルアップ10kΩを下回る。外付けを100kΩへ修正した。
既存100nF NRST容量は維持するが、この容量を含む停止時間の合格証拠はない。
CT開放のメーカー遅延値は指定負荷条件の値であり、100nF実装に直接適用しない。

## 接続

RESET1→BQ_HOST_NRST、GND2→CELL_B_MINUS、MR3/VDD6→BQ_CTRL3V3、
CT4開放、SENSE5→分圧点。VDDに100nF C0Gを追加。
型番はbq_local_host_candidate.jsonのpartsが正本。
SENSEへの追加フィルター容量は未選定。ノイズ対策と応答遅延を一緒に判断する。

## 次の評価の問いと終了条件

急な電源低下でも、MCUが不定状態になる前にNRSTと独立禁止が成立するか。
解消に必要なのは、実効容量・負荷に基づく電圧降下包絡、NRST100nFを含む応答の根拠、
CPU出力High保持時も禁止できる回路である。これらが揃ってから時間応答を評価する。
包絡と応答上限を裏づけられなければ未合格とし、架空の緩やかな降下波形を追加しない。

今回確認したのは静的なしきい値・負荷。以下は未確認：電源立上り、短い低下、
RESETの低電圧時有効性、NRST実負荷での停止時間、通信適合、独立停止、監視IC故障。
電源監視を追加しただけではBQの設定前BOTHOFF無効やGPIO固着の問題は解消しない。
