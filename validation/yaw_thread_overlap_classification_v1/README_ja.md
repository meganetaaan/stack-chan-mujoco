# 残存12組はタップ下穴とねじ外径のモデル差

対象は統合v4の全1326組検査で正の重なりが残った12組。形状を削除したり、一般の干渉許容量0.01mm³を変更したりせず、生成元に宣言されたタップ下穴との対応を確認した。

元スクリプト `build_yaw_nut_plate.py` はM3×0.5を指定し、実ねじ山の代わりに直径2.5mmの下穴をモデル化している。`build_yaw_backing_keeper.py` はM2×0.4に対して直径1.6mmの下穴を作る。相手ねじは外径3mm/2mmの円柱であり、ねじ山の溝はない。

3mm厚のねじ受け板における期待体積は次の通り。

- M3: π×(1.5²−1.25²)×3 = 6.479534848mm³、左右各4本の計8組。
- M2: π×(1.0²−0.8²)×3 = 3.392920066mm³、左右各2本の計4組。

体積一致だけではなく、各ねじ軸位置にこの環状体をCADで作り、実重なりから環状体を引いた残りと、その逆差分を検査した。全12組で両方向の差分は事前1e−6mm³以下、解析式との体積差も同許容内。従って今回の残存重なりは宣言済みのねじ簡略表現だけで説明でき、無関係な位置の干渉を許容していない。

この分類が意味するのは名目CADでの干渉の説明まで。実ねじ公差、加工、面取りによる有効ねじ長の減少、予圧、ねじ抜け・せん断強度、組立トルクは未検証。下穴のままの部品を製作してねじを通せるとは言わない。M2/M3のタップ加工が必要という元設計条件を維持する。

統合v4は、全静止組合せで未説明の正体積干渉を今回残さなかった。ただしこれは全機体・動作・工具・配線・公差の判定ではない。変形0.203709mmの未達も変わらず、製作可やIssue完了にはしない。

再現:
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/classify_yaw_thread_overlap.py --candidate validation/yaw_integrated_candidate_v4 --out /tmp/stackchan-thread-overlap
```

候補のSTEP、在庫、全組合せ結果、ねじ生成元のハッシュをreport.jsonへ保存。部品/寸法が変わればこの分類を自動継承せず再実行する。
