# 単セル構成の具体的な比較対象

Molicel INR-18650-P30Bを**1S1Pのセル比較対象**に絞る。完成パックの採用品ではなく、既存3S電池BOMは変更しない。メーカー公開データに電流別放電曲線と最大寸法があり、抽象的な単セル仮定から電池・搭載の評価へ進めるための選択である。

確認した仕様の数値・条件・PDF SHAはcell_candidate.json。最大外形Ø18.6×65.2 mm、セル単体最大47 g。公表3000mAhはtyp値であり、ロボットが必要とする負荷時約3.78V以上の範囲で使える容量ではない。公表容量の測定終止2.5Vまでサーボを動かしてよいとは扱わない。

放電30Aは80°Cで打ち切る条件付き記載。高温の筐体内で30Aを連続保証する根拠ではない。DC抵抗17mΩも50%SOCのtyp値で、低残量・低温・寿命末期の最大抵抗として流用しない。23°Cの電流別曲線は比較資料であり、そこから全条件の保証容量を作らない。

[メーカーPDF Version 1.0](https://www.molicel.com/wp-content/uploads/Product-Data-Sheet-of-INR-18650-P30B-80111-1.pdf)を2026-09-22に取得し、表と曲線を確認した。公開資料には参考情報で性能保証を意味しない旨がある。調達対象の仕様・版の確認も残る。

## 搭載と残件

`validation/direct_cell_p30b_geometry_v1`で最大寸法のセル円柱を旧電池中心[29,0,80]mm、長軸Yへ配置。最新比較ヨー固定52部品＋Tab5と静止干渉なし、公称最小距離8.1mm。これは単体セルの空間確認だけで、端子・配線・絶縁・保護・保持具・取り出しを含まない。旧トレイへ置くだけで保持できるとはしない。

次は完成パックとしての端子/保護/保持構成と、その抵抗・電池負荷時電圧・使用可能容量を揃える。セルへ直接配線して試作可能と判断しない。Tab5の別給電、回生受入れ/遮断後の吸収、過充電/過放電/短絡/温度、充電器は未選定。電池購入・加工・メーカー照会は行っていない。

今回の終了条件は1型式の仕様照合と1配置の公称空間確認。容量や電圧基準を緩和せず、未確認パラメータの放電シミュレーションは追加しない。製作保留。
