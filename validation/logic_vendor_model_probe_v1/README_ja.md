# メーカーモデルの互換性確認（失敗）

TI公開モデルの所在とファイルハッシュをreport.jsonに保存。モデル本体は再配布せず、再現時にTIから取得する。

- TPS70933: SBVM571A、Final1.10、2016-01-15。非暗号化PSpiceモデル。起動/逆流/電流制限を扱うが、温度依存と静止/GND電流の入力電圧依存は非対応とモデルヘッダに記載。
- TPS26601: SLVMBY3、Final1.0、2017-01-20。PSpiceライブラリは暗号化。ngspiceへ転用しない。公開説明に温度依存と比較器オーバードライブの制限あり。TINA版の利用可否は未確認。

判定対象はモデル互換性だけ。入力は理想12.6V/100µsランプ、EN開放、出力27.975µF、165Ω負荷。20mA定電流や実際の起動負荷を表すモデルではない。eFuseも未接続。

最初はngspice初期化ファイルが見つからずTABLEモデル、次にスイッチモデルが未登録で失敗。ローカルのanalog/table/xtradevコードモデルを読み込むと解析開始したが、EN関連の特異行列警告の後、7.10588µsで timestep too small により停止。run.logを保存した。プロセス終了コードのみを成功判定にしない。

これは回路の失敗・合格の証拠ではない。ENの結線や負荷を変えて見かけ上通すことはしない。数値モデルが実装条件を扱えない状態なので、当該モデルのパラメータ走査は行わない。対応PSpice/TINAで同一回路を実行する方法か、別の検証可能なモデルへの移行を先に決める。

再現（出力はモデルを含むためリポジトリ外を指定）:
```sh
.venv-engineering/bin/python software/sim/circuits/probe_logic_vendor_model.py --out /tmp/stackchan-logic-model-reproduce
```
60秒で終了しない場合は打ち切りを記録。回路の成立証拠へ昇格させない。
