# メーカーCADによるヨー支持の最終姿勢確認

サーボ挿入経路の検査に先立ち、X330のメーカーCADをヨー軸へ配置した。変換はplan.json、入力ハッシュと部品別交差はreport.json。ケース3部品の包絡は凍結予約形状のX/Y/Z範囲と数値誤差内で一致する。これは配置仮説の整合確認であり実組立校正ではない。

全15部品を含むSTEPでは、左右とも背面アイドラ（index10）、キャップ（11）、背面ねじ（12）が支持棚と交差。交差体積はそれぞれ448.996284、43.904712、32.894897 mm³。全構成の判定は不合格として保存した。

一方、現行案は `software/sim/mujoco/build_yaw_dynamics_candidate.py` に明記された「no rear idler」。この既存の構成に対応するindex0〜9、13、14には、今回の支持形状との体積交差はない。背面アイドラ3部品を取り外すことを新たな合格化の手段として提案したものではない。支持棚へのケース接触・ゼロ隙間を許した体積チェックであり、隙間、公差、ケース固定ねじ、支圧、軸荷重の適合を証明しない。

## 設計判断

現行の片側出力支持候補は、背面アイドラを装着した支持案と混同しない。反対側支持が必要と判断された場合は、棚の穴/受け構造、アイドラ保持、組立方法を再設計する必要がある。荷重許容未確認のまま「両側支持にすれば解決」としない。

この作業では最終姿勢だけを確認し、挿入経路は未評価。既存候補の背面アイドラなし構成で挿入方向とケース固定方法を検討する余地が残る。全STEP構成の挿入掃引は、最終姿勢が不合格なので実施しない。
