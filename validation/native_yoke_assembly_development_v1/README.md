# 実ケース・キャップ・ねじを含む足ヨーク中立検査

新規足ヨークv4を、メーカーSTEPの全15ソリッドと中立姿勢で検査した。左右30部品対の体積干渉は0.01 mm³以下。ホーン2面への接触は意図したものであり、接触面積は前段の検査を参照する。

さらに足首フレーム逃げ形状v4を同じ実部品に照合したところ、左右とも中間ケース55.524 mm³、後ケース17.612 mm³の干渉を検出した。製造上の嵌合として許可した重なりではなく、不成立とする。以前の簡略ケースと実ケースでは軸基準の包絡が異なるため、フレームのケース支持部を再設計する必要がある。

メーカー座標の登録はx=Z−3.5、y=−X、z=−Y。足首フレームはピッチ座標からロール座標へ(26,0,10) mm移動して検査する。入力ハッシュ、対象部品名、距離、重なり体積を保存した。メーカー内部部品同士の接触を今回の合否には使わず、設計側ヨーク／フレームと各部品との干渉を対象とした。

この検査は中立姿勢のみで、公差・弾性変形・軸回転・配線・新規フレーム用M2ねじを含まない。STEP内のねじは図面部品であり、実採用のねじ長さを確定するものではない。機構全体の合格や可動域拡大を意味しない。

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" \
 .venv-engineering/bin/python software/sim/structural/check_native_yoke_assembly.py \
 --out outputs/native_yoke_assembly_repeat
```
