# 電源部品の部分置換質量

旧電池103g・旧変換器20g・旧トレイ6.9038gを引き、候補電池76g・
UBEC36g×2・新トレイ推定7.8369gを加えると、差は+25.9331g。
旧ストラップはこの差の対象外で、新ベルトへの置換もまだ計算していない。
TTL、固定具、保護基板、追加配線等も対象外。全身質量や下限ではない。

同じ対象の一次モーメント差も保存した。
X方向−0.00175594kg m、Z方向+0.00424082kg m。
質量差だけを既存モデルの重心へ足す方法では、後方・上方への配置変更を表せない。
電池とUBECの重心はケース中心という仮定、トレイは均一な実体密度の推定。
UBECの公称重量に含まれる配線の分布も不明なので確定慣性には使用しない。

元の全身モデルは変更していない。新部品の重心・慣性と残る質量項を確定してから
一括置換し、全身荷重を再取得する。旧予約を残して追加する二重計上を避ける。

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/estimate_power_payload_delta.py --out /tmp/power-payload-new
```
