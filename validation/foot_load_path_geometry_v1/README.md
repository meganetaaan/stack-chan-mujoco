# 足部の実接触面と荷重経路

左右の候補CADを同じankle_roll座標で照合した。足裏とヨークはz=-19 mmで4047.892 mm²接触。ブーツとヨークはz=-16 mmの4座面で計96.478 mm²接触。ブーツと足裏は3 mm離れ、直接接触しない。いずれも体積重複なし。

したがって床の圧縮荷重は主に足裏→ヨーク底板→ヨーク耳→サーボホーンへ伝達される。足首合力をブーツの4本のねじに全量配分することは、この形状の荷重経路を表さない。ブーツは自身の慣性・接触外力・締付力と、ヨークの変形に伴う反力で評価する必要がある。

この結果は名目形状の確認であり、接触圧・摩擦・滑り・強度を証明しない。足裏の引張保持・せん断伝達・交換可能な保持機構は未設計。足裏をヨークへ接着したと仮定して強度や干渉の合格扱いにはしない。

次の構造評価では、ヨーク全体にホーンからの入力と足裏からの分布反力を与え、慣性を含む釣合いを確認する。接触位置が変化する歩行では床反力分布を動力学モデルから取り出す必要がある。足首合力だけでは局所圧力分布は一意に決まらない。
