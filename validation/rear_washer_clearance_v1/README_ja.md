# 後部ワッシャーの首下逃げ案

現行内径3.2mmの角穴縁形状では、SNS-M3-16の首下径da最大3.6mmに対して着座を証明できない。標準寸法の市販ワッシャーへの交換だけでは、この問題は解消しない。

加工候補SCW-YAW-REAR-WASHER-01を8点生成した。SUS304、外径7mm・厚さ0.5mm・配置は旧形状を維持し、内径を3.7mmへ変更。提案公差は内径3.7〜3.8、外径6.95〜7、厚さ0.45〜0.55mm、半径方向の面取り量最大0.05mm。これらは調達先の保証値ではない。

同心状態で首下径に対する半径隙間0.05mmを確保する。最小頭径と最大穴径・面取りを使う投影重なり面積は10.283mm²。頭下面の実際の有効座面や偏心は未評価であり、保証接触面積・耐力とは扱わない。首下丸みを架空の円弧で仮定することは避け、既存部品仕様のda上限で逃げを定めた。

8点の公称質量合計0.880g（既存SUS304参照密度7930kg/m³）。前段の未割当てワッシャーに追加した比較小計661.229gは全胴体質量ではない。各CADの体積を解析式と照合し、旧包絡の部分集合であることを確認したため、この公称形状の穴拡大で新しい外部干渉は生じない。公差時の干渉は別途確認する。

製造・組立承認は保留。加工可否、厚さ公差込みの軸方向積層、ねじかかり、座金曲げ、実座面、締付け・接触圧を確認する必要がある。主組立CADとMuJoCoは未更新。
