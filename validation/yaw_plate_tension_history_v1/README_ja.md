# 保存荷重全体の板―棚間引張り伝達下限

38ケース×7000サンプル、合計266000サンプルを静力学で確認。開発条件を含む既存bolt_group_v1の全記録が対象であり、最新設計で成功した歩行だけの集合でも、実機最悪条件の保証でもない。

圧縮接触域は孔や逃げを埋めた外接長方形、引張り側は4本の支持ねじ軸の凸包とする。これは実接触より有利な緩和モデル。法線力Fzと曲げMx/Myについて必要な合計引張りTの最小値を、圧縮力C=Fz+Tと両長方形の一次モーメント範囲から計算する。各ケースの最大下限、Fz最大、Fz最小サンプルで線形計画との一致・釣合いを確認した。

## 全身荷重ケース

| 保存走行 | 支持側 | 最大の必要引張り下限 N | ピークを決める引張り列 |
|---|---|---:|---|
| fullbody_load_left | 左 | 8.988 | Y=36（外側） |
| fullbody_load_left | 右 | 9.358 | Y=-36（外側） |
| fullbody_load_right | 左 | 9.390 | Y=36（外側） |
| fullbody_load_right | 右 | 9.038 | Y=-36（外側） |

全記録の最大はfullbody_load_rightの左支持、時刻2.663秒の9.3895 N。前回の時刻2.661秒の9.309 Nを全履歴の代表最大とは扱わない。全記録中226791サンプルで圧縮のみでは不成立となる。全身荷重ケースだけでは、各7000サンプル中4317〜4909サンプルで引張り経路が必要。

表の列は理想下限を支配するモーメント条件から特定したもの。各ねじの実分担や、外側列だけを評価すれば十分という意味ではない。内側列、せん断・ねじり、座面とナットの保持、板の曲げ、接触離間、予圧のばらつき・クリープも残る。

## 設計判断

外側の2本のねじと保持部を含む引張り経路を、金属板・樹脂棚の接触モデルに明示する。9.39 Nをねじの設計荷重上限や締付け力として指定しない。最新質量の負荷履歴、締結剛性、実際の接触域、材料許容値なしにIssueを完了にしない。従来の分布荷重FEは比較として残し、実締結の強度証拠にはしない。
