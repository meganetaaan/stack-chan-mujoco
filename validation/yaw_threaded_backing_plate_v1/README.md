# 背面支持締結のねじ付き金属板候補

内側の座金0.5 mm＋4個のナット2.4 mmに代えて、厚3×幅22×高さ32 mmのねじ付き金属板を左右各1枚設ける。座面X=−53.5、前面−50.5、M3×0.5を14×24 mm配置で4箇所。ケース位置と支持背面ボルト配置は維持。既存M3×16なら座面−64.7から先端−48.7で、板前方へ公称1.8 mm突出。3 mmの板厚は有効ねじ掛かりの保証ではない。

従来の4個の内側ナットを個別に工具で保持する工程を、共通板の保持へ置換する構成。中央M2×0.4穴は別の仮保持ねじ用予約。支持側の穴/座面、ねじ長、工具アクセス、脱落防止はまだ設計していない。主M3ねじを締める前にこの板が落下/回転しない構造が必要で、中央穴を作っただけでは保持成立とはしない。

荷重経路：背面M3ボルト→金属板のねじ山→金属板座面→支持背面。回り止めも金属板へ移すが、最初のねじを掛けるときの反力と位置拘束を仮保持部で受ける必要がある。樹脂だけのナットポケットの強度を根拠なく仮定しない。

左右2板は有効単一ソリッド。支持との接触を許した体積チェックと、今回の周辺部品（ケース予約、連結部、電源、Tab5、電池、取付板）との公称隙間0.90 mmチェックは計22組で基準内。実ねじ頭/配線、完全な脚、組立経路を含む全身干渉証明ではない。

材質・ねじ精度/不完全ねじ・抜け許容・座面圧・金属板曲げ・支持クリープ・ねじロックは未確定。CADはφ2.5/φ1.6の下穴を表し、実ねじ山を持たない。製造図にはM3/M2のタップ指定とねじ公差を別途確定する。製造リリースはfalse。

次は中央仮保持を具体化して背面からの組立を確認し、成立後に材質とねじ山強度・支持座面を評価する。同じ内側工具包絡の追加掃引は不要。
