# ヨー支持部の変形集中領域

既存6単位荷重解を使い、38個の直接評価済み荷重のうち変位最大のケースを後処理した。新規FE計算・メッシュ細分化・基準変更は行っていない。

| 要素重心のX位置 mm | ひずみエネルギー割合 |
|---|---:|
| -50未満（後部） | 17.90% |
| -50以上-30未満 | 20.20% |
| -30以上-10未満 | 19.89% |
| -10以上（前端側） | 42.00% |

要素を重心で分類するため区切り面に厳密な体積切断ではない。区切りは診断用で合否基準ではない。
全体エネルギー1.061669 N mmと外力仕事の半分は相対誤差3.8e-13で一致。
最大変位0.220130 mmは前端X=11.6 mmで生じた。0.20 mmの割当を満たさない。

次の設計変更は前端棚板と側板・クロスウェブの接続断面を優先する。
後部固定面だけの増厚を主対策とする根拠は弱い。エネルギー割合は
形状感度ではなく、前端だけの増厚で合格するという意味ではない。
変更前にねじ・工具・回転部の占有空間を除外し、外形を維持する。
変更後は同じ荷重で一度比較し、0.20 mmを超えれば細分化せず形状案を棄却する。
通過時だけ既定の2 mm比較と全荷重評価へ進む。

E=1120 MPaの等方性仮定、理想固定、接着相当の荷重分配を継承。
実締結・印刷材料の強度・最新質量・全時刻での最大値は未証明。
TPUを荷重支持部へ置換する判断には使わない。製造承認・Issue完了の証拠ではない。

```sh
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/structural/diagnose_yaw_strain_energy.py --out /tmp/yaw-energy-check
```
