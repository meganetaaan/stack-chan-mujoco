# 金属取付板の端距離改訂

板を42×30から45×33 mmへ拡大。四隅穴中心の端距離は2→3.5 mmとなり、φ6 mmの剛体座金候補の半径3 mmに対して公称0.5 mmの縁余裕を持つ。これは公差・強度の合格ではない。サーボ位置、ケースねじ座面Z=89と名目下穴進入2.5 mmは維持。

板は各11.6141 g（仮密度8000 kg/m³）、単一有効ソリッド。支持の下面ポケットは前端へ開くため、保持は別の4本の通し締結に依存する。ポケットだけで脱落防止とはしない。

再現は `build_yaw_metal_seat.py --wide-plate --out <新規出力先>`。フラグなしは旧v1寸法を再現する。材質、板厚公差、ねじ座面、板曲げ、棚引抜きは未確定。金属板/支持の現行比較候補はv2、v1は端距離比較の履歴。
