# 内部TPU突起による足裏保持候補

各足4点、軸半径2.8 mm・ヨーク穴半径3 mm・傘半径4 mm・傘厚1.5 mm。傘下面z=-15.8 mm、ヨーク上面z=-16 mmに名目0.2 mmの遊び。外形86×48 mm、接地z=-22 mmを維持し、内部へ突起を追加する。接着なしで引張・せん断荷重経路を得る候補であり、強度成立は未証明。

左右とも単一有効ソリッド。ヨークと足裏、ブーツと足裏の体積重複なし。各足TPU追加616.858 mm³、ヨーク除去339.292 mm³。既存ブーツねじ・頭部ポケットは維持。

メーカーサーボSTEPの全15ソリッドを既存変換（軸(-1,1,-1)まわり120度、移動(-3.5,0,0) mm）で照合した中立距離は最小4.8 mm、体積干渉なし（servo_neutral.json）。全可動域・フレーム・工具アクセスは未検証。

組立候補はブーツ締結後、下からTPU傘を穴へ押し込む。直径8 mmの傘を直径6 mmの穴に通すため大変形が必要で、押込力・局所ひずみ・疲労・クリープ・引抜力・公差を解析するまで組立可能とは認定しない。筒軸と穴の0.2 mm遊びにより荷重開始時の微小変位も評価する。取外し時の工具到達も未設計。

```sh
export LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu"
.venv-engineering/bin/python software/sim/structural/build_sole_retention.py --out outputs/sole_retention_repro
```

次は傘の挿入力・抜け荷重を局所非線形モデルで評価し、困難なら分割クランプ等へ変更する。現候補の穴追加はヨークの全体強度再評価を要する。Issue #20は未完了。
