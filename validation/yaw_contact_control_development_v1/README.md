# 接地中断・横揺れの開発診断

事前の接触・着地・運動基準を変更せず、接地中断の原因を調べ、指令参照の時間配分を比較した。正式受入シードは使っていない。すべて同じ仮配置の12軸モデル `assets/r7_yaw_xc_ankles_v1` に対する開発結果。

## 得られた結果と限界

- 旧参照で5秒に停止していたランダムシード310613は、重心移動／遊脚／整定の時間配分を35/55/10%から25/65/10%にすると、32秒を安全に完了した。
- 前進周期0.30秒、後退・その場旋回周期0.32秒、定常COM inset25.9 mmの混合周期では、開発6シード310611〜310616すべてが32秒の全5区間の運動基準と着地要件を満たした。
- 同じ混合周期の固定条件205秒では、転倒・自己衝突・関節逸脱・保護停止なく完走し、全移動区間の着地要件を満たした（左右292/292回）。ただし `10_forward`, `12_forward`, `21_arc_left`, `22_arc_right` の横速度RMSEがそれぞれ0.03026, 0.03062, 0.03097, 0.03121 m/sで、閾値0.030を超えた。全体は不合格。
- 固定20/20・ランダム化18/20は未実施・未達。32秒の成功率を205秒の成功率へ読み替えない。開発シードは複数条件の調整に再使用しており、独立な受入標本ではない。

## 診断の内容

`yaw_contact_ms_310613_v1` は荷重・足裏高さ・滞空時間・接地確認時間・有効着地を1 msごとに保存する。十分な滞空後も荷重が0.35 Nを1〜2 ms下回り、40 msの連続接地確認が解除されていた。初期化や評価の閾値を緩めていない。

| 比較 | 結果 |
|---|---|
| 遅延・ノイズ付き姿勢補正5条件 | 旧参照の開始時中断を解消しなかった |
| 足首速度減衰0.08/0.10/0.13/0.16 Nm s/rad | 同じく開始時中断 |
| 積分刻み0.5/0.25 ms | 同じく約5秒で中断。単に細かくしても解消しない |
| 重心移動比率25/30/40% | 25%のみ8秒完了。30/40%は5秒で中断 |
| 25%、周期0.32秒、inset25.5 mm | 32秒の開発6シードは全て物理異常なし。ただし3シードで前進横速度基準を超過 |
| inset25.9 mmへ変更 | 比較した固定条件・2ランダム条件の32秒は基準内。ただし有効着地回数が減る条件がある |
| 全動作を周期0.30秒 | 前進は改善、後退の横速度基準を超過 |
| 動作別の混合周期 | 上記の6/6短期結果。205秒は4区間の運動基準が未達 |

初回の0.5 ms試験では有効モータ遅延11 ms、0.25 msでは11.25 ms。遅延の刻みへの丸めも記録しており、すべての数値が厳密に収束したという主張ではない。採用する積分刻みは引き続き1 ms。

姿勢オブザーバは20 msでサンプリングし、既定20 msの遅延、重力方向推定のノイズ、ジャイロのノイズとバイアスを含む。制御に使うのは6値だけで、世界位置・速度・ヨーの真値は渡さない。ただし重力方向は姿勢推定器出力の仮定であり、生の加速度計や加速度除去フィルタの再現ではない。実機同定が必要。今回の混合周期の成績では姿勢補正・学習済み方策・足首減衰変更を使っていない。

`yaw_contact_comparison_v2/landing_comparison.png` とPDFは同じランダム物理条件の右足を比較する。旧試行は5秒で終了するため、それ以降の線は描かない。新条件でも最初の右着地は棄却され、次の右着地が5.099秒に確定する。それ以前の左着地が歩行中断を防いでいる。

## 再現

CAD元データ・MuJoCo環境は既存の再現文書に従う。出力は未使用のパスにする。

```sh
python generate_yaw_maneuver_reference.py --cad-design outputs/design_r6_base_collisions --design assets/r7_yaw_xc_ankles_v1 --out outputs/new_mixed_ref --shift-fraction .25 --steady-inset-mm 25.9 --period .32 --forward-period .30
python probe_yaw_dynamics_candidate.py --design assets/r7_yaw_xc_ankles_v1 --reference outputs/new_mixed_ref/reference.json.gz --protocol configs/maneuver/acceptance_v1.json --out outputs/new_mixed_trial --duration 205 --static-torque-scale 1 --yaw-kp 6 --yaw-kd .13
```

32秒の比較は生成・実行の両方へ `--duration 32`。ばらつきは実行へ `--randomize --seed 310613` 等を追加する。詳細荷重記録は `--record-contact-trace`。刻み比較は `--physics-dt-s .0005` または `.00025`。姿勢比較は `--attitude-gain .2 --attitude-rate-gain .01 --attitude-axes roll` など。いずれも診断用で合格済み設定ではない。

記録した状態を再生する場合：

```sh
MUJOCO_GL=egl python replay_yaw_candidate.py --trial outputs/new_mixed_trial --design assets/r7_yaw_xc_ankles_v1 --out outputs/new_mixed.mp4
```

`yaw_phase25_trial32_v1/videos/random310613.mp4` は改善条件の実状態再生。参照・試行・失敗・ソース・ハッシュを収録した。各reportに残るoutputsパスは実行時の履歴で、同名フォルダへ収録している。既定35%参照の先頭8秒は、q/q12/base/support/静的トルクが旧版と完全一致することを確認した。改良パラメータは明示指定し、旧既定を合格設定へ黙って変更していない。

## 機構側の新しい未解決事項

メーカー図面・STEP・慣性資料を取得し、現行ヨー候補の軸がケース長手中心に仮置きされ、実図面の7.5 mm偏心を反映していないことが分かった。取付フランジも未確定。詳細は `docs/X330_MANUFACTURER_REVIEW_ja.md` と `design/x330_manufacturer_reference.json`。この差を修正して質量・慣性・干渉を再検証したモデルで、最終の動作評価を行う必要がある。現在の成績は製作適合の証明ではない。
