# 背面板統合後の上半身締結・工具確認

`yaw_plate_stack_integration_v1` の外側締結部品−0.20 mm修正を、胴体候補、四隅締結、Tab5、電池/電源予約、ヨーサーボ/連結部の既存CADに照合した。入力STEPのハッシュと1,248組の検査はreport.jsonに保存。

- ねじ・座金・ナットの対象干渉：0。
- 完成状態の工具経路：10組不合格。左右ナット工具とヨー連結部4組、ヨーサーボケース4組、変換器2組が交差する。
- サーボ/連結部・変換器・TTLインターフェースを取り付ける前の状態：対象工具不足0。既存の公称隙間0.90 mm（仮公差予算0.40＋残余0.50）を保持した。

## 組立への判断

左右支持を背面板へ先に締結し、その後にヨーサーボ/連結部・電源部品を取り付ける順序が候補。完成状態での増締め・取り外し性は不合格として残す。組立順序を変えただけで完成状態の10組を合格に読み替えない。

この検査は後付け部品の挿入経路や固定ねじへの工具到達を証明しない。次はその後付け工程の成立を確認する。メーカーサーボ形状との照合、実ソケット空洞/かみ合い、配線、脚の可動域、締付け後変形も未確認。工具包絡は既存の簡略円柱であり、製造リリースではない。

同じ対象の再掃引は不要。新しい実部品や後付け工程で矛盾が出た場合に限り再検査する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_integrated_yaw_access.py --out validation/integrated_yaw_access_repeat
```
