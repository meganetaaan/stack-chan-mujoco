## 判断に必要な数値

3個の局所COUTが必要実効75µFを満たすには、同じ条件で1個平均25µF以上が必要。公称141µFに対する総残存率は53.19%以上。

旧資料の初期下限と温度特性を独立乗算する**感度比較**では、141×0.8×0.85=95.88µF。残るDCバイアス・経時等の合成残存率は75/95.88=78.22%以上を要する。ただし独立乗算がメーカー保証の合成法とは未確認であり、この95.88µFは保証下限ではない。型番別DCバイアス曲線の典型値だけを掛けて合格へ昇格しない。

最低でも分圧比較の上側5.08813V、設計上の通常上限5.25V、温度・経時・初期公差・測定条件を覆う実効容量の根拠が必要。異常時6Vへの耐圧確認と、通常時の制御ループ容量確認は別に行う。10V定格という表示は容量残存率の保証ではない。
