# 足部候補の質量予算

6部品のCAD体積と明示した密度仮定で片足54.459 g、左右合計108.917 gと試算。ねじは単純円柱CADの体積から計算せず、NBK SLH-M2-10の公称0.23 g/本を使用。樹脂1270、TPU1200、ステンレス8000 kg/m³は計算仮定。造形インフィル・実重量・材料保証ではない。

外付けナットへの変更そのものは、閉室の充填と8→10 mmねじの差で各足約0.0748 g増。これは直前の閉室候補からの差であり、凍結MuJoCoモデルからの差ではない。ナットの位置が上がるため、小さな質量差でも重心/慣性の更新は別に必要。

サーボ・ホーン締結品・配線・接着材を含まない。既存mass_budget.jsonのbase質量を機体総質量と混同せず、今回の足部推定値を古い機体総質量へ単純加算しない。古い足部のどの質量を置換するか確定してから全身を更新する。

結論：外付けナット化の局所質量増は小さいが、現候補全体への旧荷重の適合は未証明。材料と部品構成を固定する前に質量を仮定して歩行解析を追加しない。強度/動作の元荷重を使用する箇所には旧設計由来と明示する。
