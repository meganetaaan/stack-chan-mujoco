# 足首ロール連続回転の局所隙間下限

v4フレームを使い、±0.32 radの全区間を評価する。各移動部品のX軸からの最大半径RをCAD外接箱から保守的に求める。区間中央の距離d、角度半幅hに対し、剛体回転の移動量はR*h以下なので全区間の距離はd−R*h以上。下限が足りなければ区間を二分する。

判定前に1.1 mm＝残存0.5＋両面公差0.4＋相対変形予約0.2 mmを要求し、数値保護量1e-5 mmも差し引く。変形0.2 mmは予算であり、変更した足首のFEがその範囲内と確認した値ではない。

左右各4組、計8組について全区間で要求下限を確認した。足ヨーク対フレームは各16区間、ブーツ対モータは各4区間、靴底対フレーム／モータは各2区間で証跡を保存した。

不成立の移動部品対:

- 足ヨーク対モータ軸包絡体: 0.884590 mm。
- ブーツ対フレーム: 1.100000 mmのサンプルがあり、数値保護量を含む基準に余裕なし。これは1.1 mmより明確に小さいことを示す結果ではなく、保守的な合格根拠がないという判定。

固定フレーム対モータは元形状・v4とも距離0、重なり体積0。変更で新たな体積干渉は生じていないが、取付面の可能性があり、単なる隙間基準で合格にできない。実際の締結面・予圧・支持剛性を別途定義する必要がある。

全体は未合格。脚全体、床、反対足、ハーネス・締結部品は対象外。可動域拡大や製造を承認する結果ではない。ソフトの関節範囲も変更していない。

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" \
 .venv-engineering/bin/python software/sim/structural/certify_ankle_roll_clearance.py \
 --gimbal-dir validation/ankle_gimbal_relief_development_v1/v4/cad \
 --limit-rad .32 --out outputs/ankle_clearance_bound_repeat
```
