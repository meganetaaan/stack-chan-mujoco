# 電池中心の並進荷重推定

元scene.xmlのbaseはfreejoint、電池中心はbase内(29,0,80)mm。
run_probe.pyは全qposを記録する。左右履歴各7000点、間隔1msを確認した。
候補電池76gを同じ位置で元の運動に追従させた推定であり、全身の再計算ではない。

世界座標の中心p = base位置 + R×中心を二回差分し、電池から取付部への力を
R転置×m(g−pの加速度)で計算。静止時は重力、自由落下時は0となる符号規約。
差分は各段で二次精度端点処理、判定から両端2点を除外。
回転による中心の並進加速度は含むが、電池自体の回転慣性モーメントは含まない。

最大1.661489Nは左右とも0.016sで、開始直後の応答。
同時刻の3成分を保持し、別時刻の成分最大を組み合わせていない。
このピークを旋回の定常荷重や最悪停止荷重と呼ばない。
差分誤差、サンプリングで失う衝撃、元質量との差が未評価。
保持の合否基準やベルト必要定格ではなく、追加照合が必要な荷重入力。

再現はリポジトリルートから:

```sh
.venv-engineering/bin/python software/sim/structural/estimate_battery_translation_load.py --out /tmp/battery-translation-new
```

次に回転モーメント・荷重の方向別負担、開始区間と旋回区間を確認し、
停止ケースと更新質量での荷重を補う。今回の推定で#5を完了扱いにしない。
