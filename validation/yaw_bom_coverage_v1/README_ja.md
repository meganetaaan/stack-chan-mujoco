# ヨー組立と製作候補BOMの数量照合

現行revAの52部品を10種類のBOM項目へ一度ずつ対応付けた。従来の一覧は足裏の締結数だけを記載していたため、SLH-M2-10を14本（足裏2、ヨー取付8、裏板仮保持4）、PTS A56202を10個（足裏2、ヨー取付8）へ修正した。前回修正したスペーサー10個も同時照合した。

胴体外装1、左右ヨー固定支持2、SUS304取付板2、背面M3座金8のBOM行を追加した。背面座金は材質・面取り・型番未選定として記載し、寸法だけの行を購入可能な部品と扱わない。造形部品も材質・方向・工程の確定前である。

機械的な数量照合に合格したことは、製造リリースや全ロボットBOM完成を意味しない。対象CADに含まれないサーボ・ホーン・ケース用TAPねじ・胴体隅固定ねじ・脚・その他足部品・電装配線・工具・予備・試験片は別途必要。部品仕様や締付け・工具アクセス・保持能力の未確認事項も残る。

再現：`python3 software/sim/structural/audit_yaw_bom_coverage.py --out /tmp/yaw-bom-coverage-check`（未作成の出力先）。部品名による対応を一対一で検査し、組立数量に別途明示した足裏共用数量を加えてBOM値と比較する。対応漏れ・二重対応・数量差は失敗になる。入力のSHA-256を保存する。
