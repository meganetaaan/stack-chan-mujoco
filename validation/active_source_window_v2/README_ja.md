# 現行回路へ結び付けた電源電圧条件

currentポインターが示すrevMについて左右のeFuse OV分圧35.7 kΩ/10 kΩ・初期公差0.1%、電源窓監視UV102 kΩ/10 kΩ・OV130 kΩ/10 kΩ・総合公差仮定1%を確認。参照した既存しきい値計算と実装値を照合した。eFuseの各静的コーナー式も再計算した。

通常電源目標4.75〜5.25 Vは設計仮定。最初にOV検出し得る静的比較値は5.362365 Vで、古い5.175695 Vではない。電源窓監視器だけのOV復帰下限5.316446 Vは、回路全体の復帰条件とは区別する。部品・抵抗・漏れ電流の適用条件、OVLO故障時入力範囲、遅延とサーボ端子過電圧は未解決。

既存OKL-T/6-W12比較の典型過渡±0.45 Vを同じように適用すると、損失ゼロでも下限を保つ設定電圧は5.20 V以上、通常上限を保つには4.80 V以下となり、範囲は空。OVしきい値だけを上限としても設定電圧は4.912365 V未満となり空のまま。旧回路のしきい値を修正しても、この比較で採用可にはならない。

0.1 V損失の行は、既存4.75 V端子目標にも同じ下限を要求する場合の追加比較。いずれの損失値も実配線保証ではない。±0.45 Vも資料の特定条件の典型値で、実ロボットや最悪条件を保証せず、モジュール自体の故障を意味しない。基準変更・部品採用・回路変更は行っていない。

```sh
.venv-engineering/bin/python software/sim/circuits/audit_active_source_window.py --out validation/active_source_window_reproduce
```

出力先は未使用のものを指定。v1は既存レポートのキー名を読み違えた実行エラーで、回路結果を含まない。v2に修正後の計算を保存した。
