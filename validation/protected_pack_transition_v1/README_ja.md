# 保護済み電池への移行：現行接続から求めた変更範囲

## 結論

LB-020を使う場合、旧セル保護回路を単に削除して給電してはいけない。現行250部品からBAT領域100部品と信号絶縁器/専用デカップリング3部品を除くと147部品が残るが、これは動作回路ではない。以下の接続と制御機能を置き換える必要がある。正式回路は変更していない。

| 途切れる経路 | 現行の役割 | 移行先で必要な設計 |
|---|---|---|
| CELL_POS_FUSED → PACK_POS_PROTECTED | BQ制御の主保護FET | ヒューズ・逆接保護後から分岐への経路と故障遮断の分担を確定。勝手に直結しない |
| CELL_B_MINUS → PACK_RETURN | 電流検出シャント | パック出力負極と系統基準の接続を定め、入力電流検出の要否・代替を判断 |
| BQ_CTRL3V3 / BQ_AUX_START_REQUEST | BQ側制御電源・起動要求 | PACK_RETURN基準で動く独立制御電源と起動許可回路 |
| SYS__LOGIC_START_ALLOW | 絶縁器からロジック電源保護のSHDNへ | 削除後はR_LOGIC_SHDN_SERの入力だけが残る。未接続や常時Highを解決策にしない |

各経路の残存ピン・除去ピンはreport.json。明示された接続を列挙したもので、IC内部の導通・漏れ・異常動作を解析していない。

## 残す機能と代替の完了条件

1. パックPCM復帰・電源瞬断後もサーボを自動再始動しない。既存の分岐停止/手動復帰に加え、削除したBAT側の起動ラッチ・監視の役割を対応付ける。
2. 起動要求元が無給電・リセット中・異常時はロジック/駆動の許可を出さない。信号をSTOP_AUX電源へ直結する置換は採用しない。
3. パック低電圧警告、Tab5終了要求/確認、給電遮断、再起動待ち時間を系統側で実装する。PCMの未公表閾値を仮定して終了時間が足りるとは判定しない。
4. ヒューズ、逆接保護、各分岐保護、回生電流の行先は引き続き必要。PCMがこれらを代行すると仮定しない。
5. 分岐側の未選定ILIM・立上り部品等は残る。除去部品数を設計完了率や製作可能性へ読み替えない。

今回の境界抽出は終了。次の回路変更は、この表の各機能に実部品とピンを割り当ててから実施する。ロボットへ生セルタップは持ち込まず、充電はパックを外して指定充電器で行う方針を維持する。
