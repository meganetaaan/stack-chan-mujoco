# 方角観測付きPPOの40試行評価

**固定20/20、ランダム化14/20。目標未達。**
事前固定シードは固定97000–97019、ランダム化98000–98019。
いずれも同じ凍結方策・モデルで実行した。全状態・観測・行動・失敗を保存する。

このバッチのランダム化6失敗は、10 m到達時間または前進距離不足によるもの。
この40試行では転倒・自己接触・関節制限・飽和保護停止の終了判定は発生しなかった。
元の20/20・12/20バッチとはランダム化シードが異なるため、成功数の差だけで改善量を推定しない。

方策は `policies/r6_heading_seed20260922`。学習時にノイズ付き外部方角・横位置を観測し、
IMU単独でその推定を実現したとは主張しない。
`manifest.json` は事前固定シード、方策・設定・評価コードのハッシュと両バッチの集約。
各 `*_state_audit.json` と `policy_trace_verification.json` に保存状態・行動の再計算結果を収録する。

この評価のモデルには後から追加した固定クレードル・電装予約の22形状を含まない。
追加候補は `docs/BASE_COLLISIONS_ja.md`。この成績を追加候補の成績に流用しない。

再現は `docs/R6_RL_ja.md` の `run_planned_r6_evaluation.py` コマンドを使う。
次の改善に使った時点で、このバッチを次版の未使用受入データとして再利用しない。
