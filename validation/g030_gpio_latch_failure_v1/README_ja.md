# 出力ラッチの書込み失敗を検出する順序の修正

旧版efd2178に対し、模擬レジスタでBSRR書込みを反映しない故障を与えた。
処理は最終的に失敗を返したが、その前に古いHigh値を持つPA8を出力化した。
「失敗を返す」だけの検査ではこの順序の欠陥を見逃す。

修正はBSRR書込み直後、出力化前のODR読み戻し。
期待するEN Low・CLEAR High・資格Lowと違えば、その時点で終了する。
修正後はPA8がanalogのままで、出力化への書込みを行わない。
100初期状態と2故障ケースをg030_gpio_init_v2で再検査し、Arm向けコンパイルも通した。

この故障注入は実ICで同じ故障が起こることや、実機の誤通電を証明しない。
読み戻し自体の故障、初期化前の状態、外部の給電禁止回路は別の評価範囲。
