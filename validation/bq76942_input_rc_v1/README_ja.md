# 直列化入力フィルタの連成RC応答

目的は入力フィルタ固有の遅れを分離し、抵抗1個×容量だけで検出時間を判断する誤りを避けること。
終了条件は実候補の4経路から連成C行列を作り、正常および各経路の単一C開放・短絡で
各物理セルの単位変化に対する3セル測定差分の応答を再現できること。
電池の負荷降下・残量・内部抵抗は仮定しない。

候補JSONの入力接続を読み、直列中点を合成容量へ縮約する。抵抗は初期公差上限22.1221Ω、
Cも初期公差上限。正常157.5nF、単一開放126nF、単一短絡315nF。
`C dx/dt + G x = G u` を行列指数で解く。各セルの電圧変化はそのセルより上の全タップへ加える。
報告は単位変化に対する応答比であり、実電池へ1Vの急変が発生するという予測ではない。

最遅モード時定数は正常12.3066µs、比較した故障ケース最大18.3629µs。
10/50/100µsで全3セルの差動応答を保存し、隣接セルへの一時的な影響も含める。
時定数はしきい値を横切るまでの時間、収束時間、IC判定遅延のいずれでもない。

```sh
OPENBLAS_NUM_THREADS=1 .venv-engineering/bin/python software/sim/circuits/analyze_bq76942_input_rc.py
```

正常1ケース＋各4経路の開放/短絡8ケース。各バンク内のどの1個が故障しても、同一値理想モデルでは
同じ合成容量になるため等価ケースへ縮約した。部品ばらつき全組合せの走査ではない。
C0Gの温度・バイアス・漏れ、IC入力電流、開線検出電流、寄生、抵抗発熱は含まない。
実部品での全条件保証や保護の合否判定ではない。

追加の任意電池波形を用いた解析は行わず、この入力RC計算はここで終了する。
