# メーカーX330部品識別と足首座標への仮配置

STEPCAFでアセンブリの製品名と配置を読み取り、ケース3部品、出力ホーン、アイドラーホーン、キャップ、ねじ、コネクタを識別した。単純なソリッド列順から部品名を推測せず、インスタンスの参照製品名を記録する。

仮配置はメーカー座標から x=Z−3.5、y=−X、z=−Y mm。メーカー前ケース面Z=3.5を現行簡略ケース前面x=0へ一致させる。この変換は正規の剛体回転＋平行移動で、反射ではない。軸線は一致させるが、最終組立の基準面として承認したものではない。

|部位|仮配置の軸方向位置 mm|
|---|---:|
|前ケース外面|0|
|後ケース外面|−23|
|出力ホーン外端|＋3|
|アイドラーホーン外端|−26|

現行足ヨークの前側内面x=5.6、後側内面x=−31.6と比較すると、それぞれ約2.6 mm、5.6 mmの軸方向隙間が残る。この配置仮定では、現行ヨークはホーン取付面に直接接していない。ねじを長くするだけで隙間を締め潰す構成にせず、耳位置・接続板・スペーサーを荷重経路とともに再設計する。

またメーカーケース高さ方向は本仮配置で[-9.5,24.5] mm、現行簡略ケースは[-10,24] mm。寸法が同じ34 mmでも、回転軸基準の包絡は完全包含ではない。以前の簡略形状の干渉結果を実部品の保証として流用しない。

STEP中にはBTS2_M2_6X8という製品名があるが、別途取得した組立図のアイドラーねじはM2.6×6表記である。CAD名だけで8 mmねじを選定しない。異なる図面版・形状省略等の可能性を残し、取付板厚と有効ねじ込み量を確認して選ぶ。

再現:

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" \
 .venv-engineering/bin/python software/sim/structural/map_x330_components.py \
 --step validation/x330_manufacturer_cad_v1/XL_XC_330.stp \
 --out outputs/x330_component_map_repeat.json
```

この段階ではホーン固有の穴配列と公差、軸受容量、出力側とアイドラー側の回転部割当、締結構成が未完了。凍結モデルと実装の関節範囲は変更していない。
