# 後部板と支持を先に組む挿入順序

## 判断

統合比較v2の51部品（外装を除く支持ユニット・後部板・後部ねじ／座金）を外装の外で組み、後方から一体で挿入する順序を、公称幾何の組立候補とする。外装内で左右支持棚を別々に保持しながら後部板を取り付ける工程を避けられる。締付けトルクや最終組立承認はまだ与えない。

1. 外装の外で、左右各17部品の支持ユニットを後部板へ組み合わせる。後部主ねじ8本と座金8枚を含め、合計51部品のモジュールとする。
2. 空の外装へ後方から+X方向に直線移動し、公称最終位置へ収める。
3. 外装―後部板の四隅締結を後から行う。これらの部品・工具作業は今回の51部品の検査には含まれない。
4. サーボ・脚・Tab5・電池・配線はこの挿入時に取り付けない。後工程の成立確認は別途必要。

## 検査

各支持ユニットの包絡直方体、後部板の包絡直方体、後部ねじ／座金16点それぞれの包絡直方体を、最終位置から-Xへ150 mm連続的に延ばした。全包絡を同じ変位で動かすため、時刻サンプリングに依存しない保守的な掃引範囲となる。

51部品すべての外装との掃引体積重複は0。接触座と後部板合わせ面には公称距離0があり、これは意図した接触。正の作業隙間や公差吸収を保証するものではない。後部板と支持の追加比較も重なりなし。これらは一体移動時に相対運動しないため、内部の追加比較は必要条件以上の保守的確認。

v1は支持ユニットを先に個別挿入し、後から後部板を付ける順序の記録。同じ公称経路は通るが、外装内で未固定支持を保持する工程が残るため、v2のモジュール順序を優先候補とする。

## 残件

座面高さと後部穴位置の公差が同時に成立すること、印刷反り・接触の離間、締結予圧、ねじ保持能力、手／持ち手の空間、四隅締結工具、後工程、実荷重での強度を確認する必要がある。モジュール内の体積干渉は既存 `yaw_integrated_candidate_v2` の限定検査を参照し、この挿入検査から全組立の強度や干渉を保証しない。製造リリースなし。

