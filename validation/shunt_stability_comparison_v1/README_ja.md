# 検出抵抗の実装安定性比較

次に評価する構成を、片脚につきWSLF25124L000FEAを2個直列（合計8mΩ）とする。既存WSLP1個案を消さず比較履歴として保持し、現行保護回路には未採用。

メーカーの[WSLF仕様書](https://www.vishay.com/docs/30193/wslf.pdf)では4mΩが標準値として掲載され、部品TCR±70ppm/K、はんだ耐熱試験変化±0.5%。WSLPの固定0.5mΩ変化項を持たない。部品数・面積・中間接続が増える代償がある。

両製品のTCR記載範囲が重なる-55〜150℃、初期±1%、同じはんだ変化の条件付き適用で比較。2個の誤差は同符号として加算し、相殺を仮定しない。WSLF案は制限電流5.494〜7.042A、残余検出誤差4.723mV。旧案は5.053〜7.328A、1.209mV。温度範囲を要求の変更や合格条件の緩和には使わない。150〜155℃は本比較の対象外。

直列中間配線の抵抗が追加されるため、その影響を含むKelvin取出しと熱設計を確認してから選定を確定する。調達、実装工程、IC閾値、FET耐量も未確認。完成基板への承認ではない。

再現：`.venv-engineering/bin/python software/sim/circuits/compare_shunt_stability.py --out /tmp/shunt-stability-review`。
