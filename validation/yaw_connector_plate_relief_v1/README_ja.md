# ヨー金属板のコネクタ逃げ候補

各ポートの9.5×3.8mm投影に外向き1.3mmの余裕を加え、12.1×6.4mm・角R1.3の貫通逃げを左右各2か所へ追加。1.3mmは既存の残余0.5mm＋公差2×0.2mm＋変形2×0.2mmから定め、結果に合わせて基準を変えていない。

板の外形・取付軸は維持。ケース固定4穴と支持固定4穴の各軸から半径3mm内の材料除去は0。新形状は妥当な単一ソリッドで旧形状の内側に収まる。片側の除去体積151.979mm³、公称嵌合ハウジングとの最小距離1.64012mm、既存配分控除後0.84012mm。

局所幾何のスクリーニングは通過したが、強度・疲労・板の変形、電線の出口と支持棚の通過、挿入経路は未確認。半径3mmの座保存だけで耐力維持とは言えない。既存revB組立と質量モデルは未変更。次は開口周囲の有効断面と荷重経路、支持棚を含む線材通過を確認して採否を決める。
