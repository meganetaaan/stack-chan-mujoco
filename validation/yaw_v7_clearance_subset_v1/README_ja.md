# v7剛体隙間へのv6下限の引継ぎ

左右支持部のv7−v6の体積差は0、v6−v7は各119.405 mm³。
他50部品はinventory一致に加えてCAD差分を両方向で確認し、数値閾値1e-6 mm³以内。
既存回転検査の入力CADハッシュも照合した。

固定障害物の集合が小さくなり、回転する形状が同一なら、各回転角度での
剛体間最短距離は減少しない。したがって、既存v6の±15°範囲で得た
最小サンプル距離2.082322 mmと点間上限を用いた保守的下限をv7にも適用できる。
同じ公差・変形割当を差し引いた下限は1.008439 mmで、0.50 mm条件内。
これはv7の新規測定最小値ではなく、v6から引き継いだ下限。

削除で剛性が下がる効果は集合包含では扱えず、変形割当の成立は別問題。
一荷重再評価・全保存荷重評価は別保存で、実締結・材料・最新荷重は未確定。
全脚・配線・工具・電池・手の隙間は引き継がない。CAD数値演算であり
厳密算術による集合包含の形式証明ではない。製造・全組立承認は保留。

再現：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/transfer_yaw_clearance_subset.py --out /tmp/yaw-v7-clearance-subset
```
