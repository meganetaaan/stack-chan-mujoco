# 生産終了UBEC後の評価候補

次の設計・最小実機評価候補をPololu D42V110F5（#5671）左右各1台とする。
仕様・制約はschematics/power/dual_pololu_candidate.json。購入・通電承認ではない。

旧30603000は生産終了。D24V90F5は±4%と熱依存の電流記載があり、
より厳しい電圧降下予算となる。D42V55F5は小型だが公称電流余裕が小さいため、
まずD42V110F5の左右分離案を配置と配電へ進める。
11Aという名前だけで合格とせず、3S入力時の熱・過渡・保護を確認する。

既存の4.917 A／脚という設計比較点を維持。これは実DC最大値ではない。
5V±3%の下限4.85Vから既存端子下限4.75Vまでは0.10V。
したがって往復配線・接点・遮断素子の合計抵抗20.338 mΩ以下が必要になるが、
この値にはリップル／負荷急変余裕がなく、許容配線抵抗の確定値ではない。
評価を通すために4.75V条件を変更しない。メーカーtyp電流・PGを保護保証にしない。

ENAには入力電圧が掛かり得る。制御側は適切な耐圧の電流吸込み回路を選定し、
電源断時・リセット時に給電を許可しない構成へ接続する。
基板内逆接保護を回生吸収や出力逆流遮断として扱わない。

次は3S入力でのメーカー電流／ドロップアウト曲線と実装熱条件、
既存配置へ収まるか、端子までの電圧降下予算を確認する。
解析で確定できない熱・過渡・回生は最小試験へ切り分けるが、
実配線・遮断・保護素子の選定未完了を実機Issueへ押し出さない。
