# 足裏スライドロックねじ候補

x=35、y=±6 mmにM2×8低頭ねじの名目包絡を追加。TPU足裏下側に座ぐり、ヨーク上面に8×8 mmのナット保持ボス。ナットは造形途中埋込みを想定し、固定部の挿入力に大変形を使わない。足裏をキーホールへ挿入・スライドした後、下側からねじで滑り戻りを拘束する構成。

左右ともsole/yoke/screw/nutは単一有効ソリッド。ブーツおよび部品相互の名目体積重複なし。半径1.5 mmの工具包絡は下側からアクセス可能。工具先端・実六角穴は未選定。

ねじ頭座面z=-20.5 mm、頭高さ1.3 mm、接地面z=-22 mmで名目沈み0.2 mm。公差・摩耗・圧縮を考慮する余裕として未資格であり、接地突出対策が必要。ねじ先端はナットから名目0.5 mm突出。実製品M2×8・長さ公差・不完全ねじ山を含むかかり長さは未確認。

ナット保持、TPU頭部座面の引抜き/圧縮クリープ、ねじ横荷重、ボス曲げとヨーク穴追加後の強度、サーボ/フレームとの全可動域、ナット埋込み工程は未検証。滑りロックの追加は強度成立を意味しない。
