# 12軸モデルの連続指令切替とばらつき診断

事前定義の205秒・24区間を12軸候補へ接続した。停止、前進、後退、左右旋回の全20通りの有向切替と前進旋回を含む。物理・保護・着地基準と運動閾値は変更していない。すべて開発シードであり、固定20/20・ランダム化18/20の受入評価ではない。

## 実装

`YawCommandReference` は歩の境界で指令を取り込み、途中で接地足をリセットしない。停止へ移ると足位置と足向きを順にそろえて両脚支持へ戻す。接地足のヨー可動域を超えないよう切替直後の参照旋回速度を制限するが、評価器は元の指令に対して測定する。胴体へ位置・姿勢・補助力を与えない。周期は0.32秒。初期姿勢の高さ補正は2 mmで、脚長や外形は変更しない。

初版の参照は46.28秒の右旋回開始でヨー限界を超えた。v2では205秒すべてを生成でき、関節参照の限界余裕は最小0.01796 rad。20 ms間の最大関節変化0.1755 radは実サーボのスルーレート制限・フィルタを通す前の値であり、追従を仮定していない。

`probe_yaw_dynamics_candidate.py --protocol ...` は全物理刻みの既存検査を保持し、停止中だけ着地間隔要件を免除する。区間別着地回数、実積分状態、実測位置・ヨー、運動指標を保存。部分試験は全体合格にならない。初期衝突で時刻0に停止した場合も失敗記録を残す。

## 段階的な結果

- **v2・205秒:** 転倒・自己衝突・関節逸脱・保護停止なし。全移動区間の着地要件を満たし、左右計287/285回の有効着地。ただし前進・後退8区間と曲線歩行2区間で横速度RMSEが0.030 m/sを超え、不合格。その他の運動指標、停止、その場旋回は基準内。
- **v3・重心目標inset25 mmを開始から適用:** 5秒で歩行中断。有効着地0/0。
- **v4・v3の足上げを4→5 mm:** 同じく5秒で歩行中断。詳細診断では接地確認の中断と短い滞空による棄却を確認。
- **v5・最初24 mmから数歩で25 mmへ移行:** 32秒を安全に完了。後退・停止は運動基準内、前進の横速度RMSE0.03044 m/sで不合格。
- **v6・最初24 mmから25.5 mmへ移行:** 32秒の全5区間が運動基準内。前進横速度RMSE0.02830、後退0.02386 m/s。左右33/32回の有効着地。
- **v6・205秒:** 物理異常なし、全移動区間の着地要件を満たし、左右262/264回着地。24区間中22区間が運動基準内。`10_forward` と `12_forward` の横速度RMSEが0.03133/0.03125 m/sで閾値を超え、全体は不合格。
- **v6・ランダム化32秒、310611/310612/310613:** 2試行は全5区間の運動基準・区間着地要件を満たして完了、1試行は5秒で歩行中断。310611の前進左着地は2回で、基準に対する余裕は小さい。
- **v7・開始inset23 mmで310613を再試験:** 開始を通過したが20.753秒、後退中に歩行中断。開始位置調整だけでは頑健性を確保できず、公開スクリプトの既定はv6へ戻した。

## ばらつきと再生

`candidate_variation.py` は従来の事前範囲を12軸へ拡張する。総質量±5%、胴体COM各軸±1 mm、摩擦0.6〜1.0、トルク倍率0.9〜1.0、速度倍率0.95〜1.05、追加遅延0〜4 ms、初期関節角±0.005 rad。全接触面の摩擦を変え、全12モータのトルク・速度・遅延を変える。参照姿勢とフィードフォワードは名目値のまま。乱数シードと実パラメータを保存する。現在のばらつき試験は参照追従のみで、IMU等の観測補正は使用していない。観測ノイズの範囲も記録するが、未使用センサーのノイズが制御へ影響したとは扱わない。

10軸時と同じ乱数列から同じ既存パラメータを抽選するテスト、12軸すべてへの適用、固定条件で元のモデル配列を保持するテストを追加した。固定条件の先頭8秒の全積分状態は変更前と完全一致した。関連16テストが通過。

`yaw_maneuver_full_v2/videos/full205.mp4` は実MuJoCoの10,251状態を50 fpsでそのまま再生（状態0〜205秒、動画205.02秒）。104秒のフレームを抽出・確認した。描画用床の表示範囲には境界があるが、衝突床は無限平面であり、黒い背景への移動は物理床の端を意味しない。`yaw_random32_v1/videos/failure310613.mp4` は失敗試行を保存したパラメータで復元した再生。モデル・凍結アセット・状態のハッシュを検査し、ロボットの動きを補間・生成しない。

## 再現

CAD元データと実行環境は既存再現文書に従い、未使用の出力先を指定する。

```sh
python generate_yaw_maneuver_reference.py --cad-design outputs/design_r6_base_collisions --design assets/r7_yaw_xc_ankles_v1 --out outputs/new_maneuver_ref
python probe_yaw_dynamics_candidate.py --design assets/r7_yaw_xc_ankles_v1 --reference outputs/new_maneuver_ref/reference.json.gz --protocol configs/maneuver/acceptance_v1.json --out outputs/new_maneuver_trial --duration 205 --static-torque-scale 1 --yaw-kp 6 --yaw-kd .13
MUJOCO_GL=egl python replay_yaw_candidate.py --trial outputs/new_maneuver_trial --design assets/r7_yaw_xc_ankles_v1 --out outputs/new_maneuver.mp4
```

32秒の比較は参照生成・実行の両方に `--duration 32`。ばらつき試験は実行に `--randomize --seed 310613` 等の開発シードを追加する。公開された各参照ファイルを直接指定すれば過去条件を再実行できる。参照生成版ごとの `reference_source.py` は比較時のスナップショットで、最新の既定と区別する。元のoutputsパスを報告書に履歴として残し、同名フォルダへデータを収録した。

全受入試験、ロバストな切替、機構の実ホーン・締結・軸受との適合は未達。実機検証と起き上がりは今回の範囲外。
