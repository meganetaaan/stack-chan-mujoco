# 高精度電源案を最新負荷で再比較

結論：TPSM63610RDFRを各脚に1個、設定5Vのまま使う案を再検討する。最新の保護・放電負荷と50mm共通給電線を算入したXC枝の静的比較余裕は65.69mV。Pololu案の3.57mVより62.12mV増える。端子基準4.75〜5.25Vや設定電圧を変更して得た改善ではない。ただし未算入損失と動特性が残り、製作採用ではない。

## 更新した条件

旧 `precision_supply_screen_v1` は旧モータ負荷と別eFuseを使っていた。今回は現117部品候補のTPS259813L、各脚SiSS80DN1個、放電360Ω2本を照合し、各脚電流4.947702A、OEM片端切断案の電源往復2接点で計算した。3S候補の存在は入力最低電圧の保証ではないので、2S時代のドロップアウト懸念を「解決済み」としない。

[TI SLVSGU1A](https://www.ti.com/lit/ds/symlink/tpsm63610.pdf)の電気特性表はFPWM時のFB基準0.985〜1.015V。本文の±1%説明より狭い値を採用せず、表を使用した。100kΩ/25kΩはメーカー5V例の比率で、抵抗初期±0.1%、FB電流±50nAの比較包絡を維持。50nAを全条件の保証値にはしない。抵抗の温度/経時変動と実品選定は未完了。

|項目|計算結果|
|---|---:|
|分圧・基準・比較バイアスのみの出力範囲|4.91212〜5.08813V|
|上側5.25Vまでの余裕（リプル/過渡前）|161.87mV|
|XL枝の下側残余（既知比較損失後）|71.09mV|
|XC枝の下側残余（既知比較損失後）|65.69mV|

未算入：OEM線、PCB銅箔、はんだ、その他回路電流、温度/経時変動、規定条件外の保護抵抗、負荷過渡。65.69mVをそのまま過渡許容値にはしない。TIの150mV典型負荷過渡は別試験条件で、実機の合否へ直接転用しない。

## 採用へ進むための変更範囲

この候補は配線済み完成基板ではなく基板実装モジュール。PCB熱設計・入出力容量・周波数/モード・分圧・実装工程が必要で、PololuのCADや取付機構へ単純置換できない。メーカーの発注一覧ではRDFRが現品番であり、アプリケーション例内のRDLR記載を発注根拠にしない。

次は3S電池候補の負荷時入力範囲と選定動作モードを固定し、メーカー推奨実効容量・PCB実装条件を満たす構成を作る。特に基準精度の表はFPWM条件なので、自動省電力へ無条件に移せない。FPWM時の負電流は入力への回生を処理できる保証でもない。

Murata OKL案も確認したが、既存 `pol_module_screen.json` に記録したトリム精度/負荷過渡/容量制約が残る。候補名を増やすだけの置換は行わない。

再現：`python software/sim/circuits/screen_precision_current_stack.py --out validation/precision_supply_current_stack_v1`

最新接続候補・BOM・CADと正式currentは維持。ここでの結論は高精度5V案の再検討開始であり、電源適合・通電試作の合格ではない。
