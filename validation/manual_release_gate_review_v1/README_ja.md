# 解除確認ゲートの接続候補と適合境界

SN74HCS11PWRの1番ゲートに健全・生信号解除・整形信号解除を入力し、出力をTPS3808 MRへ送るピン候補を作成。未使用入力はGND、出力は未接続。これは接続候補で、直結を承認した回路図ではない。

## 駆動負荷

TPS3808 MRの内部プルアップ最小70 kΩ、想定電源最大3.393 Vから、Low出力時に最大約48.47 µAを吸い込む。HCS11の全電源範囲2〜6 Vで提示されたVOL保証は20 µAの条件で、これを超える。4.5 VのmA駆動値を3.3 Vの保証として転用しない。駆動不可能と証明されたわけではないが、今回資料だけで最悪値適合を断定できない。

## 入力負荷と保護

MAX6816 INの内部プルアップ最大100 kΩでは、追加漏れ1 µAでHighが0.1 V低下する。ゲート単体漏れのほか保護素子・基板漏れ・ノイズを合算する必要がある。HCS11の追加漏れ1 µAは6 Vの規定点に基づく比較であり、全保護回路の保証値ではない。

MAX6816入力の±25 V耐性／ESD定格はIC単体の条件。HCS11を同じ外部入力へ直結して同じ耐性と扱わない。生信号分岐には保護・直列抵抗・無給電時経路を含むインターフェースを定義する必要がある。ユーザーが±25 V外部入力を要求したという意味ではなく、従来部品仕様と組合せ後の適用範囲を区別する。

## 次の設計判断

追加論理シミュレーションは不要。生信号の入力回路と3.3 V範囲でMRを駆動できる出力段を具体化した後に、静的電圧と遅延を一度照合する。今回のゲートへ未確定な停止系まで統合しない。条件不成立・ボタン押下はタイマーを解除するが、すでに許可した投入DFFをボタン押下で消去する配線にはしない。#24は未完了。
