# 深い側面リブの保存荷重評価：変形配分未達

事前に0.2 mmの既存変形配分、3 mm→条件を満たした場合のみ2 mmの評価順を設定した。荷重、E=1120 MPa、ν=0.35、Z89分布荷重面、X=-62.2理想固定は `yaw_shelf_compliance_v1` と同じ。局所応力の収束を目的にしない。

3 mmメッシュで最大変位0.237657 mm、外力仕事2.692463 N mm。数値釣合いとエネルギー整合を確認。同じ3 mmの補強前（開口後）0.279659 mm、2.921076 N mmに対し、最大変位は約15.0%減少、外力仕事は約7.8%減少した。ただし形状別メッシュでの比較であり、厳密な改善率や誤差上限ではない。

**0.2 mmの配分未達。** 事前条件に従い2 mm解析は実施しない。基準を緩めず、この補強だけで十分とは判断しない。最大応力で合否を決めず、最新荷重・材料許容値・接触・締結を含む強度保証もしない。

この候補は外形と対象可動部の空間を保ちつつ変形を減らす設計比較として残すが、現行revBへの統合と製造承認は保留。金属板と樹脂棚を別々に解いている限界が残るため、次の補強の追加前に、取付板による荷重分散と締結・接触のモデル化が設計判断に与える影響を確認する。完全接着を実締結の保証とみなさない。
