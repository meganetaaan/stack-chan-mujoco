# 制御分岐の電圧窓

目的はTPS26600の既定UVLO/OVPを置き換える抵抗値の具体化であり、電池セル保護ではない。UVLOは上40.2 kΩ/下10 kΩ、OVPは上124 kΩ/下10 kΩという一案を試験前に設定。総合抵抗±1%、入力漏れ±100 nAと公開閾値端点の全組合せを計算した。

| 条件 | 電池側電圧範囲 |
|---|---:|
| UVLO立上がり／起動許可 | 5.801..6.253 V |
| UVLO立下がり／停止 | 5.332..5.743 V |
| OVP立上がり／停止 | 15.378..16.734 V |
| OVP立下がり／解除 | 14.260..15.369 V |

式: Vtrip=Vthreshold×(1+Rtop/Rbottom)+Ileak×Rtop。分圧の満充電時消費は合計最大約348.5 µAで、電池側の待機負荷に加える。抵抗は公称値候補であり注文品・温度係数・定格は未確定。

基準は既定値で起動できなかった12.6 Vでの許可、TPS709の3.3 V+1 V参照条件より高いUVLO停止、TPS709推奨入力上限30 Vより低い静的OVP停止。全て計算上満たすが、最小実用電池電圧・各セル保護の成立を判定していない。低電圧停止が約5.5 Vでよいという電池側の判断には使わない。

資料の電気特性表には24 V共通試験条件があり、3S域での適用・起動遷移・OVP遅延中の上昇・逆接時のピン電流を未確認。計算を保護成立や製作承認として扱わない。復帰方式と下流の起動が未設計のため現アセンブリ未変更。

再現: `.venv-engineering/bin/python software/sim/circuits/size_logic_input_window.py --out /tmp/logic-input-window`（出力先未作成）。一次資料: [TPS2660 RevG §7.5](https://www.ti.com/lit/gpn/tps2660)。
