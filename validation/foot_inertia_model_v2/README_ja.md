# 足部30部品の慣性を反映した比較モデル

足部revEの左右各15部品から質量・重心・慣性を合成し、旧ankle_roll慣性を置換した。追加加算ではない。比較密度は剛性部1.27、接地部1.2、金属包絡7.9 g/cm³。剛性部は既存PETG候補の代表密度、後二者は更新処理を実行するための未認定入力で、手持ちTPUや実締結品の測定値ではない。

この入力では各足56.348g、旧足との差は左右合計+0.680g。接地部密度を0.1g/cm³変えると各足約0.327g変わる（CAD体積3270.484mm³）。未知密度を隠した最終設計値として使わない。ねじ部品は実ねじ形状ではなく包絡体であり、金属密度を掛けた値は仮の比較値。

検証内容:
- 30部品を重複なく左右それぞれへ割当て、平行軸の定理で慣性を合成。
- MuJoCo3.13でコンパイル後、慣性をリンク座標へ戻して合成値と照合。
- 変更対象は左右ankle_rollの慣性のみ。他bodyの慣性、関節と形状の配列が旧モデルと一致。
- 全身の質量差が、2個の旧足を除き新足を加えた差と一致。

初回v1はfullinertia指定をMuJoCoが主慣性へ変換する際の約2.51e-11kg·m²の差で厳密照合に失敗した。v2ではnumpyで主慣性と姿勢を計算してdiaginertia/quatとして渡し、同じ判定精度を維持して照合を通した。v1のXMLとfailure.jsonを保存。

残る範囲: 実材料/造形率/締結品の質量、サーボホーン締結品と配線、足部CADとbody座標の最終照合、全身搭載物、最新衝突形状、更新荷重での強度・歩行性能。このモデルは慣性更新の比較用であり、最新足部の干渉合格や製造リリースを意味しない。WASDデモの現行モデルも置換しない。

再現（出力先は未作成ディレクトリ）:

```
.venv-engineering/bin/python software/sim/structural/build_foot_inertia_comparison.py --rigid-density 1.27 --contact-density 1.2 --metal-density 7.9 --out /tmp/foot-inertia-comparison
```

scene.xmlは元モデルのメッシュを相対参照する。単独配布ではなく、このリポジトリから上記手順で生成する。
