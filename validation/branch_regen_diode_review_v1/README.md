# 分岐保護の逆向きダイオード案：現吸収回路との組合せは採用保留

2026-09-21。plan.jsonで評価対象と終了条件を定義し、既存結果の電圧予算を一度計算した。新しい回生波形・モーター特性は仮定していない。

## 構成と部品

各分岐保護と並列にPMEG3050EPを置く。アノードをサーボ側、カソードを共通バス側に接続する案。通常給電の直列降下を増やさず、分岐保護の開放後にもサーボ→共通吸収器の経路を残す。GNDの健全性が前提で、ケーブル抜けには効かない。

Nexperiaの[メーカー資料](https://assets.nexperia.com/documents/data-sheet/PMEG3050EP.pdf)（2023-01-01、表7）では1 A・接合温度25℃の順方向電圧最大が0.275 V。温度全域の保証値へ拡張しない。5 A表記も無条件の連続許容電流ではない。漏れ・熱・実装・発注コードは未適合確認。

## 既存候補との電圧予算

比較電流1 Aは実機上限ではない。既存治具線長0.25 m、線抵抗呼び値＋コネクタ環境試験後上限から往復降下0.066575 Vを用いる。

`サーボ端子予算 = 共通バス電圧 + ダイオード降下 + 往復配線降下`

| 分岐保護開放時の共通吸収器状態 | 端子電圧予算 V | 6 Vまでの余裕 V |
|---|---:|---:|
| 両吸収枝健全 | 5.966462 | 0.033538 |
| 主吸収枝開放 | 6.008163 | −0.008163 |
| 副吸収枝開放 | 5.966462 | 0.033538 |
| 両吸収枝開放 | 20.666275 | −14.666275 |

ここで主吸収枝開放は、分岐保護開放と合わせた複合故障。単一故障と呼ばない。各時刻の厳密な端子波形ではなく、既存行動モデルのバス最大値に条件付き降下を加えたスクリーニングである。負の予算は実機過電圧の断定ではなく、この情報では成立を承認できないことを示す。

この比較だけでも共通バスに必要な上限は5.658425 V以下で、さらに温度・線抵抗公差・インダクタンス・制御遅れの余裕が必要。健全時の約34 mVを十分とみなさず、6 V基準を緩和しない。

## 設計判断と終了

**このダイオードと既存吸収回路の組合せを製作BOMへ昇格しない。** 電圧だけでなく、ダイオード短絡が分岐保護を迂回して給電を復活させる故障も残る。開放故障では元の回生経路喪失へ戻る。共通バス短絡への回生流入も吸収器への到達と同一視しない。

次の回路設計では、(a) この降下を含む実部品クランプ上限と独立遮断を成立させる、または (b) サーボ端子側の局所吸収を選ぶ必要がある。(b)も抜線時に保護部品がサーボへ残る実装、共有GNDへの依存、吸収容量・質量・発熱を確認してから採用する。どちらも今回の結果だけでは選定完了としない。

追加の仮想回生シミュレーションは行わず、この比較を終了する。#22/#24は未完了。実機評価#49へは端子電圧測定・分岐開放・保護部品故障・抜線時の保護残存を引き継ぐ。実測前に回路と試験上限を確定する。
