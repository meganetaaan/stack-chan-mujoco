# ヨー回転中のねじ先端とカプラの連続隙間下限

凍結モデルの左右ヨー軸位置と±15度の範囲を読み、CAD配置とモデルの可視形状オフセットが相殺することを確認した。中立距離から、CAD包絡箱で上限評価した回転半径Rに対する最大変位2R sin(最大角/2)を差し引いた。任意の回転角で形状が移動できる距離の上限を用いるため、離散角度サンプル間の見逃しに依存しない。

事前判定は全組の隙間下限が正であること。8本×左右カプラの16組で成立し、最小下限は6.357mm。これは公称軸・横位置における突出部分とカプラだけの分離証明で、全身の動的干渉合格ではない。傾き、変形、位置公差、配線、他の脚部品は含まない。制御で可動範囲を逸脱しないことも別途確認が必要。
