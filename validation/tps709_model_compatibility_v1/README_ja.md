# TPS70933メーカー過渡モデルの実行確認

TIの非暗号化SBVM571モデルを取得。モデル本体は同梱せず、取得元・ハッシュ・適用除外をreport.jsonに保存。定常の9 V直結・2.2 kΩ負荷で出力3.300421 V、入力1.50159 mAが得られた。これは定常計算が実行できることの確認に限る。

直列1 kΩ、入力2.3 µF、出力5.4 µF、2.251 kΩ負荷の過渡計算は起動直後に時間刻みが極端に小さくなった。通常解法は約1.00350 ms時点で停止し、Gear2への一度の変更も40秒上限で終了。目標100 msの波形は得ていない。回路の不合格・起動失敗と判定しない。

8 V入力源は9 V電池から仮のダイオード降下1 Vを引いた比較値。BAS116の実過渡モデルではない。出力容量・負荷も比較用で、全回路の温度/誤差包絡ではない。モデル自身が消費電流の入力依存・温度特性を含まない。これを使って最悪条件を合格扱いしない。

再現はTI提供元 https://www.ti.com/lit/zip/SBVM571 から取得したTPS70933_TRANS.LIBを作業ディレクトリのmodel.libへ置き、check.cirまたはgear.cirを実行する。ngspice42のPSpice互換モードとXSPICEのコードモデル読み込みが必要。`.spiceinit` に `set ngbehavior=ps` とインストール先の各`.cm`への `codemodel` 設定を置く。モデル内部は変更していない。実行上限は40秒とする。

同じモデルへの数値設定の追加試行はここで打ち切る。メーカー想定PSpice環境での確認または起動電流を適切に扱う別の検証手段が必要。直列抵抗候補の起動適合は未確認のまま。無負荷RC比較から起動時間を決定しない。
