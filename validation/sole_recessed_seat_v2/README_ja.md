# 内側へ厚くした足裏座面の形状比較 v2

目的は0.6mm座面の薄さを、床側ねじ位置を変えずに改善できるか確認すること。
厚さ1.6mmは設計比較値で、材料許容値に基づく合格寸法ではない。

スライド溝を追加。左右各17姿勢でヨークとの交差0。固定姿勢ではヨーク・ブーツ・ねじとの交差0。

床側公称隙間0.8mmを維持。ヨークには深さ1mmのくぼみを作り、局所公称残厚2mm。
旧スペーサーを戻さず、sole_clamp_seat_v1のワッシャを使用する比較。
接地部にはTPUまたは購入シートを別途選べるが、この検査は材料・接着を評価しない。

再現（リポジトリルート、CadQuery環境）：
```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/build_sole_recessed_seat.py --out /tmp/sole-seat-v2 --slide-channel
```

終了条件はこの寸法比較で固定姿勢とスライド姿勢の干渉有無を決めること。
形状探索を強度合格の代わりにしない。垂直挿入、全経路・公差、座面とヨークの曲げ・割れ、
締付け・クリープ、ワッシャの実部品選定は未完了。通電試作の承認には使用しない。
