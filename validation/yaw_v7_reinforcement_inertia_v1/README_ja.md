# v5→v7補強の密度別慣性入力

左右支持部の増分だけを算出。追加体積合計9122.083 mm³。
既存の一様PETG比較密度1270 kg/m³なら11.585 g増だが、実造形重量ではない。
ABS/PETGの製品、内部構造、造形条件は未確定。TPU支持部への置換は仮定しない。

旧部品をCAD差分で除き、残る追加形状の体積・重心・慣性を直接計算した結果と、
v7/v5保存モーメントから得た差分を独立に照合した。残り50部品の属性と
モーメントは同一。座標は組立CAD原点、単位m、kg、kg/m³。

report.jsonの各係数に同一の密度ρを掛けると質量・一次モーメント・原点慣性の増分になる。
既にv5へ置換済みの台帳へ一度だけ加える。古い凍結MuJoCoモデルへこの増分だけを加えて
v7相当としない。支持部の旧→v5、取付板、背面板、締結品、電池、回路、配線の置換が別途必要。
材質・密度も変更する場合は同一密度の差分式を使わず、旧項を引いて新項を追加する。

原点慣性を重心慣性として直接代入しない。全項を同じ原点で合算し、
総質量と一次モーメントから新重心を求めて平行軸項を除いた後、
MuJoCoのbody座標へ変換する。ナット包絡を実質量へ換算しない。
今回はモデルや荷重履歴を更新していない。全身の成立証明ではない。

