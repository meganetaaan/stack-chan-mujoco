# 後板ユニットを6 mm持ち上げる挿入経路

## 結論

形状と0.5 mm基準を変更せず、次の公称経路の全区間を確認できた。

1. 最終位置から後方70 mmの位置で、ユニットを6 mm持ち上げる。
2. 持ち上げたまま前方へ70 mm移動する。
3. 最終X位置で6 mm下ろし、後板を合わせる。

CADの移動量(mm)は(-70,0,0)→(-70,0,6)→(0,0,6)→(0,0,0)。6 mmは、台座底面94→100 mmが既存ねじ先端98 mmを越え、フランジ上端119→125 mmが外装内側天井126.2 mmに収まることから検査前に選んだ。

45移動部品×39固定部品×3区間=5265組。意図した後板接触面を除く距離の保証下限は0.683999 mmで、0.5 mm条件を満たす。この値は保守的下限であり経路上の実際の最小隙間を求めた値ではない。

## 連続区間の確認方法

- 5162組は移動全体を含む直方体同士の距離下限で確認。
- 80組は移動を包む直方体と固定実形状の距離で確認。
- 8組は区間中央での実形状距離から区間の移動長の半分を引く。剛体平行移動によって距離は移動量を超えて減少しないため、この値は区間全体の下限になる。必要箇所だけ区間を分割し、計10区間で確認した。
- 15組の意図した後板の接触は、移動形状と相手がX方向の接触平面を挟む別々の半空間にあることから非貫通を確認した。接触する面に0.5 mmの隙間を要求した結果ではない。

数値計算の比較には1e-6 mmのCAD許容差を使用。これは製造公差ではない。一般距離の下限からは同量を差し引いた。区間の抜け・重複がないことをcertificate_audit.jsonに整理。監査は証明データの整合確認であり、別のCAD計算による独立検証ではない。

## 組立上の条件と残る事項

既存後板1、既存後板ボルト8本、後部座金8枚を外す。残る支持部を仮保持した状態を想定する。仮保持治具、手、配線、ケーブルの曲げ、摩擦、重力、弾性変形は未評価。後板が接触平面に沿って下がる工程の公差・バリ・面の仕上げも未確定。6 mm上げた姿勢で後板上端が元の上端を一時的に越えるのは組立中の経路であり、完成外形の変更ではない。

電子基板は高さが大きい共通モデルを含む外包形状を使用した。この包絡に入らない端子・配線・追加保護回路は含まない。先行工程のソケット深さ、基板側締付工具、ポケットの造形公差、締付保持/強度の課題も残る。したがって公称幾何学的経路の確認であり、試作リリースや全組立工程の保証ではない。
