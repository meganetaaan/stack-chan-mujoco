# ブーツ取付座面の延長候補

取付穴周囲に外径6 mm、内径2.3 mmの一体座面を追加し、ブーツ側の接触面をz=−15.8から−16 mmへ0.2 mm延長した。ブーツ全体の位置、足裏、脚長は変更しない。生成時の融合用0.01 mm重なりは既存ブーツ内部に入る。

左右とも有効な単一ソリッドで、ヨークとの重なり0 mm³。各側4座面すべてで接触面積24.119577598 mm²となり、事前の形状確認基準20 mm²/座を満たした。体積増加は19.295662078 mm³/側。接触面積基準は幾何確認であり、許容応力から導いた耐荷重保証ではない。

平面度、公差、予圧、締結仕様、ねじと工具のアクセス、印刷方向、クリープ、座面圧縮・脚全体の強度は未検証。座面追加後の干渉検査も必要であり、旧ブーツの合格結果を無条件に継承しない。製造承認・Issue完了を意味しない。
