# 電源台座ナットの連続挿入経路

## 判定

8個のナットを各列の外側からY方向へ10 mm移動し、最後に0.1 mm上へ引き上げて座面に当てる経路を検査した。全8経路で重複なし。台座ポケットの滑り隙間は最小0.1 mm、既存固定部・電池・トレイ・Tab5・TTLとの最小距離は2.2 mm。公称経路スクリーニングは合格、製作リリースは未成立。

ナットは対辺4・高さ1.6 mmの理想六角柱。始点と終点の六角形の凸包を押し出した形状は、直線平行移動の連続掃引そのものとなる。さらに着座方向の掃引を加えた。穴を埋めたナットで保守的に扱い、途中姿勢のサンプリングによる見逃しはない。実物のバリ・公差・傾き・手や工具の空間は含まない。

## 公差と仕上げ要求

- X方向: ポケット公称4.2 mm、ナット公称対辺4 mmで左右各0.1 mm。
- Z方向: ポケット高さ1.8 mm、ナット高さ1.6 mmで、挿入中は上下各0.1 mm。着座後の上面接触は意図したもの。
- 事前の組立隙間条件は片側0.05 mm。公称値から残る誤差予算は各対向面について0.05 mmで、造形内向き誤差、ナット外向き誤差、位置ずれ、表面凹凸の合計で消費される。

ABS/PETGでこの予算を達成できるという証拠はない。必要条件として仕上がり幅は実ナット対辺+0.1 mm以上、仕上がり高さは実ナット高さ+0.1 mm以上。ただし全体寸法だけでは局所的な引っ掛かり・偏りを保証しない。造形方法・後加工・検査方法を確定するまで、ポケットをそのまま印刷すれば組めるとは扱わない。広げる場合もナットの回り止めを同時に確認する。0.05 mmはこの嵌合の設計仮定で、他部品との0.5 mm基準を緩めたものではない。

## 組立順序の候補

1. 機体へ台座を取り付ける前に、台座単体を基板側が上となる姿勢で保持する。仕上がりポケットとナットの適合を確認する。
2. 低いYの穴列は-Y側、高いYの穴列は+Y側からナットを差し込む。ねじはこの段階では差し込まない。移動経路はreport.jsonのstart_center_xy_mmを参照。
3. ナットが抜けないよう仮保持し、スペーサと基板を配置して上からねじを導入する。ねじの掛かりでナットが上面へ引き上げられる。仮保持方法・工具・締付トルクは未確定。
4. 基板側の締結を成立させた後、台座を後板へ取り付ける。この後板締結と、基板を付けた台座の取付経路は未評価。

これは確定した製造手順ではなく、検証済み経路に矛盾しない組立順序案。ねじを先に挿すと横方向からナットを通す経路を妨げる。挿入確認は締結後の保持強度、クリープ、緩み止め、絶縁の代替ではない。

## 再現

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_pololu_nut_insertion.py --out validation/pololu_nut_insertion_v1
```
