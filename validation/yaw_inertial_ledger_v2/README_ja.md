# 既選定SUS304座金の反映

v1で密度未確定に分類したヨー取付座金8個は、組立生成コードと組立READMEですでにSCW-SOLE-SPACER-01と指定されていた。部品仕様のSUS304を使用し、既存の金属板集計と同じ参考密度7930 kg/m³で質量・慣性を計上した。材料の新規選定や強度基準の変更ではない。

8個の公称CAD体積を仕様の外径6 mm・内径2.3 mm・厚さ0.9 mmから独立に計算した円環体積と照合した。公称質量は合計1.377131 g。旧割当の保持分・金属板・座金の部分質量は420.336580 g、カタログねじ質量を加えると432.696580 gになる。未確定密度係数は19点から11点（造形部品3点、背面座金8点）へ減った。

参考密度と公称形状による値であり、公差・面取り・材質証明を含む製造保証値ではない。ナット、残りの配線締結部品、ねじの重心・慣性などは未確定。全胴体・全身モデルの質量や荷重合格には使わない。

部品仕様とBOMも、足裏用2個にヨー取付用8個を加えた計10個へ修正した。予備・破壊試験片は含めない。背面M3用座金8個は別形状であり、この材質・部品番号を流用しない。

再現：`.venv-engineering/bin/python software/sim/structural/build_yaw_inertial_ledger.py --include-selected-washers --out /tmp/yaw-ledger-v2-check`。出力先は未作成とする。v1は座金未反映時点の履歴として保存する。
