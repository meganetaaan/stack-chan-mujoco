# ベルト中央寄せの比較：不合格

v3の幅12.7mm・単層厚み予約2.5mm・上側二重厚みを維持し、ベルトYを±20から±12mmへ変更。
結果はreport.json。周辺10組の体積干渉が残り不採用。
純粋な偶力モデルF=M/dでは、間隔40→24mmにより同じモーメントを支える力は1.667倍。
実際のベルト張力には初期張力、電池接触、伸び、床反力が加わるため、この倍率だけで強度判定しない。

右支持部との交差形状を追加確認した範囲はX9.8..11.6、Y−18.35..−8、Z80..93mm。
後ろ側へ張り出す二重厚みが原因に含まれ、Y間隔だけの変更では除けない。
次案は間隔を40mmへ戻し、閉じ部を上面・前側に配置する。厚み予約と判定閾値は変えない。

再現：`LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/build_lb020_retention_v4.py`。
