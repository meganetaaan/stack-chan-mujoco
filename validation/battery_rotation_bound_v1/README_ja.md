# 電池回転モーメントの条件付き上限

質量76gが22×60×30mmの箱内にあり、重心が箱中心という条件で、
慣性テンソル最大固有値はm×(半寸法二乗和)以下、9.4696e-5kg m²。
均一密度は仮定しない。||Iα + ω×Iω|| ≤ Imax(||α|| + ||ω||²)を使用する。
姿勢差から世界座標角速度を区間中点で求め、その差分から角加速度を推定した。
両端2点を除き、左4.5751Nmm、右4.6999Nmmの上限最大値を得た。
実際のモーメント値や各成分ではなく、条件付きの大きさ上限である。

前段の力の作用点による約4.54Nmmと同程度なので、回転慣性を無視して
保持部の合格を出すことはできない。ピーク時刻は異なるため同時最大とは呼ばない。
全体を包む上限を作る場合でも、保守的な大きさ和と同時ベクトルを区別する。

**残る重心の仮定**: メーカーから重心位置を得ていない。
並進荷重v1も箱中心を質量中心としているため、中心ずれがあればその荷重も変わる。
この資料は未知の重心ずれを包含した上限ではない。電池内部・配線を含む質量分布、
記録の差分誤差、停止、新質量での運動、予荷重・接触は引き続き未確認。
今回の目的は回転慣性を省略できるかの判断であり、結論は「省略しない」。
