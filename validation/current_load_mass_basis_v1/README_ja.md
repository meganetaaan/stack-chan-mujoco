# 最新候補へ旧負荷データを適用できるか

**現候補の強度・電源合否には、統合モデルからの負荷再生成が必要。** 旧波形とその失敗記録は保存し、参考比較に限定する。

凍結r9のscene.xmlをFROZEN_FILES.jsonのハッシュと照合し、EPIC4用のfull_body初期化を実行した。ランタイムのbase質量は0.522939648 kg、全機0.918440046 kg。物理歩行は再実行せず、モデルの質量設定を検査した。

現胴体の数値78点と均質PETG比較7点が重複しないこと、7点の体積が現台帳と一致することを確認。小計0.672388822 kgは旧base値より約28.6%大きい。ただし未割当CAD30点、モーター・脚・配線・制御基板など未収録項目があり、両集計の範囲は異なる。実重量差・保証下限としての28.6%ではない。旧質量±5%感度試験が現候補を包絡すると判断する根拠はない。

質量を増やしただけの全体倍率では、重心移動・慣性・接触・制御追従による反力の変化を表現できない。旧力/トルク/電流へ1.286を掛けて最悪値としない。特に材料許容・締結評価へ旧合格を移さない。

次の負荷評価は全機の部品割当と質量/重心/慣性・座標変換をそろえ、別の統合モデルで行う。構造と電源へ同じ時刻の負荷を渡す既存インターフェースを維持し、試行前にケース/判定条件を固定する。

来歴の限界：旧EPIC4のtraceレポートには全ボディ質量配列が埋め込まれていない。今回確認したのは凍結XMLと現在の対応fixture初期化であり、履歴実行の全メモリ状態を再現したという主張ではない。最新候補の製作HOLDを継続する。
