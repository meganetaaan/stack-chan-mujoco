# ブーツ締結部の実部品寸法照合

[PTS A56202](https://www.pts-uk.com/products/nuts/square-nuts/metric-a2/a56202)のM2角ナットは対辺3.70〜4.00 mm、厚さ0.80〜1.20 mm。4.4 mm幅、1.8 mm高の仮収納には公称寸法上は入る。許容公差や浮動状態の挿入・保持は別途確認する。

[Accu SSCF-M2-6-A2-R360](https://www.accu.co.uk/metric-cap-head-screws/250399-SSCF-M2-6-A2-R360)は公称長さ6 mm、頭径最大3.8 mm、頭高さ最大2 mm、六角穴1.5 mm。製品を正式採用したものではなく寸法参照である。入手性は確認できていない。

ヨーク下面z=−19に頭を着座させると公称先端はz=−13。ナットを収納底z=−14.6に着座させた場合、最大厚さ1.2 mmの上面から0.4 mm突出する。ただし先端面取り・不完全ねじ・ねじ長公差は未反映で、有効ねじかかりや耐力の保証ではない。

頭収納は公称軸方向余裕0.2 mm、半径方向余裕0.4 mm。印刷面位置誤差0.2 mmを収納が狭くなる方向に仮定すると軸方向余裕は0になり、事前条件の残余0.2 mmに不合格。収納を深くする場合は足裏の残厚が減るため、低頭ねじまたは保持・収納構造の再検討が必要。
