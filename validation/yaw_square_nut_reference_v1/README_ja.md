# ヨー取付板の四角ナット参考形状

PTS A56202候補の記録済み寸法（二面幅3.7..4.0 mm、高さ0.8..1.2 mm）から、8箇所それぞれに小寸法/大寸法の角柱参考STEPを作成した。配置は統合v4のナット下面と中心に合わせ、足部の位置・使用数は流用していない。寸法資料は `docs/prototype/mechanical/sole_spacer/nut_candidate.json` および `validation/yaw_nut_source_review_v1/README_ja.md`。

| 座面表現 | 公称座金との接触面積 mm² |
|---|---:|
| 旧外接円柱包絡 | 20.988167 |
| 四角参考・幅4.0 mm | 11.845244 |
| 四角参考・幅3.7 mm | 9.535244 |

同じ軸力を各公称面に平均化すれば、四角参考形状の平均面圧は円柱包絡の約1.77〜2.20倍になる。これは荷重の分担・強度・実面圧を求めた結果ではなく、円柱接触面を使うモデル誤差の指摘である。

**実接触面積の下限は未確定。** 面取り・座面形状・ねじ山はまだ省略している。小寸法の9.535244 mm²も保証下限として使用しない。穴径2 mmは従来のねじ簡略表現を残しており、有効ねじ長や締結耐力を意味しない。座金は公称内径2.3 mmを使用し、実公差・面取り・偏心はこの比較に含めない。

16ソリッドが妥当で旧ナット包絡からはみ出さないこと、接触面積が角面積から座金穴面積を引いた解析式と1e-6 mm²以内で一致することを確認した。最大四角形の外接半径も旧円柱より小さいため、外形の回転だけで旧包絡を超えない。ただし工具や回り止めの成立は別途未確認。

干渉検査用の円柱包絡は保守的な形状として残す。今回の参考形状を正式組立・質量・強度へ自動採用しない。現行BOM・ポインタ・0.2 mm基準は変更せず、製作保留。接触解析を進めるにはナット実座面・保証荷重と締結条件を確定する必要がある。
