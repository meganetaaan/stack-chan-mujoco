# 最新ヨー支持と凍結モデルの質量置換対応

既存のbase質量来歴レポートを再利用し、参照する元ファイルのSHA256が現在も一致することを確認した。今回の対象は全身ではなくbaseボディの割当。動的解析や材料選定は行っていない。

最新52部品のうち、外装・背面構造板・左右固定支持の4部品は、凍結モデルのbody_shroud／rear_cover／左右yaw_fixed_supportを置換する。旧割当の合計は201.173 g。ねじ付き板・ケース取付板の計4部品は支持置換後に追加する構造部品、残る締結部品44個は既存の25 g一括予約との関係を明細化してから追加する。

凍結baseは522.940 g。旧4部品を除いた321.767 gには、配線・締結部品の25 g予約がまだ含まれる。この予約もいったん計算式から分離すると296.767 gとなるが、これは候補baseの完成質量ではない。新しい4置換部品、追加構造板、実締結品、残りの配線・固定部品を足し戻す必要がある。電池などの別の仮予約も確定品にはなっていない。

25 gを残してねじを全て追加する方法、または25 gを削除して配線などを落とす方法の双方を避ける。空欄の新質量はゼロではなく未確定。質量、重心、慣性の更新には各部品の組立座標と置換前後の物性が必要で、異なる重心まわりの慣性テンソルを直接差し引かない。

この対応表を使い、材料・製法と購入品重量の確定後に更新候補を別モデルへ作る。凍結r9および既存の荷重・歩行判定は今回変更していない。#17/#18の完了証拠ではなく、次の荷重更新の入力整理である。

再現：`python3 software/sim/structural/map_yaw_mass_replacements.py --out /tmp/yaw_mass_replacements`。未作成出力先を指定。元の質量来歴が変わっていれば処理を停止する。対象52部品をreplacement_map.csvに、質量割当の差分をreport.jsonに保存する。
