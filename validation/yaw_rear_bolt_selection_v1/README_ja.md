# 背面主固定ねじの部品選定

NBK SNS-M3-16を8本の主固定ねじの優先候補とする。製造リリースではない。公称M3×16、頭径5.5、高さ3、六角2.5 mmは現行配置と一致する。製品資料でSCM435・黒染め・12.9級を確認。旧計算の8.8級／580 MPaは比較用の低い値として維持し、ねじ変更によって過去の不合格や保持能力を合格へ変更しない。

メーカーが指定する技術資料では長さ15.65〜16.35 mm、頭高さ2.86〜3.00 mm、六角穴深さ最小1.3 mm。頭径最大5.68 mmはローレット付きの場合で、なしの場合は5.5 mm。ローレット有無未特定の公差包絡には5.68 mmを使う。

長さ公差だけを加えると背面板からの突出は公称1.80 mmから1.45〜2.15 mmとなる。板厚・座金・支持の公差を含む全体保証ではない。工具経路の1.3 mm比較深さはこの候補自身の最小深さとも一致するが、工具先端長・口元面取りを含む有効かみ合い長の保証ではない。

首下の最大丸みは資料式からr=0.30 mm、広がり径da=3.6 mm。旧座金CADは内径3.2 mm・面取りなしなので、このままでは実部品の着座を証明できない。実座金の面取りまたはボルト対応座金を指定し、座面と積層厚を確認する。全体メッシュ解析より先に解消すべき締結条件である。

寸法正本は `docs/prototype/mechanical/yaw_support/rear_bolt_candidate.json`。出典はsources.json。メーカーPDFはブラウザーで確認したが直接保存はHTTP 403だったため、保存済み原本があるとは扱わない。購入やメーカーへの問い合わせは行っていない。#17/#18の組立・保持能力の未達を維持する。
