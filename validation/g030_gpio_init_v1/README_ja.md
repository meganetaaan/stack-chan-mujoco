# G030 GPIO初期化の書込み順序

電源制御CコードへGPIOレジスタ操作のコアを追加した。
読み書き関数を受け取る構成で、実MMIOアダプター・起動コードは未実装。
GPIOのオフセットはST公式stm32g030xx.hを参照した。
https://github.com/STMicroelectronics/cmsis-device-g0/blob/master/Include/stm32g030xx.h

順序：
1. 使用端子と同一端子につながる未使用ポートをanalogへ移す。
2. 無効化を読み戻して確認。失敗なら出力化せず終了。
3. 出力ラッチをEN=0、CLEAR=1、保持資格=0にする。
4. プル・速度・代替機能を設定し、入力を有効にする。
5. 最後に3出力を有効にし、モードと安全側の出力値を読み戻す。

100通りの初期値を模擬レジスタへ入れ、最終モード・SWD保持・順序を検査。
共有ポートの無効化書込みが反映されない場合も、後続出力化を拒否することを確認。
ホストとCortex-M0+のコンパイルを通した。

呼出し前に外部回路で給電を禁止し、GPIOクロックを有効にし、
RTC/外部発振器の端子所有とPA9/10リマップを解除する必要がある。
競合する割込み等のレジスタ書込みも禁止する。
この検査はそれらの前提や物理的な過渡・短絡を証明しない。
特に、不正な旧設定で起動した瞬間から端子が安全とは主張しない。

再現：

```sh
python3 software/sim/circuits/check_g030_gpio_init.py --out /tmp/g030-gpio-init
```
