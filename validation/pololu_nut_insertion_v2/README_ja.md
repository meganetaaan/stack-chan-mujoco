# 後板M3締結後の基板用ナット挿入

工具検査で組立順序を「後板M3締結→基板用ナット挿入→基板装着」へ変更したため、その順序に存在する部品を挿入経路の相手に追加した。

最新43部品の統合候補から、追加穴を持つ後板、左右台座、全M3締結16部品を採用。挿入対象以外のM2ナット7個も最終位置に置き、ナット相互の組立順序に依存しない条件を検査した。M2ねじとスペーサ、電源基板はこの工程では未装着。既存機構・Tab5・TTL・電池等も相手に残す保守的な検査で、対象ナット自身と対象台座は一般相手から除き、台座は別の嵌合基準で確認した。

全8経路、相手部品640組で干渉なし。対象台座との滑り隙間最小0.1 mm、他部品最小2.2 mm。経路は前回と同じY方向10 mmの直線挿入とZ方向0.1 mmの着座で、連続掃引を用いた。基準(嵌合0.05 mm、他部品0.5 mm、重複0.01 mm³以下)は変更していない。

公称形状について改訂順序の工程2を支持する結果である。FDM誤差・バリ・面取り・工具と指・仮保持・摩擦は未モデル化で、片側0.1 mmの隙間が工程で得られる証拠は増えていない。後板工具のソケット有効深さ、M2締付工具、組立済み後板ユニットの機体への装着、保持強度も未確認。製作リリースはfalse。

再現(CadQuery、NumPy、SciPy):

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_pololu_nut_insertion.py --out validation/pololu_nut_insertion_v2
```
`mounted_assembly`の指定がないv1では旧検査条件を維持する。統合候補の43ソリッドは体積と6方向の外形座標をinventoryと照合してから部品名へ対応させる。
