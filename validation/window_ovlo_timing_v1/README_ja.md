# revNの遮断時間に関する採否判断

**revNを唯一の高速過電圧保護経路として採用しない。** 静的な端子電圧比較を通過しても、サーボ端子6 V以下を証明する遮断時間の上限がない。部品の故障や実際の過電圧発生を観測した結果ではなく、設計の保証根拠が不足するという判断である。

TPS3700 SBVS187G §6.6では正方向の入力変化に対する遅延は29 µsのNOM値。名称は入力の変化方向を指すため、INB−上昇→OUTB下降には18 µsではなく29 µsを参照する。条件はVDD=5 V、入力オーバードライブ10 mV、プルアップ10k。現行STOP電源は約3.3 Vであり、この値を最大遅延として使用できない。TPS25981のOVLO応答1.2 µsもTYP値で最大ではない。

現行の130k/10k、誤差配分±1%、比較漏れ電流で検出点上限は5.7641 V。さらに遅延の測定条件である10 mVを入力端子で超える時点は、分圧前で最大5.9067 Vに相当する。サーボ上限6 Vまで残る差は0.0933 V。

参考として、この差を29+1.2 µsで除すと約3.09 V/msとなる。しかしこれは許容入力スルーレートの仕様ではない。公称遅延を足し、追加回路の遅延を無視し、サーボ端子が電源に追従する線形上昇を仮定した楽観的な説明用計算にすぎない。波形をこの値より遅く設定して合格させてはならない。

終了条件はデータシートから採用を裏付ける最大時間が得られるかの判断。得られなかったため、revNの波形掃引を増やす作業は行わない。窓監視は監視・起動条件には利用できるが、コンバータ故障による電池電圧の流入と回生について、電圧・エネルギーを制限するハードウェア経路の設計を先に進める。異常入力条件、制限素子の応答と負担、遮断経路を組み合わせて評価する必要がある。未完了設計を実機評価Issueへ移さない。
