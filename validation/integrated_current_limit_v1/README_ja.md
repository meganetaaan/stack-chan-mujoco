# 統合保護ICの電流設定比較

目的は既存片脚モデル4.917Aとの余裕と、短絡保護を別に評価する必要性を確認すること。
1.10kΩ、抵抗初期±0.1%、公称6585/RとIC±10%の比較で、検出範囲5.382〜6.592A。
最小側のモデル余裕0.465A。設定抵抗を左右ILM端子9へ仮置きした。実型番は未選定。

高速遮断の可変閾値比上限242%を組み合わせると比較上15.952A。
これは流し続けてよい電流ではない。直後の制限・再試行・発熱と遮断までのエネルギーは別。
ケーブル・接点・基板が保護されることを約6Aの設定値だけから判定しない。

IC資料SLVSGG6Dの式5と電気特性表を用いた寸法決めに相当する比較。
一部の説明が814系を明記しているため、候補813の適用範囲、5V条件、
抵抗温度・経年、実負荷と起動、配線協調は未確認。製造・回路合格ではない。
過電流猶予時間を増やす容量は、必要性と許容エネルギーが確定するまで追加しない。
