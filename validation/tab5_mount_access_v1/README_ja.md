# Tab5背面4点の工具進入検査

## 結果と設計判断

Y=±60mm、Z=52/124mmの4軸について、後方X−80から49mmまでの直線工具包絡を検査。
半径1.5mmと2.5mmの両方で、全4軸が外装と後部板に干渉した。
新しいブラケットだけを作っても、現在の組立状態で背面からねじを操作できるとはいえない。
電池交換ごとにこの背面ねじを解除する方式は、現状のサービス手順の候補から外す。

次の固定案はTab5を4点で取付枠へ先に固定し、取付枠を前方へ取り外す構成とする。
Tab5背面ねじは枠をロボットから外した状態で操作し、日常の電池交換では触らない。
枠の対胴体締結は外から操作できる位置へ設ける。まだ枠・締結具のCADや強度は確定していない。
外装へ工具穴を開ける案は強度・外形・ケーブルへの影響が必要なため、この検査から自動採用しない。

## 条件と限界

plan.jsonは実工具未選定の円柱予約。終端49mmはTab5背面52mmから3mm離した仮置きで、
実際のブラケット厚さ・ねじ頭位置を保証しない。工具の柄、曲げ工具、斜め操作は含まない。
この結果は円柱経路の不合格であり、全種類の工具で取り外し不能という証明ではない。
部品は最新のLB-020トレー・電池・ベルトで置換した現行胴体を使用。
半径を細くして合格にする探索はせず、8ケースで終了した。

## 次案で満たす条件

- Tab5取付枠と固定具が既存外形・画面・端子を妨げない。
- 枠を外しても胴体やヨー支持の主要締結を解除する必要がない。
- Tab5のねじ有効深さを確認し、底付きせず必要な掛かりを得る。
- 前方取外し中に本体を保持でき、配線を引っ張らず切り離せる。
- 枠を追加した状態で電池の持上げ・前方引抜きを再検査する。
