# Tab5背面取付パターンの一次資料照合

## 設計判断の更新

背面外側4点のM3取付位置をブラケットの優先候補にする。
前回は製品ページ本文だけを見て側面1/4″-20を候補にしたが、今回メーカー寸法図の裏面情報を確認した。
側面ねじ一箇所へ荷重を集める構成を先に作る必要はない。
ただしねじ長さ・有効深さ・締付け・取付部許容荷重は未確定で、製造リリースはしない。

## 根拠と照合

[M5Stack公式PDF](https://m5stack.oss-cn-shenzhen.aliyuncs.com/resource/docs/static/pdf/static/zh_CN/core/Tab5.pdf)
2026-09-17更新、15ページ寸法図を画像として確認。背面にM3*10の表記がある。
外側穴の横ピッチは47+73=120mm、縦ピッチ72mm。M3*10をねじ長さや深さ10mmとは解釈しない。
現行CADの外側4円筒の軸はX52mm、Y±60mm、Z52/124mmで、120×72mmピッチと一致。
半径1.45mmのCAD穴はねじの実効径・強度・加工指定には使わない。

元生成コード`board/mechanical/design/r5a_source/cad/r4_geometry.py`にも包絡モデルであり
ねじ掛かり未確認という注記がある。公称ピッチ一致によりこの注記を消さない。
図面の全穴・端子・締結の詳細を再現したCADと扱わない。

[メーカー構造データ](https://github.com/m5stack/M5_Hardware/tree/master/Products/C145_Tab5/Structures)
にはTab5.stlがある（取得時のGit blob SHAはreport.json）。今回STEPやねじ深さ指定は確認できなかった。
STLを精密なねじ仕様へ変換して推定することはしない。

PDFは通常のWeb取得がサイズ制限で失敗し、直接取得後に画像化して確認した。
ローカルpdftotextが利用できなかったためPyMuPDFでページ位置とリンクを抽出した。
PDFのSHA256とCAD抽出結果のSHA256はreport.jsonへ保存。

## 次の製作設計

4点固定ブラケットを、前方へのTab5引出しと電池交換を妨げない締結方向で構成する。
工具の進入、ねじ脱落防止、Tab5を支えながら固定解除する工程、配線の切離しを組み合わせる。
ねじ穴の深さが未確定のため固定長のねじはまだ選ばない。
穴ピッチ一致は#17の取付情報を進める証拠であり、#18の保持強度や#20の製造図完成ではない。
