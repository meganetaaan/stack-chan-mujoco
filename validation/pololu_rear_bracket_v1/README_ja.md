# 電源基板の後板固定台座 — 不採用案

基板を機体内に浮かせたままにしないため、基板の4個の固定点を2本のレールと前後連結部で受け、後板へ荷重を伝える台座を作成した。ABS/PETG候補、左右同形の位置移動、各1ソリッド。基板位置・穴位置・外形を保持し、後板へのM3通し穴2個/側を提案した。正式後板には未加工。

事前plan.jsonの113組固定干渉検査で不合格:

- 左台座とleft_plate_0_screw: 隙間0.316 mm、基準0.5 mm未満。
- 右台座とright_plate_1_screw: 体積重複11.4748 mm³。

基板・固定具だけの外包形状検査では、機体まで荷重を伝える台座の空間を検証できていなかったことが具体化した。左右の穴列を鏡像にせずメーカー配置を保持しているため、左右の干渉は一致しない。許容隙間は変更しない。

各台座体積6959.89 mm³。STEPと生成手順は失敗案の証跡であり製作対象ではない。後板に接触する位置は距離0で確認したが、接触面積・締結保持・座面圧・公差・工具の出し入れは未評価。基板締結ねじ、台座締結ねじ/ナット/ワッシャー、配線、動作干渉も未統合。

次の設計変更は特定されたねじ周辺の逃げを設け、残るレール断面と基板固定穴の支持を確認すること。先に形状を成立させるまでFEは行わない。ねじ周辺の逃げが取付剛性を損なう場合は台座の支持経路を変更し、結果を通すための基準変更は行わない。
