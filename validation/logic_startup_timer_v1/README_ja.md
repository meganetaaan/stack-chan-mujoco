# 起動充電と遮断タイマの整合

TPS26601の遮断モードを[TI RevG §7.6](https://www.ti.com/lit/gpn/tps2660)で確認した。tCB(dly)の4 msはNOM欄で、最小・最大欄に保証値は示されていない。875 µsは別のPGOOD関連遅延であり、遮断タイマの値として使わない。

保存済み充電電荷94.919 µCについて、一定80 mA供給・一定20 mA負荷の診断モデルでは1.582 ms、4 ms公称値との差は2.418 ms。しかし、この差を起動保証の余裕とは呼べない。80 mAは3S実回路全体の供給保証ではなく、実負荷も一定ではない。起動時間の最大値とタイマの最小値を比較できていない。

また、TPS26601のdVdTで直接制御するのはTPS709入力側。TPS709の出力容量が同じ傾きで充電されるとは限らず、前段スルーレートだけから後段充電電流を算出しない。TPS709の起動時間仕様も指定負荷・容量条件付きである。

**判断:** 現在の120 kΩ・22 µF案を起動合格にしない。一方、公称時間だけで誤遮断すると断定して容量や制限値を変更することもしない。次の統合モデルには選定済み入力容量、TPS709の有効な起動モデル、電流負荷条件が必要。タイマのばらつきはメーカー資料または後続実機評価で扱い、未知の最小値を仮置きした掃引で合格させない。

実機へ分離できるのは専用ICの内部タイマ実特性・実基板の起動波形であり、未設計の入力保護接続・容量・放電回路まで実測Issueへ移して#24を完了扱いにはしない。

report.jsonは4 msをnominal、min/maxをnullと保存。計算再現は`logic_startup_charge_v1/report.json`のcharge_Cを(0.080−0.020)で割る。製造リリースなし。
