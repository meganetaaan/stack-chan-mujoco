# 側面ねじ取外し経路とナット抜け経路

## 結果

111部品統合CADの各側面ねじを、左右外側へ12mm移動する連続包絡で検査。
全4本で他部品との0.01mm³超の体積干渉0。
終端でねじ先端|Y|66mm、頭部外端78mmとなり、胴体から完全に抜ける。
半径1.5mmの軸と半径2.75mmの頭を同軸円柱として、移動中の全領域を作成。
元のねじ形状との双方向差分が1e-6mm³未満であることも確認した。
ねじ山や工具・指はモデル化していないため、これだけで工具操作可能とはしない。

## ナット保持の欠落

対応ねじを除いた状態で、各ナットを内側へ5.4mm並進する経路を追加検査した。
目的はナットポケットが単なる回り止めか、取外し時にも保持できるかを区別すること。
同一六角断面を移動量だけ長く押し出した連続包絡を使用し、4本とも体積干渉なし。
最大寸法ナットでも内側へ抜ける経路が存在する。現構成を脱落防止ナットとは呼ばない。
これは落下時刻・落下確率の解析ではなく、幾何学的に拘束されていないことの反例。

次は内側開口の蓋・保持爪などを部品として設計する。摩擦やきつい造形だけで保持成立とはしない。
保持を追加した後はナット挿入、ねじ取外し、枠引出しを再検査する。
ユーザーが使えるTPUを採用する場合も、硬度・クリープ未定のまま保持強度を保証しない。
