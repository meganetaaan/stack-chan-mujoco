# 旋回応答を使って初期化したPPO候補

記録済みの実シミュレータ観測に対し、測定した左右膝の旋回応答から教師出力を作り、
ニューラルactorを8,000更新で初期化した。その後、衝突形状を追加した実MuJoCo環境で
32,768ステップのPPO学習を行った。**合格判定はまだ未確定。**

評価・実行時には別の解析的旋回制御則を加えず、ニューラル方策が関節目標補正を出力する。
参照歩容と静的トルク補償、サーボ遅延・制約は従来と同じ。
`initial_policy.zip` は教師出力で初期化した方策であり、その時点のPPO実行ステップは0。
最終 `policy.zip` はその後のPPO更新を含む。

教師関数への適合誤差を歩行性能と混同しない。`initialization_fit.json` は
未使用の4試行の観測に対する関数近似だけを検証する。
新しい受入シードは固定107000–107019、ランダム化108000–108019。
モデルは `assets/r6_base_collisions` で、固定クレードル・電装予約の22形状を追加している。
