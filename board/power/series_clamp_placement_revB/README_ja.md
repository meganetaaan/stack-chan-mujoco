# 4mΩ×2直列／片脚の配置案

WSLF25124L000FEAを左右2個ずつ配置したLT4363代替案。現行revMには未統合。[メーカー仕様書](https://www.vishay.com/docs/30193/wslf.pdf)のランド1.8×3.4mm・間隔3.4mmを使い、直列中間パッド中心間を2mmの幅3.4mm配線で接続する。外側両端から独立の検出線を引く。

銅厚35µm、抵抗率20℃で1.724e-8Ωm、温度係数0.00393/Kを比較入力とした矩形配線計算では、150℃で約0.438mΩ。モデル電流4.917Aで約2.153mVを消費し、部品比較の残余4.723mVから約2.570mVが残る。150℃の基板使用を承認するものではなく、抵抗比較の温度入力である。

追加配線だけで部品変更による余裕を全て失う結果にはならなかった。ただしパッド内電流分布、端子取出し、はんだ、エッチング・銅厚公差は未評価。矩形部分の計算だけで全配線誤差を保証しない。線幅・銅厚は比較案で製造仕様未確定。

KiCad7で読込みとSVG出力を確認した。回路の大部分は未配置で外側配線は未接続。製造用基板ではない。

再現：`.venv-engineering/bin/python software/sim/circuits/place_dual_series_shunts.py --out /tmp/series-shunt-b-review`。
