# 電源取付部の現行設計候補

`current.json`を解析・統合の参照先とする。revBは43部品を維持し、
左右ブラケットのねじ通し穴を2.4mmへ拡張した候補。
ナット溝4.2mm、部品型番、基板配置、外形は維持する。
製作許可ではなく、次の設計判断に用いる候補の一本化。

## 製造条件の確定に必要な評価量

| 対象 | 必要な条件 | 現状 |
|---|---|---|
| ブラケット穴 | 最小実径、中心位置、軸の傾き、穴と溝の偏心 | 公称2.4mmのみ。造形／仕上げ後の範囲未指定 |
| ナット溝 | 最小幅で位置調整、最大幅で回り止め、挿入高さ | 公称4.2mm。工具・トルク・抜け防止は未確定 |
| スペーサー座面 | 公差後の接触面積と偏心、局所圧縮、長期沈み | 公称姿勢の投影面積のみ。許容値未設定 |
| 締結 | 有効ねじ掛かり、初期・残留締付け力、緩み | カタログ最大トルクを組立トルクに流用しない |
| 部品配置 | PCB穴・ねじ径限界と個別調整量 | 32姿勢の公称比較。全公差適合ではない |

仕上げ加工を採用する場合、基準面と穴位置の加工・検査方法を先に決める。
未知のプリンター精度を許容値へ読み替えない。ナット溝を無制限に広げる変更もしない。
この候補の選択で、座面・剛性・締結の合格を宣言しない。

現行胴体統合は `validation/torso_power_integration_v2`。
旧v1・旧電源組立は失敗／比較記録として保持する。
#17–20は未完了、製作HOLD。
