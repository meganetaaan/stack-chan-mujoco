# 3S候補電池トレイ revA（形状候補）

電池22×60×30mm、中心(29,0,80)mmに合わせて新規形状を作成。
旧トレイでの電池干渉を解消し、床上面Z65mmで電池底面を支える。
側面固定軸(29,±61.2,63)mm、穴径2.2mmを維持。左右の腕から床へ立上りを追加。
旧形状を削って壁厚を失う方法ではなく、電池寸法に合わせて壁と床を構成した。

単一の有効ソリッドを確認。電池との体積重なり0mm³。
現行ヨー支持組立、旧Tab5・変換器・TTL・ヨーモーター包絡との体積重なり0mm³。
ヨー支持組立との最短距離は0で接触あり。固定部を含む接触のため、
この検査を正のクリアランス合格とは扱わない。新UBECはまだ配置していない。

片側0.7mmの隙間は設計仮定で、電池公差・膨張・緩衝材を保証する値ではない。
素材はABS/PETG比較対象。造形方向・許容応力・層間強度が未確定なので、
密度を仮定した質量・強度合格は出していない。

次は固定部の荷重経路と接触、ストラップと通し穴、配線出口と取り出しを設計する。
穴位置維持だけで既存ねじ・締結が使えるとは保証しない。
製造リリース不可。全身モデルは変更していない。

```
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/build_rc_battery_tray.py --out NEW_DIRECTORY
```
