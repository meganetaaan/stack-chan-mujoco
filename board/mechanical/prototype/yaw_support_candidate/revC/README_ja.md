# ヨー支持部 revC：現行設計候補

工具逃げを含むv7比較形状を製作候補の正規ディレクトリへ整理した。
STEP・部品一覧・幾何モーメントはv7とバイト単位で同一。形状を再生成していない。
`current.json`はrevCを参照するが、**製作リリースではない**。

revBから52部品の名前を維持し、20件の部品属性に差分がある。
内訳と体積差は `change_check.json`。属性差分数は新規部品数ではない。
主要な修正は支持部の補強・工具逃げと周辺取付部品の更新。
脚長・関節位置の変更はこの整理に含めていない。

## 適用できる既存証跡

- v7の全1326組の静的比較：revBからの新規体積干渉フラグなし。
  既存のねじ包絡等の重複が残り、無干渉組立の保証ではない。
- v6からv7への集合包含検査：50部品不変、左右支持部は材料を除去した形状。
  v6の剛体隙間下限を保守側に引き継げる。v7を新たに動かして測った値ではない。
- 対象はヨーカプラー＋ロール支持部と固定組立、ヨー±15度。
  公差・仮定変形量を差し引いた残余下限1.0084mm。
  変形量の仮定が実物で成立することや、全関節・配線の隙間は未証明。

コピー元、検査結果、検査に使われたCAD、個々の部品元ファイルのハッシュを確認した。
`python software/sim/structural/package_yaw_revc.py`でこのパッケージと参照先を再作成できる。

## 適用しない結果と残件

revBを入力にした強度・質量・メーカー形状適合結果をrevCの合格結果とは呼ばない。
幾何モーメントは均質な形状の量であり、造形密度・材料・締結強度の確定値ではない。
Pololu取付部とその更新後部板、足revE、脚全体、配線、最新電源部品はこの52部品に統合されていない。
後部板を含む全身統合時は同名部品を重複加算せず、置換差分を扱う必要がある。

ABS/PETGの製品・積層条件、締結部の保持・接触、荷重への質量反映、
実変形と全身干渉、製造公差・組立工程が未完了。#17–20は開いたまま。
