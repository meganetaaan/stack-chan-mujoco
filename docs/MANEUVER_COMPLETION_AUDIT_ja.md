# 動作・切替目標の証拠確認

対象はTab5を顔とする二足歩行ロボットの設計と、平坦床のMuJoCoによる前進・後退・左右旋回・停止の指令切替検証。実機検証と転倒後の起き上がりは対象外。

| 要件 | 確認した証拠 |
|---|---|
| Tab5の顔、胴体・脚長・足形状を大きく変えない | 採用r8と元r6の直接比較で、元の11部位の初期位置・姿勢と11個の胴体・Tab5・足の外形ジオメトリが一致。`validation/yaw_acceptance_phase22_v1/geometry_audit.json`。r8のCAD STEP、メッシュ、関節位置も公開。 |
| 前進・後退・左右旋回・停止と切替 | 凍結プロトコルの205秒・24区間。基本5指令間の全20有向切替、前進左右旋回、停止を含む。`configs/maneuver/acceptance_v1.json`、`docs/MANEUVER_GOAL_ja.md`。各試行の実位置・ヨー角から全区間を評価。 |
| 実機を想定した物理条件とばらつき | 浮遊ベース12軸、重力、質量・慣性・摩擦、トルク速度制限、遅延、目標フィルタ、飽和保護。質量・重心・摩擦・駆動特性・初期角度を凍結範囲で変動。実際の全パラメータを各reportに保存。モデル仮定と未同定事項を正式結果READMEに明示。 |
| 固定条件20/20 | 217000〜217019の全20件が205秒の全運動・着地・物理安全要件を通過。`validation/yaw_acceptance_phase22_v1/trials/summary.json`。 |
| ランダム化条件18/20以上 | 218000〜218019の18件が総合通過。218004は後退の着地不足、218015は後退の横速度超過で不合格として保存。シード置換・再試行なし。 |
| 転倒・自己衝突・関節制限逸脱・保護停止なし | 全40件で実行エンジンの物理異常記録なし。1 ms刻みで判定。総合不合格2件も追加の運動・着地要件による。20 ms記録からサブステップ安全を再証明したとは扱わない。 |
| 制御ソフトと設計データ | `yaw_maneuver_reference.py`、`generate_yaw_maneuver_reference.py`、`probe_yaw_dynamics_candidate.py`、`stackchan_rl/`、`assets/r8_yaw_offset_flange_v1/`。凍結対象101ファイルの変更なし。 |
| 状態記録・再生動画・結果 | 正式全40件のstates.npz、接地イベント、ソース、プロトコル、report、集計を保存。成功218000と不合格218004の全205秒動画を実積分状態から50 fps・10,251フレームで生成し、ハッシュ・動画フレーム数・代表場面を確認。 |
| 再現可能な評価 | 凍結参照、物理設定、シード、Python・依存パッケージ版をsnapshotに保存。`docs/YAW_ACCEPTANCE_RUN_ja.md` と正式結果READMEに実行・再評価コマンド。公開用ディレクトリの全40件でも `assess_yaw_acceptance.py` の再評価が20/20・18/20で一致。 |

正式試験では独立な未使用シードで候補を評価し、開発20/20を正式試験の代用にしていない。判定基準は開発中も正式試験中も維持した。関連32テストと全件集計の欠落・重複・ソース変更の拒否3テストを確認した。最終的な合格の根拠は合成テスト軌跡ではなく、正式試験の実MuJoCo状態と凍結エンジンの結果である。

この達成の適用範囲は公開モデルと明示したばらつきのシミュレーションである。固定ケース締結・ねじ選定・支持強度、実物の電源構成・パラメータ同定は未確定であり、製造リリースや実機歩行の達成を主張しない。IMU姿勢補正を使わない候補なので、IMUノイズへのフィードバック耐性もこの試験の結論には含めない。
