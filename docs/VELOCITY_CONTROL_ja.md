# r9の並進・旋回速度追従

W/SとA/Dを独立した速度指令として扱う。W+A、W+D、S+A、S+Dで曲線歩行できる。
速度は機体の向きを床へ投影した座標系を基準に、前進を正、上から見た左旋回を正とする。
S+Aでも機体の向きは左へ回る。通常のWASDは横移動の指令を扱わない。Shift＋WASDの横歩きは [操作手順](TELEOP_ja.md#shiftwasd向きを保った並進r9) を参照。

```sh
GALLIUM_DRIVER=d3d12 python teleop_yaw.py --fps 15
```

キーを離す、Space、またはフォーカスを失うとゼロ速度を要求する。加減速制限と接地中の歩を完了する処理があるため、瞬間停止ではない。Rでリセットする。

## 指令と制限

| 操作 | 並進要求 | 旋回要求 | 定常時の制限後目標 |
|---|---:|---:|---|
| W | +0.025 m/s | 0 | 同左 |
| S | −0.012 m/s | 0 | 同左 |
| A / D | 0 | ±32度/s | 同左 |
| W + A/D | +0.025 m/s | ±32度/s | +0.025 m/s、±12度/s |
| S + A/D | −0.012 m/s | ±32度/s | −0.012 m/s、±12度/s |

並進中は旋回目標を±12度/sに制限し、ヨー関節の移動余裕を確保する。目標速度の変化は0.04 m/s²、目標角速度の変化は0.8 rad/s²まで。実際の機体加速度をこの値に固定するものではない。フィードバック補正後の歩行生成入力にも別の上限がある。姿勢の傾斜が10度を超えると目標を減らし、14度でゼロにする。両足の支持荷重が0.35 N未満の状態が0.1秒を超えた場合もゼロ目標へ減速する。これらは元の1 ms周期の転倒・衝突・関節・駆動保護判定を置き換えない。

画面には要求値 Req、加減速・制限後の目標 Tgt、実測 Meas、制限理由を表示する。単位は m/s と度/s。APIでは `Simulation(..., fast_turn=True).step((v, omega))` として、m/s と **rad/s** の有限値を渡す。大きすぎる有限値は制限し、NaN等は計画異常として停止する。

## 制御の構成

1. 入力を2軸の速度指令へ変換。同じ軸の反対キーは相殺し、別の軸は維持する。
2. 速度制限と加減速制限を適用する。
3. 実際の浮遊ベース速度をMuJoCoから取得し、水平な機体向きの座標系へ変換。40サンプル・0.8秒（2歩分）の移動平均を使う。
4. 目標との差をPI補正し、歩行生成へ渡す。目標が一定になって0.8秒経つまで積分を待ち、起動時の測定遅れを積分しない。飽和時は積分を進めず、ゼロ指令の軸は積分を解消する。静止や純旋回で意図しない並進を発生させないため、非指令軸のドリフトを積極的に相殺する制御は行わない。
5. 0.4秒/歩の参照を接地境界で更新。並進＋旋回時は、左右足の旋回中心からの距離に応じた前後移動差を着地点へ加える。小角度の旋回向けの近似であり、全身の軌道最適化ではない。足の向きは既存のヨー参照とIKで計算する。その場旋回を止めるときは現在のステップを完了し、その時点の足の向きで両足支持へ移り、余分な足揃えを避ける。
6. 静的トルク補償と既存の駆動モデルで関節を動かす。シミュレーション中にルート位置・姿勢・速度を上書きしたり、補助外力を加えたりしない。

速度の追従とは上記の周期平均速度の追従を指す。一歩の途中の瞬間速度、横流れ、任意の急変入力について完全な一致を保証しない。実機用の速度推定器はまだ未実装で、MuJoCoの状態値を使用している。

## 再現する

```sh
python -m unittest tests.test_velocity_control tests.test_teleop_yaw tests.test_teleop_r9 -v
python run_velocity_evaluation.py --out outputs/velocity_evaluation_new --workers 3
```

出力先は新しいディレクトリを指定する。短縮確認は `--quick`。各試験のJSON、50 Hzの速度・姿勢記録NPZ、集計とソースハッシュを保存する。角速度の保存単位はrad/s。試験中はソースを変更しない。

正式な実機合格試験ではなく、r9の速度制御のシミュレーション評価である。定常試験は2秒静止、9秒指令、3秒停止で、時刻5〜10秒の周期平均速度を評価する。合格基準は並進・旋回の平均誤差が0.004 m/s・3度/s未満、RMSEが0.008 m/s・5度/s未満、横流れRMSが0.012 m/s未満、停止整定2.5秒未満、かつ物理・駆動異常なし。停止整定は並進0.004 m/s・旋回3度/s未満が残り期間（最低0.5秒）続く最初の時刻とし、最後に立位へ戻ることも要求する。

名目グリッド15条件、4種類の曲線歩行に対する質量±5%と摩擦0.7/0.9の単独変動16条件、急反転・短時間入力1条件を評価する。反転試験は安全性と最終停止を評価し、非定常の速度誤差では合否判定しない。別途、フィードバックを無効にした4条件と比較する。有限個の試験であり、範囲内の全指令列や全ての複合外乱を保証しない。

既存のr8・r9有限90度試験のモデルと凍結結果は変更しない。r8の操作へ戻す場合は `--profile r8`。r9の有限90度試験とは、連続操作の停止条件・速度制限が異なる。

## 保存した評価結果

`validation/velocity_tracking_v1/` にソースハッシュ、全36試験の記録、回帰テスト結果を保存した。制御あり32/32条件が通過。制御なし4条件は比較用で、合格数には含めない。

全定常条件での平均誤差の最大値は並進 0.00190 m/s、旋回 0.446度/s。停止整定は最大 1.96秒、横流れRMS最大 0.00652 m/s。横流れは残っているため、厳密な円軌道追従を保証するものではない。

|---|---|---|---|
| +0.025 m/s / +12度/s | +0.02505 m/s / +12.23度/s | +0.02655 m/s / +13.21度/s | joint_limit |
| +0.025 m/s / -12度/s | +0.02505 m/s / -12.23度/s | +0.02655 m/s / -13.21度/s | joint_limit |
| -0.012 m/s / +12度/s | -0.01117 m/s / +12.14度/s | -0.00973 m/s / +12.81度/s | 停止完了 |
| -0.012 m/s / -12度/s | -0.01116 m/s / -12.14度/s | -0.00973 m/s / -12.81度/s | 停止完了 |

比較用の制御なし前進旋回2条件は停止過程で関節制限に達した。この失敗も保存している。初回評価でその場旋回の停止整定に失敗した記録は `development_stop_failure_summary.json` に残し、最終成績には混ぜていない。
