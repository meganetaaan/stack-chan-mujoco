# r9：左右90度を6歩・約2.76秒で旋回

MuJoCoで左右とも90度（停止誤差±1度以内）を6歩で行い、約2.50秒から安定停止、約2.522秒で最後の着地確認、約2.76秒で胴体の移動・回転も落ち着いた。試験はそのまま7秒まで継続し、転倒・自己干渉・関節限界逸脱・保護停止はなかった。実機の結果ではない。

## 結果と確認範囲

- 名目条件の最終方位は左右約±89.836度。最大傾きは約7.1度。
- 名目条件に加え、重量±5%と摩擦係数0.7／0.9をそれぞれ単独で変えた左右計10条件が通過。全条件とも6着地、着地確認は約2.515〜2.532秒、胴体の移動・回転を含めた停止は全条件で約2.76秒。ランダム受入試験ではない。
- 安定停止は方位誤差±1度、ヨー速度5度/秒以下、傾き10度以下、両足荷重0.35 N超を残りの試験時間（最低1秒）で維持することで確認。方位は記録した胴体四元数から独立に再計算する。状態の記録間隔は20 ms。
- 着地は1 msごとに既存の判定を使用。空中時間80 ms以上、高さ2 mm以上、接地荷重0.35 N超で40 msの継続確認などを満たす。名目条件の6歩目は旋回開始約2.522秒で確認される。
- 全身CADは45部品、左右各63姿勢で異なるリンク間の交差を検査し、0.01 mm³を超える干渉なし。離散姿勢の検査であり連続掃引の証明ではない。
- トルク上限、速度・遅延モデル、重力、時間刻み、減衰、摩擦損失、飽和保護を維持。浮遊ベースへの補助力、姿勢拘束、衝突除外は追加していない。

胴体の停止は並進速度0.02 m/s以下、全軸角速度10度/秒以下を残り試験時間（最低1秒）で維持することも確認した。最終的な完了時刻には、方位・着地・胴体停止のうち最も遅い時刻を使う。動画には冒頭2秒の立位を含み、所要時間は旋回指令時から計測する。

既存r8とその正式評価は保存した。今回の変更後も旧40試行を再評価し、固定20/20・ランダム化18/20が一致している。旧成績をr9の成績には転用しない。

## 機構と制御の変更

胴体128 mm角、Tab5の顔、大腿50 mm、下腿44 mmを維持。ヨー軸を20 mm前へ移し、左右の股関節を片側4 mm外へ移した。足はつま先側を8 mm短くし、内側を4 mm狭め、86×48 mmにした。足首の開口、ヨー連結板、胴体下面の逃げをCADと衝突形状の両方に反映している。

バッテリーを30 mm前へ、コンバーターを後方へ移し、トレーは側壁支持に変更。CAD由来の質量・慣性を再集約した。締結部の強度やモーターの実機同定、電源適合の確認は別途必要で、製造リリースではない。

周期0.4秒のうち45%を重心移動に使い、その後の遊脚中に旋回する。最終歩だけ残りの角度に制限し、停止後の余分な足揃えを省いた。左右で初期支持足も反転する。参照角度±91.5度は、名目条件で見られた約1.5度の停止偏差を補正する設定であり、実方位は90度を基準に採点している。

## 再現

既存のMuJoCo実行環境を使用する。CAD環境は動作の再現には不要。

```sh
python probe_fast_turn.py --design assets/r9_fast_turn_v1 --out outputs/r9_left \
  --rate-deg-s 40 --heading-goal-deg 91.5 --period .4 \
  --shift-fraction .45 --inset-mm 25.5 --initial-inset-mm 25.5
python assess_fast_turn_trial.py --trial outputs/r9_left --out outputs/r9_left/assessment.json
```

右旋回は `--rate-deg-s -40 --heading-goal-deg -91.5` に変更する。出力先は既存の結果を上書きしない新規パスにする。

10条件をまとめて再試験する場合：

```sh
python run_fast_turn_sensitivity.py --design assets/r9_fast_turn_v1 --out outputs/r9_verification
```

モデルは [assets/r9_fast_turn_v1](../software/sim/mujoco/assets/r9_fast_turn_v1)、検証記録・動画は [validation/fast_turn_v1](../validation/fast_turn_v1)、失敗例を含む経緯は [FAST_TURN_GOAL_ja.md](FAST_TURN_GOAL_ja.md) に分離した。WASD用の既存 `teleop_yaw.py` は引き続きr8を既定としている。
