# X330メーカー資料と現行ヨー候補の照合

2026-09-20にROBOTIS公式マニュアルから、図面・STEP・重心／慣性資料を取得した。旧ダウンロードページのJavaScript内に実ファイルへの転送先がある。参照元と取得ファイルのSHA-256は `design/x330_manufacturer_reference.json` に記録した。メーカーのPDF・STEPそのものはリポジトリへ再配布せず、取得スクリプトで再現する。

- [XL330公式マニュアル](https://emanual.robotis.com/docs/en/dxl/x/xl330-m288/)
- [メーカー図面](https://www.robotis.com/service/download.php?no=1986)
- [メーカーSTEP](https://www.robotis.com/service/download.php?no=1987)
- [メーカー重心・慣性資料](https://www.robotis.com/service/download.php?no=2136)

図面では長手34 mmに対し出力軸は端から9.5 mm、したがって長手中心から7.5 mm偏心する。ケース厚23 mm、前ホーン突出3 mm、前ホーン込み26 mm、背面アイドラー込み29 mm。ホーンは直径16 mm、PCD12 mmの4穴（穴径1.6 mm、最大深さ3 mm、M2タッピングねじ）と読める。メーカーは図面・慣性資料を参考値としている。

現行 `r7_yaw_xc_ankles_v1` はヨー軸を長手方向のケース中心に仮置きしているため、7.5 mmの位置差を反映していない。また回転側ポストの半径4 mmではPCD半径6 mmの取付穴に届かず、取付フランジと締結穴が必要。ポスト上端とケース代理形状の下面には0.5 mmの隙間がある。これらは実ホーンへの接続を確定した製作形状ではない。

メーカーSTEPは15ソリッドを含み、全体の長手範囲は−24.5〜9.5 mm、軸方向範囲は−22.5〜6.5 mm。前ホーンと背面アイドラーを含む29 mmの全体幅と整合する。現行26 mmの一体箱へ無条件に置換せず、使用する付属品、座標系、固定側／回転側の分離を決める必要がある。

慣性資料からXL330-M288とXC330-M288の質量・COM・慣性行列を転記した。これは旧一様箱近似より具体的な入力になるが、STEP座標と資料座標の対応、慣性の基準点、付属品の範囲を確認してから適用する。今回、現行モデルの慣性や衝突形状を黙って更新してはいない。

次版では胴体外形・脚長・足形状を保ち、メーカー形状に合わせたケース位置、ホーンフランジ、固定側の締結を設計し直す。干渉と質量・慣性を再計算した後、そのモデルで動作試験を再実施する。現在の歩行成績は仮配置モデルについての開発証拠であり、実機製作適合の証明ではない。

```sh
python fetch_x330_reference.py --out outputs/new_x330_reference
```

## 偏心を反映した開発候補

`assets/r8_yaw_offset_flange_v1` にケース偏心・回転ホーン・穴付きフランジとトレー支持経路の修正を追加した。ヨー取付部の離散干渉検査と短期動作試験の結果は `validation/yaw_offset_flange_development_v1/README.md`。ケース固定・ねじ・支持強度・慣性同定は未完了で、製作リリースではない。
