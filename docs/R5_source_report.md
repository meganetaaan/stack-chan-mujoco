## 検査方法と継承範囲

新しい外装部品と他の部品の組合せは再計算しています。無変更の脚同士の301姿勢の検査は、元のR4結果を継承しています。その同一性は元ソース・機構パラメーターと各部品の形状フィンガープリントで確認しました。全組合せを301姿勢すべてで再検査したという意味ではありません。追加の同時開脚では全機械部品をチェックしています。

体積干渉の判定閾値は0.01 mm³。材質領域を覆う保守的なボックスを用いた広域判定後に、CadQuery/OCCTのB-rep交差を計算します。同一リンクや隣接関節を一括除外していません。グラフィック用の顔と画面色のみ検査対象外です。

## 大きな同時開脚の不合格

股ピッチ0.6 rad、膝−1.2 rad、足首ピッチ0.6 radを維持し、左右の股ロールを外向きに同じ角度にした試験です。足首ロールは逆向きに補償します。

- 6°の全機械部品試験では閾値を超える体積干渉なし。
- 6.5°の対向腿リンク試験では約0.184 mm³の干渉。
- 16.04°では腿リンク・股キャリア・股ピッチサーボ同士の干渉を確認。
- これはR4脚の制約で、新外装とは干渉していません。脚を変えない条件に従い未修正です。

したがって「全関節の可動域全体で干渉なし」「6°まで実機で安全」「歩ける」とは判定していません。ビューアーの同時開脚は0〜5°に限定しています。

## 見た目・モデルの限界

実CADと同じメッシュを使用しています。3Dビューアーの再生・開脚は目標姿勢の表示で、接触力・転倒・滑りを計算しません。増加した外装質量と慣性をMJCF/URDFへ反映しましたが、動力学の実行・学習・歩容調整は今回実施していません。

実物のねじ、ホーン、コネクター、電源、配線、材質の変形、印刷公差、締結強度は未検証です。最終製作用データではありません。
