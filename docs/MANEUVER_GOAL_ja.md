# 前進・後退・旋回・停止の設計検証

新目標は指令に応じた動作と切替。起き上がりは対象外。従来の前進受入は
`assets/r6_mounted_battery`、`policies/r6_mounted_seed20260924` として維持する。
新しい制御・機構の成績に従来の20/20・18/20を転用しない。

## 先に固定する評価条件

`configs/maneuver/acceptance_v1.json` を新しい開発評価の前に定義する。
実現手法は限定しない。現行10軸での制御拡張と股関節ヨー軸追加を比較対象に残す。

| 指令 | 前後速度 | 旋回速度 | 1区間 |
|---|---:|---:|---:|
| 前進 | 0.10 m/s | 0 | 10秒 |
| 後退 | -0.05 m/s | 0 | 10秒 |
| 左その場旋回 | 0 | +π/20 rad/s | 10秒（指令積分90°） |
| 右その場旋回 | 0 | -π/20 rad/s | 10秒（指令積分-90°） |
| 停止 | 0 | 0 | 4秒、最後は5秒 |
| 前進左／右旋回 | 0.06 m/s | ±0.12 rad/s | 各10秒 |

前後速度はロボットの向きを基準とする。旋回は世界鉛直軸まわりのヨー角速度。
5種類の基本指令間の20通りの有向切替を1試行で全て含み、さらに前進左右旋回と最終停止を行う。
合計24区間・205秒。前進↔後退や左↔右の直接切替も含む。評価の指令に瞬時に追従する
必要はなく、制御器の中で加減速を扱えるが、実指令と実動作の誤差をそのまま計測する。

切替直後2秒を除いた区間で、前後速度平均誤差≤0.02 m/s、旋回速度平均誤差≤0.04 rad/s。
0.5秒で平滑化した速度のRMSEは前後≤0.03 m/s、旋回≤0.06 rad/s、横方向≤0.03 m/s。
歩行に伴う左右の揺れを横移動の誤差と混同しないよう、横速度も平滑化して評価する。
区間全体の前後変位積分誤差≤0.20 m、ヨー角変化誤差≤15°。前後変位は実速度の
機体前方成分を符号付きで積分し、道のりの絶対値に置換しない。

その場旋回・停止中の区間開始位置からの最大移動≤0.15 m。
停止指令の2秒後以降は、平面速度RMS≤0.015 m/s、ヨー角速度RMS≤0.08 rad/s、
同計測区間開始からの位置変化≤0.03 m、ヨー角変化≤5°。
動作区間では左右各2回以上の有効着地も必要。既存の滞空0.08秒・足上げ2 mm・接触確認0.04秒等の
着地資格を引き継ぐが、世界+X方向への進行だけを着地として数える条件は使わない。
停止区間では着地回数や「歩き続ける」条件を要求しない。

固定条件seed217000–217019で20/20、ランダム化seed218000–218019で18/20が必要。
合格試行は全区間の動作条件と、全物理刻みの安全条件の両方を満たすこと。
モデル・制御を凍結してから評価し、失敗の除外やシード置換をしない。
これらのシードは開発調整に使用しない。条件変更が必要なら別版として理由を公開し、旧結果を残す。

## 物理条件

現行の固定具込みモデルと、公開設定 `policies/r6_mounted_seed20260924/config.json` の
質量・重心・摩擦・トルク・速度・遅延・IMUノイズ範囲を出発点とする。
物理1 ms、指令処理20 ms、転倒35°、関節数値許容10 µrad、接触侵入10 nmまたは力1 µN、
連続飽和0.25秒／1秒窓50%の保護条件を維持する。足裏以外の床接触も失敗。
自由基底への補助力、姿勢・位置の強制補正、物理制約を無効化した成功は認めない。

ヨー軸等を追加する場合は、CAD、質量・慣性、接触形状、配線空間、トルク速度モデルを更新する。
脚を長くして成立させることを前提にしない。実物の電源・同定・歩行受入は次段階。

## 現在の実装範囲

`stackchan_rl/maneuver_protocol.py` は指令スケジュールと実位置・ヨー角の動作評価を担う。
`yaw_maneuver_reference.py` と生成器で12軸の指令参照を作り、
`probe_yaw_dynamics_candidate.py` で浮遊ベースの実MuJoCo動力学、全軸の駆動制約・保護、
物理的安全、着地イベントを統合して評価する。
`motion_pass` だけを試行合格として扱わず、物理異常なしと全着地要件も必要とする。
テストの合成軌跡は評価器の正負対照であり、ロボットの歩行証拠ではない。

正式評価の候補凍結と全40試行の実行器は実装済み。
手順は [YAW_ACCEPTANCE_RUN_ja.md](YAW_ACCEPTANCE_RUN_ja.md)、
後退の位相比較は [開発記録](../validation/yaw_backward_contact_development_v1/README.md) を参照する。
22%候補の正式評価を開始した。凍結記録は `validation/yaw_acceptance_phase22_v1/candidate/`。
結果が揃うまで達成は未確認であり、開発結果を正式20/20・18/20の達成に転用しない。

旧方策には前進専用の参照・報酬・歩行中断条件がある。新しい指令系は別実装とし、
停止を失敗にしないことと、停止指令中の動き過ぎを失敗にすることを両立させる。
実現候補の採否はMuJoCoの実状態と機構制約を根拠に判断する。
