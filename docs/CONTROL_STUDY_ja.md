# 電池込み候補の参照歩容診断

2026-09-19。胴体内電池配置・股間隔44 mm・質量約859 gの候補で実行した。
これは機構と制御の問題を切り分ける短時間の研究試験で、10 m受入試験ではない。
形状・脚長・サーボの物理パラメータは変更していない。

## 制御方法

`probe_reference_gait.py` は、左右の足位置、前進する重心、横方向の支持移行から
逆運動学で関節角を計算する。左右の足の中点へ重心を連続的に進め、
各相の境界で足・重心・支持率が跳ばないことを単体試験で確認した。
旧参照のように支持足の前後位置へ重心を固定する方法も診断用に残している。

自由基底のMuJoCoに位置目標を送り、1 msごとにPD・トルク速度包絡・通信遅延を計算する。
胴体位置を強制移動せず、外力・重力補償拘束を追加しない。
`--static-compensation` は静的必要トルクをPDゲインで割った目標角補正を追加する。
補正後も関節目標範囲、速度制限、40 ms LPF、サーボのトルク速度制限を通す。
実機サーボの同定済み補償ではなく、予定支持率を用いたフィードフォワードの実験である。

実測の足裏荷重・最低高さから、既存の着地検出器を物理サブステップごとに更新する。
無転倒・無接触で時間が経過しても、歩行成功とは判定しない。
自己接触と足裏以外の床接触もサブステップごとに検出するが、簡略衝突形状の限界は残る。
熱・電圧・電流保護、姿勢・速度の状態推定器はまだ実装されていない。

## 実行結果

各1試行、4ステップ分の予定軌道。速度は参照歩幅／1歩周期の設計値であり実測速度ではない。
時間には開始前1秒と最後の整定区間を含む。

| 設計速度 / 1歩周期 | 目標角補正 | 高さ変更 / slew | 実行時間 | 前進量 | 有効着地 左/右 | 結果 |
|---|---|---|---:|---:|---:|---|
| 0.02 m/s / 0.8 s | なし | 0 mm / 2 rad/s | 4.700 s | −1.871 mm | 0/0 | ほぼ静止 |
| 0.02 m/s / 0.8 s | あり | 0 mm / 2 rad/s | 4.700 s | 56.607 mm | 2/1 | 短距離の前進と左右着地。実機・長距離未検証 |
| 0.06 m/s / 0.4 s | あり | −5 mm / 6 rad/s | 2.739 s | 81.287 mm | 2/2 | 自己接触で終了 |
| 0.10 m/s / 0.3 s | あり | −5 mm / 6 rad/s | 1.478 s | 23.519 mm | 0/0 | 自己接触で終了 |
| 0.10 m/s / 0.2 s | あり | 0 mm / 6 rad/s | 2.300 s | 0.982 mm | 1/1 | 前進着地0/0。目標未達 |

低速補正ありの最大姿勢傾斜は約1.66°、静的計算の最大トルクは股ロール約0.215 N·m、
足首ピッチ約0.168 N·m。実際のピークトルクはそれぞれ約0.220 / 0.172 N·m。
これらはモデルの値で、サーボの連続定格を確認したことにはならない。
0.2秒周期では参照股ロール速度約9.13 rad/sがモデルの無負荷速度約8.48 rad/sを超える。
この準静的な重心移動を単純に高速化する方針には速度・動的安定性の問題がある。

## CADで確認した追加干渉

0.10 m/s・0.3秒周期の停止時関節角を全機械部品のB-repへ適用したところ、
胴体と左腿・左膝モーター・左脛、左固定クレードルと左膝モーターの4組に体積干渉。
0.06 m/s停止姿勢でも胴体と右腿・右膝、左膝モーターと左足首ジンバルの3組に干渉があった。
実際のMuJoCo接触ペアとB-repの干渉ペアは一致せず、衝突代理形状の見直しも必要。

**既存の同時開脚5姿勢での無干渉は、歩行中の無干渉を保証していない。**
次は外形・脚長を保ったまま、歩行中の姿勢集合で胴体底面開口を再生成し、
同じ脚内の固定部品・膝・足首の干渉を関節の組合せ制約または局所形状修正で解決する。
高速制御は準静的横移動の短縮だけでなく、身体の慣性を含む重心・接触制御を検討する。
干渉を無効化して歩行成功にする変更は行わない。

## 再現

先に `design/README_ja.md` の胴体内電池候補を生成する。

```bash
uv venv --python 3.12 .venv-dynamics
uv pip install --python .venv-dynamics/bin/python -r design/requirements-dynamics.txt
.venv-dynamics/bin/python probe_reference_gait.py \
  --design outputs/design_r6_battery_lower --speed .02 --step-period .8 \
  --static-compensation --out outputs/my_reference_probe
.venv-dynamics/bin/python -m unittest tests.test_reference_gait
```

保存結果と5条件のコマンドは `validation/reference_gait/`。
診断コマンドの終了コード0は記録完了を示し、歩行成功を表さない。
`report.json` は判定・入力ハッシュ、`reference.json` は予定関節・胴体姿勢、
`trajectory.csv` は物理計算の関節・位置・荷重・足高さを含む。
出力先は新しいディレクトリを指定する。

```bash
.venv-cad/bin/python check_design_clearance.py \
  --design outputs/design_r6_battery_lower \
  --trajectory-terminal-csv validation/reference_gait/fast_crouched/trajectory.csv \
  --out outputs/fast_terminal_cad.json
```

このCAD検査は終端1姿勢のみを扱う。関節姿勢による内部干渉は基底の剛体移動・回転に不変なため、
基底は検査側の基準変換を用いる。全軌道や床との接触、柔軟物を検証するものではない。
上記の既知の干渉ケースでは不合格の終了コード1になる。

## 底面開口の修正候補

歩行ログ49姿勢から底面開口を拡張した候補では、抽出姿勢の胴体との干渉を解消した。
脚内部の干渉は残っている。外形・関節配置の不変検査と再現手順は
[`design/gait_opening/README_ja.md`](../design/gait_opening/README_ja.md)を参照。
これは変更後モデルの歩行性能を示すものではない。

## 脚内部の局所修正と検査間隔の改善

クレードル・ジンバル・足外装内側の修正、全保存姿勢からの開口再生成を追加した。
[設計と再現手順](../design/leg_relief/README_ja.md)を参照。
高速動力学ではモーター同士の接触が続き、制御・関節の組合せ制約の課題が残る。

## 重心軌道の前後位置・横振幅の診断

[追加診断](COM_REFERENCE_STUDY_ja.md)で最大約1.04 mまで前進したが、接触停止している。
短時間の約0.52 m試験にも、ジンバルの衝突形状不足により見逃されたCAD干渉がある。
実機・10 m受入の成功とは扱わない。
