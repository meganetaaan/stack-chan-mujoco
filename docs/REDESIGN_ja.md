# Tab5 二足歩行再設計の作業台帳

2026-09-19開始。目標は `GOAL_PROTOCOL_ja.md`。現時点で製作用設計・実機歩行は未完成。

## 現状の根拠

R5-AはTab5横置き、128 mm立方体の胴体、左右各5軸、腿50 mm・脛44 mm、
足裏94×52 mm。モデル質量約826 gには電池70 gなどの仮定を含む。
出典: `assets/r5a/robot.json`、`scene.xml`、`R5_source_report.md`。
既存CAD生成元を `design/r5a_source/` に取り込み、`build_design.py` でSTEP/STL・
MuJoCo・URDF・部品表を再生成できるようにした。手順は `design/README_ja.md`。

既存の `outputs/walk_lp40_eval.json` は0.02 m/s指令、12秒×20試行で平均0.221235 m、
旧品質基準6/20合格。実測速度の全時間平均は約0.01844 m/s。
このログは発見した既存結果であり、今回再実行した結果と区別する。

今回の100秒診断は `validation/goal_baseline/diagnostic.json` に保存する。
20試行が完了し、平均前進量0.079431 m、旧基準合格0/20。実機の結果ではない。
`status=INCOMPLETE` のスナップショットは途中経過であり、20試行完了を意味しない。
チェックポイント・コード・モデルのハッシュ、評価設定、試行ごとの失敗理由を含む。
新受入判定器8件を含む220件の単体・runtime試験が既存WSL仮想環境で合格した。
コマンドは `python -m unittest discover -s tests`。スキップなし。
判定器の非有限値対策を追加後、該当8件を再実行して合格した。

主な未解決点:

- 脚同士は同時外向きロール6.5°で干渉するとの既存CAD報告。
  10軸という基本構成は維持しつつ、股間隔・キャリア・腿ヨークの干渉を改設計する必要がある。
- 現行サーボモデルはカタログ近似。連続出力・熱・電圧降下・バックラッシュが未同定。
- 61次元の観測にはシミュレータから取得した速度・位置・高さ・接触が含まれる。
  現行方策をそのまま実機に送るための状態推定器はない。
- 接触代理形状とCADの厳密形状は異なり、親子リンク接触にもフィルターがある。
  全姿勢の自己干渉をMuJoCoの無接触だけで保証できない。

## 設計方針と判断順序

Tab5の顔、胴体、左右の脚・足という構成を保存する。寸法固定や脚形状完全保存は
今回の指示には含まれないため、必要な股間隔・リンク・支持部品の変更を候補にする。
未確認の製作条件は別途確認中。

| 領域 | 次の設計・実装 | 採用に必要な根拠 |
|---|---|---|
| 機構 | 股キャリアと腿の逃げ、股間隔、電池位置、外装軽量化をパラメータ化 | 可動域と公差を含むCAD干渉、質量・慣性、剛性・締結の検証 |
| アクチュエータ | 現在のXL330×6、XC330×4を基準に、足首などの高負荷軸を再選定 | 実測トルク速度包絡、100秒以上の温度・電流履歴、電源降下 |
| 制御 | 立位→重心移動→遊脚→着地の歩容生成と姿勢安定化、必要なら残差RL | 両脚の交互支持、速度・距離・外乱試験、推定器入力での性能 |
| 推定・実機I/O | IMU、関節フィードバック、足裏接触、時刻同期、指令監視 | 計測対照、通信遅延分布、欠測と通信断時の試験 |
| MuJoCo | 同じ設計パラメータから慣性・衝突形状・関節・サーボを生成 | CAD整合、自由基底、無補助力、接触・熱・電源モデルの同定 |
| 受入 | 固定20試行の10 mコースと生ログ | 実機18/20、100秒以内、禁止イベントなし |

歩容周期1.6秒のまま0.10 m/sを出すには、左右均等な定常歩行なら1歩80 mmが必要
（0.10×1.6÷2）。これは現行の短い脚に対して大きく、指令速度だけの変更ではなく
周期・歩幅・可動域・速度上限の同時検討が必要。例えば周期0.6～0.8秒なら
1歩30～40 mmとなるが、これは探索候補であり実現性の検証結果ではない。

## 確認したメーカー仕様

2026-09-19参照。ストール値を連続許容値として採用しない。

| 部品 | 確認した値 | 設計での扱い |
|---|---|---|
| XL330-M288 | 5 V、0.52 N·mストール、103 rpm無負荷、18 g | 現行仕様の照合用 |
| XC330-M288 | 5 V、0.93 N·mストール、81 rpm無負荷、23 g | 高出力化に速度・質量の代償がある |
| Tab5 | メーカーdocsで128×80×12 mm、118.4 g、BMI270搭載 | 現行顔配置を維持。実機個体を計量する |

出典: [XL330](https://emanual.robotis.com/docs/en/dxl/x/xl330-m288/)、
[XC330](https://emanual.robotis.com/docs/en/dxl/x/xc330-m288/)、
[Tab5](https://docs.m5stack.com/en/core/Tab5)。
Tab5は販売ページ検索結果に別の質量値もあるため、実機型番と計量を優先する。
Tab5のRS485とX330のTTL半二重通信を直接同一バスとして扱わない。

暫定制御構成は、Tab5の顔描画と歩行の実時間処理を分離し、有線のサーボ通信、
IMU・足裏センサーの状態推定、指令の鮮度監視を専用制御側で担う。
計算ボード・センサー・電源の型番は予算と実測負荷が揃うまで未確定。
