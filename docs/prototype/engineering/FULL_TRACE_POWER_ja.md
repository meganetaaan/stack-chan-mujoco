# 記録12軸負荷の全時間評価

`run_full_trace_power.py` はEPIC #4の左右旋回で保存した各7,000サンプル・7秒の合成電流を、省略せず結合電源モデルに入力する。負荷開始は50 ms、解析終了は7.06 s。モデルは補助電源・EN・二重回生吸収・連続LDO近似を含み、電池7.4 V、内部抵抗0.1 Ωなどの仮定を維持する。

最大時間刻みは1 µs。合否用電圧極値は、ngspiceの内部計算点に対して `meas` を実行して取得する。その後、表示用波形だけを100 µs間隔へ補間する。表示波形のピーク値を合否に使わない。

この区別は、25〜26 µsに1 Vとなる短いパルスで確認した。内部計算点の最大値は1 V、100 µs間隔の表示波形の最大値は0 Vだった。表示波形だけの確認ではピークを失うため、生の測定結果・実行ログ・ネットリストを保存する。

事前基準は50 ms以降のバス4.75〜5.25 V、起動中ゲート0.4 V以下。負荷ピークが元波形と一致することと、表示波形が解析終端へ達することも確認する。

```sh
.venv-engineering/bin/python software/sim/circuits/run_full_trace_power.py \
  --side left --battery-v 7.4 --out outputs/full_trace_power_reproduction
```

右旋回は `--side right`。この記録負荷は機構改訂前のものなので、質量更新後のMuJoCo負荷再計算を置き換えない。部品の最悪条件・全歩行動作・実MOSFET・熱・電池容量・全エネルギー収支も未検証。記録電流は低電圧時の限定的な低減処理以外に電圧依存せず、機械と電源を再結合した実挙動ではない。

## 結果

|記録負荷|内部計算点のバス最小 V|バス最大 V|合成電流最大 A|モデル電池供給エネルギー J|
|---|---:|---:|---:|---:|
|左旋回・全7秒|5.113983|5.143602|0.5598435|34.0651|
|右旋回・全7秒|5.113970|5.143602|0.5601095|34.0668|

両方とも今回の基準内。起動ゲート最大は0.114412 V未満。表示用波形は各70,601点。エネルギーは仮定した電池モデルの端子電力積分であり、実電池の容量選定や収支閉鎖の証拠ではない。

`validation/full_trace_power_development_v1` に左右結果、元負荷と回路のハッシュ、判定前計画、測定ログ、ネットリスト、表示波形と短パルス確認を保存した。`.dat` は可逆圧縮し圧縮前SHA-256も保存している。
