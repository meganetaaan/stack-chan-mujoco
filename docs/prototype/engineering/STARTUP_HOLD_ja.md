# 回生ブレーキの起動時ゲート保持

起動中の不要なMOSFET導通を抑える候補として、バッテリー側で給電するTPS3700を各吸収経路に1個ずつ追加し、サーボ電源が低い間はOUTAでゲートを低く保持する構成を検討した。分圧は95.3 kΩ/10 kΩ、解除電圧は公称4.212 V。実装する回路・部品の確定ではない。

[TI TPS3700データシート](https://www.ti.com/lit/ds/symlink/tps3700.pdf)の仕様に基づき、起動待ち最大450 µs、入力しきい値公称400 mV、ヒステリシス公称5.5 mV、出力Low最大250 mV/3 mAをモデル化の出発点とした。電源動作範囲は1.8〜18 V。電源投入直後の正しい出力を仮定せず、450 µsは高インピーダンスとした。

## 比較結果

事前の開発目標は、起動後50 ms未満でゲート0.4 V以下、監視IC吸込み電流3 mA以下。通常負荷のバス4.75〜5.25 V、回生時4.75〜5.8 Vを確認した。

|条件|起動ゲート最大 V|定常/回生バス最大 V|今回の判定|
|---|---:|---:|---|
|監視IC追加、DC/DC起動遅延なし|0.42451|5.14360|起動ゲート不合格|
|起動遅延1 ms、通常負荷|0.11463|5.14360|今回の基準に合格|
|起動遅延1 ms、回生|0.11463|5.59264|今回の基準に合格|
|起動遅延1 ms、主経路開放|0.11463|5.67182|今回の基準に合格|
|起動遅延1 ms、補助経路開放|0.11463|5.59264|今回の基準に合格|
|起動遅延1 ms、両経路開放|0.11463|30.51702|過電圧で不合格|

遅延ありの吸込み電流最大は0.8054 mA未満。遅延なし初回試行では電流波形の保存・判定をまだ追加していないため、その項目は未評価。失敗記録を保持している。

## 実装に必要な条件と限界

バッテリー側が先に有効であることを仮定した。1 ms遅延はDC/DCの指令波形を遅らせて実現しており、実際の有効化端子・遅延回路の実装は未完了。緩やかな電池電圧上昇、瞬断、再投入、電池低電圧での監視IC動作も別途検証する。電圧監視入力の未使用側の処理、デカップリングと配線、部品BOMは回路図確定時に含める。

モデルは公称分圧・公称基準電圧で、監視ICの伝播遅延と温度・部品公差の全組合せを含まない。出力Lowを83.33 Ωで近似した値は実出力特性の保証ではない。ブレーキMOSFETも依然2.5 Vで切り替わる理想スイッチで、実際の線形領域・SOA・熱・エネルギー収支をこの試行では再検証していない。全電源保護の成立とは見なさず、Issue #24は未完了とする。両経路開放時の数値は部品破壊を再現しない過電圧の検出結果である。

## 再現

```sh
.venv-engineering/bin/python software/sim/circuits/run_startup_hold.py \
  --converter-delay-ms 1 --case normal --out outputs/startup_hold_reproduction
```

`--case` は `normal`, `no_fault`, `primary_open`, `secondary_open`, `both_open`。遅延なしは `--converter-delay-ms 0`。計画・ネットリスト・ログ・結果・可逆圧縮した生波形を `validation/startup_hold_development_v1` に保存した。
