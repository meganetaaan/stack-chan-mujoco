# 補助電源・EN・平均DC/DC・負荷の結合試行

`run_coupled_power.py` は保存済みの補助電源起動モデルと、DC/DC平均モデル・記録12軸負荷・二重回生吸収回路を結合する。モデル境界を越える制御依存を確認する開発試行で、実部品の電力・熱・保護成立の証拠ではない。

## 結合時の変更

補助電源と電池監視を電池内部抵抗の後へ接続した。ENは平均DC/DCを直接停止し、有効化後は時定数1 msの指令上昇で起動する。実DC/DCのソフトスタート保証値ではない。

ゲート保持監視ICはAUX3V3から給電し、AUX3V3が1.8 Vを割ると450 µs相当の起動待ちを取り直す。以前の電池側直給電からの変更で、補助電源が共通故障点となる。独立した二経路の全故障耐性は主張しない。

無給電時に定電流負荷でバスが非物理的な負電圧にならないよう、記録負荷の正電流を0.5 V未満で低減する。3 W制御負荷も同様に低電圧側を抵抗性にする。サーボやTab5の実低電圧動作ではない。今回は保存負荷の最初の150 msのみを使用する。

## 完了した試行

|条件|通常判定区間のバス V|電源断・復帰区間のバス最小 V|起動ゲート最大 V|判定|
|---|---|---:|---:|---|
|通常起動|5.12976〜5.14361|該当なし|0.114412未満|今回基準内|
|短い瞬断|5.12976〜5.14361|4.14244|0.114412未満|今回基準内|
|約20 msの電源断|5.12976〜5.14361|0.0120114|0.114412未満|今回基準内|

通常判定区間は電源断前50〜75 msと復帰後130 ms以降。電源断中は4.75 V維持を要求していない。30 msまでの起動、起動・復帰中ゲート0.4 V以下、通常区間4.75〜5.25 Vを確認した。瞬断中の歩行継続、サーボ再初期化、制御状態復旧は未検証。

保存先は `validation/coupled_power_development_v1`。緩やかな立上りと主経路開放回生は、この保存バンドルに未収録で未判定。今回のファイルにある合格を、電源全体の最悪条件合格と読み替えない。

```sh
.venv-engineering/bin/python software/sim/circuits/run_coupled_power.py \
  --case short_dip --out outputs/coupled_power_reproduction
```

モデル根拠と限界は各試行の `plan.json`、生波形は可逆圧縮で保存。ソースにはログの逐次保存と全区間電圧極値の出力を追加したが、保存済みの最初の3試行はその診断項目追加前の結果である。ネットリストと判定条件は変更していない。
