# 補助電源・EN・平均DC/DC・負荷の結合試行

`run_coupled_power.py` は保存済みの補助電源起動モデルと、DC/DC平均モデル・記録12軸負荷・二重回生吸収回路を結合する。モデル境界を越える制御依存を確認する開発試行で、実部品の電力・熱・保護成立の証拠ではない。

## 結合時の変更

補助電源と電池監視を電池内部抵抗の後へ接続した。ENは平均DC/DCを直接停止し、有効化後は時定数1 msの指令上昇で起動する。実DC/DCのソフトスタート保証値ではない。

ゲート保持監視ICはAUX3V3から給電し、AUX3V3が1.8 Vを割ると450 µs相当の起動待ちを取り直す。以前の電池側直給電からの変更で、補助電源が共通故障点となる。独立した二経路の全故障耐性は主張しない。

無給電時に定電流負荷でバスが非物理的な負電圧にならないよう、記録負荷の正電流を0.5 V未満で低減する。3 W制御負荷も同様に低電圧側を抵抗性にする。サーボやTab5の実低電圧動作ではない。今回は保存負荷の最初の150 msのみを使用する。

## 完了した試行

|条件|通常判定区間のバス V|電源断・復帰区間のバス最小 V|起動ゲート最大 V|判定|
|---|---|---:|---:|---|
|通常起動|5.12976〜5.14361|該当なし|0.114412未満|今回基準内|
|短い瞬断|5.12976〜5.14361|4.14244|0.114412未満|今回基準内|
|約20 msの電源断|5.12976〜5.14361|0.0120114|0.114412未満|今回基準内|

通常判定区間は電源断前50〜75 msと復帰後130 ms以降。電源断中は4.75 V維持を要求していない。30 msまでの起動、起動・復帰中ゲート0.4 V以下、通常区間4.75〜5.25 Vを確認した。瞬断中の歩行継続、サーボ再初期化、制御状態復旧は未検証。

保存先は `validation/coupled_power_development_v1`。緩やかな立上りと主経路開放回生は、この保存バンドルに未収録で未判定。今回のファイルにある合格を、電源全体の最悪条件合格と読み替えない。

```sh
.venv-engineering/bin/python software/sim/circuits/run_coupled_power.py \
  --case short_dip --out outputs/coupled_power_reproduction
```

モデル根拠と限界は各試行の `plan.json`、生波形は可逆圧縮で保存。ソースにはログの逐次保存と全区間電圧極値の出力を追加したが、保存済みの最初の3試行はその診断項目追加前の結果である。ネットリストと判定条件は変更していない。

## LDO近似の見直しと追加試行

旧LDOモデルは入力2.7 Vで0から最大150 mAへ不連続に変化する式だった。緩やかな立上りでは解析時刻が約3.359 ms付近から極めて遅くなった。部品仕様を見直したため、その計算はSIGINTで中断した。未完了記録・ネットリスト・ログを保存しており、収束失敗や実回路不良と断定していない。

[TPS709データシート](https://www.ti.com/lit/ds/symlink/tps709.pdf)に基づき、3.3 V品のDC精度1%、ライン変動10 mV、負荷変動50 mVを保守的に合算した3.207 Vを下側指令とした。以前の「3.3 V±2%」はこれらの合算保証を表していない。電流制限は典型320 mAへ変更（旧150 mAは定格出力電流に相当し、電流制限値ではない）。指令の時定数200 µsは95%到達600 µsを近似する検討条件で、実過渡特性の再現保証ではない。

`--ldo-model continuous` では低電圧側を連続に変化させる。10 mVと100 mVの切替幅は感度条件で、メーカーが規定したUVLO幅ではない。未規定の挙動を任意に選んで部品成立を主張することはできない。旧式は `legacy` として再現用に残した。

新モデルによる通常起動、短い瞬断、長い電源断、緩やかな立上り2条件、主吸収経路開放での回生の計6試行は完了した。今回の基準にはすべて合格。通常区間は5.12976〜5.14361 V、主経路開放回生では最大5.67183 V未満。短い瞬断のバス最小4.14244 V、長い電源断では0.007674 V未満まで低下するため、無停電動作ではない。起動ゲート最大は0.114412 V未満。

保存先は `validation/coupled_power_ldo_development_v1`。この追加により前節で未判定だった緩やかな立上りと主経路開放回生について、**新しい近似モデルでの**結果が得られた。実部品・温度・負荷全域・エネルギー収支・熱・各種故障の検証は残る。

```sh
.venv-engineering/bin/python software/sim/circuits/run_coupled_power.py \
  --ldo-model continuous --ldo-transition-v .01 --case slow_ramp \
  --out outputs/coupled_power_continuous_reproduction
```

左右旋回の記録負荷を全7秒入力した追加結果は [FULL_TRACE_POWER_ja.md](FULL_TRACE_POWER_ja.md) を参照。150 msの試行とは別バンドルで保存し、過渡時刻の省略をなくした。ただし記録負荷以外の動作・故障と実部品モデルの未検証範囲は残る。
