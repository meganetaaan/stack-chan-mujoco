# 背面締付け用の角ナットポケット候補

四隅をナットドライバーで保持する案では工具全長の包絡が胴体に交差した。そこで、y=±57 mm、z=8/120 mmのボスに、内側から横方向へ角ナットを差し込むポケットを追加した。背面のM3ボルトを締める際にナットの回転を壁で止める候補である。

## 寸法と材料情報

候補は[Accu HFSN-M3-A4、DIN 562](https://www.accu.co.uk/flat-square-nuts/21333-HFSN-M3-A4)。メーカー掲載の幅5.5 mm（+0/−0.4）、厚さ1.8 mm（+0/−0.4）、ねじM3×0.5を使用する。A4という材質表示から保証強度を推定しておらず、ねじ耐力・証明書は未確定。

ポケットは幅6.2 mm・厚さ2.4 mm、各面の製造誤差±0.2 mmを仮定する。摺動部の事前基準は総すきま0.1 mm以上。最小幅5.8 mmと最大ナット幅5.5 mmの差は0.30 mm、最小厚さ2.0 mmと最大ナット厚さ1.8 mmの差は0.20 mmとなる。

最小の正方形ナット幅5.1 mmと最大ポケット幅6.6 mmで、平面内回転は約21.22°で壁へ接触する。これは正方形外形・軸方向傾きなしの幾何計算であり、締付けトルクに耐える証明ではない。ナット角部の実形状、壁のたわみ、ボルトとねじの相互作用は接触解析へ反映する必要がある。

ナット後面はx=-55.7 mmで、ボス前面x=-56.2 mmとの間に厚さ0.5 mmの座金を1枚配置する。ポケット前側に保持壁を設け、ボルト用穴を通す。側方開口はナットの脱落を防ぐ閉鎖構造ではないため、ねじを掛けるまでの保持・姿勢・治具を組立手順で定義する必要がある。

## CAD検査

4個のナットについて、組立位置と内側20 mmからの直線移動を包含する角柱を作成し、胴体・板・搭載予約領域・ヨー関連部品との体積交差を検査した。判定0.01 mm³超に対して交差は0件。有限の姿勢サンプルではなく、連続した直線移動全体を含む包絡を使用する。

計算はTab5を取り付ける前の部分組立を想定する。ナットを運ぶ手・工具が前面開口からポケットへ到達できることは未検証。ナットだけの移動が通過しても組立完了とはしない。

新しい胴体は有効な単一ソリッド。直前の穴移設・ボス拡張候補に対する追加質量は約0.948 g（PETG密度1,270 kg/m³仮定）。元r9に対しては約1.377 g増える。ボス・保持壁の強度、造形方向とブリッジ、座面圧縮、締付け・緩み・保持機能は未検証で、製造リリースには使用しない。

## 再現と次の作業

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/build_captive_rear_nuts.py --out outputs/captive_rear_nuts_new --slot-width-mm 6.2
```

入力形状は`validation/rear_joint_assembly_development_v1/rear_joint_socket_double_v1`。板の四隅位置はこの入力から変更していない。出力・ナット・挿入包絡・計画・合否・コード・BOMは`validation/captive_rear_nuts_development_v1`に保存する。

次は、角ナットを側方開口へ送る治具とその進入経路を具体化し、保持壁とボスを含む接触解析へ進む。旧y=±59 mmの背面板解析結果は、この形状の強度証明に流用しない。
