# 常時電源とEN起動順序の結合試行

TPS70933、TPS3840PL30、無給電時停止用EN回路を結合する行動モデルを追加した。候補構成は `schematics/power/aux_sequence_candidate.json`、再現可能な試行は `validation/aux_sequence_development_v1` に保存した。回路図・BOMの製造承認ではない。

[TPS709データシート](https://www.ti.com/lit/ds/symlink/tps709.pdf)の3.3 V固定版を常時給電候補とする。ENは未接続で有効となる。EN許容動作電圧は6.5 V以下なので2S電池へ直結しない。出力容量は実効2.2 µF以上を確保する。今回の4.7 µF、出力抵抗10 Ω、ドロップアウト0.5 V、電流上限150 mAのモデルは実部品の過渡特性保証ではなく、設計検討用の仮定である。

## 発見した問題と修正

最初の構成は3.3 V電源だけを監視していた。電池が100 µsで0 Vへ下降し100 µs後に再上昇する短い瞬断では、補助電源は約3.215 Vを保ち、ENも1.60 V以上のままで、復帰後450 µsの停止待ちを満たさなかった。通常起動と長い電源断だけの確認ではこの問題を検出できない。

追加のTPS3700で電池を公称6 V判定し、低電圧出力を遅延ICのMRへ接続する案へ変更した。電池監視は3.3 V側で給電して瞬断中も保持する。入力分圧140 kΩ/10 kΩ、監視の遅れは50 µsのRC近似。実部品の保証遅延ではない。MRによるタイマー放電は簡略モデルで、実際の放電・再充電特性は未検証。

|試行|制御電源だけを監視|電池監視によるMR追加|
|---|---|---|
|200 µsで電池立上り|今回基準内|今回基準内、EN有効化約1.868 ms|
|10 msで電池立上り|今回基準内|今回基準内、EN有効化約8.792 ms|
|短い瞬断|復帰待ち不合格|復帰待ち基準内|
|約20 msの電源断|今回基準内|復帰待ち基準内|

判定は初期1 msのEN停止、30 ms以内の初回起動、130 ms以降の復帰、電池復帰後450 µsの停止待ち。失敗を含め8試行を保存した。短い瞬断では補助電源が残るため、単にENが低くなっただけでなく復帰待ち区間を検査した。

これは補助電源からENまでの結合モデルであり、DC/DC電力段・12軸負荷・回生エネルギーは含まない。6 V検出は起動順序をリセットする候補値で、電池各セルの過放電保護を意味しない。各監視ICの実電源投入挙動、LDO負荷過渡、部品温度公差、MR入力の保証条件、故障時残留電圧を詰める必要がある。

```sh
.venv-engineering/bin/python software/sim/circuits/run_aux_sequence.py \
  --battery-reset --case short_dip --out outputs/aux_sequence_reproduction
```

`--case` は `startup`, `short_dip`, `long_dip`, `slow_ramp`。`--battery-reset` なしで旧構成を再現できる。
