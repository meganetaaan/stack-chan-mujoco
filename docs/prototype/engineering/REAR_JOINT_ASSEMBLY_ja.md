# 背面板と胴体の四隅接合：組立形状の検討

現行r9の胴体ボス端面をSTEPから確認すると、背面x=-62.2 mm、内側端面x=-56.2 mmで、長さ6 mmだった。過去の概略寸法ではなく、この実形状を使用する。元の穴中心はy=±59 mm、z=8/120 mm、穴径2.5 mmであり、M3の貫通固定には変更が必要。

## 候補の形状

四隅をM3x16の貫通ボルト・座金・ナットで固定する候補を作成した。旧穴を埋め、穴径を3.4 mmとする。軸を左右それぞれ2 mm内側のy=±57 mmへ動かす候補では、元のボスと内側の半径4.6 mm円柱を合体して受けを広げる。ボス根元は未補強で、強度は未検証。外形と脚長を変えず、胴体の計算質量増加は約0.429 g。背面板の四隅穴も同じ位置へ変更する。

内側座金は外径7・内径3.2・厚さ0.5 mmの公称寸法。1枚では締結積層11.4 mm、2枚では11.9 mmとなり、M3x16のナット先端からの公称突出は4.6/4.1 mm。これらは部品公差・座面の沈み込み・締付けを含む保証値ではない。

## 干渉検査の結果

| 構成 | 体積交差 | 工具隙間不合格 |
|---|---:|---:|
| 元の穴位置、先端より前方25 mmの工具範囲 | 8 | 4 |
| 穴を2 mm内側へ、同じ限定工具範囲 | 0 | 0 |
| 穴を2 mm内側へ、ナットを覆うソケットを含む、内側座金1枚 | 0 | 4 |
| 同上、内側座金2枚 | 0 | 0 |
| 内側座金2枚、実在工具の軸・柄の全長を含む包絡形状 | 6 | 4 |

体積交差の判定は0.01 mm³超。工具隙間は両面各0.2 mmを差し引いて0.5 mm以上。部品は中立姿勢の胴体、背面板、Tab5、電池予約領域、トレー、電源・TTL部、ヨー関連部品を含む部分集合であり、全身・配線・手の動作を含まない。

初期の25 mm範囲はナットにかぶさるソケットと工具の柄を含まない。そこで通過しても組立の証明にはならない。内側座金1枚の場合、ソケットを覆う範囲まで含めると先端からボスまでの距離が不足する。

メーカー資料で[Wera 2069・品番05118126001](https://hybris-media.wera.de/download/pdfgenerator-datasheets/en/05118126001.pdf)の対辺5.5 mm、軸径7.8 mm、軸長60 mm、柄長97 mm、外形157×13×13 mmを確認した。この寸法で軸と柄を円筒包絡すると、全4箇所で胴体、上側2箇所でTab5との交差が残った。これは保守的な包絡形状の検査で、工具の実形状そのものの交差を証明するものではない。内部のソケット深さ8 mmも資料にない仮定であり、採用品として確定していない。

## 判断と次の設計

この貫通ナット候補は**組立未検証・未採用**。工具の短い範囲だけを使って合格にしない。Tab5を外す工程だけでは胴体との交差が残るため、回り止め付きナットポケットを設け、背面の六角レンチで締める案へ進める。ナットの挿入経路、保持部の寸法・強度、造形方向、締付けによる座面変形を検証する必要がある。

旧背面板解析の境界はy=±59 mm・穴半径1.65 mmであり、この候補に流用できない。採用する接合形状が決まった後、座面全体と胴体周縁の接触、ねじ、ボスの柔軟性を含む解析へ更新する。接触ソルバー単体の検証は`CONTACT_SOLVER_CHECK_ja.md`を参照。

## 再現

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/build_rear_joint.py --out outputs/rear_joint_full_tool_new --inset-mm 2 --inner-washers 2 --driver-model wera_2069_envelope
```

`--driver-model local_socket`ではソケットと短いアクセス範囲だけを再現する。元の先端より前方だけの限定モデルは初期候補のSTEPと計画に保存している。証跡は`validation/rear_joint_assembly_development_v1`。各候補のナット・ボルトのねじ形状は簡略化しており、ねじ同士の意図した重なりを締結強度の証拠にしない。
