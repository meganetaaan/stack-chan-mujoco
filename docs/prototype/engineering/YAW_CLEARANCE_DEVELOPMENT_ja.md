# ヨー支持部の連続角度区間での隙間評価

Issue #19の部分評価。EPIC #4の左右旋回記録から左右ヨー軸の最小・最大角を取り出し、その間の角度全域についてCAD距離の下限を求める。
実時間の刻みだけで検査せず、約0.25°刻みの角度格子を使う。両側各93姿勢。

対象はr9の旋回カップリング、およびオプションで旋回側のロール受け部品と、同じ側の固定ヨー支持部。
固定支持部は元形状と、リブ・背面壁・ボルト座を追加した候補を比較した。
ロール受け部品は既存r8 STEPをy方向へ左右それぞれ外向き4 mm平行移動する。既存 `audit_fast_turn_body_cad.py` と同じr9への配置変換を使う。

## 見落とし上限と判定

軸からの最大半径Rは移動部品のCAD境界箱の四隅から上側に評価する。
任意の角度から最近接の検査角までの角度差はΔθ/2以下であり、各点の移動量はRΔθ/2以下。
固定形状との距離もそれ以上は減少しないため、次の下限を用いる。

`残余隙間下限 = 最小検査距離 − RΔθ/2 − 2×公差0.2 mm − 2×変形許容量0.2 mm`

判定基準は残余隙間0.5 mm以上。値は計算前に `plan.json` に保存した。
これは回転一自由度の剛体形状に対する距離の下限であり、部品公差と変形を差し引く条件付きの結果。
**変形許容量0.2 mmは各部品で成立を別途証明する必要がある。** 元支持部は以前の強度解析でこの値を超えており、元形状の隙間結果を実機での成立と解釈しない。

## 結果と範囲

カップリングだけの追加支持部との最小距離は約9.4507 mm、連続区間の見落とし上限は約0.0671 mm、残余隙間下限は約8.5836 mm。
ロール受け部品を含めても最小距離は同じで、半径が増えることにより残余下限は約8.5828 mmになる。
この部品対では、追加リブによる干渉は検出されなかった。

ロボット全体、ヨーモーター、他の軸で動く部品、締結部品、配線、工具、バッテリー搭載部、前進・後退・停止軌道の検査は含まない。
角度範囲は記録値の範囲であり、記録時刻間で範囲外へ出た運動や制御可能な全関節範囲を保証しない。
元形状と追加候補で各2側を評価したが、全組合せの干渉検査ではない。Issue #19は未完了。

## 再現

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_yaw_clearance.py --out outputs/yaw_clearance_new
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/check_yaw_clearance.py --out outputs/yaw_clearance_cradle_new --include-cradle
```

入力CAD・軌道・sceneのハッシュ、角度ごとの距離、判定を `validation/yaw_clearance_development_v1/` に保存する。
初回実行は結果のJSON保存時にNumPy真偽値の型エラーで終了した。型変換を修正して再計算し、基準や形状は変更していない。
