# 全記録ヨー荷重に対する支持部の線形解析上限

Issue #17・#18の開発評価。ボルト穴と背面座を追加した左ヨー支持部に、6成分それぞれの単位荷重を与える。
対象形状は `validation/yaw_connection_development_v1/yaw_connection_v1/left_yaw_fixed_support.step`。
4か所の背面座の面（x=-62.2 mm）を理想固定し、実際の背面カバーやボルト接触はモデル化しない。
以前の背面壁全体を固定した解析と境界条件が異なるため、値をそのまま比較しない。

## 評価方法

各単位荷重に対する変位ベクトル・応力テンソルを求める。線形弾性なので、任意の6成分荷重での場はその重ね合わせで得られる。
変位ノルム、対称応力テンソルの最大絶対固有値、von Mises応力は三角不等式を満たす。
各単位応答の最大値に荷重成分の絶対値を掛けて合計すれば、全節点・全積分点に対する上限になる。

`上限(w) = Σ |w_i| × 単位荷重iの場の最大値`

この上限をEPIC #4から保存した全266,000組時刻へ適用する。
ボルト群中心で保存されたモーメントをヨー軸原点へ戻して使用する。右側は鏡映対称を仮定し、力を極性ベクトル、モーメントを軸性ベクトルとして左側座標へ写す。
各軌道で変位上限が最大となる時刻については、変位ベクトル場を実際に重ね合わせ、ノルム最大値も算出する。
この選択時刻が実変位の最大時刻とは限らない。

上限が基準以内なら、その線形モデル内の全記録荷重を包含する。**上限が基準超過でも、実際の場が超過した証明にはならない。**
選択時刻の実際の重ね合わせ結果が超過すれば、そのモデル・荷重での不合格を示す。

## 事前条件

材料は既存PETG仮定の感度ケースとしてE=1,120 MPa、ν=0.35、応力許容値5.6 MPa。変位は0.2 mm以下。
既存仮定の0.8倍を使ったもので、測定済み材料保証値ではない。
初回メッシュ寸法は3 mm。基準、荷重源と形状のハッシュ、拘束面、材料条件を実行前に `plan.json` に保存する。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/bound_yaw_loads.py --out outputs/yaw_load_bounds_new
```

## 限界

今回の全荷重包含は単一メッシュの線形モデルに対するもの。メッシュ収束、異方性、締結接触、座屈、実際の背面構造の荷重伝達、疲労・クリープを証明しない。
記録後の形状・質量変更を反映した負荷再計算も必要。全荷重を走査しただけでIssueを完了にしない。

## 結果

全266,000組時刻の変位上限は最大0.5028 mm、応力上限は最大16.4500 MPaで、上限だけでは基準内を証明できなかった。
選択時刻のうち最大の実変位は、右旋回記録の左支持部、2.661 sで0.39214 mmだった。
この同じ荷重を直接与えて再解析したところ、変位0.39214 mm、最大絶対主応力12.5025 MPaとなり、変位0.2 mmと応力5.6 MPaの両基準で不合格。
単位応答の重ね合わせとの相対差は変位3.8×10⁻¹⁵未満、応力1.5×10⁻¹³未満だった。

現候補は理想固定でも今回の判定基準を満たさない。背面壁・座周辺の補強と実際の背面フレームの荷重伝達を設計し直す必要がある。
応力は全積分点を含めた値で、局所集中とメッシュ収束をまだ分離評価していない。単一メッシュの値を実機の確定破壊応力とは扱わない。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/verify_yaw_superposition.py --bounds outputs/yaw_load_bounds_new --out outputs/yaw_load_direct_new
```

証跡は `validation/yaw_load_bounds_development_v1/`。六つの単位荷重の全変位・応力、全時刻の上限、選択荷重の直接解、入力ハッシュと判定を保持する。
