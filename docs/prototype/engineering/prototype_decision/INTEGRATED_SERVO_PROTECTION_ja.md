# 保護段を統合する比較候補

TI TPS259813LRPWを比較候補に追加する。
[資料SLVSGG6D](https://www.ti.com/lit/ds/symlink/tps25981.pdf)の比較表・電気特性・時間表を確認。
可変OVLOと過電流遮断を持つため、LTC4365＋TPS259823の2段を置き換える案を検討できる。
外付け逆流阻止FETとサーボ側の回生吸収器は別途必要。まだ接続変更はしない。

OVLO立上り基準1.176〜1.224V、入力漏れ±0.1µA。
応答1.2µsは9ページ表のTYP列で、MAX列は空欄。表を画像でも確認した。
5Vでの過電圧上限をこの時間だけから保証しない。
低抵抗・素子数削減は比較の理由であり、成立の証拠ではない。

次は分圧・電流制限・逆流阻止を同じ回路として評価し、
故障種類ごとの復帰動作と手動許可回路との接続を確認する。
L型の名称だけで全故障が手動復帰になると仮定しない。
製造BOMと既存回路は維持し、比較結果が揃うまで採用を確定しない。

## 故障通知と再始動の判定

資料27ページの表7-2では、UV/OVは内部ラッチN、FLTはH。
過電流・過熱の通知を受けるだけの回路で、電圧異常まで記憶したとは判定できない。
20〜21ページは814系のOV復帰を明記し、閾値復帰後に再給電する。
候補813系は比較表に含まれるが、OVLO・PGの説明に814系の明記があるため、
詳細動作の適用範囲は未確認として扱う。

外部の故障記憶に必要な動作を次のように固定する。

| 状態 | 必要な扱い |
|---|---|
| 起動前、PGが低い | そのままRUN中故障として扱わない。電圧資格確認を先に行う |
| 起動中 | 規定時間内の立上りを確認。失敗なら停止を記憶する |
| RUN中の電圧異常 | FLTだけに依存せず検出・記憶し、許可を解除する |
| 入力電圧が正常に戻る | 記憶を保持し、自動で許可を再発行しない |
| 手動再始動 | 電圧資格確認と新たな操作を確認してから記憶を解除する |

PGの遅延中に再給電する可能性も含め、PGだけで全異常を捕捉できるとは仮定しない。
この表は設計条件で、実装済み状態機械や実回路の証明ではない。
既存手動許可回路へのFLT直結だけの統合案は採用しない。
