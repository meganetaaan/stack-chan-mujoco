# OV監視端子のクランプ比較

[TI TLV431B資料SLVS139Z](https://www.ti.com/lit/ds/symlink/tlv431.pdf)の工業温度品を確認。
1.24Vの直接クランプは不採用。全温度の基準下限1.224Vが、eFuseのOVLO最大閾値1.224Vと
等しく、確実に過電圧判定へ入る余裕がない。値はカソード10mA時で、今回の低電流条件とは異なる。

次の比較対象は約1.35Vへ調整する構成。必要条件は、クランプ下限>1.224Vかつ上限<1.5V。
ただし調整抵抗やREF電流が元の35.7k/10k分圧を負荷するので、元の検出値を流用しない。
クランプが動作する前の入力電流も無視しない。最低動作電流の最大仕様は100µA。
12.6Vの1点だけでなく、過電圧発生からクランプに至る入力範囲で成立を確認する。

抵抗値の追加前に、検出閾値変化、電流条件、応答と容量安定性の根拠を揃える。
この部品の追加でサーボ6V上限が保証されたとは扱わない。回路候補へは未接続。
