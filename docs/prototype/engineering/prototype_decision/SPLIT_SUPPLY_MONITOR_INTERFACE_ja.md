# 左右電源の起動・故障監視入力

確認結果：manual_rearm_revIのPG受信部はMAIN_EFUSE_PGを論理信号として受けるだけで、
サーボ電源のUV/OVを直接監視する回路ではない。単一PGでは左右電源の成立も確認できない。
既存候補に左右監視が実装済みであるという扱いをしない。

startup_sequencer_interface.jsonに左右それぞれの入力を追加した。
source voltage validは遮断段より前の電源の正常範囲と監視回路自身の有効性を表す。
PG validは各遮断段の状態を表す。閾値・検出回路・配線・遅延は未確定。

| 状態 | 遷移・停止条件 |
|---|---|
| OFF/WAIT | 両電源が正常で新たな手動許可が来るまで停止 |
| START | PG低を起動中に限り許容。両PGの成立を待ち、時間切れで停止 |
| START/RUN | 片側でも電圧資格が失われたら両側許可を解除し、クリア手続きを開始 |
| RUN | 片側PG低でも両側許可を解除し、故障を記憶 |
| CLEAR | 既存の両ラッチ出力・リセット観測・保持時間の条件を満たすまで維持 |
| 電圧回復 | 回復だけでは再給電せず、クリア完了と新たな操作を待つ |

共通の停止要求を出すことと、実際の両レールが同時に放電することは別。
検出・伝搬・スイッチ遮断・出力容量の時間は実回路で別途評価する。
短い異常を取りこぼさない記憶回路、未給電状態、断線への対応も設計残件。
この文書は実装済み回路や回路シミュレーションの代用ではなく、未接続入力を明確にするもの。
