# 純正ケーブルを使う試作配線候補

ROBOTIS Robot Cable-X3P 180mm（10本入りSKU 903-0249-000）を12軸分の経路検討候補に追加する。メーカーはXシリーズTTL向けとしている。ConvertibleやXL-320用3P-XLと取り違えない。サーボ側の工場圧着を維持し、自作圧着の線径適合問題を増やさない。

案は両端コネクタを維持し、配電基板に12個の対応EHヘッダを設ける。左右のV+分離と各軸個別給電は保持する。これは従来の片端はんだ付け案との選択肢であり、両方の部品を同時にBOMへ足さない。配電側の接点追加による降下・発熱は再計算が必要。

180mmで全軸に届くとは未確認。製品ページには各芯の絶縁径、経路ごとの曲げ寿命、個別正味質量、最大抵抗の根拠が不足している。小型化できるかは未判定で、写真だけから束径を推定しない。販売ページの0.1lbも1本質量として扱わない。

次の終了条件は12本それぞれのコネクタ基準面、固定点、全関節範囲での余長と干渉を決め、180mm案の可否を判定すること。通電合格や動的寿命は別途確認する。産業用ケーブル5本束の経路を無条件にこの案へ置換しない。
