# 既製POLモジュールの一次比較

Murata OKL-T/6-W12P-Cを比較。小型6A品だが、今回のOVP条件を満たす代替品としては未採用。
[メーカー資料C03](https://www.murata.com/-/media/webrenewal/products/power/datasheet/okl-t6-w12.ashx?cvid=20200224053011000000&la=en-sg)
の2〜4ページを確認した。入力4.5〜14V、外形12.2×12.2×7.2mm。
過電圧保護なし、出力への逆電流を受ける用途に適さない。

負荷急変の偏差±450mVは注1に従う典型値であり、全条件の上限ではない。
5Vに正側偏差を加えた比較5.45Vは、既存分圧候補の最小検出5.17570Vより高い。
これは正常過渡で保護停止する可能性を示す比較で、実機で必ず停止する証明ではない。
容量の追加で解決とせず、許容容量・ESRと応答の適合を別途確認する必要がある。

判定：電流定格と外形だけでUBECの置換を決定しない。
正常過渡と故障検出の分離、回生吸収、熱と基板実装が残る。
この候補のCAD配置やBOM展開は、電圧範囲の成立を確認するまで進めない。
5V定格からの電圧変更で検出条件に合わせる場合も、サーボ下限と配電降下を先に確認する。

`validation/servo_voltage_corridor_v1/`で設定電圧低下のみの案を確認した。
既存の通常下限4.75Vと比較過渡±0.45Vでは、配電損失ゼロでも設定範囲が空になる。
通常下限を都合よく緩めず、この候補を電圧設定変更だけで採用する案は見送る。

## 現行revMとの再照合

上記5.175695 Vと`servo_voltage_corridor_v1`は旧分圧での履歴。現行比較は`validation/active_source_window_v2`を使う。実装分圧を照合した静的OV検出の最小値は5.362365 V、通常電源目標は4.75〜5.25 V。典型偏差±0.45 Vの同条件比較は、損失ゼロでも必要設定5.20 V以上と通常上限による4.80 V以下が両立せず、未採用判断は維持する。旧しきい値を現行の基準として引用しない。
