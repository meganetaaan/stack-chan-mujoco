# 単セル完成パック：標準リード品の判定と照会仕様

## 結論

Keeppower P2150Rの標準JST SYP-02リード付き仕様を、12軸共通電源へそのまま採用しない。電池の連続15A表記に対し、JST RCYはAWG22使用時でも定格3A。既存比較電流9.834Aに不足する。片脚4.917Aへ分けても、この標準コネクタでは不足する。コネクタを切り替えるだけで既存リードや内部接続の容量まで増えるとは扱わない。

一次資料（2026-09-22確認）：
- [Keeppower P2150Rリード付き製品](https://www.keeppower.com.cn/products_detail.php?id=688)：標準JST SYP-02、連続15A表記、保護回路内蔵。
- [JST RCY製品仕様](https://www.jst-mfg.com/product/index.php?series=521)：3AはAWG22、0.5AはAWG28、適用線AWG28..22。SYP-02T-1は本シリーズ。
- [Keeppower P1831Rリード付き製品](https://keeppower.com/ja/product/15a-keeppower-18650-3120mah-protected-li-ion-rechargeable-battery-p1831r-with-jst-wires-out/)：こちらも標準JST SYP-02。配線/コネクタのカスタマイズ受付の記載はあるが、ロボット適合仕様の完成品が存在する証拠ではない。

既存15A表記との不一致はメーカーへ確認すべき事項として残す。製品が不良・危険と断定するものではなく、今回の負荷への適合根拠が不足するという判断。

## 照会する完成パックの構成

- 保護回路とリードをメーカーで組み立てた1S完成品。内部セルや保護への利用者による加工を前提にしない。
- 電池外部の正負2線のみを使用。電源、Tab5、USB、通信の共通GNDは外部負端子側へまとめる。内部CELL−への別接続は作らない。
- 電池だけでなく保護基板・接続材・リード・コネクタを含む連続定格と温度条件が必要。型番不明の「高電流コネクタ」表記だけでは採用しない。
- 取り外して専用充電器で充電する候補。充電器の組合せ、電流/電圧公差、復帰手順を回答対象に含める。
- 既存モデル予算9.834Aに適合することは必要条件。実測未確定の全軸ピークや回生を無制限に受け入れられるとはしない。

リード付きP2150R/P1831Rのカスタム品は**未発注・未選定**。独自の注文型番、リード径/長さ、質量、コネクタ定格を補って完成BOMにしない。

## 回答からの判定と終了条件

1. 型番・完成配線図・全体定格・寸法/質量が出るまでは、製造用部品として採用しない。
2. 完成品の端子電圧データを配電/停止回路と照合する。既存参考必要値3.776783Vは未計上損失を含まず、eFuseの3A試験点外抵抗も使った比較である。これを完成パックの保証要求値としてそのまま転記しない。
3. 保護の自動復帰とは独立した手動再始動を設計し、満充電/低温/遮断時の回生は別に評価する。標準CC-CV充電電流を回生許容値に置換しない。
4. 資料で未記載なら「不明」とし、仮定で過渡解析を追加しない。#21/#24の未設計部分を実測Issueへ移さない。
