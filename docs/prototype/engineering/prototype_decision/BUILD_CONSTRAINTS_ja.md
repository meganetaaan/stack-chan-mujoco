# ユーザー指定の製作条件と選定方針

ユーザーの最新指定：
- 電池は設計側で選定する。既存ロボット向け電源ボードを参考にし、既製品採用も検討する。
- 造形は3Dプリント。使用可能材料はABSまたはPETG。

従来の「電池選定を任せてよいか」「使用可能な材料は何か」は解消済み。
NP-F550・103g、2S固定、専用基板自作、左右2電源はユーザー要求ではない。
電源構成の候補として比較し、寸法・質量・保護・給電・充電方式で選定する。

剛性部品はPETGを初期候補、ABSを熱・剛性・耐クリープの比較候補とする。
これは材料の確定や強度合格ではない。フィラメント製品・造形方向・壁厚・
積層条件を設計入力に落とし、材料一般の引張値を造形品の許容値へ流用しない。
既存TPU足裏案は使用可能材料に含まれないため、既製の滑り止め材等も含めて再検討する。
材料指定を全ての金属ねじ・板部品まで樹脂へ置換する指示とは解釈しない。

## 候補BOMの読み方

`candidate_bom.csv`へ3S電池、UBEC、revBトレイ、外部充電器、ベルト、
セル監視とTab5ハーネスを反映した。NP-F550は過去の比較候補、TPUは現行工程外として
区別した。表全行を一括購入したり、全重量を合算したりしない。
未選定の項目は完成回路や必要部品から除外したという意味ではなく、設計残件。
最小試験数量0は現段階でその部品を用いた試験を開始しないことを表す。
回路の代替候補や過去検討も混在するため、製造用BOMの確定版ではない。
