# 電池保護と駆動停止の遮断範囲

現在の主eFuse候補TPS259823ONRGEは左右5V駆動枝の遮断候補であり、
3S電池そのもののセル保護ではない。`main_efuse_candidate.json`の電流設定・
逆方向遮断は未確定。役割を変更する場合は既存解析の前提も再評価する。

## 経路別の判断

| 操作・異常 | 確認できる経路 | 残る設計条件 |
|---|---|---|
| 電池の正極供給を切る | UBEC入力とTab5 HV分岐の給電源を失う | UBEC出力残留・回生は別処理。USB接続中のTab5は生き得る |
| 左右5V正極を切る | 意図したサーボ給電枝を開く | DATAからの逆給電、逆方向導通、蓄積エネルギーを確認 |
| USBを接続する | Tab5内部の別電源経路が有効になり得る | 電池なしでも監視論理や信号が駆動枝へ許可を出さないこと |
| 電池負極のみを切る案 | 主帰路の開放 | 監視線・USB・通信・試験器が負極両側をつなぐ場合は遮断を迂回する |

負極遮断は、USBがあるだけで必ず迂回するとは限らない。実際に別の帰路が
電池負極と負荷GNDを結ぶ場合が問題。よって負極遮断の既製BMSを無条件には
採用せず、全接続先を含む回路で確認する。絶縁を実装していない共通GNDを
「絶縁されている」と扱わない。

## 次の統合回路で満たす条件

電池側にはセル電圧・主電流・逆接・短絡に対応する保護を設計する。
左右5V側には、変換器故障と回生を含む過電圧/電流制限・停止経路を残す。
電池の遮断だけでは、変換器出力側の残留・回生・USB由来の信号給電を証明できない。
低電圧保護の自動復帰があっても駆動許可は自動復帰させない。

最小の机上確認対象は、電池のみ、USBのみ、両方、両方なしの4状態と各遷移。
それぞれについて実素子のボディダイオード、逆流仕様、無給電端子の電流経路を追い、
停止/許可信号と左右サーボ電源の状態を示す。まだ実部品の全経路が未定なので、
理想開閉器だけの真理値表を実回路の遮断成立として提示しない。
