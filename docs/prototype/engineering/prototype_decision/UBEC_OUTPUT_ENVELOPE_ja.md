# UBEC出力範囲の資料判定

結論：現在のOVP比較と組み合わせた採用は未確定。正常出力の最大値を資料から置けない。

2026-09-21に[製品ページ](https://www.hobbywing.com/en/products/ubec-10a-2-6s152)と、
そこからリンクされる[現行公開マニュアル](https://oss.hobbywing.com/pdf/pdfen/UBEC10A2-6S.pdf)
を確認した。文書識別子はHW-SM817DUL_10A-UBEC_140905。
5V設定と保護機能の存在は記載されるが、出力誤差、リップル、起動・負荷解除時ピーク、
内蔵保護の検出値・応答時間は確認できなかった。機能が存在しないという意味ではない。

95.3k/10k分圧の比較では正常最大値が5.175695V未満であることが必要。
この数値は抵抗・ICの既存仮定から得た設計比較条件で、ユーザー要求でもUBECの仕様でもない。
これを満たしても5Vでの遮断動作、回生吸収、抵抗の温度変化等が残るため十分条件ではない。

## 次の判断と実機評価の分離

#6では正常出力精度・過渡条件が明示された変換器との選定比較を進める。
理想5V源での波形をUBECの保証として扱わず、同じ未記載仕様の検索を繰り返さない。
UBECを保持する場合の起動・負荷解除・リップルの測定は#49の実機評価項目。
その測定結果を得る前にUBEC構成の給電・保護が成立したとして#6を閉じない。
試験値1点から量産公差や全温度保証も推定しない。

未完了の回路設計（OVPの分圧、FET駆動、回生容量、手動再始動）は#6側に残す。
電源変更時は左右配電の電圧降下・電池電流・発熱・CAD配置と質量を再評価する。
