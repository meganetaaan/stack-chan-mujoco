# UBEC出力範囲の資料判定

結論：UBECの正常出力誤差・過渡最大値が未確認のため、現行保護回路と組み合わせた採用は未確定。旧回路の5.175695 Vという比較値を現行revMの検出値として使わない。

## 現行回路との対応

`validation/active_source_window_v2` がcurrentポインターのrevM実装値を照合した。既存の通常電源目標は4.75〜5.25 V（Codexの設計仮定、ユーザー要求やUBEC保証ではない）。静的なOV検出開始の最小比較値は5.362365 V。電源窓監視器単体のOV復帰下限は5.316446 Vだが、これだけで再始動シーケンス全体を保証しない。

しきい値は既存の部品・抵抗公差仮定に基づく計算であり、過渡保護の保証値ではない。revMのOVLO入力は12.6 V故障比較で適用条件外となる問題と、遮断時間未確認を残す。正常範囲に収まることと異常時保護の成立は別々に確認する。

## UBECの資料で未確認の項目

2026-09-21に確認した[製品ページ](https://www.hobbywing.com/en/products/ubec-10a-2-6s152)と[公開マニュアル](https://oss.hobbywing.com/pdf/pdfen/UBEC10A2-6S.pdf)（HW-SM817DUL_10A-UBEC_140905）では、5 V設定と保護機能の存在は記載されるが、出力誤差、リップル、起動・負荷解除時ピーク、内蔵保護の検出値・応答時間は確認できなかった。機能が存在しないという意味ではない。今回は同じ未記載仕様の検索を繰り返していない。

## 次の判断と実機評価の分離

#6では正常出力精度・過渡条件を根拠とともに示せる変換器を比較する。理想5 V源をUBECの保証として扱わない。UBECを保持する場合の起動・負荷解除・リップルの測定は#49へ引き継ぐが、測定が必要な条件を未確認のまま給電・保護成立として#6を閉じない。単発測定から全温度・量産公差保証を推定しない。

未完了のOVP、FET駆動、回生容量、手動再始動の設計は#6に残す。電源変更時は配電損失・電池電流・発熱・CAD配置・質量を更新する。

旧95.3 kΩ分圧の5.175695 V比較と関連計算は履歴として保持する。原資料を変更して過去のハッシュや結果を現行値に見せかけない。
