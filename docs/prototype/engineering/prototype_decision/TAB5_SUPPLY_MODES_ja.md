# Tab5給電と再投入の設計条件

2026-09-22。対応する設計入力は `schematics/power/tab5_supply_policy_candidate.json`。
**回路実装・給電成立の証明ではない。試作製作は引き続きHOLD。**

## 要求と根拠

ユーザー要求はTab5を顔として使用し、12軸駆動系と共存させること。
NP-F550の搭載、USB同時接続、自作電源は必須ではない。

[メーカー資料](https://docs.m5stack.com/en/core/Tab5)は給電範囲6–24 V、
計画的な電源切断前のシャットダウンを指定している。直接切断した場合は
再投入まで5秒待つ必要があり、短い間隔ではIMU初期化に失敗する可能性がある。
これは部品側の条件で、Codexが設定した合格値ではない。
5秒を内部レールの完全放電時間や起動完了時間とは解釈しない。

設計候補は保護済み3Sから独立した遮断・保護枝を設け、J9の2番SYS_VIN／1番GNDへ給電する。
端子番号の根拠は `rc_supply_candidate.json` の回路図照合記録。
嵌合方向、端子電流、保持、実装アクセスは未確定で、配線製作指示には使用しない。
歩行構成ではNP-F550とUSBを接続しない方針とする。これは逆給電経路を減らす設計上の選択であり、
ユーザー要求への追加制約ではない。将来併用する場合は別の給電状態として評価する。
Tab5の電池端子へ3Sを接続しない。Tab5経由で3Sを充電しない。

## 状態別の処理

| 状態 | 必要な処理 | 未確定の設計 |
|---|---|---|
| パック予備充電中 | Tab5枝をOFFに維持 | 枝スイッチ・既定OFF・漏れ電流 |
| 通常起動 | 主電源成立後にTab5を給電。準備完了と新しい駆動許可を別途要求 | 起動ピーク、準備完了信号、許可回路 |
| 計画停止 | 駆動を禁止し、Tab5をシャットダウンしてから電源を切る | 完了確認。一定時間の経過だけで完了扱いしない |
| 電気異常 | 必要な保護遮断を優先。正常終了を待って遮断を遅らせない | 故障別の検出・遮断期限 |
| 遮断後の再投入 | 自動復帰させず、実際の電源切断から5秒以上確保。履歴不明なら新たなOFF期間を設ける | 内部残留・逆給電の確認、タイマー自身の電源断への対応 |
| USB保守 | ロボット電池を切り離し駆動不能にしてからUSB接続 | 信号線経由の逆給電、物理的な切離し手段 |
| 電池充電 | ロボットから取り外し、適合する外部バランス充電器を使う | 最終充電器BOM・切離し構造 |

Tab5の停止・初期化失敗・再起動を、サーボの再始動許可にしない。
既存のサーボ枝にある0.92秒の放電比較値でTab5の5秒条件を代用しない。
遮断指令がLowであることと、Tab5が実際に無給電であることを区別する。
タイマーがパックとともに落ちる場合も、再接続直後に過去の待ち時間を満了扱いしない。

## #21–24の判定と追加作業の終了条件

現在の統合候補には227部品があるが、Tab5枝の部品・ネットは未登録。
従って本書によって全負荷給電や異常保護の条件を達成したとはしない。

次の設計作業は独立枝の部品選定・接続・予備充電中OFF・再投入抑止を
統合回路へ反映すること。電流制限は起動負荷と配線定格から選び、
Tab5の典型動作時間からピーク電流を逆算して確定しない。
6–24 Vとの静的な整合だけで、過渡電圧・熱・故障時の成立を判定しない。

追加解析は、(1)全モードの給電・逆給電経路、(2)保護部品と配線の定格余裕、
(3)再投入条件が電源断で失われないことを確認する範囲に限定する。
部品データで拘束できない起動電流や内部残留電圧は「合格」とせず、
選定判断に必要な上限条件と実測手順を定めて#49へ渡す。
未選定回路と未実装の再投入制御は#21–24の設計残件であり、実測Issueへの移送だけでは完了しない。
