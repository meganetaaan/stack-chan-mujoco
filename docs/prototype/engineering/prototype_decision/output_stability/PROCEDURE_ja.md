# E0-S／E1-S: 出力安定性の最小実機評価手順（未実施）

## 開始条件

回路・部品・コンデンサー有効容量範囲、配線、保護定格、熱限界と停止経路を#21〜#24で確定してから実施する。候補比較資料だけでは開始不可。初回は実電池とサーボを外し、電流制限電源・電子負荷・既知容量を使用する。負荷／電源が回生を吸収できる条件は別途確認する。

## 手順

1. **E0-S、局所容量のみ**：確定した回路版・部品ロット・容量/ESRの実測または保証範囲を記録する。保護出力OFFの状態で変換器を投入し、入力、局所5 V、停止／異常信号を同時記録する。入力試験点は既存の9 V／12.6 Vを用い、実端子値とオーバーシュートを測る。
2. **E0-S、既知負荷接続**：保護をONにし、解析で使った最小／最大容量と配線条件、EPIC4の凍結済み片脚負荷波形を電子負荷で再生する。抵抗負荷だけの合格を歩行波形の合格に置き換えない。公差を代表一点へ縮めない。
3. **E0-S、停止と復帰**：通常停止、異常停止、電源低下、復電を解析と同じ定義で実施。局所電源と下流バスを別々に記録する。遮断で負荷容量が外れる瞬間、再接続時、保持押下時を含め、自動再始動がないか確認する。
4. **E1-S、固定単関節**：E0合格後に限り、実サーボの保持・動作・停止波形を測る。非線形電流や回生のある波形へ単純RC式を当てて容量を断定しない。単関節結果を片脚6軸の保証に外挿しない。

## 判定と記録

通常端子4.75〜5.25 V、適用する異常過渡6.0 V以下という既存基準と、各選定品のより厳しい定格を維持する。起動途中の0 Vからの上昇を通常状態の範囲違反とせず、解析で定義した許可時刻から通常条件を適用する。保護定格は起動中も守る。下限を満たさない間は駆動許可を出さない。

電流、温度、保護停止、再始動は確定した部品仕様・故障真理値表と照合する。発振らしい波形は生波形・周波数・振幅を記録し、定常DC平均だけで合格としない。現段階で新しい位相余裕値や整定時間を合否基準として創作しない。必要ならモデルと仕様から実施前に定義する。

測定帯域・標本間隔・電圧/時間不確かさ・差動プローブ負荷・電子負荷の追従誤差・周囲温度・部品温度を記録する。許容範囲との差が不確かさ以下、あるいは波形を捕捉できていなければ未判定。全項目未実施。

記録項目: 回路commit、部品/計測器、入力波形、負荷波形の元ファイルとハッシュ、容量/配線条件、局所/負荷電圧・電流・制御信号、生波形、温度、判定とモデルとの差、次段階への可否。
