# 出力容量と電源安定性の設計／実測境界

## 部品選定判断

PTH08T240Wの全容量バンクESR最低7 mΩを、未知のサーボ容量が接続された状態で保証できていない。最低ESRを無視して採用確定しない。**PTH08T241Wを低ESR対応の詳細比較候補に加える**。現回路・CADへの置換はまだ行わない。

| 項目 | PTH08T240W | PTH08T241W |
|---|---|---|
| 5 V静的出力精度 | 条件付き総合±1.5% | 同左 |
| TurboTransなしの局所出力容量 | 5 Vで最低330 µF | 最低300 µFのセラミック |
| 上限／安定性条件 | 非セラミック上限5000 µF、全バンクESR最低7 mΩ | セラミック上限3000 µF。未知の混合負荷全般を保証する記載とはしない |
| 主な選定残件 | 全バンクの最低ESR | 実効容量、並列負荷・配線の範囲と適用性 |

出典：[TI共通データシートRev.J p5/p7/p13/p14](https://www.ti.com/lit/gpn/pth08t240w)、[PTH08T241W製品ページ](https://www.ti.com/product/PTH08T241W)。製品ページでACTIVEを確認したが、注文末尾・在庫・製作版は未確定。入力電解EEUFR1C471は前回の初期比較を維持し、全温度・周波数適合まで確認済みとはしない。

## 設計側で閉じること（#21〜#24）

1. 局所コンデンサーの正確な品番、DCバイアス・初期公差・温度・経年込み実効容量。セラミックの公称値をそのまま合計しない。
2. 遮断OFF時の局所容量と、ON時のサーボ・配線を含むインピーダンスを区別する。既存960 µFは比較条件であり実容量ではない。
3. 回路の接続、電流制限、電圧監視、INHIBIT、入力7〜14 V条件、熱、回生処理と測定に必要な停止経路を確定する。
4. 解析モデルには未知の負荷容量／インピーダンスを入力として残し、解析で成立した適用範囲を報告する。範囲外を暗黙に合格にしない。

これらは実機へ丸投げしない。PTH08T241Wの表条件だけから現サーボ接続時の安定性を断定しない。
