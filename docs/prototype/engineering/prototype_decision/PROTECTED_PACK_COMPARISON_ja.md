# 保護済み電池との構成比較（2026-09-22）

## 判断条件

ユーザーは電池選定と既製品採用を許可。外形・脚長維持、12軸とTab5給電は維持する。
既製品PCMを採用しても停止、逆接、回生処理、起動抑制、異常後の手動復帰は省略しない。
評価の終了条件は、公表仕様で候補を絞り、現行CADで置換可否を確認し、未公表の保護条件を区別すること。

## BQ入力について確定したこと

[TI BQ76942 SLUSE14B §16.3、§7.1](https://www.ti.com/lit/ds/symlink/bq76942.pdf)：
任意接続順対応は、正しいセル割当ての接触順に関する仕様。誤配線対応ではない。
VC0はセル接続前から基板内の抵抗を介してVSSへ接続する必要がある。
隣接セル入力間には内部ダイオードがあり、上位入力を下位より低く固定すると順方向電流が流れる。
VC1–VC10の下限はVSS−0.3 Vと直下VC−0.3 Vの高い方。負電源へ抵抗を接続するだけでは保護を証明できない。
100mAのセルバランス定格は逆接クランプ電流の許容値ではない。
従って前回384状態のうち正規配線の接触順と、誤配線24置換を区別して扱う。

## 採用した場合の回路変更範囲

保護済み出力だけをロボットへ接続し、生セルタップは接続しない。
ロボット側にヒューズ・逆接保護・電圧監視・各分岐保護・手動再始動を残す。
セル保護をPCMへ移す場合、現行BQとローカルMCUだけを削除するとBQ_AUX_START_REQUESTが消え、
起動許可信号が未定義になるため、全体シーケンスを代替しなければならない。
PCMの自動復帰でサーボが自動再始動しない回路を引き続き必須とする。
低電圧でPCMが切れる前のTab5終了時間・電圧余裕も未確認。

正式BOM・回路・MuJoCo質量はまだ置換しない。LB-020単体は現行76g電池より26g増えるが、
削除可能なBQ系と追加取付部の差分が不明なので全体で重くなるとは断定しない。
CAD配置結果は`validation/protected_battery_fit_v1`。6姿勢の結果を見てトレー再設計の要否を決める。
製作HOLD・#21〜#24未完了を維持する。
