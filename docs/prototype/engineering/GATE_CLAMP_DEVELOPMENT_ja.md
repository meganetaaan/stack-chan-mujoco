# 回生吸収MOSFETのゲート保護候補

吸収経路が開放故障した場合、2.2 kΩプルアップでゲート電圧も上昇する。
ゲートとソース間へツェナーダイオードを追加する候補を解析する。バスの過電圧保護は別途必要。

候補は [Nexperia BZT52H-C6V8](https://assets.nexperia.com/documents/data-sheet/BZT52H_SER.pdf)（Rev.7、表8）。5 mAで6.4〜7.2 V、温度係数最大4.5 mV/K、微分抵抗は1 mAで80 Ω、5 mAで8 Ω。
モデルは膝電圧7.2+0.0045×125=7.7625 V、傾き80 Ωの区分線形電流源と200 pFを使用する。
この広い傾きによる外挿は感度解析の仮定であり、メーカーが保証する全電流・全温度の包絡ではない。低電圧での漏れと負方向過渡は未反映。

実行前の判定基準はゲート絶対値10 V以下（MOSFETの12 V定格に余裕）、ツェナーピーク0.1 W以下、プルアップ抵抗ピーク0.25 W以下。
データシートの標準実装での熱抵抗330 K/Wを用いると、0.1 Wに対応する定常温度差は33 K。実基板と筐体の熱環境は未検証。
2.2 kΩ抵抗は従来の呼び抵抗値だけでは選定できず、故障時の電力を満たす購入部品が必要。

```sh
.venv-engineering/bin/python software/sim/circuits/run_brake_probe.py --out outputs/gate_clamp_open_new --case brake_open --gate-clamp
.venv-engineering/bin/python software/sim/circuits/run_brake_probe.py --out outputs/gate_clamp_late_new --corner late --gate-clamp
```

ゲート電圧が基準内でも、モーター側の過電圧、不足する独立吸収経路、他の部品の故障時定格は解決しない。Issue #24全体は未完了。
