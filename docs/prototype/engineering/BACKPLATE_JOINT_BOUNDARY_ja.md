# 背面構造板から胴体への接合境界

現時点の背面板解析は四隅の座面を理想固定する。これはねじの許容荷重を確認したことを意味しない。`extract_backplate_reactions.py`は解析メッシュから固定自由度を再構成し、各隅の反力と反モーメントを、その隅の中心に移して抽出する。胴体へ作用する荷重は反作用として符号を反転する。自由節点の数値残差を接合荷重へ含めない。

記録右旋回2.661 s・3 mmメッシュの同時負荷では、胴体側へのx方向力は各隅で約−0.56、−0.57、+4.71、−3.58 Nとなる。引張と圧縮が混在し、同時に最大約83 Nmmの局所モーメントが存在する。ねじ軸力だけに置き換えると、この伝達を落としてしまう。

この値は剛な支持条件での荷重分担であり、柔らかい胴体へそのまま適用して合格を宣言できない。次の接合モデルには以下を含める。

- 板とボス端面は離間可能な圧縮接触。摩擦係数と締付けの根拠が未確定な間は、摩擦によるせん断保持を確定値として使わない。
- ねじは板の座面・軸・保持側を含み、接触を介して曲げモーメントを伝える。ねじ1本に任意の固定モーメントを直接負担させない。
- 現行の胴体ボス穴は直径2.5 mmで、M3通し穴ではない。保持方式と有効かかり長さ、積層方向、ボス根元の強度は未確定。
- 胴体と板の変形を同じ荷重経路で扱い、接合部の剛性による反力再配分を確認する。理想固定の局所評価と連成後の結果を混同しない。
- 追加の板質量約50 g、支持部・ねじ等の変更質量を動作モデルへ反映してから最終荷重を再生成する。

抽出した反力の全球座標での合計と外力の釣り合いは、力・モーメント各成分で1×10⁻⁵ NまたはNmm未満を要求する。3ケースの最大残差は8.66×10⁻⁸。これは反力抽出の整合性検査であり、接合の成立判定ではない。

```sh
LD_LIBRARY_PATH="$PWD/.tools/root/usr/lib/x86_64-linux-gnu" .venv-engineering/bin/python software/sim/structural/extract_backplate_reactions.py --analysis validation/back_cover_development_v1/backplate_load_v1 --out outputs/backplate_reactions_new
```
