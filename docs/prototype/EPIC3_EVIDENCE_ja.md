# EPIC #3の完了条件と証跡

## #10 配置・実行入口

実体を `software/sim/mujoco` と `board/mechanical/design` へ移動した。
回路図・基板・ファームウェア・回路/構造解析の責務と後続Issueを各READMEに記載。

## #11 共通仕様

`board/mechanical/prototype` に12軸のID・軸・ゼロ規約・符号・制限・部品表・質量表を生成。
`verify_prototype_spec.py` がMJCFの各軸・制限・慣性と照合し、総質量0.9184400456 kg、
XL330 6個 / XC330 6個の整合を確認する。
凍結モデルの古い説明値は変更せず、製作用robot.jsonでヨー有効・±15度と実行時歩行設定を明示。
エンコーダ実測校正値はnullのままとし、設計上のゼロ規約と区別した。
回路部品・ねじ等の未確定仕様は予約枠としてBOMに明記。ハードウェア制御は有効化しない。

## #12 基準試験・共通形式

新規venvに `software/sim/requirements-runtime.txt` を導入し、解決した全依存はlockへ保存。
`software/sim/run.py baseline` で左右旋回を再実行した。
`validation/prototype_epic3_v1` に状態列・1 ms接触・ログ・独立採点を保存。

| 試験 | 結果 |
|---|---|
| 左90度 | 6着地、胴体停止を含む完了2.76 s、最終誤差−0.163844度 |
| 右90度 | 6着地、胴体停止を含む完了2.76 s、最終誤差+0.163899度 |
| 操作系 | WASD・切替・速度・横移動の16テスト成功 |
| 凍結資料 | 全4,176ファイル一致 |
| デジタル仕様 | 12軸・質量・部品数・座標・制限の検査成功 |
| 共通結果形式 | 5解析種別と、不正な合格・根拠区分・非有限値・外部パス拒否の4テスト成功 |

共通 `result.json` は解析種別・出典区分・入力ハッシュ・実行環境・コマンド・判定・成果物を保持。
回路・構造解析自体を実行したという主張はしない。単関節・片脚の駆動解析はEPIC #4に続く。
今回の検証はシミュレーション再現であり、実機歩行や製造強度の検証ではない。
