# 候補アクチュエータの選定と解析モデル

対象はEPIC #4。実機の連続定格・熱特性・制御ゲインを同定したものではない。
基準となるr9の凍結モデルは変更せず、別の電流・位置制御モデルで要求動作を試験する。

## 選定

| 関節（左右各1） | 候補 | 理由 |
|---|---|---|
| 股関節ヨー、股関節ピッチ、足首ロール | XL330-M288-T | 現行r9の軽量側の候補を維持 |
| 股関節ロール、膝、足首ピッチ | XC330-M288-T | 現行r9で高い駆動上限を割り当てた軸を維持 |

各6個、合計12個。仕様の一次資料は
[XL330-M288-T](https://emanual.robotis.com/docs/en/dxl/x/xl330-m288/) と
[XC330-M288-T](https://emanual.robotis.com/docs/en/dxl/x/xc330-m288/) のe-Manual（2026-09-21確認）。
数値は `software/sim/actuator/catalog.json` に保存した。

両者の外形は20×34×26 mm、推奨5 V、電源範囲3.7〜6 V。TTL半二重で、電流ベース位置制御を使用可能。
XLは18 g・樹脂歯車、XCは23 g・金属歯車。5 V時のストール端点はXLが0.52 Nm/1.47 A、
XCが0.93 Nm/1.80 A、無負荷速度はそれぞれ103/81 rpm。
これらは短時間の端点であり、連続トルクとしては扱わない。

代替案は全軸XC化（型式と外形を揃えられる一方で、現在の6個のXLを置換すると部品質量は30 g増加）と、
同シリーズの別減速比。今回はどちらも採用せず、必要な動作と負荷が現候補の制約内にあるか先に検証する。
変更時は慣性・電源・速度の再評価が必要。

ホーン・固定穴・軸位置は既存のメーカー参照
`board/mechanical/design/x330_manufacturer_reference.json` に図面/STEPの出典とハッシュがある。
ホーンを含む奥行きと後部アイドラ追加時の奥行きを区別し、現在のr9に後部アイドラは搭載しない。
取付支持・ねじ長・保持強度の決定はEPIC #5に残る。

## 実装可能な指令モード

Operating Mode 5（電流ベース位置制御）をモデル化する。
位置は4096 count/回転、電流指令は1 mA刻みとして量子化する。
外部の軌道指令は20 ms周期、内部の実効位置PDと電流応答は1 ms刻みで計算する。
このPDゲインはNm/rad等の実効値で、メーカーのPIDレジスタ値への換算・同定を意味しない。
モード5では内部のMin/Max Position Limitだけに頼らず、指令側で角度制限を適用する。

## 電気・機械の近似

電圧ごとのストールトルク `Tstall`、電流 `Istall`、無負荷速度 `w0` から次を構成する。

- 等価抵抗 `R = V/Istall`
- 等価逆起電力係数 `K = V/w0`
- 歯車等を含む効率係数 `eta = Tstall/(K*Istall)`
- 駆動時トルク `eta*K*I`、回生時トルク `K*I/eta`
- モーター端子電圧 `R*I + K*w` を電源電圧内に制限

駆動・回生の両方で歯車損失を非負とし、銅損と待機電力を加えてDC側電力を計算する。
待機17 mAを無負荷モーター電流に流用しない。無負荷モーター電流や内部損失の分配は不明で、
等価抵抗・効率は端点に合わせた近似。電流応答の一次遅れは内部帯域の近似で、巻線インダクタンスではない。
PWMリップルやスイッチング過渡は再現しないため、1 ms負荷だけで電源の最終設計を完了できるとは主張しない。

解析上のトルク上限0.26/0.45 Nmを維持し、電流上限をXL 0.735 A / XC 0.870 Aに設定する。
これは既存の設計上限に整合させた値で、メーカーの連続定格ではない。
ガタは位置のデッドバンドとして近似し、歯打ちや2慣性系の衝撃は含めない。
関節摩擦・減衰・アーマチュアはMuJoCo側で扱う。

## 要求動作と治具

`capture_workload.py` で成功済みの左右旋回、`capture_translation_workload.py` で既存r9の前後進を採取。
`merge_workloads.py` で全軸の可動範囲とピークトルクの包絡を作る。
前後進は現行指令0.04/−0.02 m/sであり、最終的な0.10 m/sの達成はEPIC #9の対象。

単関節では、この可動範囲とピーク負荷を使った等価慣性の物理治具を動かす。
要求軌道や誤差基準を緩めず、既知の指令軌道に対するフィルタ・輸送遅延の先行補償と速度フィードフォワードを使用。
ステップ応答・負荷掃引では0.10 radの指令ステップと、解析上限の0〜125%の外部トルクを適用する。
過負荷の不合格も保存し、許容外の荷重を通過させることを目的にしない。

片脚は実際のr9 CAD/MJCFから反対脚を除き、胴体慣性の半分を搭載する。

- 支持：胴体の横移動・姿勢だけを案内し、鉛直荷重は床と脚で支持する。
- 荷重移動：同じ治具に既知の鉛直外力を加え、支持荷重を50〜100%で変化させる。
- 振出し・ヨー：胴体を固定し、床のない空間で成功済み軌道を追従する。

これらは試験治具であり、片脚自立や補助なしの全身歩行を証明するものではない。
全身への試験適用も別に残し、新駆動モデルでは旋回終端に従来との差があることを明示する。

## 不確かさと温度

電圧、輸送遅延、電流応答、ガタ、質量、摩擦を一因子ずつ変えて試験する。
熱抵抗・熱容量・環境温度は `catalog.json` の工学的シナリオであって、実測信頼区間ではない。
一つの実効ケース温度RCモデルで600秒の繰返し負荷を投影し、連続使用時の発熱傾向を調べる。
巻線ホットスポットや温度による駆動低下を連成していないため、温度結果からメーカー連続定格を確定しない。
連続トルク定格はnullのまま、条件付きRMS電流の推定と、ピーク電流の保持で温度上限を超えるケースを区別して出力する。
