# SCW-SOLE-SPACER-01 加工部品候補

足裏スライドロックの独立スペーサー。左右共通、1台2個。`specification.json` は加工・組立に要求する寸法案であり、製造能力や材料強度を実証した値ではない。市販品の寸法不一致は `validation/sole_spacer_procurement_v1` に保存した。

寸法は外径6（−0.05/+0）、内径2.3（−0/+0.05）、厚さ0.9±0.05 mm。SUS304の切削部品を候補とし、端面平面度・平行度各0.02 mm、径方向の縁落とし最大0.05 mmを要求する。厚さ限界は端面の形状誤差を含む包絡値。製造図の最終リリースと見積は未実施。

相手側への要求案は穴径6.4±0.1、局所足裏厚さ3±0.1、ねじ頭高さ最大1.4 mm。この場合、半径隙間は最小0.15 mm、無負荷での頭の沈みは最小0.55 mm。残すべき床面余裕0.2 mmを差し引くと、圧縮・摩耗・傾き・埋込みへ割り当てられる合計は0.35 mmになる。この値を変形量の実証値として扱わない。TPU造形品とねじ製品が要求寸法を満たす根拠はまだない。

縁落としと公差で平坦な座面の幾何学的面積も減る。既存の外径6 mm剛体支持解析は公称・鋭角モデルなので、今回の公差案への合格証明にはならない。次の接触解析では最小座面、最薄スペーサー、離間と材料弾性を扱う。局所接触面積はこの幾何学面積より小さくなり得る。

リポジトリルートで再現:

```sh
python3 software/sim/structural/check_sole_spacer_tolerances.py --out outputs/sole_spacer_tolerance_repro
```

保存結果: `validation/sole_spacer_tolerance_v1/report.json`。条件付き寸法チェックが通っても製造リリースやIssue完了を意味しない。
