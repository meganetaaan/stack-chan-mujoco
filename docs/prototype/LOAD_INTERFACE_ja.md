# 機構・電源解析へ渡す負荷インターフェース

`software/sim/actuator/export_loads.py` は、同じMuJoCo記録から構造解析用と回路解析用の入力を作る。

```sh
.venv/bin/python software/sim/actuator/export_loads.py \
  --source outputs/actuator-fullbody-left --out outputs/load-left
```

- `loads.npz`: 全時刻の関節反力・モーメント、軸トルク、電流、電力・損失、速度・加速度、同時駆動率。
- `bus.csv.gz`: DC側の消費・回生・正味電流と同時駆動軸数。
- `joints.csv.gz`: 軸名付きの構造・駆動負荷時系列。
- `schema.json`: 単位、座標、出典、近似、時刻を揃えた代表最悪荷重ケース。

反力は関節原点での親から子への合力。並びは `[Fx,Fy,Fz,Mx,My,Mz]`、単位はNとNm。
MuJoCoの `cfrc_int` は運動学的サブツリーのCOM原点・世界軸方向の `[moment,force]` なので、
関節原点へモーメントを移し、関節ボディのローカル軸へ回転する。
この規約は[MuJoCoの計算説明](https://github.com/google-deepmind/mujoco/blob/main/doc/computation/index.rst)に対応する。
1 kgの既知の偏心荷重で、9.81 Nと0.981 Nmの静的反力を再現する単体テストを設けた。
内部歯車・個々の軸受への荷重分配は別の機構解析が必要。

DC側電流とモーター側電流は別物。回生を負の電流として差し引いた正味電流だけでなく、
消費と回生を分離して渡す。実際の電源が回生を吸収できるかはEPIC #6で確認する。
同時駆動率はモーター電流50 mA以上の軸数/全軸数と定義し、PWMデューティとは区別する。
加速度は保存した速度の有限差分。端点は一次精度。

サンプリングは1 ms。駆動量は積分区間の開始状態で計算し、反力・状態はその1 ms後に保存する。
異なる時刻の成分最大値を合成せず、最大力・最大モーメント等が生じた時刻の全軸同時データを渡す。
回路・構造の両コンシューマーは `load_export.py` の読込み関数で同じ記録を検査できる。

## 余裕の扱い

保存する波形と代表荷重の倍率は1.0（解析で発生した値のまま）。安全率を既に含む許容荷重ではない。
電流・トルク上限は `catalog.json` の解析用制限であり、構造部品の安全率や電源定格の余裕とは別。
後続解析では元波形を保持し、採用する荷重倍率・温度条件・材料許容値・電源余裕を各解析の入力に明記する。
本段階では実測に対する誤差上限が不明なため、実機を保証する安全率は確定しない。
質量±5%、電圧3.7–6 V、遅延5–20 ms等の感度試験は保存済みだが、すべての組合せや衝撃を網羅していない。
