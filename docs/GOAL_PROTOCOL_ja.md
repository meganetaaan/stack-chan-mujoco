# Tab5 二足歩行のシミュレーション受入条件 v2

現段階は**強化学習方策**のシミュレーション受入を目標とする。
現行の胴体128 mm角、大腿50 mm、下腿44 mm、足94×52 mm、Tab5の顔を維持する。
実機10 m・18/20は、電源構成の確定と実機パラメータ同定後の次段階とする。
実機の既存手順は [HARDWARE_PROTOCOL_ja.md](HARDWARE_PROTOCOL_ja.md) に保存する。

## 合格条件

- 指令前進速度0.10 m/s。開始時の胴体基準位置から前方10 mに初めて到達するまでを測る。
  発進時間を含め100秒以内。道のりの積算を前進距離に置き換えない。
- 固定プラント条件で20/20、事前に固定したランダム化条件で18/20以上。
  固定条件もIMU白色雑音・バイアスを有効にし、試行ごとに異なるシードを用いる。
- 転倒、自己衝突、足裏以外の床接触、関節制限逸脱、飽和による保護停止、中断なし。
  10 m通過後も予定した停止・静止まで評価し、停止失敗を除外しない。
- 重力、接触、摩擦、慣性、関節範囲、トルク速度制限、制御周期、遅延を有効にする。
  自由基底へ外力や位置補正を与えない。接触・関節限界・保護は物理刻みごとに監視する。
- 1つの凍結したモデル・方策・設定で各20試行を行う。失敗を選別・再抽選しない。
  調整に用いた試行は開発評価と表示し、最終受入は未使用シードで改めて実施する。

## 記録と公開

設計・モデル・方策・コードのハッシュ、依存関係、学習設定・シード、評価シードと実現した
質量・重心・摩擦・モータ・遅延・IMUノイズを記録する。
実MuJoCoの状態、方策観測と行動、接触と保護イベント、初回10 m到達時刻を保存する。
動画は保存した実状態を再生して作る。IK参照や合成アニメーションを実状態の証拠にしない。

## 残差RLの初期実装

`configs/r6_residual.json` と `stackchan_rl/residual.py` はR5環境と別のインターフェース。
参照歩容＋PPOの関節目標補正で学習する。参照のみの成功を学習結果に数えない。
最初の学習エピソードは12秒であり、長距離および停止学習の達成を示さない。

- 物理1 ms、方策20 ms、指令遅延10–14 ms、スルー6 rad/s、LPF40 ms。
- 質量0.95–1.05倍、胴体慣性中心各軸±1 mm、摩擦0.6–1.0、トルク0.9–1.0倍、
  無負荷速度0.95–1.05倍。質量変更に伴って各部慣性を同倍率にする。
- 重力方向観測の各成分ノイズ標準偏差0.001–0.004、ジャイロ0.005–0.02 rad/s、
  エピソード中一定のジャイロ偏りの標準偏差0–0.005 rad/s。毎リセットで範囲から抽選する。
- 固定条件でも重力方向0.002、ジャイロ0.01 rad/s、偏り標準偏差0.002 rad/s。
- 飽和保護は、任意の関節で連続0.25秒、または直近1秒の飽和率50%超で停止。
  判定は未飽和の短い隙間で履歴を消さない。最初の1秒は連続時間の判定を適用する。
- 接触は侵入10 nm超または接触力1 µN超を失敗とする数値許容値。
  関節限界の数値許容値は10 µrad、転倒判定は胴体傾斜35度。

これらは**未同定の設計仮定とシミュレーション上の保護設定**。
モータの実機連続定格や熱・電源保護を検証した値ではない。
速度・関節角等には現段階でシミュレータ由来の理想状態推定を用いる。
IMUだけの実機制御器へそのまま移植できることは示していない。
接触形状の未モデル化部分とCAD構造上の未検証事項は既存設計文書を参照する。
