# v2 設計メモ

## 診断と変更範囲

ユーザーの出力から確実に分かるのは、正の速度指令に対してほぼ前進せず、設定した離床・着地基準のカウントがゼロで、エピソードが時間上限まで進んだことです。学習済み重みと詳細軌跡は受け取っていません。報酬の局所解だけが原因、探索分散が小さかった、立位が全基準に合格、といった断定はしません。

旧ソースでは、速度報酬が `2 * exp(-||v-command||² / 0.035²)` なので、0.02 m/s指令でも静止は速度報酬の約72%を得ます。遊脚位相でも両足接地に対する接触一致率は1/2でした。これらは改善対象ですが、それだけで今回の失敗原因が証明されたわけではありません。

MJCFと全assetのSHA-256、関節の順番と動作軸、トルク・速度・遅延・slew、観測の順番とスケールを維持しています。機械変更と報酬変更を混ぜません。

## 報酬

正の指令時のみv2を使います。速度項は、`sigma = max(0.006, 0.6*vx_cmd)`、`b=exp(-vx_cmd²/sigma²)` とし、`clip((exp(-||v-vcmd||²/sigma²)-b)/(1-b), -1, 1)` です。速度ゼロならゼロ、指令一致なら1です。速度を上げれば無制限に高報酬になる形にはしません。

前進項は、歩行指令の有効化以降の胴体x座標の最大値を更新した距離です。1制御ステップでの得点を指令の2倍の進行量までに制限します。後退して同じ地点へ戻っただけでは再加点しません。これは実際の足取りの条件とは独立なので、滑り歩きの除外には接地検査・滑り罰則・成功判定を併用します。

除荷項は、遊脚を要求している足の荷重割合を1/2からゼロに下げるほど増えます。反対足が接地しているときだけ有効です。高さ項は反対足の支持下で遊脚の足底が離床していることを要求し、6 mmを超えて非常に高く持ち上げるだけでは得点が増え続けない形にします。

「有効着地なし」1.5秒の猶予後に、1秒かけて最大0.45/秒の罰則へ増加します。停滞を理由にエピソードを終わらせません。終了すると負の将来報酬を逃れる学習が起き得るためです。実際の転倒等に対する終端罰則は残します。

速度・姿勢などのrate項はdt=0.02秒を掛けて積算します。離床・着地のevent項は一度だけ加え、dtを掛けません。停止指令時には歩行eventも停滞罰則もゼロです。

## 接地イベント

raw contactsは従来と同じ荷重判定で、方策観測の意味を変更しません。イベント判定だけを強化します。

1. 初回接地の40 ms確認後、その足を有効な支持履歴ありとします。
2. 非接地が連続80 ms以上、足底最低高さが2 mm以上、空中時間の半分以上で反対足が接地していると、適格な離床です。
3. 再接地が40 ms確認されると有効着地です。瞬間的接地から再離床すると未確認候補を捨て、滞空時間を蓄積し直します。
4. 離床前の支持位置から4 mm以上前へ出ており、同じ足の過去の最大前進位置も4 mm以上更新した着地を「前進着地」とします。
5. 通常の離床・着地報酬は同じ足の連打を避け、250 msのイベント間隔を置きます。独立した評価用カウントは、報酬の間引きと分離します。

これは接地履歴の検査で、CADの動的干渉判定ではありません。両足同時の跳躍は支持条件で除外しますが、あらゆる不自然な歩容を排除できるという主張はしません。

## 学習の移行

旧方策の入出力を維持し、Stage 1はactorネットワークをコピーします。criticとoptimizerは新規のままです。旧方策のlog_stdをコピーした直後に、Stage 1設定で−1.0へ明示的に変更します。旧分散の縮小を測定した結果ではなく、探索を再開するための設定です。変更前後は転送記録へ残します。

Stage 2/3は同じ報酬式なのでactorとcritic、log_stdを引き継ぎ、optimizerだけ新しくします。トレーニングbudget経過のみでは進級しません。別seed評価と映像を確認してから次の設定を選びます。

## best選択と成功

報酬と成功は別です。v2のbest選択は辞書順で、指令別成功率の最低値、指令別成功率の平均、実歩数・前進・生存時間・接触に基づく探索進捗スコア、左右共通の前進着地数、生存時間、最後に報酬を比較します。すべて失敗していても候補はbestとして保存されるので、その存在だけで成功とは判定しません。

Stage 1だけは前進距離を25 mm以上か指令距離の10%以上の大きい方まで緩め、左右の前進着地を各1回以上とします。それでも有効着地は各2回、交互切替3回を要求します。Stage 2/3では指令距離の50%以上、前進着地各2回へ上げます。他の姿勢・接触・速度誤差・飛行時間条件は残します。
