# 制御電源の立上り調整候補

TPS26600 RHFの20番dVdT端子からRTNへ、既存部品候補GRM31C5C1H104JA01L（100 nF、C0G）を追加した。前の40部品案から41部品となる。端子開放案を履歴として残す。正式システム回路は未置換。

[TI TPS2660 RevG](https://www.ti.com/lit/ds/symlink/tps2660.pdf)の端子表・§7.5・§9.3.4に基づく選定。充電電流4〜5.5 µA、利得23.75〜25.5と容量比較範囲94〜106 nFから、立上り速度0.896〜1.492 V/msを算出。IC表の既定試験条件は24 Vであり3S実回路の保証へ無条件に拡張しない。100 nFはユーザー要求ではなく設計選択。

接続データから直接集計したLDO入力側/3.3 V側のコンデンサに比較上限を割り当てると合計15.177 µF。C0G/フィルムは総変動+6%、X7Rは初期+10%×温度+15%と仮置き。実効容量の保証値ではない。リセット信号の100 nFは直接レール容量に含めず、その充電は既存抵抗電流配分の対象。

| 比較 | 容量充電＋既知部分負荷 | 0→12.6 Vのランプ部分 |
|---|---:|---:|
| 端子開放・典型速度 | 237.75 mA | 0.844 ms |
| 100 nF・公称 | 28.59 mA | 10.90 ms |
| 100 nF・遅い側 | 24.64 mA | 14.06 ms |
| 100 nF・速い側 | 33.68 mA | 8.44 ms |

LDO出力も同時に入力の速度で充電される仮定。開放案の比較電流が公称制限101.7 mAを超えるため、100 nFを優先候補にする。ICの内部遅延を含む総起動時間ではなく、LDO出力は3.3 V到達後にこの傾きで上がり続けるものでもない。

LDOが遅れて立ち上がり出力容量を急に充電する場合、このモデルではピークを包絡できない。既知負荷11.041 mAは全最大でもない。したがって33.68 mAを実機突入上限として扱わず、起動合否はnullのまま。入力電流制限下限と未計上電流、LDOの低入力起動/出力充電、リセット解除順序を次の確認に残す。

出力過電圧を含む追加故障仮定の扱いは`validation/pack_control_fault_scope_v1`に従う。今回の変更は起動充電の設計選択で、異常全体の成立ではない。製作HOLD、#21〜24未完。

再現：

```sh
.venv-engineering/bin/python software/sim/circuits/select_pack_control_ramp.py
```

ramp_report.jsonに容量一覧、式の入力、比較結果を保存。assembly.json/BOM/接続CSVは41部品の候補を表す。
