# 監視・既定状態用抵抗の型番候補

revIの抵抗13個をVishay TNPW0603の注文表に従った型番候補へ置換した。部品数94、ピン数308、配線と公称抵抗値は維持。現物在庫・少量調達の確認ではない。

メーカー資料： https://www.vishay.com/docs/28758/tnpw_e3.pdf （10-Apr-2026、2〜4ページ）。B=初期±0.1%、Y=±10 ppm/K、EA=5000個包装。13個の値と型番はresistor_report.jsonを参照。

既存の総合±1%予算を変更せず、膜温度−40〜85°Cを仮定した初期公差＋温度分は±0.165%、未配分は0.835%。この残枠をはんだ付け・経時・環境変化が満たすことは未確認。温度範囲は今回の比較条件であってユーザー要求ではない。

各抵抗へ単独に12.6 Vを与える保守的な定常電力比較では最大16.04 mW。一般動作モードの85°C周囲温度における比較上限80 mW未満。実PCBの膜温度、過渡電圧、抵抗以外の端子定格や故障保護はこの比較では証明しない。

再現：

```sh
python3 software/sim/circuits/select_monitor_resistors.py --out /tmp/monitor-resistor-selection
```

追加の同一条件掃引は不要。次は未選定コンデンサ、保護電力段、全体電源・熱予算の設計を進める。回路適合・製造リリースは引き続きfalse。
