# ロジック電源を含む主回路の統合候補

98部品のR14変更候補を基に、TPS26601入力保護、抵抗6本、バイパス4個、TPS70933DRVR、出力コンデンサを追加した111部品・371端子項目の接続データ。正式currentポインタはrevMのまま。製作不可・電気的成立は未検証。

`assembly.json` と `candidate_bom.csv` は再生成する。入力ファイルとSHA256をassembly内に保持し、個別候補が変更された場合は再生成が必要。

```sh
.venv-engineering/bin/python software/sim/circuits/integrate_logic_supply_candidate.py --out schematics/power/servo_power_logic_integration_candidate_v1
```

検査は参照番号の重複、基となる98部品の完全一致、RTNとGNDの区別、分圧下側/電流設定抵抗のRTN帰路、保護出力からLDO入力とLOGIC3V3への接続。`report.json` はこの限定範囲の結果であり、KiCad ERCや動作シミュレーションの合格ではない。

旧回路から継承した履歴・制約は過去の検討経緯として残す。今回の追加内容と未成立項目は `candidate_integration` を参照する。ロジック電源の供給元は具体化されたが、起動シーケンサ、全電池/コンバータ接続、回生、信号経由逆流、出力コンデンサの安定性、118kΩ設定時の電流保証、熱・PCB配置は未成立。

追加した入力放電抵抗127.27µA最大（12.6V、±1%枠）は電池側負荷で、LOGIC3V3負荷へ加算しない。出力ポリマーの漏れ電流は既存のロジック負荷見積りへ別途加算が必要。IC負荷の過去の集計を111部品全体の集計として使用しない。

失敗記録: 最初の検査では「全抵抗の2番をRTN」と誤指定して分圧上側を誤検出した。回路は変えず、対象を分圧下側2本とILIM抵抗へ修正して再実行。放電抵抗はGND帰路でありRTNへ変更しない。

この統合で#22〜#24をクローズしない。次の解析はこの候補を入力にし、起動/電源切断と出力短絡での回路動作を対象とする。未実装の電源や制御を理想素子へ置換した場合、その範囲を明示する。
