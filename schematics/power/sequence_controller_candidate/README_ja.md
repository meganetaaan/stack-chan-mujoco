# 電源状態制御ICの候補

STM32C011F6P6（TSSOP20）を電源シーケンス用の比較候補とする。
端子割当は成立するが、電気的適合・回路統合・ファームウェア実装は未完了。
現行revIに追加済みの部品ではなく、製作BOMの確定品でもない。

必要な端子は入力11、出力3、電源2、専用リセット1、SWD2。
残り1端子を予備にできる。起動タイマーは内部処理とし、モデル上の
STARTUP_EXPIREDとstartup_timer_runをそのまま外部配線にしない。
一方、実CLR端子の観測は2入力確保し、自分が出したクリア指令で代用しない。
PC14/PC15を入力へ使うため、外部水晶を接続する構成とは両立しない。

メーカー制約は電源2.0〜3.6 V、型番末尾6の周囲温度−40〜85℃。
各接続の電圧・電流は別途確認する。MCUの入力漏れ代表値を最大値として使わない。
特に既存起動待ち受信部は、20 µA駆動条件まで残る負荷が約3.47 µAしかない。
ここにMCUを接続してよいかは未確定である。

このICは起動・再始動の手順を管理する案で、故障遮断をソフトウェアだけに依存させない。
電源低下、未書込み、デバッグ停止、更新中にも外部回路が給電を禁止する必要がある。
BOR・クロック・監視タイマーの設定、両CLRの観測回路、非同期故障記憶を設計する。
それらを実装するまでは、状態モデルの検査結果を実回路の証明にしない。

再現：リポジトリルートから未作成の出力先を指定する。

```sh
python3 software/sim/circuits/check_sequence_controller_pins.py --out /tmp/sequence-controller-pins
```

これはパッケージ端子表と信号数の照合。消費電流、タイミング、配線故障の評価ではない。
出典：[ST DS13866 Rev 5](https://www.st.com/resource/en/datasheet/stm32c011f4.pdf)
pp.28〜30、37、60〜61、93。2026-09-21確認。
