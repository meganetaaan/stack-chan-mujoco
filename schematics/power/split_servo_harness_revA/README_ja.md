# 左右分離給電のハーネス接続候補

12軸を個別給電し、左右それぞれ6本を各5V配電点へ戻す接続表。
`connections.csv`はjoints.jsonから軸名とIDを生成する。左右V+は接続しない。
これはCodexの設計候補であり、ユーザーが指定した方式ではない。
接点に複数軸の電流を流す既製デイジーチェーンとは異なる配線が必要になる。

候補部品は既存のEHR-3×12、SEH-001T-P0.6×36。
サーボ側pin1 GND、pin2 VDD、pin3 DATA。一次資料は
https://emanual.robotis.com/docs/en/dxl/x/xl330-m288/ と
https://emanual.robotis.com/docs/en/dxl/x/xc330-m288/ 。
コネクタ外観からの左右判断をせず、製作図には嵌合面と端子番号を明示する。
可動用電線、長さ、圧着・保持方法、端子カバーは未選定。
固定治具用Alpha3051を全身用として流用しない。

各サーボのもう一方のポートは使用せず、誤接続防止を設計する。
左右間を通常の3線ケーブルで接続すると別電源の出力同士を接続してしまう。
共通GNDは電気的絶縁を意味せず、帰路電圧降下を信号側の検査にも含める。
DATAは左右別区間としたが、ホスト接続・片側無給電時の逆給電防止回路は未設計。
この接続表だけで通信や通電を許可しない。

故障時の要求：片側異常は両脚への停止要求へ集約する。
信号停止だけを動力遮断と扱わず、各出力の遮断・回生吸収・放電を独立に設計する。
片側故障で両脚を止めれば姿勢を維持できる、という保証でもない。

無通電検査は、電源・サーボを外したハーネス単体で全36端子の接続表との一致、
左右V+間の非接続、電源とDATA間の非接続を確認する。
抵抗・絶縁の数値基準は電線と保護素子を確定してから設定する。
製作リリースの終了条件は実配線長、公差込み降下、保護協調、DATA電源遷移、
CAD上の可動範囲と曲げ半径、組立図の確認。現状はいずれも完了扱いにしない。

再現：`python3 software/sim/circuits/build_split_servo_harness.py --out NEW_DIRECTORY`
