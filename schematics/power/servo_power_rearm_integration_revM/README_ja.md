# 停止監視電源の入力容量候補

C_STOP_INをWIMA MKS2C042201K00JSSDへ具体化。公称2.2 µFは維持。63 V、±5%、PETフィルム、5 mmピッチ、胴体公称7.2×13×7.2 mm（W×H×L）。注文表のMKS2C042201K00にJ（5%）S（バルク）SD（脚長）を付けた候補で、在庫確認ではない。

出典：https://www.wima.de/wp-content/uploads/media/e_WIMA_MKS_2.pdf （03.26、34〜35ページ）。旧50 V品の寸法・注文コードを流用しない。85°C超での電圧低減等は資料に従う。13 mm高さの実装包絡、固定方法・振動・PCB配置は未確認。

入力の高周波経路用としてC_STOP_IN_HF=GRM31C5C1H104JA01Lを追加し、TPS709のIN/GND直近へ置く。フィルム品のリードと離れたGND経路だけに高周波電流を流す配置は避ける。これで98部品317ピン。

初期公差のみの合計容量は2.185〜2.415 µF。直列抵抗の±1%と合わせた単純RC時定数は2.16〜2.44 ms。負荷電流やLDOの立ち上がりは含まないため、これを起動待ち時間へ転用しない。12.6 Vでの最大初期蓄積エネルギーは約0.192 mJ。全温度・経時の容量範囲や全体の安定性を保証した値ではない。

再現：

```sh
python3 software/sim/circuits/select_stop_input_capacitors.py --out /tmp/stop-input-capacitors
```

次はこの入力構成とLDOの起動負荷を接続した評価。基板高さが許容されない場合は、2.2 µFという公称値を通すために外形を広げず、別の小型候補を比較する。製造リリースは未承認。
