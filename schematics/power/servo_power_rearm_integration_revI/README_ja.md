# 給電許可要求の浮遊入力を修正

revHではSEQUENCE_ENABLE_REQUESTの実接続がU3の4番端子だけだった。
インターフェース名の存在を駆動回路の存在と取り違えてはならない。
未実装の状態回路を理想信号源で置き換えれば、この欠陥が隠れる。

revIはU3直近へ10 kΩプルダウンを追加した94部品・308端子の比較案。
将来の状態回路との配線が切れた場合も抵抗がIC側に残る配置を要求する。
入力漏れ1 µA・抵抗総合±1%という比較では入力電圧10.1 mV。
将来のHigh駆動は3.6 V比較時に約0.365 mAの負荷を供給する必要がある。
これは全電源範囲のLow保証、停止時間、状態回路実装の証明ではない。

10 kΩは設計選択で、メーカーの入力終端に関する適用説明も参考にした。
ユーザー要求や停止基準を変更していない。抵抗実品、ドライバと漏れ、
部分給電、状態遷移と故障記憶は#6の残件として残す。

再現（リポジトリルート、未作成の出力先）：

```sh
python3 software/sim/circuits/add_sequence_request_default.py --out /tmp/sequence-request-default
```

生成した2つのJSONを本ディレクトリと比較する。実接続の前後と数値の前提を
integration_report.jsonに記録した。回路シミュレーションの合格とは扱わない。

出典：[SN74HCS11 SCLS790B](https://www.ti.com/lit/ds/symlink/sn74hcs11.pdf)
pp.5、11、2026-09-21確認。
