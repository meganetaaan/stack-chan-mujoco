# 起動制御専用入力保護の接続候補

29部品の起動制御にTPS26600RHFRと周辺10部品を接続し、40部品の候補を作成した。旧BQ REG0枝から保護部分だけを転用し、旧エミッタフォロワー・ダイオード・直列抵抗は持ち込まない。正式システム回路は未置換で、製作承認ではない。

経路は `PACK_FUSED_REVERSE_PROTECTED → TPS26600 → CONTROL_INPUT_PROTECTED → TPS70933 → CTRL3V3`。入口は系統のヒューズ・逆接保護後を要求する境界で、主入口との統合はまだ行っていない。RTNをPACK_RETURNへ銅箔で直結しない。

## 部品仕様と設計仮定

[TI TPS2660 RevG §9.3.5](https://www.ti.com/lit/ds/symlink/tps2660.pdf)のMODE402 kΩにより、過負荷中は電流制限し、熱遮断に達した後ラッチ停止する構成。瞬時にラッチ遮断する回路ではない。入力がPOR以下に下がるかSHDN操作で復帰するため、PCM復帰後の手動再始動要件は別の制御ラッチに引き続き必要。

ILIM118 kΩからの公称式は約101.7 mA。これは実電圧・抵抗公差を含む保証上限/下限ではない。前回部分負荷11.041 mAとの差だけで適合としない。

UV分圧40.2 kΩ/10 kΩの公称上昇5.974 V、下降5.522 V、OV124 kΩ/10 kΩの公称上昇15.946 V。これらはRTN基準の公称式で、オフセット・公差未反映。制御電源を維持するための入力窓であり、3Sセルの過放電保護やTab5終了時刻を決める条件ではない。

SHDN、dVdT、FLT等は元候補同様に未接続。開放時立上りで今回の容量・負荷が起動できるかは未確認。手動復帰は現状では電源を外す操作が必要となる可能性があり、最終操作仕様には採用していない。

## 確認範囲と未確認

7つの接続検査で入口、LDOへの経路、GND/RTNの分離、MODE抵抗、自己給電ループがないこと等を確認。これはピン接続の検査で、短絡電流・熱・過渡のシミュレーション合格ではない。出典ハッシュ、実品番、全ピンをassembly.json/BOM/接続CSVに保存する。

優先して解く故障はTPS709のIN–OUT短絡。通常より高い電圧がCTRL3V3へ出ても入力電流が制限値以下なら、入力eFuseだけで低電圧ICを保護できない。出力側過電圧への対処を決めるまで、この保護枝を成立済みとしない。

次に、実効出力容量と負荷の上限を決め、起動の充電電流・時間と電流制限下限の整合を確認する。短絡時のエネルギーと熱遮断時間、入力過渡、上流ヒューズ、PCB放熱、無給電/復帰時の状態も残る。旧BQ負荷向けのシミュレーション結果は継承しない。#21〜24未完、製作HOLD。
