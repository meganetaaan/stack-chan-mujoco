# 左右サーボバスの常設放電候補

既存113部品の各モジュールENA接続を変更し、常設放電抵抗4個と起動禁止用抵抗4個を追加した。121部品・401接続項目。左右V+は接続せずGNDのみ共通とする。機能接続/BOM候補であり、製造ネットリスト・PCB・保護合格ではない。正式currentポインタは変更しない。

選定比較品は既存 `CRCW1206360RFKEA`。メーカー品番体系による候補で、在庫/調達確定ではない。[Vishay資料20035 Rev14-Apr-2026](https://www.vishay.com/docs/20035/dcrcwe3.pdf)では1206の定格0.25W、許容膜温度155°C。実基板の熱条件を満たして初めて定格が適用できる。初期±1%と100ppm/Kだけで長期抵抗範囲を保証しない。

## 要求と条件

0.92秒後0.5V以下は旧案の工学的仮基準でありユーザー指定でもトルク消失保証でもない。今回は基準を維持する。抵抗全変動±5%、各脚960µFは未確定の比較条件。実サーボ/基板/配線の合成容量を確認済みとしない。5.25Vに加え従来の異常上限6Vからの放電も計算したが、保護が実際に6V以下へ抑える証明は別に必要。

`V(t)=V0 exp(-t/(Req C))` の隔離RC計算。流入が一定Iなら `V(t)=V0 E+I Req(1-E)` として同じ期限を満たせる上限を求めた。回生を一定電流へ置き換えて保証したものではない。

|開始電圧|生存抵抗/脚|960µFで0.92秒後|流入ゼロ時の容量上限|同容量・同期限の一定流入上限|
|---|---:|---:|---:|---:|
|5.25V|2|0.0330V|2070µF|2.487mA|
|5.25V|1|0.4160V|1035µF|0.241mA|
|6V|2|0.0377V|1959µF|2.462mA|
|6V|1|0.4754V|979µF|0.0706mA|

両方断線では本経路による放電なし。片断線6Vケースの容量余裕は比較960µFから約19µFしかなく、未確定容量/流入のまま試作へ進めない。この抵抗を回生ブレーキに兼用したと扱わない。

## 電源・熱への追加負荷

±5%比較の抵抗最小342Ωでは、5.25Vで各脚30.702mA、全体0.3224Wを常時追加する。従来4.917A/脚はモータ比較値であり、新候補全体の電流ではない。モータと放電抵抗だけでも4.947702A/脚になり、さらに他回路消費が必要。

前回のeFuse+逆流FET比較11.4mΩには放電負荷だけで約0.3500mVを追加。3079片道50mmなら共通給電線分も含め約0.3782mV追加し、XC枝の残余は約3.5711mVへ減る。元の配線予算報告は旧候補の記録として保持し、新候補の評価へ流用しない。

6Vで各抵抗0.1053W。0.25Wを下回るだけで熱合格にしない。抵抗短絡時の保護、基板上の放熱/配置、両抵抗が共通断線で失われる経路も未設計。

## 次の判断と実機評価への引継ぎ

- 設計に残す：実装位置と熱、短絡保護、制御線からの逆給電、回生吸収、未選定ゲートRC。これらを実測Issueへ移して現在Issueを閉じない。
- 実機で必要：電源/サーボ/通信の全組合せでバス波形と流入、合成容量相当、抵抗温度。両正常と片断線の各条件を区別する。実機試験は本ゴールでは実施しない。
- 放電の合否は実測容量・抵抗上限・流入包絡から同じ基準へ照合する。比較計算の緑判定を回路全体の合格にしない。

## 予備充電中のモジュール起動禁止候補

PololuのENAはVINへ1MΩでプルアップされ、ENBもVINへ1MΩ、ENA–ENB間に10kΩがある。
従来のENA開放は初期ONとなる。各モジュールに2.21kΩのENA–GND抵抗を追加し、
各ALLOWから100Ω経由でENAを駆動する候補へ変更した。
制御配線断線時も抵抗が残るよう、プルダウンはモジュールENA_1の近くへ置く。
既存座標表ではENA_1=(26.67,2.54)mm。PFM/ENBは開放のまま。

100Ω=TNPW0603100RBEEA、2.21kΩ=TNPW06032K21BEEA。
LEFT/RIGHT_REGULATOR_ALLOWは未接続の制御ポートであり、完成した許可回路ではない。
信号の基準はこのサーボ回路のGND（上位ではPACK_RETURN）。BQのCELL_B_MINUSへ短絡しない。
電源喪失時はLow/高インピーダンス、初期化中はLow、電池設定・予備充電・主FET確認後に許可する。
ENAによる停止だけをサーボの独立遮断や逆流阻止の代わりにはしない。

内部2経路を含む公称DC計算でVIN=12.6V・ALLOW開放時ENA≈55mV。
ALLOW=3.3VならENA≈3.159V、ドライバー電流≈1.411mA/脚。
公称抵抗計算のみであり、公開ページにLowしきい値の数値保証がないためOFF成立を合格にしない。
無給電モジュールへの注入、電圧上昇中の挙動、抵抗公差、制御回路との適合も残る。
停止時の2モジュール合計約0.2504mAはメーカーの典型式による参考値であり上限ではない。

この変更はサーボ側のみ。Tab5と他の下流負荷の予備充電中禁止は未完成。
