# 停止電源専用の入力保護候補

BATTERY_RAW → 1 kΩ（TNPW12061K00BYEA）→ BAS116 → STOP_LDO_INPUT → TPS70933。入力コンデンサもSTOP_LDO_INPUTへ接続する。STOP_LDO_INPUTからGNDへ100 kΩ（TNPW0603100KBYEA）を置く。BAS116はSOT23、1番アノード・3番カソード・2番NC。包装を含む注文コードは未確定。

サーボ電流をこの抵抗へ流さない。電池端子から抵抗までの配線短絡、電池セル保護、主電源の逆接対策は別途必要。電池共通GNDを維持する。

事前比較条件：12.6 V最大、抵抗総合±1%、周囲85°C、Vishay一般モードのディレーティングを使用。保護後短絡時の上限12.73 mA、抵抗損失160.36 mWは比較上限196.36 mW以下。パターンで抵抗を迂回しない配置が前提。抵抗短絡故障までは保護していない。

比較低電池9 V（セル遮断閾値ではない）、ダイオード降下1 V、既存の条件付き負荷と放電抵抗負荷を用いるとLDO入力約6.39 V。ダイオードの温度・定常電流条件、LDOのGND電流・起動電流は未検証なので全条件動作の証明ではない。

逆方向漏れ80 nAと100 kΩの比較では負電圧の絶対値8.08 mV。これは定常漏れだけの値で、通電中の反転・容量結合・外部逆給電・LDO逆特性を含まない。逆接保護全体の合格に使わない。

```sh
python3 software/sim/circuits/add_stop_input_protection.py --out /tmp/stop-input-protection
```
