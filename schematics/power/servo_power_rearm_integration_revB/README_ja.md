# 停止監視用の独立3.3 V供給候補

revAの停止回路用EFUSE_INPUT_5Vを、別のTPS70933DBVRによるSTOP_AUX3V3へ置換。U9/U10/U11と周辺の9端子を移し、旧ネットを削除した。71部品・247端子。LOGIC3V3へは接続しない。

入力はサーボ変換器の出力ではなく、電池の逆接保護後の分岐。逆接・分岐保護自体はまだ未設計。従来のLOGIC3V3用補助電源とは別のLDOで、部品を同一個として数えない。

TI TPS709 SBVS186Hの推奨入力2.7〜30 Vに対し、3S満充電12.6 Vは範囲内。TPS3808へ12.6 Vを直接供給していた場合の定格超過を避ける接続案であり、LDO故障や入力過渡まで保護したという意味ではない。

TPS709（A/B付きではない）のDBV端子は1 IN、2 GND、3 EN、4 NC、5 OUT。ENはメーカー指定に従い開放し、電池へ接続しない。入力容量2.2 µF、出力4.7 µFは候補値で、出力有効容量2.2 µF以上を満たす実部品は未選定。

出典: https://www.ti.com/lit/ds/symlink/tps709.pdf （表5-1、6.3、7章）

残件:

- U9/U10/U11・抵抗・容量を含むDC/過渡負荷、LDOの発熱と基板熱条件。
- 5 Vから3.3 Vへ変わったU11→U10 MRの電圧条件と応答、出力のクランプ能力。
- STOP_AUX3V3とLOGIC3V3の投入・遮断順序、立上り途中の停止状態。無給電時の漏れだけで途中電圧の動作を仮定しない。
- 電池喪失とLDO自体の異常、変換器故障の他の信号経由、左右EN/UVLO駆動。

既存5 V回路の計算結果はこの構成の合格根拠に使わない。完成回路でも製造リリースでもない。

再現:

```sh
.venv-engineering/bin/python software/sim/circuits/add_stop_aux_supply.py --out /tmp/servo-power-rearm-revB
```

U11→U10 MRの静的出力条件は`validation/stop_aux_mr_levels_v1`で確認。指定電源区間でHigh/Low最小余裕0.8621 V、MR吸込み上限48.47 µA。入力論理・電源遷移・停止応答は対象外。
