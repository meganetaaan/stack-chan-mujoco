# LOGIC3V3入力保護の端子接続候補

製作不可・未統合。`branch.json` は TPS26601RHFR の24端子と放熱パッド、分圧抵抗・電流設定抵抗、必要なバイパスの接続先を記録する。主回路revMの置換ではない。

一次資料: https://www.ti.com/lit/gpn/tps2660 (SLVSDG2G, sections 6, 7.3, 9.3.5.5–7, 10.4)。端子表と照合し、24番号の重複・欠落なし、NC=1–7/11/16/21、IN=8/9、OUT=23/24を確認。RTN=15とEPは専用ネット、GND=17とは別である。RTNをGNDへ接続すると逆接保護が無効になる。PCBでも銅箔を共用しない。

SHDNは内部プルアップを利用する開放候補（資料Figure48、出力電圧仕様参照）。MODE開放でラッチ式遮断、未使用IMON/FLTも開放。dVdT開放は既定ランプを使う候補で、後段LDOの起動合格を意味しない。

初版で見つかった追加の制約: RILIM推奨範囲の上限は120kΩ。これまでの120kΩはデータシート評価点であり、正の抵抗公差を含む製造選定では上限を超える。発注前に公差・温度係数を含めて上限内となる抵抗を選び、電流しきい値を再評価する。120kΩの評価点に対する数値をそのまま別抵抗の保証値として使わない。

入力・出力バイパスは接続先のみで型番未定。入力側は逆接時の電圧にも対応する必要がある。電池セル保護、電源再投入時の放電、全系統の逆流、起動と異常時の動作は未成立。これらを後続実測だけに移して#24を完了扱いにはしない。

次の統合条件は、実抵抗・バイパスの選定、起動時電流の評価と放電経路の確定。条件が揃うまでKiCadや主回路の製作用BOMへ昇格しない。

## 抵抗選定の更新

RILIMを118kΩへ変更し、分圧4本も含む発注コード候補を `resistor_bom.csv` に記録。メーカー型番規則による候補で、在庫確認・購入はしていない。検算と温度条件の限界は `validation/logic_branch_resistors_v1/README_ja.md` を参照。旧120kΩのIC評価点を保証値として転用しない。その他の未成立事項は変わらない。

## バイパス候補の更新

初版で未選定だった入力・出力バイパスを各100nF C0G×2へ具体化。`capacitor_bom.csv` と `validation/logic_branch_bypass_v1` を参照。25〜125℃での容量検算のみ確認済みで、全温度・過渡・レイアウトは未検証。
