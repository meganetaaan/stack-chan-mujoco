# 起動待ち信号の受信回路を追加

revGへSN74AUP1T50DCKR、出力プルダウン220 kΩ、100 nFを追加。
93部品・306端子。候補の接続データであり、通電試作の承認ではない。

## 採用理由と評価範囲

前回比較した1G17の離散電源点の閾値を補間せず、3.0〜3.6 Vの範囲で
閾値が規定される受信部品を選んだ。既存の1G17は変更していない。
受信部の電源はLOGIC3V3、入力はSTOP_AUX側の起動待ち出力。
給電許可へ直結せず、後段の状態回路とのインターフェースを残す。

メーカー規定：入力High閾値上限1.19 V、Low閾値下限0.5 V、
受信電源3.0〜3.6 V、周囲温度−40〜85℃。
これは選定部品の制約であり、ユーザー要求やシステム温度基準の変更ではない。
85℃超で使う場合には本候補を採用できない。

既存の条件付き電源下限と抵抗総合±1%を用いた比較では、
入力High下限3.1262 V、Low上限0.4 V。各閾値との余裕は1.9362 V、0.1 V。
出力抵抗負荷は上限16.53 µA、20 µA出力規定まで残る負荷は3.47 µA。
後段入力を追加する際はこの残余を再評価する。

電源0 Vでの漏れだけを考えた出力上限は0.1111 V。
これを中間電圧でのLow保証や後段込みの禁止保証に拡張しない。
入力容量は代表値なので、起動タイマーの負荷・遅延の保証も残る。

## 残件と終了条件

- 実際のLOGIC3V3と受信部温度が規定内に収まる根拠を示す。
- 後段入力を接続し、負荷と部分給電時動作を含めて判定する。
- タイマー負荷、短い電圧低下後の再判定、状態回路による起動禁止を閉じる。

これらは#6の設計残件。実測Issueへ移して設計完了にはしない。
今回の数値は定常インターフェース比較であり、過渡シミュレーションではない。

## 再現

リポジトリルートから未作成の出力先を指定し、両JSONを比較する。

```sh
python3 software/sim/circuits/add_monitor_ready_receiver.py --out /tmp/monitor-ready-receiver
```
