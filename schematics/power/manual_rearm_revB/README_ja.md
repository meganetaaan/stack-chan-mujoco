# 手動復帰回路 統合候補 revB

現在の接続候補は19部品・78端子。revAに独立した電源監視U7、CT抵抗R3、RESETプルアップR4、デカップリングC7を追加した。電気的適合・製造リリースはいずれも未承認。

## 追加した回路

U7 TPS3808G33DBVRはラッチ位置のLOGIC3V3を監視。RESET出力を両DFFのCLRと解除ANDの健全入力へ接続する。CTは100k経由でVDD、MRはVDDへ接続。MRを自分のRESET線へ戻して自己保持させない。解除タイマーU5とU7は別部品で、ボタン押下はU5のみをリセットする。

RESET_Nへ停止・故障のオープンドレイン出力を接続する境界を設ける。押下整形や解除タイマーを経由せずCLRをLowにできる。ただし停止・故障・監視無効を検知する実出力回路は未完成で、単に線が予約されたことを保護成立と扱わない。RESET_Nへプッシュプル出力を並列接続しない。

## メーカー条件と残件

下降しきい値は3.02395〜3.11605 V、解除側の保守上限3.19395125 V。想定電源下限3.207 Vとの差約13 mVは小さく、過渡余裕は未確認。電源健全後の解除遅延は180〜420 msの候補だが、これは停止を遅延させる設定ではない。

RESETの電源投入時保証は電圧・負荷・電源傾斜条件に依存する。0 Vから常にLowが保証されると仮定しない。100kプルアップの実公差、DFF2入力とAND1入力および外部故障出力の合計漏れ・容量、電源降下速度を照合する必要がある。主電源の既定OFF段は別の未設計項目として維持する。

この追加は電源監視のピン接続を具体化するもの。全体の故障時安全性、起動波形、独立停止の実部品適合、後続#49の実測を完了したとは扱わない。

## 再現

`python3 software/sim/circuits/package_manual_rearm_candidate.py --supervisor --out <未作成ディレクトリ>`。接続表と入力仕様SHA256を生成する。revAは旧候補として保存する。生信号処理、出力段、受動部品実型番は未確定。

[TI TPS3808 SBVS050N](https://www.ti.com/lit/ds/symlink/tps3808.pdf)、2026-09-21確認。

## 共通クリア線の負荷予算

`validation/manual_rearm_reset_fanout_v1/`に漏れ電流の端点比較を追加。外部故障出力のOff漏れ5 µAではHigh比較値が約2.37 Vとなる。任意の出力追加は不可。0.8 V起動条件ではプルアップ以外の電流予算は6.92 µAだが、定格外のHCS入力電流を通常規定で代用できず、起動適合は未確認。
