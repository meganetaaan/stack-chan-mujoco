# Pololu電源2個を接続した保護回路候補

## 決定した接続

各脚のD42V110F5のVOUTを、それぞれ既存TPS259813Lの入力へ接続する。左右出力は並列にせず、サーボバスへ直結しない。VINは別途成立させる保護・遮断後の3S駆動電源 `DRIVE_BATTERY_PROTECTED`、GNDは共通。Tab5用電源には接続しない。

ENA・ENB・PFM・PGを未接続とする。メーカーの標準状態でレギュレータは起動し、PFMで動作する。ENA/ENBは入力電圧へ引き上げられる端子なので、既存の3.3V信号へつながない。ENBは標準PFMで使用しない。PGはeFuse由来の監視信号とは別物で、既存シーケンサー入力へ置き換えない。

一次資料: https://www.pololu.com/product/5671 のConnections節。端子ごとのメーカー仕様と設計判断は `schematics/power/dual_pololu_interface.json` に分離した。

## 電源投入・停止の意味

| 状態・操作 | この接続案での扱い | 未確認事項 |
|---|---|---|
| 駆動電池の投入 | レギュレータは自動起動。サーボ給電許可は後段eFuseで別に制御 | 部分給電・立上り全域でeFuseが既定OFFとなること、突入電流 |
| 手動再アーム | 既存許可回路・監視・シーケンサーを通じてeFuseを有効化する設計 | 実入力の有効化タイミング、リセット、負荷下立上り |
| STOP・異常 | 後段eFuseを遮断して許可を保持解除する設計。レギュレータ自体は通常ONのまま | 遮断応答、単一異常条件、残留電圧/回生エネルギー |
| 電池の完全切離し | 別途上流の切離し手段が必要 | スイッチ・ヒューズ・電池保護・逆流経路 |

「レギュレータが起動している」と「サーボへ給電してよい」を分ける設計である。eFuse OFFだけで端子電圧が即座にゼロになるとは扱わない。メーカー内蔵保護やPFMモードを回生吸収・異常時安全遮断の証明にしない。

## 成果物と確認範囲

元の111部品と全接続を保持し、2モジュールを追加した113部品の論理接続候補。385接続項目のうち14はモジュールの**機能ポート**で、物理端子番号・重複GND穴・パッド配置を表さない。基板製造用ネットリストやフットプリントには使用できない。

生成時に既存111部品が無変更、参照名が一意、左右が自分のeFuse入力に接続されること、出力並列/サーボ直結がないこと、任意ポートが明示NCであることを確認した。これは接続構造の確認で、eFuse/レギュレータの電気的挙動、ERC、立上り、異常保護、配線、熱の合格ではない。

品番欄が空の10部品は引き続き未選定。非空の欄にも値候補などが含まれるため、「残り10個だけ選べば製作できる」という意味ではない。上流電源保護と分配も未統合。物理端子対応・配線/端子台・外部FET駆動RC・電流/過電圧設定・回生/放電と統合過渡が残る。正式currentポインタ、既存KiCadレビュー図、ファームウェアは更新していない。
