# 統合保護ICと外付け逆流阻止FETの接続候補

TPS25981資料図7-8を画像で確認し、左右各4部品の接続を保存。
外付けN-FETはSをeFuse OUT、Dをサーボバス、GをDVDTから抵抗経由で接続。
図に従いゲート容量はゲートとGND間。抵抗・容量値は未選定。
SiSS80DNは既存比較品を仮に対応させただけで、駆動適合は未確認。

重要な回路判断：内蔵QODはeFuse OUT側なので、逆流阻止FETがOFFならサーボバスを放電できない。
回生吸収器と受動放電抵抗は外付けFETよりサーボ側へ接続する。
QODを実機の停止時放電や回生処理の代わりとして数えない。

PG図のVOUT+2.8V表記だけから最低VGSを保証しない。DVDTの駆動上下限、
ゲート電荷、ゲート抵抗／容量、遮断中の負VGS、熱・SOAが未確認。
特にゲートをLowへ引いた瞬間のソース電圧をゼロと仮定しない。
分圧・電流設定・入出力容量・論理接続は未収録。完全回路や製造BOMではない。
