# 左右変換器出力の独立電圧窓候補

各脚へTPS3700DDCRを1個使用。INA+で低電圧、INB−で過電圧を監視し、2つのオープンドレイン出力を結合する。電源はSTOP_AUX3V3。左右の監視出力は結合しない。計14部品の局所接続候補で、主回路と状態回路への統合は未完了。

設計目標は通常比較範囲4.75〜5.25 Vを誤って異常扱いせず、異常後もこの範囲で電圧監視を正常へ戻せること。復帰が給電の自動再始動を許可するわけではない。手動再始動と状態回路は別途必要。

UV分圧102 kΩ/10 kΩ、OV分圧130 kΩ/10 kΩ、抵抗総合±1%を比較。TPS3700のしきい値範囲と入力漏れの公表値を適用した結果はreport.json。127 kΩの旧OV案は復帰下限が5.25 Vを下回るため不採用とし、失敗をrevAに残した。

- 低電圧の解除最大4.611 Vで、正常下限4.75 V未満。
- 過電圧の解除最小は5.25 Vを上回り、正常上限へ戻った場合に解除可能。
- 3S貫通故障12.6 Vでも、分圧後の入力は推奨入力最大6.5 Vを下回る。

しきい値はCodexの設計候補で、ユーザー指定値ではない。監視点は変換器出力であり、配線降下後のサーボ端子電圧は未保証。異常検出から停止までの遅延・過渡上昇を含む6 V上限の保護証明ではない。

入力漏れの試験点はINA+が6.5 V、INB−が0.1 Vであり、実用範囲への適用は確認事項。出力は電源1.8 V超から最大450 µsまで未確定で、起動時の禁止が必要。状態回路の信号として直接合格扱いにしない。抵抗・コンデンサ実品、出力受信、監視断線・固着、温度・遅延は未確定。

一次資料: https://www.ti.com/lit/ds/symlink/tps3700.pdf （SBVS187G、端子表・6.5）。

再現:

```sh
.venv-engineering/bin/python software/sim/circuits/build_source_window_monitors.py --ov-top-ohm 130000 --out /tmp/source-window-revB
```
