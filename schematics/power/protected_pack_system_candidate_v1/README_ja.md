# 保護内蔵電池を使う全系統の接続候補

**未動作・製作HOLD。** 旧250部品から生セル保護/ローカル制御100部品と境界絶縁3部品を除き、41部品のパック制御枝と主起動許可インターフェース3部品を統合した。回路参照数191、外部電池LB-020は別項目。部品数は確定購入点数ではない。

## 意図した電力経路

LB-020出力→ロボット側ヒューズ→逆接保護→共通分配。負極はPACK_RETURNへ統一し、旧シャント/生セル基準を持ち込まない。制御枝、ロジック、Tab5と既存左右駆動系は同じ逆接保護後バスを参照する。

これは明示した構成変更で、旧BQ主遮断FETの機能が自動的にPCMへ移ったとは扱わない。駆動停止は分岐側へ割り当てる候補で、全電池遮断ではない。停止後の待機消費、全枝の故障エネルギー、PCM/ヒューズの協調・回生・復帰条件の成立は未確認。セルタップをロボットへ引き出さず、充電はパックを外して指定充電器を使う方針。

## 信号境界

MAIN_START_ALLOW→受信側給電バッファ→既存SEQUENCE_ENABLE_REQUESTを接続。既存AND入力の手動許可とRESETは保持した。ただし電圧遷移・全公差の論理余裕は未確認。

LOGIC_START_ALLOWとSYS__LOGIC_START_ALLOWは接続適合未確認のため別ネットに残す。加えてTab5許可、UV警告、左右レギュレーター許可、シーケンスクリアが未設計/未駆動の境界として残る。7ネットの全ピンをassembly.jsonに列挙し、「同じ名前にして接続完成」としない。人の新しい起動操作やTab5終了連携も未実装。

## 検査と限界

重複なし191参照、旧CELL/BQネットの不存在、入口と共通負極、保護後給電、主許可の接続と独立停止入力維持を確認した。導通/漏れ/論理タイミング/短絡/温度のシミュレーションではない。旧未選定12参照と値だけの仮置き部品も引き継ぐ。
