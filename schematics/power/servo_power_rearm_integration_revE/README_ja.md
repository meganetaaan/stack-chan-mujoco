# EN断線時の局所プルダウン

共通ENのR5=39 kΩを削除し、左右それぞれのTPS259813Lの1番端子直近へ78.7 kΩを配置する。通常時は並列39.35 kΩとなり、既存の信号負荷をほぼ保つ。73部品・251端子。配線はMAIN_EFUSE_EN→左右EN_LOCALの明示的なPCB配線として記録した。

規定EN漏れ0.1 µA、抵抗総合±1%の条件で、分岐配線が開放された側の定常入力は最大7.9487 mV。プルダウンがIC側に残る配置が必要で、回路図上で同じネットというだけではこの断線条件を満たさない。

通常時の16コーナー計算ではHigh下限2.767407 V、バッファ出力電流上限75.958 µA。1.224 Vの有効化しきい値と100 µAの出力規定に対して余裕がある。既存の停止クランプは保持する。

## 限界

- 断線後の容量放電時間は未評価。定常電圧が低いことは、要求時間内に停止する証明ではない。
- ICの電源が有効な条件の漏れ仕様を用いる。途中電圧や外部からの寄生電流は未評価。
- ICピンと抵抗の間の切断、抵抗の断線、GND断線、ENが電源へ短絡する故障は保護できた扱いにしない。
- 片側EN断線後、他方も停止させるPG監視と状態回路は未完成。
- 抵抗型番はstop_enable_resistors.jsonの候補を適用。温度・経年込み総合公差と実レイアウトは未確定。

旧R5を含むrevJの抵抗セットをそのまま発注しない。この統合候補ではR5を2個の局所抵抗で置換する。製造リリースではない。
