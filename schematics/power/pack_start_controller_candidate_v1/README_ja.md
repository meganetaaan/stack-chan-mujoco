# 保護済み電池用の起動制御サブ回路候補

前回の移行調査で失われると判明した起動制御を、29部品の実品番・ピン接続として切り出した。セル電圧監視/主保護FETを含む旧BAT領域をそのまま保護済みパックへ追加しない。完成した電源回路ではなく、正式システム回路/BOMは未置換。

## 構成

- STM32G030F6P6、TPS3808G01DBVR、TPS3431SDRBR、リセットバッファ、SN74LVC1G74許可ラッチ、2個のANDゲートと周辺部品25個を既存案から継承。
- TPS70933DBVRと入出力コンデンサを独立制御電源に追加。STOP_AUXへMCU負荷を追加しない。
- 低電圧警告入力のプルアップ1個を追加。旧BQ用I2C端子2本は未接続とし、セル監視機能を残したように見せない。
- GNDはパック保護済み出力負極のPACK_RETURNへ統一。旧CELL_B_MINUS/BQ_CTRL3V3を持ち込まない。

`assembly.json`、`connections.csv`、`bom.csv`がこのサブ回路の接続/BOM候補。元回路のハッシュと移植元参照を保持する。

## 確認した範囲

7項目の接続検査：旧セル基準の残存なし、専用制御電源、ウォッチドッグのリセット接続、リセットからラッチクリアへの経路、補助/主許可それぞれのラッチ入力、LDOのENをパックへ直結していないこと。部品の動作タイミング・全異常時の安全性を証明する検査ではない。継承した回路の以前の未確認事項も引き継ぐ。

[TI TPS709 Rev.H](https://www.ti.com/lit/ds/symlink/tps709.pdf)の表5-1/§7.4でTPS709のDBVピン配置とEN開放で有効になる仕様を再確認。ENはパック電圧へ接続しない。推奨入力範囲2.7〜30 Vは3S公称範囲を含むが、過渡・熱・出力電流適合は別途必要。使用コンデンサの実効容量の未確認状態をそのまま保持する。

## 未完の接続・機能

1. CONTROL_INPUT_PROTECTEDは独立枝の境界で、入力保護回路は未実装。入力電流・熱・短絡時の成立を確認してから既存入力へ接続する。
2. PACK_UV_WARN_Nの検出器/閾値は未選定。断線でHighになるため、これだけを独立安全遮断とは扱わない。
3. 実操作から新しい起動要求を取り込む入力、Tab5の起動/終了確認の接続が未実装。ラッチのクロックはMCU出力であり、現在の回路が新しい人の操作を保証するわけではない。
4. LOGIC_START_ALLOWの出力レベル・無給電/部分給電時挙動を確認する。MAIN_START_ALLOWは既存独立停止/再始動条件とのANDに接続する必要があり、旧BQ主FETへの出力をそのまま転用しない。
5. 電池瞬断・PCM復帰でのクリアと、手動再始動・監視タイミングの統合が未完。ファームウェア未実装を回路検査で補ったことにしない。

この候補の目的は起動機能の実部品配置を具体化すること。次は上記境界を閉じるために入力保護・消費電流と制御信号を確定する。PCM未知値を仮定した波形掃引を追加しない。#21〜24未完、製作HOLD。
