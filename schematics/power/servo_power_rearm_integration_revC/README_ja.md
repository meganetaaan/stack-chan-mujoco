# 停止補助電源の最低負荷を明示した構成

revBへR_STOP_MIN_LOAD=30.1 kΩを追加。72部品・249端子。TPS709の負荷変動規定は100 µA〜150 mAの試験範囲で、停止監視ICの無負荷時消費に最小値がないため、既存の小負荷回路だけでは下限を保証できない。

既存の設計電圧区間3.207〜3.393 V、抵抗総合±1%の条件で、抵抗だけで105.49〜113.86 µAを消費する。抵抗損失上限0.3864 mW。これに各IC・MRプルアップ・CT経路・過渡負荷を加える。部品の温度込み公差と型番は未選定。

3.207〜3.393 Vは3.3 Vに対しDC精度±1%、ライン変動10 mV、負荷変動50 mVを加算した既存の条件付き比較区間。TI仕様の入力・温度・負荷・容量条件への適合が必要で、抵抗追加だけでLDOの出力を保証したことにはしない。起動中はこの定常区間の評価外。

出典: https://www.ti.com/lit/ds/symlink/tps709.pdf （SBVS186H、6.5）

電流集計ではU11がU10のMRプルアップをLowへ引く約48.47 µAをSTOP_AUX3V3へ計上する。一方、R9とU7 MRからU9 RESETへ流れる電流はLOGIC3V3由来であり、STOP_AUX3V3へ二重計上しない。U9出力の吸込み能力には計上が必要。入力が中間電位のU11消費電流を理想ゼロと仮定しない。

総消費・過渡電流・LDO発熱・停止順序・EN駆動は未確認。停止用LDO自体の異常を含む保護合格ではない。

再現:

```sh
.venv-engineering/bin/python software/sim/circuits/add_stop_minimum_load.py --out /tmp/servo-power-rearm-revC
```
