# PTH電源モジュールの入力コンデンサー候補

入力側を**Panasonic EEUFR1C471、各モジュール1個、計2個**の詳細設計候補とする。470 µF±20%の初期最小376 µFは必要220 µF以上。16 V定格、100 kHzリップル定格950 mArms、外形φ8×11.5 mm、端子間隔3.5 mm。一次資料は[Panasonic仕様](https://industrial.panasonic.com/ww/products/pt/aluminum-cap-lead/models/EEUFR1C471)。未購入・未統合であり、量産BOMや通電許可ではない。

前回のPTH比較に記録した入力リップル条件500 mAを**700 mArms**へ修正した。[TI資料](https://www.ti.com/lit/gpn/pth08t240w)の表脚注より、5 Vで適用されるp13の条件が厳しいため。温度・周波数係数、寿命、実リップルは別途必要で、定格差250 mAを実波形の余裕とは呼ばない。入力源が悪い場合の推奨容量増加、セラミック併用、投入エネルギーも未評価。

出力側は単体コンデンサーの選定より先に、**接続された全容量の合成ESR**を確認する。PTH08T240WのTurboTransなし条件は、5 Vで必要容量330 µF以上、全出力バンクのESR最低7 mΩ。下流の保護ICがONのときはサーボ内コンデンサー等も影響する。カタログの「ESR最大8 mΩ」などを最低7 mΩ以上の証拠には使えない。局所容量の直列抵抗だけでも並列経路の影響は消えない。

この条件が定義できなければセラミック向けPTH08T241W等を比較する。現時点でPTH系を全機採用確定にはしない。容量・抵抗の仮定を反復する解析は行わず、全バンク条件か対応品の選定根拠を次の終了条件とする。製作HOLD。

再現: `python3 software/sim/circuits/select_pth_input_cap.py`。値・根拠・適用限界はselection.json。
